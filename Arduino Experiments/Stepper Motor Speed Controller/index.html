Stepper Motor Speed Controller

← Arduino Experiments Aim Components Connections Working Procedure Code Result

Aim

To control motor speed using a potentiometer and monitor encoder pulse activity with Arduino UNO and a ULN2003 motor driver.

About the Experiment

Arduino reads the potentiometer through analog pin A0 and maps the 0–1023 reading to a 0–255 PWM command. This PWM signal is sent on D5 to the ULN2003 driver, which controls the motor speed.

The motor encoder provides pulse feedback through channels A and B. Arduino counts the encoder pulses and reports the total pulse count and pulses per second through the Serial Monitor.

Procedure

  1. Connect one outer pin of the potentiometer to 5V.
  2. Connect the middle pin of the potentiometer to A0.
  3. Connect the other outer pin of the potentiometer to GND.
  4. Connect Motor Pin 1 to the 5V motor supply.
  5. Connect Motor Pin 6 to ULN2003 OUT1.
  6. Connect ULN2003 IN1 to Arduino D5.
  7. Connect ULN2003 GND to Arduino GND.
  8. Connect encoder Channel A to D2.
  9. Connect encoder Channel B to D3.
  10. Connect encoder power to 5V and encoder ground to GND.
  11. Connect Arduino UNO to the computer.
  12. Open Arduino IDE.
  13. Enter the program given below.
  14. Select Arduino UNO and the correct COM port.
  15. Verify and upload the program.
  16. Open Serial Monitor at 9600 baud.
  17. Rotate the potentiometer and observe PWM and encoder pulse readings.

Arduino Code

Stepper_Motor_Speed_Controller.ino 
/*
  DC MOTOR SPEED CONTROLLER WITH ENCODER

  Arduino UNO
  DC Motor with Encoder
  ULN2003 Driver
  Potentiometer

  MOTOR PIN ARRANGEMENT:

  Pin 1 = Motor Positive
  Pin 2 = Encoder Channel B
  Pin 3 = Encoder Power
  Pin 4 = Encoder GND
  Pin 5 = Encoder Channel A
  Pin 6 = Motor Negative
*/

#define POT_PIN A0

#define MOTOR_PWM_PIN 5

#define ENCODER_A_PIN 2
#define ENCODER_B_PIN 3

volatile long encoderPulses = 0;
int encoderDirection = 1;

int potValue = 0;
int motorPWM = 0;

unsigned long previousTime = 0;
long previousPulses = 0;

void encoderISR() {

  int channelB = digitalRead(ENCODER_B_PIN);

  if (channelB == HIGH) {
    encoderPulses++;
    encoderDirection = 1;
  }
  else {
    encoderPulses++;
    encoderDirection = 1;
  }
}

void setup() {

  Serial.begin(9600);

  pinMode(MOTOR_PWM_PIN, OUTPUT);

  pinMode(ENCODER_A_PIN, INPUT_PULLUP);
  pinMode(ENCODER_B_PIN, INPUT_PULLUP);

  attachInterrupt(
    digitalPinToInterrupt(ENCODER_A_PIN),
    encoderISR,
    RISING
  );

  analogWrite(MOTOR_PWM_PIN, 0);

  Serial.println("DC Motor Speed Controller");
  Serial.println("Encoder Pulse Monitoring");
  Serial.println("--------------------------------");
}

void loop() {

  potValue = analogRead(POT_PIN);

  motorPWM = map(
    potValue,
    0,
    1023,
    0,
    255
  );

  analogWrite(MOTOR_PWM_PIN, motorPWM);

  if (millis() - previousTime >= 1000) {

    previousTime = millis();

    noInterrupts();
    long currentPulses = encoderPulses;
    interrupts();

    long pulsesPerSecond =
      currentPulses - previousPulses;

    previousPulses = currentPulses;

    Serial.print("Potentiometer: ");
    Serial.print(potValue);

    Serial.print(" | PWM: ");
    Serial.print(motorPWM);

    Serial.print(" | Total Pulses: ");
    Serial.print(currentPulses);

    Serial.print(" | Pulses/Second: ");
    Serial.println(pulsesPerSecond);

    Serial.println("--------------------------------");
  }

  delay(10);
}

Expected Output

Turning the potentiometer changes the PWM command from 0 to 255 and therefore changes the motor speed. Encoder pulses are counted continuously and reported on the Serial Monitor.

Potentiometer Minimum: PWM near 0
Potentiometer Maximum: PWM near 255
Serial Monitor: Potentiometer, PWM, Total Pulses, Pulses/Second

Result

The Stepper Motor Speed Controller experiment was implemented using Arduino UNO, a potentiometer, ULN2003 driver and a motor with encoder feedback. Motor speed changes according to the potentiometer position and encoder pulses are monitored through the Serial Monitor.
