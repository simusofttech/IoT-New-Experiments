Aim

To control the speed of a DC motor using a potentiometer, Arduino UNO R3 and a ULN2003 motor driver, while monitoring the motor's encoder pulse activity.

The experiment demonstrates analog input reading, PWM speed control, encoder interrupt handling and serial monitoring of total pulses and pulses per second.

About the Experiment

The Stepper Motor Speed Controller experiment uses the supplied DC motor speed-control sketch to demonstrate motor speed adjustment and encoder monitoring.

A potentiometer is connected to Arduino analog input A0. Turning its shaft changes the voltage on the middle terminal.

Arduino reads this voltage using analogRead() and obtains a value between 0 and 1023.

The map() function converts the potentiometer reading into a PWM command between 0 and 255.

Arduino generates PWM on digital pin D5 using analogWrite().

This signal is sent to the ULN2003 driver's IN1. The driver switches the motor current according to the applied control signal.

The motor used by the original program is a DC motor with an encoder. Encoder Channel A is connected to Arduino D2, while Channel B is connected to D3.

An interrupt is attached to the rising edge of Encoder Channel A. Every detected rising edge increases the encoderPulses counter.

Arduino calculates how many pulses were counted during approximately one second and displays this information on Serial Monitor.

The displayed values include the potentiometer reading, PWM command, total encoder pulses and pulses per second.

Important Clarification:

The experiment title is Stepper Motor Speed Controller, but the supplied sketch specifically describes DC Motor Speed Controller with Encoder.

The source does not produce a multi-phase stepping sequence and should not be used as conventional stepper-motor control software.

The encoder ISR increments the counter regardless of Channel B. Therefore, rotation direction is not genuinely calculated by this version of the sketch.

The measured pulses per second indicate encoder activity. They are not directly an RPM value without knowing the encoder resolution.

Motor Pinout:

The motor connector numbering shown above comes from the supplied sketch.

Verify the actual six-pin motor connector before applying power. Motor and encoder pin order is not universal across manufacturers.

A typical ULN2003 switching channel provides low-side current control rather than motor polarity reversal.

Ensure the motor's running and stall currents remain within the ULN2003 channel's ratings.

If the driver is a 28BYJ-48 stepper breakout, inspect whether its terminals actually support connection of this DC motor.

Motor supply ground, driver ground and Arduino ground must be common.

Potentiometer Input

The potentiometer acts as a voltage divider. Turning its shaft changes the voltage supplied to analog input A0.

Arduino converts that voltage to a digital value between 0 and 1023.

PWM Conversion

The program uses map() to convert the potentiometer reading to a PWM output level.

Mapping:

Potentiometer: 0–1023

PWM Command: 0–255

Arduino uses analogWrite() to generate the PWM signal on D5.

Motor Speed Control

D5 carries the PWM signal to ULN2003 IN1.

The driver switches the motor current according to the PWM command.

A larger PWM value generally produces a greater average motor drive, although actual speed depends on the motor and load.

Encoder Pulse Detection

Encoder Channel A is connected to Arduino interrupt-capable pin D2.

Every rising edge on this channel calls encoderISR().

The function increments encoderPulses by one.

Channel B is read inside the ISR, but the original code performs the same increment in both conditions.

Interrupt-Based Counting

Encoder pulses can arrive between regular loop executions.

attachInterrupt() allows Arduino to respond to the rising edge without waiting for the main loop to perform another read.

Pulses Per Second

The program stores the previous pulse total and subtracts it from the newly captured total.

Formula:

Pulses/Second = Current Total Pulses − Previous Total Pulses

This difference is calculated at approximately one-second reporting intervals.

Safe Counter Reading

The encoderPulses variable is updated by an interrupt.

The program temporarily disables interrupts using noInterrupts() while copying the counter to a local variable.

interrupts() then restores interrupt processing.

Serial Monitor Output

The system reports four values:

  • Potentiometer reading
  • PWM command
  • Total encoder pulses
  • Pulses counted during the previous reporting interval
0–1023 Analog input range
0–255 PWM command range
9600 Serial baud rate
1 second Encoder reporting interval
Measurement Limitation:

The sketch measures pulse counts rather than calculated shaft RPM.

To calculate actual RPM, the encoder pulses per revolution, gearing and counting method must be known.

The sketch also does not automatically adjust PWM to maintain a target RPM. It is an open-loop speed command with pulse monitoring.

Procedure

  1. Arrange Arduino UNO, potentiometer, DC motor with encoder, ULN2003 driver, breadboard and jumper wires.
  2. Verify that the motor and ULN2003 channel are electrically compatible.
  3. Connect one outer potentiometer terminal to 5V.
  4. Connect the middle potentiometer terminal to Arduino A0.
  5. Connect the remaining outer potentiometer terminal to GND.
  6. Connect Arduino D5 to the ULN2003 IN1 signal.
  7. Connect the motor's positive terminal to its rated positive supply.
  8. Connect the motor's negative terminal to ULN2003 OUT1.
  9. Connect the ULN2003 ground to Arduino GND.
  10. Connect the motor supply ground to the common ground.
  11. Connect COM to the positive motor supply where the ULN2003 hardware requires it.
  12. Verify the actual motor encoder connector pin numbering.
  13. Connect Encoder Channel A to Arduino D2.
  14. Connect Encoder Channel B to Arduino D3.
  15. Connect encoder power and ground according to its voltage specification.
  16. Check every electrical connection before applying power.
  17. Open Arduino IDE.
  18. Create a sketch named Stepper_Motor_Speed_Controller.ino.
  19. Copy the original Arduino program from Explore the Code.
  20. Select Arduino Uno and the correct communication port.
  21. Verify and upload the program.
  22. Open Serial Monitor at 9600 baud.
  23. Turn the potentiometer near its minimum position.
  24. Observe the printed analog value and PWM command.
  25. Slowly rotate the potentiometer toward its maximum position.
  26. Observe the changes in motor behavior.
  27. Watch the total encoder pulses increase if the motor is rotating and encoder signals are valid.
  28. Observe the pulses-per-second value printed approximately once every second.
  29. Compare pulse activity at low and high PWM settings.
  30. Return the potentiometer to minimum PWM and observe the motor response.
  31. Record several potentiometer, PWM and pulse readings for comparison.

Explore more: PWM

Pulse Width Modulation rapidly switches a digital output between HIGH and LOW.

The fraction of time spent HIGH is the duty cycle.

The Arduino sketch represents the PWM level using numbers from 0 to 255.

Explore more: Motor Encoder

An encoder produces electrical pulses as its shaft rotates.

The sketch counts rising edges on Encoder Channel A.

Channel B is read, but it is not used correctly to calculate direction in this original source.

Explore more: Interrupts

An interrupt allows Arduino to execute a short function in response to an event.

attachInterrupt() registers encoderISR() as the handler for rising edges on D2.

Using interrupts helps count pulses without repeatedly polling the encoder in loop().

Explore more: volatile

The encoderPulses variable is declared volatile because an interrupt handler modifies it.

The main loop temporarily disables interrupts while copying this multi-byte value.

Explore more: Pulse Rate and RPM

The program calculates pulses per reporting interval.

To convert pulse rate to RPM, the effective encoder counts per shaft revolution must be known.

The original sketch does not perform this conversion.

Output Limitations:

Result

The Stepper Motor Speed Controller experiment demonstrates potentiometer-controlled PWM driving of a DC motor through a ULN2003 driver.

Arduino reads the potentiometer on A0, converts the analog value to a PWM command and sends the command through D5.

Encoder Channel A provides rising-edge pulse events that Arduino counts using an interrupt routine.

The Serial Monitor displays potentiometer readings, PWM commands, total encoder pulses and pulse counts between reporting intervals.

The experiment demonstrates analog input processing, PWM output control, interrupt-based counting and motor activity monitoring.

The supplied code is not a complete stepper-motor controller and does not implement RPM regulation or actual direction decoding.
