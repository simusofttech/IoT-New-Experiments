Adjustable LED Dimmer

← Arduino Experiments AimComponentsConnectionsWorkingProcedureCodeResult

Aim

To control the brightness of an LED using a 10K potentiometer and Arduino UNO.

About the Experiment

Arduino reads the potentiometer value through analog pin A0. The analog value from 0 to 1023 is converted into a PWM brightness value from 0 to 255.

The PWM signal is sent to the LED through D9. Rotating the potentiometer changes the LED brightness from very dim or OFF to maximum brightness.

Procedure

  1. Connect the left pin of the potentiometer to Arduino 5V.
  2. Connect the middle pin of the potentiometer to Arduino A0.
  3. Connect the right pin of the potentiometer to Arduino GND.
  4. Connect the LED anode to Arduino D9 through a 220Ω resistor.
  5. Connect the LED cathode to GND.
  6. Connect Arduino UNO to the computer using the USB A-B cable.
  7. Open Arduino IDE.
  8. Enter the program given below.
  9. Select Arduino UNO and the correct COM port.
  10. Verify and upload the program.
  11. Open Serial Monitor at 9600 baud.
  12. Rotate the potentiometer and observe the LED brightness.

Arduino Code

Adjustable_LED_Dimmer.ino
#define POT_PIN A0
#define LED_PIN 9

void setup()
{
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
}

void loop()
{
  int potValue = analogRead(POT_PIN);

  int brightness = map(potValue, 0, 1023, 0, 255);

  analogWrite(LED_PIN, brightness);

  Serial.print("Potentiometer: ");
  Serial.print(potValue);

  Serial.print(" Brightness: ");
  Serial.println(brightness);

  delay(20);
}

Expected Output

Rotating the potentiometer changes the brightness of the LED. The potentiometer value and calculated brightness value are displayed on the Serial Monitor.

Potentiometer Minimum: LED OFF or very dim
Potentiometer Maximum: LED at maximum brightness
Serial Monitor: Potentiometer value and brightness value

Result

The Adjustable LED Dimmer experiment was implemented using Arduino UNO, a 10K potentiometer, an LED and a 220Ω resistor. The LED brightness changes according to the potentiometer position.
