Aim

To control the brightness of an LED using a 10kΩ potentiometer and Arduino UNO through Pulse Width Modulation (PWM).

About the Experiment

The Adjustable LED Dimmer experiment demonstrates how the Arduino UNO controls LED brightness using an analog input and PWM output.

A 10kΩ potentiometer is connected to analog pin A0.

When the potentiometer is rotated, its output voltage changes. The Arduino converts this voltage into a digital value ranging from 0 to 1023.

The Arduino maps the analog value to a PWM brightness value from 0 to 255.

This PWM signal is sent to the LED through digital pin D9.

Rotating the potentiometer changes the LED brightness gradually from OFF to maximum brightness.

Key Concept: PWM controls LED brightness by rapidly switching the output ON and OFF at different duty cycles. Higher duty cycles produce greater average brightness.

Important Pin Summary:
  • Potentiometer Wiper → A0
  • LED PWM Output → D9
  • Potentiometer Supply → 5V
  • Potentiometer Ground → GND
  • LED Current-Limiting Resistor → 220Ω

All circuit components must share a common ground.

Ensure correct LED polarity. Never connect an LED directly to the Arduino output without an appropriate current-limiting resistor.

Analog Input

The potentiometer changes the analog voltage received at Arduino pin A0.

The analogRead() function converts the voltage into a value between 0 and 1023.

Mapping Values

Arduino uses the map() function to convert the analog input range into the PWM output range.

Mapping:

0–1023 → 0–255

PWM Output

The analogWrite() function produces a PWM signal on digital pin D9.

Changing the PWM duty cycle changes the average power delivered to the LED.

Procedure

  1. Place the Arduino UNO and breadboard on a stable surface.
  2. Insert the 10kΩ potentiometer into the breadboard.
  3. Connect one outer terminal of the potentiometer to Arduino 5V.
  4. Connect the middle terminal of the potentiometer to Arduino A0.
  5. Connect the remaining outer terminal to Arduino GND.
  6. Place the LED on the breadboard.
  7. Connect the LED anode to D9 through a 220Ω resistor.
  8. Connect the LED cathode to Arduino GND.
  9. Verify the circuit connections and LED polarity.
  10. Open Arduino IDE.
  11. Create a sketch named Adjustable_LED_Dimmer.ino.
  12. Copy the complete program from Explore the Code.
  13. Select Arduino Uno under Tools → Board.
  14. Select the correct communication port.
  15. Verify and upload the program.
  16. Open Serial Monitor at 9600 baud.
  17. Rotate the potentiometer clockwise and anticlockwise.
  18. Observe the change in LED brightness.
  19. Observe the potentiometer value and calculated PWM brightness value in Serial Monitor.

Explore more: Analog Input

The Arduino UNO includes a 10-bit Analog-to-Digital Converter (ADC).

It converts the voltage at A0 into an integer between 0 and 1023.

The analogRead() function reads this value.

Explore more: PWM

PWM stands for Pulse Width Modulation.

Arduino rapidly switches the LED output HIGH and LOW.

The duty cycle controls the LED brightness.

  • 0 → LED OFF
  • 127 → Medium brightness
  • 255 → Maximum brightness
