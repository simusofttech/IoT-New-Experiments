Aim

To build an Electronic Voting Machine Prototype using Arduino UNO R3, three candidate push buttons, three LEDs, a buzzer and a 16×2 LCD.

The experiment demonstrates recording candidate selections, providing visual and audible confirmation, and displaying individual and total vote counts.

About the Experiment

The Electronic Voting Machine Prototype is a classroom experiment that demonstrates electronic selection and counting using Arduino UNO.

Three push buttons represent Candidate A, Candidate B and Candidate C.

Arduino reads these buttons using INPUT_PULLUP, so a pressed button produces a LOW signal.

When a candidate button is pressed, the program increases that candidate's vote counter by one.

The corresponding LED turns ON as a visual confirmation, and a buzzer produces a short 1000 Hz tone.

The LCD briefly displays "Vote Recorded" along with the candidate selected.

After the confirmation message, the corresponding LED switches OFF.

The showVotes() function then displays the totals for all three candidates and the combined number of recorded votes.

The program contains separate vote counters: votesA, votesB and votesC.

These counters are stored in Arduino RAM and initialized to zero.

Educational Prototype:

This experiment demonstrates button handling and counting. It is not a secure or certified voting system.

It does not authenticate voters, restrict one vote per person, prevent repeated selections or permanently store votes.

Restarting or powering off Arduino clears the stored counters.

The source also uses blocking confirmation delays, during which button inputs are not continuously processed.

LCD Library Compatibility:

The original sketch includes Adafruit_LiquidCrystal.h and constructs the LCD using Adafruit_LiquidCrystal lcd(0).

This is not the same API as the commonly used LiquidCrystal_I2C library with address 0x27.

A generic four-pin PCF8574 I²C LCD cannot be assumed to work unchanged with this code.

Confirm the actual LCD interface and compatible library before uploading to the hardware.

Important Connections:

All buttons are configured as INPUT_PULLUP and become active when LOW. External pull-up resistors are not required.

Use separate 220Ω current-limiting resistors for the three LEDs.

A low-current passive piezo buzzer is suitable for the tone() output. Use a driver if the buzzer draws more current than an Arduino pin can safely supply.

The uploaded file specifies SDA on A4 and SCL on A5, but the LCD hardware must support the Adafruit_LiquidCrystal interface used in the preserved sketch.

Button Inputs

The three candidate buttons connect to Arduino D2, D3 and D4.

INPUT_PULLUP keeps an unpressed input HIGH. A pressed button connects the input to GND, producing LOW.

Vote Counting

The sketch maintains three integer counters: votesA, votesB and votesC.

Pressing a candidate button increments the corresponding variable.

Counting Example:

Initially: A = 0, B = 0, C = 0

If Candidate A is selected: A becomes 1.

A second selection of A increases that counter again.

LED Confirmation

Each candidate has an LED connected to a separate output pin.

The corresponding LED turns ON after the candidate button is detected.

It turns OFF after the confirmation display delay.

Buzzer Confirmation

Arduino uses tone(buzzer, 1000) to generate a 1000 Hz signal.

The tone is active for 200 milliseconds.

noTone() then stops the sound.

LCD Vote Confirmation

The LCD first shows a confirmation: Vote Recorded.

The second row identifies Candidate A, B or C.

After a one-second confirmation delay, the LCD is updated with the vote totals.

Total Vote Calculation

The showVotes() function calculates the total number of votes from the three counters.

Formula:

Total Votes = votesA + votesB + votesC

The first LCD row shows A and B totals.

The second row shows C and the combined total T.

Button Release Handling

The program waits until the selected button is released before completing that candidate branch.

This prevents the held button from repeatedly incrementing its vote counter during that hold.

However, a new press after release can record another vote.

Program Limitations

The original code uses blocking delays and separate button checks.

Other candidate inputs are not checked during a confirmation delay or button-release waiting loop.

The code does not implement persistent storage, voter identification, election security or independent audit logs.

Procedure

  1. Arrange Arduino UNO, three push buttons, three LEDs, three 220Ω resistors, a buzzer, LCD, breadboard and jumper wires.
  2. Connect Candidate A push button between D2 and GND.
  3. Connect Candidate B push button between D3 and GND.
  4. Connect Candidate C push button between D4 and GND.
  5. Connect Candidate A LED anode to D5 through a 220Ω resistor.
  6. Connect Candidate B LED anode to D6 through a 220Ω resistor.
  7. Connect Candidate C LED anode to D7 through a 220Ω resistor.
  8. Connect all three LED cathodes to GND.
  9. Connect the suitable low-current buzzer positive terminal to D8.
  10. Connect the buzzer negative terminal to GND.
  11. Check which LCD interface is actually available.
  12. If the LCD is compatible with the source library, connect its I²C signals to SDA A4 and SCL A5 according to that interface.
  13. Connect LCD power and ground according to its voltage rating.
  14. Verify all connections before applying power.
  15. Open Arduino IDE.
  16. Install the library required by the original Adafruit_LiquidCrystal sketch, if the hardware supports it.
  17. Create a sketch named Electronic_Voting_Machine_Prototype.ino.
  18. Copy the complete original Arduino program from Explore the Code.
  19. Select Arduino Uno and the correct communication port.
  20. Verify library compatibility and compile the program.
  21. Upload the program to Arduino.
  22. Observe the Voting Machine Ready message on the LCD.
  23. Press Candidate A's button once and observe the LED, buzzer and LCD confirmation.
  24. Check that Candidate A's count increases by one.
  25. Repeat the test for Candidates B and C.
  26. Check the combined total displayed on the LCD.
  27. Release each button before pressing it again.
  28. Restart Arduino and observe that the counters return to zero.
  29. Record the behavior as an educational demonstration of input, counting and output control.

Explore More: INPUT_PULLUP

INPUT_PULLUP uses Arduino's internal pull-up resistor.

An unpressed button normally reads HIGH. Pressing it connects the input to GND and produces LOW.

Explore More: Vote Counters

The integers votesA, votesB and votesC store the number of selections for each candidate.

Each successful button-press branch increments its own counter by one.

Explore More: Confirmation Feedback

Each candidate has an LED indicator.

The source produces a 1000 Hz buzzer signal for 200 ms.

It then displays Vote Recorded and the candidate name on the LCD.

Explore More: LCD Library

The sketch uses Adafruit_LiquidCrystal, not LiquidCrystal_I2C.

The LCD must support the chosen interface.

A generic PCF8574 I²C display may need a different library and initialization, which have not been substituted into the original code.

Explore More: Prototype Limitations

Vote counts are stored in volatile RAM and restart at zero.

The sketch does not implement voter identity, authentication or anti-repeat voting.

It demonstrates vote counting logic only.

Important Output Notes:

The values above are examples based on the program's counting logic.

Result

The Electronic Voting Machine Prototype demonstrates recording selections for three candidates using Arduino UNO.

Each candidate button increments its own counter and activates an LED and a short buzzer tone.

The LCD displays the candidate selected and then shows the updated individual and total vote counts.

The experiment teaches digital input, integer counting, conditional logic, output control and LCD interfacing.

It remains an educational prototype, not a secure election system.
