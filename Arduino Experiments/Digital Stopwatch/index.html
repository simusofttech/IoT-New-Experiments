Aim

To develop a Digital Stopwatch using Arduino UNO R3, a 4-digit I²C 7-segment display and two push buttons.

The stopwatch measures elapsed time in minutes and seconds and provides Start, Pause, Resume and Reset functions.

About the Experiment

The Digital Stopwatch experiment demonstrates how Arduino UNO can measure elapsed time using its built-in millis() function.

A four-digit I²C 7-segment display presents the elapsed time in MM:SS format.

Two push buttons provide the user controls.

The first button starts and pauses the stopwatch. Pressing it again allows the stopwatch to continue.

The second button resets the elapsed time to zero.

The original program uses the Adafruit_LEDBackpack library to control the display.

The display communicates with Arduino over the I²C interface using address 0x70.

The sketch stores elapsed time in milliseconds and converts it into minutes and seconds before updating the display.

This experiment helps students understand digital input, state-based control, timing, and display interfacing.

Original Program:

The Arduino sketch from the uploaded HTML is preserved without changing the stopwatch logic.

The source uses a four-digit HT16K33-compatible display with the Adafruit_7segment interface and I²C address 0x70.

Initializing the Stopwatch

During setup(), Arduino configures both push buttons as INPUT_PULLUP inputs.

It initializes the 7-segment display using I²C address 0x70 and brightness level 10.

The stopwatch initially displays zero.

Starting the Stopwatch

When the Start / Stop button is pressed, Arduino reads LOW on pin A0.

If the stopwatch is not running, the program calculates startTime using millis() and the previously saved elapsed time.

It then sets running to true.

Elapsed-Time Calculation

Timing Formula:

Elapsed Time = millis() − startTime

millis() returns the number of milliseconds since Arduino started.

The result is stored in savedTime while the stopwatch is running.

Pausing the Stopwatch

When the Start / Stop button is pressed again, the program saves the current elapsed time.

It then changes running to false.

The display continues showing the saved time without increasing it.

Resuming the Stopwatch

When the same button is pressed again, Arduino calculates a new startTime that accounts for the previously saved elapsed time.

This allows the stopwatch to resume without restarting from zero.

Resetting the Stopwatch

Pressing the Reset button on A1 sets running to false and savedTime to zero.

The display is updated immediately to show zero elapsed time.

Converting Time to Minutes and Seconds

The function showTime() converts milliseconds into whole seconds.

Time Conversion:

Total Seconds = Elapsed Milliseconds / 1000

Minutes = Total Seconds / 60

Seconds = Total Seconds % 60

Display Value = Minutes × 100 + Seconds

Display Format

Arduino converts minutes and seconds into an integer representation.

For example, at 1 minute 25 seconds, the calculated display value is 125.

The display library renders this numerical value and enables the colon separator.

Program Limitations:

The original sketch uses display.print(displayValue) rather than a dedicated fixed-width zero-padded MM:SS formatter.

Leading zeros are therefore dependent on the display library's formatting behavior and should be checked on the actual HT16K33 module.

The code also does not constrain the elapsed minutes to two digits, so its four-digit display becomes insufficient for long running times.

It uses blocking button-release loops and a 200 ms delay after button presses.

Procedure

  1. Arrange Arduino UNO, a compatible four-digit I²C 7-segment display, two push buttons, breadboard and jumper wires.
  2. Check that the display uses an HT16K33-compatible I²C interface.
  3. Connect display VCC to Arduino 5V.
  4. Connect display GND to Arduino GND.
  5. Connect display SDA to Arduino A4.
  6. Connect display SCL to Arduino A5.
  7. Connect one side of the Start / Stop push button to A0.
  8. Connect the opposite side of that button to GND.
  9. Connect one side of the Reset button to A1.
  10. Connect the opposite side to GND.
  11. Verify the button terminal pairs and I²C connections.
  12. Open Arduino IDE.
  13. Install Adafruit GFX Library and Adafruit LED Backpack Library.
  14. Create a sketch named Digital_Stopwatch.ino.
  15. Copy the complete Arduino sketch from Explore the Code.
  16. Select Arduino Uno and the correct communication port.
  17. Verify and upload the program.
  18. Observe the display initialize at zero.
  19. Press the Start / Stop button to begin timing.
  20. Observe the number of seconds increasing.
  21. Press the same button again to pause.
  22. Confirm the displayed elapsed time remains unchanged while paused.
  23. Press the button again to resume.
  24. Confirm the elapsed time continues from its saved value.
  25. Press Reset to return the stopwatch to zero.
  26. Repeat the operations and compare the time with another clock.

Explore More: millis()

millis() returns the number of milliseconds that have passed since Arduino started running.

Unlike delay(), it allows elapsed time to be calculated without stopping the whole program between time updates.

Explore More: INPUT_PULLUP

INPUT_PULLUP enables Arduino's built-in pull-up resistor.

When the button is not pressed, the input normally reads HIGH.

When pressed, the button connects the input to GND, producing LOW.

Explore More: I²C Display

I²C uses two communication signals: SDA for data and SCL for clock.

On Arduino UNO, these signals connect through A4 and A5.

The sketch uses display address 0x70.

Explore More: Pause and Resume

The variable running identifies whether the stopwatch should continue counting.

savedTime stores the elapsed milliseconds while stopped.

When resumed, Arduino subtracts the saved duration from millis() to preserve the elapsed time.

Explore More: Display Formatting

The showTime() function calculates total seconds, minutes and remaining seconds.

The original sketch constructs a number in the form minutes × 100 plus seconds.

The display library prints that value and lights the colon.
