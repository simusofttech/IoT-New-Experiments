Digital Stopwatch

← Arduino Experiments Aim Components Connections Working Procedure Code Result

Aim

To create a digital stopwatch using Arduino UNO, a 4-digit I²C 7-segment display and two push buttons.

About the Experiment

The stopwatch starts at 00:00. One button is used to start, stop and continue the stopwatch.

The second button resets the stopwatch back to 00:00.

Components Required

Arduino UNO R3 (×1)

Main controller for the stopwatch.

4-Digit 7-Segment Display (I²C) (×1)

Displays time in MM:SS format.

Push Button (×2)

Used for Start/Stop and Reset.

Breadboard (×1)

Used to connect the push buttons and display neatly.

Jumper Wires

Used for electrical connections.

Working Principle

Display shows 00:00
↓
Press Start/Stop
↓
Stopwatch starts
↓
Press Start/Stop again → Pause
↓
Press again → Continue
↓
Press Reset → 00:00

Procedure

  1. Connect the display VCC to 5V and GND to GND.
  2. Connect display SDA to A4 and SCL to A5.
  3. Connect the Start/Stop button between A0 and GND.
  4. Connect the Reset button between A1 and GND.
  5. Install the required Adafruit display libraries.
  6. Upload the Arduino code.
  7. Use the buttons to start, pause, continue and reset the stopwatch.

Arduino Code

Digital_Stopwatch.ino 
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_LEDBackpack.h>

// Create display object
Adafruit_7segment display = Adafruit_7segment();

// Button pins
int startButton = A0;
int resetButton = A1;

// Stopwatch variables
bool running = false;

unsigned long startTime = 0;
unsigned long savedTime = 0;

void setup()
{
  pinMode(startButton, INPUT_PULLUP);
  pinMode(resetButton, INPUT_PULLUP);

  // Start the display
  display.begin(0x70);
  display.setBrightness(10);

  showTime(0);
}

void loop()
{
  // Start / Stop button
  if (digitalRead(startButton) == LOW)
  {
    // Start the stopwatch
    if (running == false)
    {
      startTime = millis() - savedTime;
      running = true;
    }
    else
    {
      // Stop the stopwatch
      savedTime = millis() - startTime;
      running = false;
    }

    // Wait until button is released
    while (digitalRead(startButton) == LOW)
    {
      delay(10);
    }

    delay(200);
  }

  // Reset button
  if (digitalRead(resetButton) == LOW)
  {
    running = false;
    savedTime = 0;

    showTime(0);

    while (digitalRead(resetButton) == LOW)
    {
      delay(10);
    }

    delay(200);
  }

  // Update stopwatch time
  if (running == true)
  {
    savedTime = millis() - startTime;
  }

  showTime(savedTime);

  delay(20);
}

void showTime(unsigned long timeValue)
{
  // Convert milliseconds into seconds
  unsigned long totalSeconds = timeValue / 1000;

  // Calculate minutes and seconds
  int minutes = totalSeconds / 60;
  int seconds = totalSeconds % 60;

  // Example: 1 minute 25 seconds becomes 0125
  int displayValue = minutes * 100 + seconds;

  display.print(displayValue);

  // Show colon
  display.drawColon(true);

  display.writeDisplay();
}

Expected Output

The display starts at 00:00. The Start/Stop button starts, pauses and continues the stopwatch. The Reset button returns the display to 00:00.

Result

The Digital Stopwatch experiment measures elapsed time and provides start, pause, continue and reset functions.
