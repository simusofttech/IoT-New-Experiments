Arduino Experiment

Temperature Threshold Alarm

← Arduino Experiments Aim Components Connections Working Procedure Code Result

Aim

To continuously monitor temperature using Arduino UNO, display the measured temperature on a 16×2 I²C LCD, show diagnostic information on the Serial Monitor, and activate a buzzer when the programmed temperature threshold is reached.

About the Experiment

Arduino reads the temperature sensor through analog pin A0 and converts the analog reading into a temperature value. The temperature is shown locally on the LCD and diagnostic information is sent to the Serial Monitor.

When the calculated temperature reaches or exceeds 40°C, the buzzer sounds. Below the threshold, the buzzer remains OFF.

Procedure

  1. Connect the left temperature sensor pin to Arduino 5V.
  2. Connect the middle temperature sensor pin to Arduino A0.
  3. Connect the right temperature sensor pin to Arduino GND.
  4. Connect LCD VCC to 5V.
  5. Connect LCD GND to GND.
  6. Connect LCD SDA to A4.
  7. Connect LCD SCL to A5.
  8. Connect buzzer positive to D8.
  9. Connect buzzer negative to GND.
  10. Connect Arduino UNO to the computer.
  11. Open Arduino IDE.
  12. Install the LiquidCrystal_I2C library if required.
  13. Enter the program given below.
  14. Select Arduino UNO and the correct COM port.
  15. Verify and upload the program.
  16. Open Serial Monitor at 9600 baud.
  17. Observe the temperature reading and buzzer status.

Arduino Code

Temperature_Threshold_Alarm.ino 
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// PIN DEFINITIONS
#define TEMP_PIN A0
#define BUZZER_PIN 8

// LCD SETTINGS
LiquidCrystal_I2C lcd(0x27, 16, 2);

// TEMPERATURE THRESHOLD
const float TEMPERATURE_LIMIT = 40.0;

void setup() {

  Serial.begin(9600);

  // LCD SETUP
  lcd.init();
  lcd.backlight();

  // BUZZER SETUP
  pinMode(BUZZER_PIN, OUTPUT);
  noTone(BUZZER_PIN);

  // STARTING MESSAGE
  lcd.setCursor(0, 0);
  lcd.print("Temperature");

  lcd.setCursor(0, 1);
  lcd.print("Alarm System");

  delay(2000);

  lcd.clear();

  // SERIAL MONITOR
  Serial.println("Temperature Threshold Alarm");
  Serial.println("---------------------------");
  Serial.println("Sensor: TMP36");
  Serial.println("Temperature Limit: 40 C");
  Serial.println("---------------------------");
}

void loop() {

  // READ TEMPERATURE SENSOR
  int sensorValue = analogRead(TEMP_PIN);

  // CONVERT ANALOG VALUE TO VOLTAGE
  float voltage = sensorValue * (5.0 / 1023.0);

  // CONVERT VOLTAGE TO TEMPERATURE
  // TMP36:
  // 500mV OFFSET
  // 10mV PER DEGREE CELSIUS
  float temperature = (voltage - 0.5) * 100.0;

  // DISPLAY TEMPERATURE ON LCD
  lcd.setCursor(0, 0);
  lcd.print("Temperature: ");

  lcd.setCursor(0, 1);
  lcd.print(temperature, 1);
  lcd.print((char)223);
  lcd.print("C ");

  // SERIAL MONITOR DISPLAY
  Serial.print("Sensor Value: ");
  Serial.print(sensorValue);

  Serial.print(" | Voltage: ");
  Serial.print(voltage, 3);
  Serial.print(" V");

  Serial.print(" | Temperature: ");
  Serial.print(temperature, 1);
  Serial.println(" C");

  // TEMPERATURE THRESHOLD CHECK
  if (temperature >= TEMPERATURE_LIMIT) {

    // HIGH TEMPERATURE
    tone(BUZZER_PIN, 1000);

    Serial.println("WARNING: HIGH TEMPERATURE!");
    Serial.println("BUZZER: ON");
  }
  else {

    // NORMAL TEMPERATURE
    noTone(BUZZER_PIN);

    Serial.println("Status: NORMAL");
    Serial.println("BUZZER: OFF");
  }

  Serial.println("---------------------------");

  delay(1000);
}
Source note: The uploaded SOP identifies the circuit sensor as an LM35, while its supplied Arduino program labels the sensor as TMP36 and uses the TMP36 500 mV offset conversion formula. The code above is preserved exactly from the SOP.

Expected Output

The LCD continuously displays the calculated temperature. The Serial Monitor shows the sensor reading, voltage, temperature and alarm status.

Temperature < 40°C: Status NORMAL, Buzzer OFF
Temperature ≥ 40°C: HIGH TEMPERATURE warning, Buzzer ON
LCD: Displays calculated temperature in °C

Result

The Temperature Threshold Alarm experiment was implemented using Arduino UNO, a temperature sensor, 16×2 I²C LCD and buzzer. The system continuously displays the calculated temperature and activates the buzzer when the programmed 40°C threshold is reached.
