Aim

To design and develop a Temperature Threshold Alarm using Arduino UNO R3, an analog temperature sensor, a 16×2 I²C LCD and a buzzer.

The experiment continuously reads the sensor voltage, calculates temperature, displays the result on the LCD and activates the buzzer when the calculated temperature reaches 40°C.

About the Experiment

The Temperature Threshold Alarm demonstrates how Arduino UNO can monitor an analog temperature sensor and control an audible warning based on a programmed limit.

The temperature sensor provides an analog voltage to Arduino input A0.

Arduino measures this voltage with analogRead(), producing a 10-bit reading normally between 0 and 1023.

The sketch calculates voltage by multiplying the ADC reading by 5.0 divided by 1023.0.

It then calculates temperature using the formula (voltage - 0.5) × 100.

The resulting temperature is shown on a 16×2 I²C LCD at address 0x27.

The Serial Monitor displays the raw sensor reading, calculated voltage, temperature and alarm status.

When the calculated temperature is below 40°C, the buzzer remains OFF.

When the temperature reaches or exceeds 40°C, Arduino generates a 1000 Hz tone through D8.

The temperature measurement and alarm decision repeat approximately once per second.

Source Sensor Mismatch:

The uploaded component list specifies an LM35 temperature sensor.

However, the original Arduino sketch prints "Sensor: TMP36" and uses a TMP36 conversion formula with a 500 mV offset.

LM35 and TMP36 are different sensors. An LM35 normally outputs 10 mV/°C without the TMP36 500 mV offset.

Using the preserved TMP36 formula with an LM35 will produce incorrect temperature values.

Confirm the actual hardware sensor before running the experiment. The Arduino sketch below is retained exactly as supplied.

Analog Temperature Measurement

The sensor output is read on Arduino analog input A0.

The analogRead() function converts the input voltage into a 10-bit numerical value.

Voltage Calculation

Program Formula:

Voltage = Sensor Reading × (5.0 / 1023.0)

The program assumes a 5 V ADC reference.

Actual reference voltage variation can affect temperature accuracy.

Temperature Calculation

The original sketch uses the TMP36 sensor formula.

TMP36 Formula:

Temperature (°C) = (Voltage − 0.5) × 100

The formula removes the TMP36 sensor's nominal 500 mV offset.

LM35 Difference:

The component list specifies LM35, whose nominal positive Celsius conversion is Voltage × 100 when voltage is expressed in volts.

The preserved sketch does not use that LM35 conversion. Its calculated value would be about 50°C lower than the LM35 nominal temperature reading under the same voltage-reference assumption.

LCD Display

The first LCD row displays the label Temperature:.

The second row displays the calculated Celsius value with one digit after the decimal point.

Threshold Comparison

The variable TEMPERATURE_LIMIT is set to 40.0.

Arduino checks whether temperature is greater than or equal to that value.

Procedure

  1. Arrange Arduino UNO, the temperature sensor, 16×2 I²C LCD, buzzer, breadboard and jumper wires.
  2. Identify whether the actual sensor is LM35 or TMP36.
  3. Verify its exact package orientation and terminal pinout using the datasheet.
  4. Connect the sensor's supply terminal to 5V, if rated for it.
  5. Connect the sensor output terminal to A0.
  6. Connect the sensor ground to Arduino GND.
  7. Connect LCD VCC to 5V.
  8. Connect LCD GND to GND.
  9. Connect LCD SDA to A4.
  10. Connect LCD SCL to A5.
  11. Connect the buzzer positive terminal to D8 if suitable for direct drive.
  12. Connect the buzzer negative terminal to GND.
  13. Check all connections before powering the circuit.
  14. Open Arduino IDE.
  15. Install a compatible LiquidCrystal_I2C library if necessary.
  16. Create a sketch named Temperature_Threshold_Alarm.ino.
  17. Copy the original Arduino sketch from Explore the Code.
  18. Before physical testing, ensure the conversion formula matches the actual sensor type. The supplied program currently assumes TMP36.
  19. Select Arduino Uno and the correct communication port.
  20. Verify and upload the sketch.
  21. Observe the LCD startup message for two seconds.
  22. Open Serial Monitor at 9600 baud.
  23. Observe the sensor reading, voltage, calculated temperature and buzzer status.
  24. Verify normal operation below the threshold.
  25. In a suitable low-voltage classroom test or simulator, vary the sensor temperature safely.
  26. Confirm that the buzzer turns ON when the calculated temperature reaches 40°C.
  27. Reduce the test temperature below the threshold and verify that the buzzer stops.
  28. Compare the LCD reading with Serial Monitor for consistency.
  29. Record readings under different temperature conditions.

Explore more: LM35 vs TMP36

Both devices are analog temperature sensors, but their voltage conversions are different.

LM35 produces approximately 10 mV for each degree Celsius.

TMP36 includes a nominal 500 mV offset at 0°C.

The supplied code specifically uses the TMP36 formula.

Explore more: ADC Conversion

Arduino UNO normally uses a 10-bit analog-to-digital converter.

analogRead(A0) returns a numerical value between 0 and 1023.

The sketch assumes a 5 V ADC reference to convert that number to voltage.

Explore more: I²C LCD

The LCD communicates with Arduino over SDA and SCL.

On Arduino UNO, SDA is A4 and SCL is A5.

The code initializes the LCD using address 0x27.

Explore more: Alarm Threshold

The variable TEMPERATURE_LIMIT is assigned 40.0.

The condition uses greater than or equal to, so a calculated temperature of exactly 40°C activates the buzzer.

Explore more: tone() and noTone()

tone() generates a square-wave output at a specified frequency.

Here, the buzzer signal frequency is 1000 Hz.

noTone() stops the generated waveform when the calculated temperature is below the limit.

Result

The Temperature Threshold Alarm experiment demonstrates how Arduino UNO can read an analog temperature signal, convert the reading to voltage and calculate a Celsius temperature value.

The calculated temperature is displayed on a 16×2 I²C LCD, while the sensor reading, voltage and alarm status are displayed in Serial Monitor.

The buzzer is activated at a calculated temperature of 40°C or above and deactivated below that threshold.

The source's LM35 component designation and TMP36 conversion must be reconciled before claiming accurate physical temperature measurement.
