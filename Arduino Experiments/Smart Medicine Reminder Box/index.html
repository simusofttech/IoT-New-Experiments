Aim

To design and develop a Smart Medicine Reminder Box using Arduino UNO R3, a single-digit common-anode 7-segment display, two push buttons, a servo motor and a buzzer.

The experiment demonstrates a five-second countdown, automatic opening of a medicine compartment and an audible alert that is acknowledged using a Close button.

About the Experiment

The Smart Medicine Reminder Box is an Arduino-based educational experiment that combines digital inputs, a countdown timer, a 7-segment display, a servo motor and an audible buzzer.

The system begins with the medicine compartment closed and the display showing the number 5.

The Start push button is connected to Arduino pin A0 and the Close push button is connected to pin A1.

Both buttons use INPUT_PULLUP, meaning a pressed button produces a LOW signal.

When the Start button is pressed, Arduino initializes the reminder timer to five seconds.

The single-digit common-anode display shows the remaining countdown time.

Every second, the displayed value decreases by one until it reaches zero.

At zero, Arduino commands the servo motor to move from the closed position of 0° to the open position of 90°.

The buzzer then produces a continuous 2000 Hz tone as the reminder alarm.

The system waits for the Close button to be pressed.

Pressing Close stops the tone, returns the servo to 0° and resets the display to 5.

Important:

The five-second timer is designed for an educational demonstration, not for real medicine scheduling.

The program does not contain a real-time clock, a daily dosing schedule or confirmation that medication was taken.

It should not be relied upon to manage actual medication doses.

Common-Anode Display Logic:

In a common-anode display, the common terminal is connected to the positive supply.

Arduino drives a segment LOW to illuminate it and HIGH to switch it OFF.

Each individual segment requires a current-limiting resistor.

Verify the exact physical segment pinout of the selected display, as package pin arrangements vary by model.

Servo Power:

The uploaded connections specify 5V for the servo.

Verify the servo's voltage and current requirements. A servo operating a mechanical box can require more current than an Arduino 5V pin can reliably provide.

If a suitable regulated servo power source is required, share GND with Arduino.

Initial System State

When Arduino starts, the servo is commanded to the closed position of 0°.

The buzzer is switched OFF using noTone(), and the display shows 5.

Start Button Operation

Pressing the Start button makes Arduino read LOW at A0.

After a basic 50 ms debounce check, the program sets remainingTime to 5 and starts the countdown.

The original sketch then waits until the Start button is released.

Countdown Timer

The sketch uses millis() to check whether at least 1000 milliseconds have elapsed since the last countdown update.

Each elapsed interval decreases remainingTime by one.

Countdown Sequence:

5 → 4 → 3 → 2 → 1 → 0

Each step takes approximately one second during normal operation.

Common-Anode Display

The displayNumber() function drives segments A–G.

First, all seven output pins are driven HIGH, switching their segments OFF.

The required segments for the selected digit are then driven LOW to illuminate the number.

Medicine Reminder

When remainingTime reaches zero, the program calls medicineReminder().

The function moves the servo to 90° and displays 0.

The buzzer produces a continuous 2000 Hz tone using tone().

Arduino then waits until the Close button becomes LOW.

Closing the Box

Once the Close button is detected, the program stops the tone using noTone().

The servo returns to the closed position of 0°.

After a one-second pause, the display is reset to 5 and the timer is stopped.

Original Program Behavior:

The code contains blocking while loops that wait for button release or acknowledgment.

While the alarm is active, Arduino remains in the reminder function until the Close button is pressed.

Pressing Start during an active countdown also restarts the five-second timer according to the original sketch.

Procedure

  1. Place Arduino UNO, common-anode 7-segment display, two push buttons, seven 220Ω resistors, servo motor, buzzer and breadboard on the working surface.
  2. Identify the seven segments and common-anode terminal of the display.
  3. Connect display segments A–G to Arduino D2–D8, each through a separate 220Ω resistor.
  4. Connect the common-anode terminal to 5V.
  5. Connect the servo signal wire to D9.
  6. Connect the servo power and ground according to its verified electrical requirements.
  7. Ensure the servo shares a common ground with Arduino.
  8. Connect the buzzer positive terminal to D10 if appropriate for direct drive.
  9. Connect the buzzer negative terminal to GND.
  10. Connect one switched terminal of the Start button to A0 and the other to GND.
  11. Connect one switched terminal of the Close button to A1 and the other to GND.
  12. Verify the display pinout, servo connections, and button wiring.
  13. Open Arduino IDE.
  14. Ensure the Servo library is available.
  15. Create a sketch named Smart_Medicine_Reminder_Box.ino.
  16. Copy the complete Arduino program from Explore the Code.
  17. Select Arduino Uno and the correct communication port.
  18. Verify and upload the program.
  19. Open Serial Monitor at 9600 baud.
  20. Observe the display showing 5 and the servo at its closed position.
  21. Press and release the Start button.
  22. Observe the display countdown from 5 to 0.
  23. Check the remaining-second messages in Serial Monitor.
  24. When the display reaches 0, observe the servo moving to 90°.
  25. Listen for the 2000 Hz reminder buzzer tone.
  26. Press the Close button to acknowledge the reminder.
  27. Verify that the buzzer stops and the servo returns to 0°.
  28. Confirm that the display resets to 5.
  29. Repeat the procedure to test another countdown cycle.

Result

The Smart Medicine Reminder Box experiment demonstrates an Arduino-controlled countdown and reminder mechanism using a single-digit 7-segment display, servo motor and buzzer.

Pressing the Start button initiates a five-second countdown.

When the countdown reaches zero, the servo is commanded to open the compartment and the buzzer generates an audible alert.

Pressing the Close button acknowledges the alert, stops the buzzer, closes the box and resets the system for another demonstration.
