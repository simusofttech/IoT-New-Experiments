Aim

To demonstrate an automatic railway crossing gate model using Arduino UNO, two IR sensors, a servo motor, LEDs and a buzzer.

The system detects an approaching model train, closes the crossing gate and reopens it when the train has passed the exit sensor.

About the Experiment

The Automatic Railway Crossing Model demonstrates how sensors can control an automated model barrier.

Two IR sensors are installed along a model railway track. The first sensor detects a train approaching the crossing.

When the approach sensor detects the train, Arduino activates a warning buzzer, switches on the red LED and moves the servo to close the gate.

When the exit sensor detects the passing train, the system waits for the sensor to clear before opening the gate again.

The green LED indicates the normal open-gate state.

Demonstration Only: This single-direction model assumes a train passes the approach sensor before the exit sensor. It does not include real railway fail-safe protection, train identification or multiple-train handling.

Train Detection

The approach IR sensor monitors the model track before the crossing.

When a train interrupts its detection area, the Arduino begins the closing sequence.

Gate Control

The servo motor controls the model barrier position. The example uses 90° for open and 0° for closed.

Train Departure

Once the second sensor has detected the train, the program waits for the exit sensor to become clear before opening the crossing again.

Procedure

  1. Place the Arduino UNO and breadboard on a stable surface.
  2. Install the first IR sensor before the model crossing in the direction of train travel.
  3. Install the second IR sensor beyond the crossing, where it can detect the passing train.
  4. Connect the approach sensor OUT pin to Arduino D2.
  5. Connect the exit sensor OUT pin to Arduino D3.
  6. Connect the compatible IR module power and ground terminals.
  7. Connect the servo signal wire to D9.
  8. Connect the servo to a suitable regulated power supply.
  9. Connect servo ground to Arduino ground.
  10. Connect the red LED to D6 through a 220Ω resistor.
  11. Connect the green LED to D7 through a 220Ω resistor.
  12. Connect both LED cathodes to GND.
  13. Connect the buzzer positive terminal to D8 and negative terminal to GND.
  14. Verify all connections with power disconnected.
  15. Open Arduino IDE.
  16. Create a sketch named Automatic_Railway_Crossing_Model.ino.
  17. Copy the complete program from Explore the Code.
  18. Select Arduino Uno and the correct port.
  19. Verify and upload the program.
  20. Open Serial Monitor at 9600 baud.
  21. Move a model train past the approach sensor and observe gate closure.
  22. Move the train through and beyond the exit sensor.
  23. Confirm the gate opens after the exit sensor clears.

Result

The Automatic Railway Crossing Model demonstrates how Arduino UNO can use IR sensors to control a servo-based crossing barrier.

The model closes the gate when an approaching train is detected and opens it after the train has passed the exit sensor.

The red and green LEDs provide visual status while the buzzer produces an audible warning.

What You Learn

  • Detecting model trains using IR sensors.
  • Reading active-LOW digital sensor outputs.
  • Controlling a servo with the Servo library.
  • Implementing sequential automation.
  • Using a state machine to control a process.
  • Operating warning LEDs and a buzzer.
  • Monitoring system status through Serial.
  • Understanding the difference between an educational model and a real safety-critical control system.
