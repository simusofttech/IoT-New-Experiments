LED Traffic Light Sequencer

← Arduino Experiments Aim Components Connections Circuit Working Procedure Code Result

Aim

To create a traffic light sequence using Arduino UNO with three red LEDs, three yellow LEDs and three green LEDs.

About the Experiment

Arduino controls nine LEDs arranged as three red, three yellow and three green lights. The three red LEDs turn ON together for 5 seconds, followed by the three green LEDs for 5 seconds, and then the three yellow LEDs for 2 seconds.

After the yellow lights turn OFF, the same Red → Green → Yellow sequence repeats continuously.

Components Required

Main controller for the traffic light sequence.

Represents the stop signal.

Represents the caution signal.

Procedure

  1. Connect Red LED 1 to D2 through a 220Ω resistor.
  2. Connect Red LED 2 to D3 through a 220Ω resistor.
  3. Connect Red LED 3 to D4 through a 220Ω resistor.
  4. Connect Yellow LED 1 to D5 through a 220Ω resistor.
  5. Connect Yellow LED 2 to D6 through a 220Ω resistor.
  6. Connect Yellow LED 3 to D7 through a 220Ω resistor.
  7. Connect Green LED 1 to D8 through a 220Ω resistor.
  8. Connect Green LED 2 to D9 through a 220Ω resistor.
  9. Connect Green LED 3 to D10 through a 220Ω resistor.
  10. Connect all LED cathodes to GND.
  11. Connect Arduino UNO to the computer.
  12. Open Arduino IDE.
  13. Enter the program given below.
  14. Select Arduino UNO and the correct COM port.
  15. Verify and upload the program.
  16. Observe the repeating Red → Green → Yellow sequence.

Arduino Code

LED_Traffic_Light_Sequencer.ino 
#define RED1 2
#define RED2 3
#define RED3 4

#define YELLOW1 5
#define YELLOW2 6
#define YELLOW3 7

#define GREEN1 8
#define GREEN2 9
#define GREEN3 10

void setup()
{
  // Red LEDs
  pinMode(RED1, OUTPUT);
  pinMode(RED2, OUTPUT);
  pinMode(RED3, OUTPUT);

  // Yellow LEDs
  pinMode(YELLOW1, OUTPUT);
  pinMode(YELLOW2, OUTPUT);
  pinMode(YELLOW3, OUTPUT);

  // Green LEDs
  pinMode(GREEN1, OUTPUT);
  pinMode(GREEN2, OUTPUT);
  pinMode(GREEN3, OUTPUT);

  // Start with everything OFF
  allLightsOff();
}

void loop()
{
  // RED
  allLightsOff();

  digitalWrite(RED1, HIGH);
  digitalWrite(RED2, HIGH);
  digitalWrite(RED3, HIGH);

  delay(5000);

  // GREEN
  allLightsOff();

  digitalWrite(GREEN1, HIGH);
  digitalWrite(GREEN2, HIGH);
  digitalWrite(GREEN3, HIGH);

  delay(5000);

  // YELLOW
  allLightsOff();

  digitalWrite(YELLOW1, HIGH);
  digitalWrite(YELLOW2, HIGH);
  digitalWrite(YELLOW3, HIGH);

  delay(2000);
}

void allLightsOff()
{
  // Red OFF
  digitalWrite(RED1, LOW);
  digitalWrite(RED2, LOW);
  digitalWrite(RED3, LOW);

  // Yellow OFF
  digitalWrite(YELLOW1, LOW);
  digitalWrite(YELLOW2, LOW);
  digitalWrite(YELLOW3, LOW);

  // Green OFF
  digitalWrite(GREEN1, LOW);
  digitalWrite(GREEN2, LOW);
  digitalWrite(GREEN3, LOW);
}

Expected Output

The three red LEDs turn ON together for 5 seconds, followed by the three green LEDs for 5 seconds and then the three yellow LEDs for 2 seconds. The sequence repeats continuously.

Result

The LED Traffic Light Sequencer experiment was implemented using Arduino UNO, nine LEDs and nine 220Ω resistors. The red, green and yellow LED groups operate sequentially with the programmed timing.
