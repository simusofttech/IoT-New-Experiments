Aim

To create a Multi-Mode LED Flasher using Arduino UNO R3, a common-cathode RGB LED and a push button.

Each button press changes the selected operating mode, allowing the RGB LED to produce individual color flashes, RGB sequences and multicolor patterns.

About the Experiment

The Multi-Mode LED Flasher experiment demonstrates how Arduino UNO can control an RGB LED to create different lighting patterns.

An RGB LED contains three individual light-emitting elements: red, green and blue.

Combining these three colors at different brightness levels produces additional colors.

The experiment uses a common-cathode RGB LED. Its common terminal is connected to GND.

The red, green and blue terminals connect to Arduino PWM-capable pins D9, D10 and D11 respectively.

Each color channel includes a separate 220Ω current-limiting resistor.

A push button connected between D2 and GND changes the mode.

Arduino enables INPUT_PULLUP for this button, so a pressed button produces a LOW input.

The program offers five operating modes: red flashing, green flashing, blue flashing, RGB sequencing and six-color cycling.

The program uses millis() instead of delay() to control LED timing.

This allows Arduino to continue checking the push button while LED patterns are running.

Important: The program starts in Mode 1 (Red Flash) when Arduino powers ON. Each accepted button press selects the next mode. After Mode 5, the program returns to Mode 1.

The four RGB LED package pins do not always appear in the same physical order. Confirm the terminal identification for your particular LED.

Use one separate current-limiting resistor per RGB channel.

Mode Selection

Arduino stores the currently selected mode in the variable mode.

The variable starts at 0 and increases by one after each accepted button press.

When its value becomes greater than 4, the program resets it to 0.

Red Flash Mode

In Mode 1, the red channel switches between ON and OFF at 500 ms intervals.

The green and blue channels remain OFF.

Green Flash Mode

In Mode 2, the green channel flashes every 500 ms while the other channels remain OFF.

Blue Flash Mode

In Mode 3, the blue channel flashes every 500 ms while the other channels remain OFF.

RGB Sequence Mode

In Mode 4, Arduino switches through red, green and blue continuously.

RGB Sequence:

Red → Green → Blue → Repeat

Each color remains selected for approximately 500 milliseconds.

Six-Color Cycle Mode

In Mode 5, Arduino combines RGB channels to generate additional colors.

Six-Color Sequence:

Red → Green → Blue → Yellow → Cyan → Magenta → Repeat

Each color remains selected for approximately 400 milliseconds.

PWM Color Control

Arduino uses analogWrite() to control the output levels of the red, green and blue channels.

Values range from 0 to 255, where 0 represents OFF and 255 represents the maximum programmed PWM duty cycle.

Non-Blocking Timing

The sketch stores the time of the previous pattern change in lastFlashTime.

It compares this value with millis() to determine whether the next LED action is due.

Important: Red, green and blue flashing modes alternate between ON and OFF at 500 ms intervals, producing an approximate one-second full ON/OFF cycle. The RGB sequence and six-color cycle switch directly between colors; they do not insert an OFF interval between colors.

Procedure

  1. Place the Arduino UNO, common-cathode RGB LED, push button, three 220Ω resistors and breadboard on the working surface.
  2. Identify the RGB LED red, green, blue and common-cathode terminals.
  3. Insert the RGB LED into the breadboard with its terminals on separate connections.
  4. Connect the red terminal to Arduino D9 through a 220Ω resistor.
  5. Connect the green terminal to Arduino D10 through a 220Ω resistor.
  6. Connect the blue terminal to Arduino D11 through a 220Ω resistor.
  7. Connect the RGB LED common cathode to GND.
  8. Place the push button on the breadboard.
  9. Connect one switched terminal of the push button to D2.
  10. Connect the other switched terminal to GND.
  11. Verify the RGB LED pinout and the three current-limiting resistor connections.
  12. Open Arduino IDE.
  13. Create a sketch named Multi_Mode_LED_Flasher.ino.
  14. Copy the complete Arduino program from Explore the Code.
  15. Select Arduino Uno and the correct communication port.
  16. Verify and upload the program.
  17. Observe the RGB LED flashing red at startup.
  18. Press and release the push button to select Green Flash.
  19. Press again to select Blue Flash.
  20. Press again to observe the Red → Green → Blue sequence.
  21. Press again to observe the six-color cycle.
  22. Press one more time to return to Red Flash.
  23. Confirm that each accepted press advances only one operating mode.
  24. Compare the flashing intervals with the color-sequence intervals.
  25. Experiment with the timing values to understand how pattern speed is controlled.

Explore more: RGB Colors

An RGB LED combines red, green and blue light to create different colors.

Red + Green produces Yellow.

Green + Blue produces Cyan.

Red + Blue produces Magenta.

Explore more: PWM Control

Arduino UNO pins D9, D10 and D11 support PWM output.

analogWrite() uses a numeric value from 0 to 255 to control PWM duty cycle.

In this sketch, the selected values are either 0 or 255.

Explore more: millis()

millis() returns the number of milliseconds elapsed since the program started running.

The sketch compares the current time with the previous flash time to update LED patterns.

Unlike delay(), this approach allows the main loop to keep reading the push button.

Explore more: Button Mode Control

The button is connected using INPUT_PULLUP.

Arduino detects a new press when the input changes from HIGH to LOW.

The program accepts a mode change only when more than 200 milliseconds have passed since the previous accepted press.
