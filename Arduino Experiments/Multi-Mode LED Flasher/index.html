Arduino Project No. 4

Multi-Mode LED Flasher

← Arduino Projects Aim Components Connections Circuit Working Procedure Code Result

Aim

To create a Multi-Mode LED Flasher using Arduino UNO, an RGB LED and a push button, where each button press switches to a different flashing or color sequence mode.

About the Project

This project uses one common-cathode RGB LED connected to Arduino PWM pins. A push button is used to change between five different LED modes.

Each press of the button advances to the next mode, allowing the RGB LED to flash red, green or blue, play an RGB sequence, or cycle through multiple colors.

Procedure

  1. Connect the RGB LED red pin to D9 through a 220Ω resistor.
  2. Connect the RGB LED green pin to D10 through a 220Ω resistor.
  3. Connect the RGB LED blue pin to D11 through a 220Ω resistor.
  4. Connect the RGB LED common cathode pin to GND.
  5. Connect one side of the push button to D2.
  6. Connect the other side of the push button to GND.
  7. Connect Arduino UNO to the computer using USB.
  8. Open Arduino IDE.
  9. Enter the program given below.
  10. Select Arduino UNO from Tools → Board.
  11. Select the correct COM port.
  12. Verify and upload the program.
  13. Press the push button repeatedly and observe each LED mode.

Arduino Code

Multi_Mode_LED_Flasher.ino 
const int redPin = 9;
const int greenPin = 10;
const int bluePin = 11;

const int buttonPin = 2;

int mode = 0;

bool lastButton = HIGH;

unsigned long lastPressTime = 0;
unsigned long lastFlashTime = 0;

bool ledState = false;

int color = 0;

void setup() {

  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);

  pinMode(buttonPin, INPUT_PULLUP);

  turnOff();
}

void loop() {

  bool buttonState = digitalRead(buttonPin);

  // Button press detection
  if (lastButton == HIGH && buttonState == LOW) {

    if (millis() - lastPressTime > 200) {

      mode++;

      if (mode > 4) {
        mode = 0;
      }

      lastPressTime = millis();
      lastFlashTime = millis();

      ledState = false;
      color = 0;

      turnOff();
    }
  }

  lastButton = buttonState;

  // Select mode
  if (mode == 0) {
    redFlash();
  }

  else if (mode == 1) {
    greenFlash();
  }

  else if (mode == 2) {
    blueFlash();
  }

  else if (mode == 3) {
    rgbSequence();
  }

  else if (mode == 4) {
    colorCycle();
  }
}

// -----------------------------
// RED FLASH
// -----------------------------
void redFlash() {

  if (millis() - lastFlashTime >= 500) {

    lastFlashTime = millis();

    ledState = !ledState;

    if (ledState)
      setColor(255, 0, 0);
    else
      turnOff();
  }
}

// -----------------------------
// GREEN FLASH
// -----------------------------
void greenFlash() {

  if (millis() - lastFlashTime >= 500) {

    lastFlashTime = millis();

    ledState = !ledState;

    if (ledState)
      setColor(0, 255, 0);
    else
      turnOff();
  }
}

// -----------------------------
// BLUE FLASH
// -----------------------------
void blueFlash() {

  if (millis() - lastFlashTime >= 500) {

    lastFlashTime = millis();

    ledState = !ledState;

    if (ledState)
      setColor(0, 0, 255);
    else
      turnOff();
  }
}

// -----------------------------
// RGB SEQUENCE
// -----------------------------
void rgbSequence() {

  if (millis() - lastFlashTime >= 500) {

    lastFlashTime = millis();

    if (color == 0)
      setColor(255, 0, 0);

    else if (color == 1)
      setColor(0, 255, 0);

    else if (color == 2)
      setColor(0, 0, 255);

    color++;

    if (color > 2)
      color = 0;
  }
}

// -----------------------------
// COLOR CYCLE
// -----------------------------
void colorCycle() {

  if (millis() - lastFlashTime >= 400) {

    lastFlashTime = millis();

    if (color == 0)
      setColor(255, 0, 0);

    else if (color == 1)
      setColor(0, 255, 0);

    else if (color == 2)
      setColor(0, 0, 255);

    else if (color == 3)
      setColor(255, 255, 0);

    else if (color == 4)
      setColor(0, 255, 255);

    else if (color == 5)
      setColor(255, 0, 255);

    color++;

    if (color > 5)
      color = 0;
  }
}

// -----------------------------
// SET COLOR
// -----------------------------
void setColor(int r, int g, int b) {

  analogWrite(redPin, r);
  analogWrite(greenPin, g);
  analogWrite(bluePin, b);
}

// -----------------------------
// OFF
// -----------------------------
void turnOff() {

  analogWrite(redPin, 0);
  analogWrite(greenPin, 0);
  analogWrite(bluePin, 0);
}

Each button press changes the RGB LED to the next operating mode. After the fifth mode, the project returns to the first mode.
