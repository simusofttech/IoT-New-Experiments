Humidity-Based Warning System

← Arduino Experiments Aim Components Connections Working Procedure Code Result

Aim

To demonstrate a humidity monitoring and warning system using Arduino UNO, a sensor input, a 16×2 I²C LCD and a buzzer.

About the Experiment

Arduino continuously reads the sensor input from A0 and calculates a humidity value. The calculated humidity is displayed on the 16×2 I²C LCD.

When the humidity reaches or exceeds the programmed threshold of 50%, the LCD shows a HIGH warning and the buzzer sounds. Below the threshold, the system displays NORMAL status and keeps the buzzer OFF.

Procedure

  1. Connect the sensor VCC pin to Arduino 5V.
  2. Connect the sensor DATA / OUT pin to A0.
  3. Connect the sensor GND pin to Arduino GND.
  4. Connect the I²C LCD VCC to 5V.
  5. Connect the I²C LCD GND to GND.
  6. Connect the I²C LCD SDA pin to A4.
  7. Connect the I²C LCD SCL pin to A5.
  8. Connect the buzzer positive terminal to D8.
  9. Connect the buzzer negative terminal to GND.
  10. Connect Arduino UNO to the computer.
  11. Open Arduino IDE.
  12. Install the LiquidCrystal_I2C library if required.
  13. Enter the program given below.
  14. Select Arduino UNO and the correct COM port.
  15. Verify and upload the program.
  16. Open Serial Monitor at 9600 baud.
  17. Observe humidity, LCD status and buzzer operation.

Arduino Code

Humidity_Based_Warning_System.ino 
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

#define SENSOR_PIN A0
#define BUZZER_PIN 8

LiquidCrystal_I2C lcd(0x27, 16, 2);

const float HUMIDITY_LIMIT = 50.0;

void setup()
{
  Serial.begin(9600);

  pinMode(BUZZER_PIN, OUTPUT);

  lcd.init();
  lcd.backlight();

  lcd.setCursor(0, 0);
  lcd.print("Humidity Alarm");

  delay(2000);

  lcd.clear();
}

void loop()
{
  // Read the physical Tinkercad sensor
  int sensorValue = analogRead(SENSOR_PIN);

  // Convert analog value to voltage
  float voltage = sensorValue * 5.0 / 1023.0;

  // Convert sensor reading
  float humidity = (voltage - 0.5) * 100.0;

  // Display humidity
  lcd.setCursor(0, 0);
  lcd.print("Humidity: ");
  lcd.print(humidity, 1);
  lcd.print("% ");

  // Humidity threshold = 50%
  if (humidity >= HUMIDITY_LIMIT)
  {
    lcd.setCursor(0, 1);
    lcd.print("HIGH! BUZZER ON ");

    tone(BUZZER_PIN, 1000);

    Serial.print("Humidity: ");
    Serial.print(humidity, 1);
    Serial.println("% -> BUZZER ON");
  }
  else
  {
    lcd.setCursor(0, 1);
    lcd.print("Status: NORMAL ");

    noTone(BUZZER_PIN);

    Serial.print("Humidity: ");
    Serial.print(humidity, 1);
    Serial.println("% -> BUZZER OFF");
  }

  delay(500);
}

Expected Output

The LCD continuously displays the calculated humidity value. When the humidity reaches or exceeds 50%, the buzzer sounds and the LCD shows a HIGH warning.

Humidity < 50%: Status NORMAL, Buzzer OFF
Humidity ≥ 50%: HIGH warning, Buzzer ON
LCD: Displays humidity percentage and system status

Result

The Humidity-Based Warning System experiment was implemented using Arduino UNO, a sensor input, a 16×2 I²C LCD and a buzzer. The system continuously displays humidity and activates an audible warning when the programmed threshold is reached.
