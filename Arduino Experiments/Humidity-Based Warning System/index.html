Aim

To develop a humidity-based warning system using Arduino UNO, a humidity sensor, a 16×2 I²C LCD and a buzzer.

The intended system displays humidity and activates an audible warning when the calculated value reaches or exceeds 50%.

Sensor Compatibility: The supplied sketch requires an analog voltage on A0. A DHT11 provides a digital humidity signal and cannot be read using the supplied analogRead() calculation. Therefore, the original sketch needs correction before this can function as a DHT11 humidity experiment.

About the Experiment

The Humidity-Based Warning System is intended to demonstrate environmental monitoring and automatic warning generation using Arduino UNO.

The source describes a humidity sensor connected to Arduino analog pin A0.

Arduino reads an analog value and converts it to an estimated voltage.

The supplied program then applies a mathematical formula and labels the result as a humidity percentage.

The calculated value is displayed on a 16×2 I²C LCD.

When the calculated value reaches or exceeds the programmed limit of 50, the LCD displays HIGH! BUZZER ON.

The buzzer receives a 1000 Hz tone signal.

When the calculated value is below 50, the LCD displays Status: NORMAL and the buzzer is switched OFF.

Serial Monitor also displays the calculated value and buzzer status at 9600 baud.

Important Technical Limitation: The supplied sensor image is named DHT11.png, but the sketch does not use a DHT11 library or digital humidity reading. The expression (voltage - 0.5) * 100.0 is not a valid formula for calculating relative humidity from a DHT11. The resulting value must not be treated as measured relative humidity until the sensor and sketch are corrected.

Analog Input Reading

The source uses analogRead(A0) to obtain a value between 0 and 1023.

The value is converted to voltage using a 5V reference.

Voltage Formula:

voltage = sensorValue × 5.0 / 1023.0

Source Calculation

The sketch uses the following expression to calculate a variable called humidity.

Original Expression:

humidity = (voltage − 0.5) × 100.0

This expression is not a valid humidity conversion for a DHT11.

Threshold Comparison

The calculated value is compared against a constant of 50.0.

Values below 50 select the NORMAL program branch.

Values of 50 or higher select the HIGH warning branch.

LCD and Buzzer Operation

The first LCD row displays the calculated value with a percent sign.

The second LCD row displays NORMAL or HIGH status.

When the HIGH branch is active, the sketch calls tone() with a frequency of 1000 Hz.

When the NORMAL branch is active, noTone() turns the buzzer OFF.

Programmed Threshold 50
Below Threshold NORMAL · Buzzer OFF
At / Above Threshold HIGH · Buzzer ON
Update Interval 500 ms
Measurement Warning: The operating logic above describes what the supplied code does. The displayed percentage is not verified relative humidity when the listed sensor is DHT11.

Procedure

  1. Place Arduino UNO, the humidity sensor, LCD, buzzer and breadboard on a stable working surface.
  2. Confirm the exact sensor model and its pin configuration.
  3. Check whether the sensor provides a digital data signal or an analog output.
  4. For the listed DHT11, use an appropriate digital humidity-reading program rather than the supplied analog formula.
  5. Connect the sensor VCC to its rated supply.
  6. Connect sensor GND to Arduino GND.
  7. Connect the sensor data output to the pin selected in the verified sensor code.
  8. Connect the LCD VCC to a compatible supply.
  9. Connect LCD GND to Arduino GND.
  10. Connect LCD SDA to Arduino A4.
  11. Connect LCD SCL to Arduino A5.
  12. Connect buzzer positive to D8 if the buzzer is suitable for direct pin drive.
  13. Connect buzzer negative to GND.
  14. Verify all wiring and electrical ratings.
  15. Open Arduino IDE.
  16. Install a compatible LiquidCrystal_I2C library.
  17. If using a DHT11, install a suitable DHT sensor library and update the sketch to read digital humidity.
  18. Create a sketch named Humidity_Based_Warning_System.ino.
  19. Review the original program in Explore the Code.
  20. Use the original sketch only for studying its analog-value threshold logic; correct the sensor reading before real humidity testing.
  21. Select Arduino Uno and the correct communication port.
  22. Verify and upload a sensor-compatible Arduino program.
  23. Open Serial Monitor at 9600 baud.
  24. Observe the LCD reading and status.
  25. Test the warning threshold using valid sensor readings or controlled test data.
  26. Confirm that the buzzer activates when the measured humidity reaches the configured threshold in the corrected program.

Result

The supplied Humidity-Based Warning System sketch demonstrates analog-value calculation, LCD display and buzzer activation using a programmed threshold.

The control logic displays NORMAL below the threshold and HIGH when the calculated value reaches or exceeds 50.

However, valid humidity monitoring with the listed DHT11 requires a corrected digital sensor-reading program.
