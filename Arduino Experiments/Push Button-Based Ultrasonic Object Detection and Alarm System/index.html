Aim

Use a push button to start ultrasonic object detection with LED and buzzer alarm.

About the Experiment

Use a push button to start ultrasonic object detection with LED and buzzer alarm. This practical demonstrates sensor interfacing, digital and analog input/output and Arduino programming.

Components Required

Working Principle

Push button → Ultrasonic reading → Compare with 20 cm → LED and buzzer alarm

Procedure

  1. Place the components on a breadboard and check the connections table.
  2. Connect the components to the Arduino UNO R3 using jumper wires.
  3. Open Arduino IDE, select Arduino UNO and install the libraries used in the code.
  4. Verify and upload the program.
  5. Observe the output and test the experiment's input conditions.
