Multi-Level Elevator Simulator

← Arduino Experiments Aim Components Connections Circuit Working Procedure Code Result

Aim

To simulate a multi-floor elevator using a 4×4 keypad, 28BYJ-48 stepper motor, ULN2003 driver and a 1-digit common-cathode 7-segment display.

About the Experiment

The user selects a floor number on the 4×4 keypad. The Arduino compares the target floor with the current floor and calculates the required motor steps.

The ULN2003 drives the 28BYJ-48 stepper motor while the 7-segment display shows the selected/current floor.

Procedure

  1. Connect keypad rows R1–R4 to D2–D5 and columns C1–C4 to D6–D9.
  2. Connect ULN2003 IN1–IN4 to D10–D13, VCC to 5V and GND to GND.
  3. Plug the 28BYJ-48 5-wire connector into the ULN2003 motor socket.
  4. Connect 7-segment a–f to A0–A5 and g to D0, each through a 220Ω resistor; connect common cathode to GND.
  5. Install the Keypad library. The sketch also uses the Stepper library.
  6. Upload the program.
  7. Press a numeric keypad key to select a floor and observe motor movement and display.
  8. Calibrate STEPS_PER_FLOOR from the starting value of 512 to suit the mechanical model.

Expected Output

At power-up the display shows floor 0. Pressing a numeric key moves the stepper by the calculated floor difference and updates the display.

Result

The simulator successfully accepts floor selections, drives the stepper motor and displays the selected/current floor.
