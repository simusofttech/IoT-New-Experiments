Aim

To simulate the movement of a multi-floor elevator using Arduino UNO, a 4×4 matrix keypad, a 28BYJ-48 stepper motor, a ULN2003 motor driver and a single-digit common-cathode 7-segment display.

The user selects a destination floor using the keypad. Arduino calculates the required movement relative to the current floor and commands the stepper motor accordingly.

About the Experiment

The Multi-Level Elevator Simulator demonstrates the basic control logic of an elevator using an Arduino-based electromechanical model.

A 4×4 matrix keypad is used to enter a destination floor. The numeric keys 0–9 represent the available floor numbers.

The selected floor is compared with the current floor stored in Arduino memory.

If the requested floor is greater than the current floor, the stepper motor is commanded to rotate in one direction.

If the requested floor is lower than the current floor, the motor is commanded to rotate in the opposite direction.

The 28BYJ-48 stepper motor is controlled through a ULN2003 motor driver.

A one-digit 7-segment display shows the selected destination floor during motor movement. When movement completes, the program records that floor as the current floor.

The simulation starts at Floor 0 and uses an initial calibration of 512 motor steps per floor.

This step value can be adjusted to match the movement required by the particular elevator model.

Important: The experiment does not include a physical floor sensor, home switch or motor encoder. Arduino assumes that the motor completes every commanded step. Therefore, the displayed and stored floor may differ from the actual mechanical position if the motor stalls or slips.

Important Hardware Precautions:

The seven display segments each require an individual current-limiting resistor. Connect all designated common-cathode pins to GND according to the actual display's datasheet.

The physical pin numbers of a 7-segment display are not necessarily arranged in a–g order. Verify the exact model before connecting.

D0 is Arduino's hardware serial RX pin. Because the original sketch assigns segment g to D0, disconnecting the display signal during sketch uploading may be necessary if it interferes with programming.

Check the motor supply requirements before powering the ULN2003. Do not drive the stepper coils directly from Arduino digital pins.

Floor Selection

The keypad is scanned using the Keypad library. Only numeric keys between '0' and '9' are processed.

When a numeric key is pressed, Arduino converts that character into an integer floor number using:

int targetFloor = key - '0';

Floor Difference Calculation

Arduino calculates the difference between the requested floor and the current floor.

Formula:

Floor Difference = Target Floor − Current Floor

Required Steps = Floor Difference × 512

The sign of the calculated steps controls motor direction.

Stepper Motor Movement

The program uses the Stepper library to command a 28BYJ-48 motor through the ULN2003 driver module.

A positive step value commands movement in one direction, while a negative value commands movement in the opposite direction.

The motor speed is set to 10 RPM by the original sketch.

7-Segment Floor Display

The program contains a digitPattern array defining the segments needed to display digits 0–9.

The showDigit() function sets the seven segment pins HIGH or LOW according to the requested digit.

Because this is a common-cathode display, a HIGH signal activates an individual segment through its series resistor.

Important: The steps-per-floor value is a calibration constant. It must be adjusted according to the actual elevator model. The source does not specify a pulley, gear arrangement or mechanical dimensions from which a universal floor spacing could be calculated.

Procedure

  1. Place the Arduino UNO, 28BYJ-48 stepper motor, ULN2003 driver, 4×4 keypad and 7-segment display on the work surface.
  2. Connect keypad rows R1–R4 to Arduino D2, D3, D4 and D5.
  3. Connect keypad columns C1–C4 to Arduino D6, D7, D8 and D9.
  4. Connect the ULN2003 IN1 pin to D10.
  5. Connect ULN2003 IN2 to D11.
  6. Connect ULN2003 IN3 to D12.
  7. Connect ULN2003 IN4 to D13.
  8. Plug the 28BYJ-48 motor connector into the ULN2003 motor socket.
  9. Connect the ULN2003 to a suitable regulated motor supply.
  10. Connect the driver ground to Arduino GND.
  11. Verify the physical pinout of the common-cathode display.
  12. Connect display segments a–f to A0–A5 respectively, through individual 220Ω resistors.
  13. Connect segment g to D0 through a 220Ω resistor.
  14. Connect the display's common-cathode terminals to GND.
  15. Inspect the full circuit for incorrect polarity or shorts.
  16. Open Arduino IDE.
  17. Install the Keypad library and ensure the Stepper library is available.
  18. Create a sketch named Multi_Level_Elevator_Simulator.ino.
  19. Copy the complete Arduino sketch from Explore the Code.
  20. Select Arduino Uno and the correct communication port.
  21. Upload the program. If D0 wiring interferes with uploading, disconnect that signal during programming and reconnect it safely afterward.
  22. Observe the display showing Floor 0 at startup.
  23. Press 1 to select Floor 1 and observe stepper motor movement.
  24. Press 3 and observe the motor moving toward Floor 3.
  25. Press 1 again and observe reverse motor movement.
  26. Press the currently selected floor and observe that no additional movement is commanded.
  27. Check the actual mechanical travel for each floor.
  28. Adjust STEPS_PER_FLOOR if the motor travels too little or too far.
  29. Verify reliable operation at each floor with the mechanical system appropriately supported.

Explore more: Stepper Library

The Stepper library provides simple functions for controlling stepper motor movement.

setSpeed() specifies the requested speed, while step() commands a number of motor steps.

The original sketch uses 2048 steps per revolution in the library configuration.

Explore more: 7-Segment Display

A 7-segment display contains seven LED segments, identified as a, b, c, d, e, f and g.

Different combinations of illuminated segments create digits 0–9.

The digitPattern array stores the segment combinations needed to display each digit.

Explore more: Floor Calculation

currentFloor stores the last completed destination in software.

The difference between targetFloor and currentFloor is multiplied by STEPS_PER_FLOOR.

Positive and negative step counts command opposite directions.

Explore more: Open-Loop Control

The elevator simulator does not measure physical movement.

It assumes that the commanded number of motor steps was completed.

The currentFloor variable is therefore an estimated software position, not a measured floor.

Expected Output

At startup, the 7-segment display shows digit 0, indicating the initial software floor.

When the user presses a numeric keypad key, Arduino calculates the floor difference and commands the motor to move the corresponding number of steps.

The display immediately shows the requested destination floor. The motor then performs its commanded movement.

Important Output Notes:

The original sketch does not use Serial.begin() or Serial.println(). Therefore, no Serial Monitor output is expected.

The display changes to the destination digit before the stepper completes its movement. It is not a live floor-by-floor indicator during travel.

The actual motor movement must be verified and calibrated against the mechanical model.

Result

The Multi-Level Elevator Simulator demonstrates basic floor selection using an Arduino UNO, a 4×4 keypad, a 28BYJ-48 stepper motor, a ULN2003 driver and a single-digit 7-segment display.

Arduino calculates the difference between the selected and current software floors and commands the corresponding motor movement.

The selected destination is displayed on the 7-segment display. The experiment illustrates relative position control, user input processing and basic elevator movement logic.
