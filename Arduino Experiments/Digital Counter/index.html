Aim

To create a digital up/down counter using Arduino UNO, two push buttons and a single-digit common-anode 7-segment display.

The counter increases or decreases according to the button pressed and displays values from 0 to 9.

About the Experiment

Digital Counter is an Arduino-based experiment that demonstrates number counting using two push buttons and a 7-segment display.

The counter starts at zero. Pressing the UP button increases the value by one, while pressing the DOWN button decreases the value by one.

The updated number is displayed immediately on the common-anode 7-segment display.

The counter works within the single-digit range of 0 to 9. Increasing beyond 9 returns the value to 0.

Decreasing below 0 changes the value to 9.

The program also provides simple button debouncing and waits for each button to be released before accepting another press.

Key Concept: A common-anode 7-segment display uses LOW signals to turn individual segments ON and HIGH signals to turn them OFF.

UP Button Operation

Each valid UP button press increases the count by one. When the value exceeds 9, the count returns to 0.

DOWN Button Operation

Each valid DOWN button press decreases the count by one. When the value becomes less than 0, it changes to 9.

Display Operation

The program selects the correct 7-segment pattern through a switch-case statement. LOW turns a segment ON for the common-anode display.

Button Debouncing

The program waits 50 milliseconds after detecting a button press and checks the button again.

It then waits for the button to be released before allowing another counting operation.

Procedure

  1. Place the Arduino UNO and breadboard on a stable surface.
  2. Confirm that the display is a common-anode 7-segment display.
  3. Identify the display's physical segment pins A through G.
  4. Place the display on the breadboard.
  5. Connect segment A to D2 through a 220Ω resistor.
  6. Connect segment B to D3 through a 220Ω resistor.
  7. Connect segment C to D4 through a 220Ω resistor.
  8. Connect segment D to D5 through a 220Ω resistor.
  9. Connect segment E to D6 through a 220Ω resistor.
  10. Connect segment F to D7 through a 220Ω resistor.
  11. Connect segment G to D8 through a 220Ω resistor.
  12. Connect the display's applicable common-anode pins to 5V.
  13. Connect the UP button between A0 and GND.
  14. Connect the DOWN button between A1 and GND.
  15. Verify the display polarity and all circuit connections.
  16. Open Arduino IDE.
  17. Create a sketch named Digital_Counter.ino.
  18. Copy the complete program from Explore the Code.
  19. Select Arduino Uno and the correct communication port.
  20. Verify and upload the program.
  21. Confirm that the display starts at 0.
  22. Press the UP button and observe the count increasing.
  23. Press the DOWN button and observe the count decreasing.
  24. Verify wraparound from 9 to 0 and from 0 to 9.

Explore more: Common-Anode Display

A common-anode display uses a common positive connection.

A segment illuminates when its Arduino pin is driven LOW.

The supplied program turns off all segments before activating the selected digit pattern.

Explore more: Button Debouncing

Mechanical switches can produce several rapid transitions during one press.

A 50 ms delay followed by a second input check filters some of these transitions.

The program also waits for the button to be released before accepting another count.

Result

The Digital Counter experiment demonstrates up/down counting using Arduino UNO, two push buttons and a single-digit common-anode 7-segment display.

Pressing the UP button increases the displayed count, while pressing the DOWN button decreases it. The count cycles between 0 and 9.

The program also demonstrates button debouncing and waiting for button release.
