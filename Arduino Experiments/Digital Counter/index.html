Digital Counter

Aim

To create a digital up/down counter using Arduino UNO, two push buttons and a single-digit common-anode 7-segment display.

About the Experiment

The counter starts at 0. Pressing the UP button increases the count by one, while pressing the DOWN button decreases it by one.

The count is displayed on a single-digit common-anode 7-segment display. The counter cycles between 0 and 9, and the program includes button debounce and waits for button release before accepting another press.

Components Required

Arduino UNO R3 (×1)

Main controller for button input and display control.

Single-Digit 7-Segment Display (×1)

Displays the counter value from 0 to 9.

Push Button (×2)

One button increases the count and the other decreases it.

220Ω Resistor (×7)

Protects each segment of the 7-segment display.

Breadboard (×1)

Used for circuit assembly.

Used for electrical connections.

Procedure

  1. Connect display segment A to D2 through a 220Ω resistor.
  2. Connect display segment B to D3 through a 220Ω resistor.
  3. Connect display segment C to D4 through a 220Ω resistor.
  4. Connect display segment D to D5 through a 220Ω resistor.
  5. Connect display segment E to D6 through a 220Ω resistor.
  6. Connect display segment F to D7 through a 220Ω resistor.
  7. Connect display segment G to D8 through a 220Ω resistor.
  8. Connect the common anode of the display to 5V.
  9. Connect one side of the UP button to A0 and the opposite side to GND.
  10. Connect one side of the DOWN button to A1 and the opposite side to GND.
  11. Connect Arduino UNO to the computer.
  12. Open Arduino IDE.
  13. Enter the program given below.
  14. Select Arduino UNO and the correct COM port.
  15. Verify and upload the program.
  16. Press the UP and DOWN buttons and observe the displayed count.

Arduino Code

Digital_Counter.ino 
#define SEG_A 2
#define SEG_B 3
#define SEG_C 4
#define SEG_D 5
#define SEG_E 6
#define SEG_F 7
#define SEG_G 8

#define UP_BUTTON A0
#define DOWN_BUTTON A1

int count = 0;

void displayNumber(int n)
{
  // COMMON ANODE:
  // LOW = segment ON
  // HIGH = segment OFF

  digitalWrite(SEG_A, HIGH);
  digitalWrite(SEG_B, HIGH);
  digitalWrite(SEG_C, HIGH);
  digitalWrite(SEG_D, HIGH);
  digitalWrite(SEG_E, HIGH);
  digitalWrite(SEG_F, HIGH);
  digitalWrite(SEG_G, HIGH);

  switch (n)
  {
    case 0:
      digitalWrite(SEG_A, LOW);
      digitalWrite(SEG_B, LOW);
      digitalWrite(SEG_C, LOW);
      digitalWrite(SEG_D, LOW);
      digitalWrite(SEG_E, LOW);
      digitalWrite(SEG_F, LOW);
      break;

    case 1:
      digitalWrite(SEG_B, LOW);
      digitalWrite(SEG_C, LOW);
      break;

    case 2:
      digitalWrite(SEG_A, LOW);
      digitalWrite(SEG_B, LOW);
      digitalWrite(SEG_G, LOW);
      digitalWrite(SEG_E, LOW);
      digitalWrite(SEG_D, LOW);
      break;

    case 3:
      digitalWrite(SEG_A, LOW);
      digitalWrite(SEG_B, LOW);
      digitalWrite(SEG_C, LOW);
      digitalWrite(SEG_D, LOW);
      digitalWrite(SEG_G, LOW);
      break;

    case 4:
      digitalWrite(SEG_B, LOW);
      digitalWrite(SEG_C, LOW);
      digitalWrite(SEG_F, LOW);
      digitalWrite(SEG_G, LOW);
      break;

    case 5:
      digitalWrite(SEG_A, LOW);
      digitalWrite(SEG_C, LOW);
      digitalWrite(SEG_D, LOW);
      digitalWrite(SEG_F, LOW);
      digitalWrite(SEG_G, LOW);
      break;

    case 6:
      digitalWrite(SEG_A, LOW);
      digitalWrite(SEG_C, LOW);
      digitalWrite(SEG_D, LOW);
      digitalWrite(SEG_E, LOW);
      digitalWrite(SEG_F, LOW);
      digitalWrite(SEG_G, LOW);
      break;

    case 7:
      digitalWrite(SEG_A, LOW);
      digitalWrite(SEG_B, LOW);
      digitalWrite(SEG_C, LOW);
      break;

    case 8:
      digitalWrite(SEG_A, LOW);
      digitalWrite(SEG_B, LOW);
      digitalWrite(SEG_C, LOW);
      digitalWrite(SEG_D, LOW);
      digitalWrite(SEG_E, LOW);
      digitalWrite(SEG_F, LOW);
      digitalWrite(SEG_G, LOW);
      break;

    case 9:
      digitalWrite(SEG_A, LOW);
      digitalWrite(SEG_B, LOW);
      digitalWrite(SEG_C, LOW);
      digitalWrite(SEG_D, LOW);
      digitalWrite(SEG_F, LOW);
      digitalWrite(SEG_G, LOW);
      break;
  }
}

void setup()
{
  pinMode(SEG_A, OUTPUT);
  pinMode(SEG_B, OUTPUT);
  pinMode(SEG_C, OUTPUT);
  pinMode(SEG_D, OUTPUT);
  pinMode(SEG_E, OUTPUT);
  pinMode(SEG_F, OUTPUT);
  pinMode(SEG_G, OUTPUT);

  pinMode(UP_BUTTON, INPUT_PULLUP);
  pinMode(DOWN_BUTTON, INPUT_PULLUP);

  displayNumber(count);
}

void loop()
{
  if (digitalRead(UP_BUTTON) == LOW)
  {
    delay(50);

    if (digitalRead(UP_BUTTON) == LOW)
    {
      count++;

      if (count > 9)
      {
        count = 0;
      }

      displayNumber(count);

      while (digitalRead(UP_BUTTON) == LOW)
      {
        delay(10);
      }

      delay(100);
    }
  }

  if (digitalRead(DOWN_BUTTON) == LOW)
  {
    delay(50);

    if (digitalRead(DOWN_BUTTON) == LOW)
    {
      count--;

      if (count < 0)
      {
        count = 9;
      }

      displayNumber(count);

      while (digitalRead(DOWN_BUTTON) == LOW)
      {
        delay(10);
      }

      delay(100);
    }
  }
}

Expected Output

The display initially shows 0. Pressing the UP button increases the count, and pressing the DOWN button decreases the count.

UP Button: 0 → 1 → 2 → ... → 9 → 0
DOWN Button: 9 ← 0 when counting below zero
Display: Shows the current counter value from 0 to 9

Result

The Digital Counter experiment was implemented using Arduino UNO, two push buttons and a single-digit common-anode 7-segment display. The UP button increases the count and the DOWN button decreases it, with the displayed value cycling between 0 and 9.

What You Learn

  • How to control a common-anode 7-segment display.
  • How to display digits from 0 to 9.
  • How to use two push buttons with INPUT_PULLUP.
  • How to create an up/down counter.
  • How to wrap the count from 9 to 0 and from 0 to 9.
  • How to apply simple button debounce.
  • How to wait for button release before accepting the next input.
