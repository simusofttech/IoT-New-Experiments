Joystick-Controlled Servo Motor

Aim

Move a servo motor from 0° to 180° by moving the joystick horizontally.

About the Experiment

Move a servo motor from 0° to 180° by moving the joystick horizontally. This educational experiment demonstrates sensor input, microcontroller processing and output control.

Working Principle

Joystick X → Arduino A0 → 0°–180° angle → Servo D9

Procedure

  1. Gather the components and verify their pin labels.
  2. Connect the components as shown in the Circuit Connections table.
  3. Open Arduino IDE and select Arduino UNO.
  4. Enter the SOP sketch in the code section below.
  5. Verify and upload the code to the board.
  6. Test the input and observe the output response.

#include <Servo.h> Servo myServo; const int joystickX = A0;const int servoPin = 9; void setup() { myServo.attach(servoPin); myServo.write(90); // Start at center position} void loop() { // Read joystick X-axis int joystickValue = analogRead(joystickX); // Convert joystick value to servo angle int angle = map(joystickValue, 0, 1023, 0, 180); // Limit angle between 0 and 180 angle = constrain(angle, 0, 180); // Move servo myServo.write(angle); delay(15);}
