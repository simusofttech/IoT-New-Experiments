Aim

To develop a multi-sensor industrial warning panel using Arduino UNO, an MQ-2 gas sensor, a vibration sensor, a DHT11 temperature and humidity sensor, a 16×2 I²C LCD, a buzzer and two status LEDs.

The system continuously checks sensor readings and provides visual, audible and LCD-based warnings when the programmed conditions are detected.

About the Experiment

The Multi-Sensor Industrial Warning Panel demonstrates how different sensors can be integrated into one Arduino-based monitoring system.

The MQ-2 sensor provides an analog output related to gas or smoke detection. Arduino reads this output through analog input A0.

The vibration sensor provides a digital signal to Arduino pin D2. The program interprets a HIGH reading as a vibration alert.

The DHT11 sensor is connected to pin D4 and provides temperature and relative humidity readings.

Arduino compares the gas sensor reading with a raw analog threshold of 400.

It also compares the measured temperature against 40°C.

When all programmed conditions are normal, the green LED remains ON, the red LED and buzzer remain OFF, and the LCD displays SYSTEM NORMAL.

When gas, vibration or high temperature is detected, Arduino activates the red LED and buzzer and switches OFF the green LED.

The LCD displays the corresponding warning message according to the order of priority defined in the program.

If the DHT11 cannot return a valid temperature or humidity reading, the system enters a warning state and displays DHT11 Error.

Valid sensor readings are printed to Serial Monitor at 9600 baud.

Important: The original sketch monitors humidity but does not define a humidity alarm threshold. The MQ-2 value represents the sensor's raw analog reading, not a calibrated gas concentration in ppm. The project is an educational warning panel, not a certified gas, fire or industrial safety monitoring system.

Vibration Module: The sketch assumes HIGH indicates a vibration event. Some digital vibration modules are active-LOW. Verify the particular module's actual output behavior before testing.

LCD: The code uses I²C address 0x27. Confirm the address and ensure the installed LCD library supports lcd.init().

Buzzer: The code drives D8 HIGH continuously while a warning is active. Use a suitable active buzzer or buzzer module. If its current exceeds Arduino pin limits, a suitable driver circuit is needed.

MQ-2: The sensor's heater requires adequate power and warm-up time. Verify the supply's current capability and avoid testing with unsafe gas exposure or flames.

Gas Sensor Monitoring

Arduino reads the MQ-2 analog output through A0.

The raw reading is compared with a threshold value of 400.

Gas Alert Condition:

gasValue > 400

This threshold is based on ADC counts. It must not be interpreted as 400 ppm.

Vibration Monitoring

The vibration sensor sends a digital signal to D2.

The original program treats HIGH as an active vibration event.

Vibration Alert Condition:

vibration == HIGH

If the selected module is active-LOW, the hardware or sketch logic needs verification.

Temperature Monitoring

The DHT11 returns temperature readings in degrees Celsius.

Arduino compares the reading with the programmed temperature threshold of 40°C.

High-Temperature Alert:

temperature > 40.0°C

Humidity Monitoring

Humidity is read from the DHT11 and displayed during normal operation.

Humidity is also printed to Serial Monitor.

The source sketch does not compare humidity against an alert threshold.

DHT11 Error Detection

The program uses isnan() to check for invalid DHT11 temperature or humidity readings.

If either reading is invalid, Arduino displays DHT11 Error and activates the red LED and buzzer.

Alarm Priority

More than one alert condition may be true at the same time.

The code uses an if / else if chain for LCD messages. This gives the display the following priority order:

1. DHT Error Invalid DHT11 reading
2. Gas Gas above threshold
3. Vibration Vibration signal HIGH
4. Temperature Temperature above 40°C
Important: Only one warning message is displayed at a time, even when multiple conditions are active. However, the red LED and buzzer remain ON whenever any programmed warning condition is true.

Procedure

  1. Place the Arduino UNO, MQ-2 gas sensor, vibration sensor, DHT11, LCD, LEDs and buzzer on a stable work surface.
  2. Connect the MQ-2 AO terminal to Arduino A0.
  3. Connect MQ-2 VCC and GND to a suitable 5V supply and ground.
  4. Connect the vibration module's digital output DO to D2.
  5. Connect the vibration sensor's supply and ground terminals according to its rating.
  6. Connect DHT11 DATA to Arduino D4.
  7. Connect the DHT11 power and ground terminals correctly.
  8. Verify whether the DHT11 module includes the necessary DATA pull-up resistor.
  9. Connect the LCD SDA pin to A4.
  10. Connect LCD SCL to A5.
  11. Connect LCD VCC and GND to a suitable supply and common ground.
  12. Connect the buzzer positive terminal to D8 if its current requirement permits direct drive.
  13. Connect buzzer negative to GND.
  14. Connect the red LED anode to D9 through a 220Ω resistor.
  15. Connect the green LED anode to D10 through a 220Ω resistor.
  16. Connect both LED cathodes to GND.
  17. Verify all connections, polarities and sensor supply ratings.
  18. Open Arduino IDE.
  19. Install the DHT sensor library, required dependencies and a compatible LiquidCrystal_I2C library.
  20. Create a sketch named Multi_Sensor_Industrial_Warning_Panel.ino.
  21. Copy the complete program from Explore the Code.
  22. Select Arduino Uno and the correct communication port.
  23. Verify and upload the sketch.
  24. Open Serial Monitor at 9600 baud.
  25. Observe the startup message displayed on the LCD.
  26. Allow the MQ-2 sensor to complete an appropriate warm-up period.
  27. Under normal conditions, observe the green LED ON and the red LED and buzzer OFF.
  28. Observe gas, vibration, temperature and humidity readings in Serial Monitor.
  29. Gently activate the vibration sensor and verify its digital output behavior.
  30. Test the warning logic with controlled sensor conditions or safely adjusted software thresholds.
  31. Confirm that the red LED and buzzer activate when a programmed alert condition is true.
  32. Confirm that the LCD displays the corresponding warning.
  33. Return all test conditions to normal and verify the normal status.

Explore more: MQ-2 Gas Sensor

The MQ-2 is a gas-sensitive sensor with a heating element.

Its analog output changes with sensor operating conditions and exposure to certain gases.

A reading above 400 triggers the programmed gas warning, but the reading is not directly a concentration in ppm.

Explore more: Analog and Digital Signals

The MQ-2 provides an analog reading through A0.

The vibration sensor provides a digital HIGH/LOW state through D2.

The DHT11 communicates digital temperature and humidity values through D4.

Explore more: Threshold Comparison

A threshold is a programmed boundary used to decide whether a condition should cause a warning.

This sketch uses gasValue > 400 and temperature greater than 40°C.

Both limits should be treated as experiment settings, not universal industrial standards.

Explore more: LCD Warning Priority

The program uses if and else if statements to select one message.

Gas is displayed before vibration, and vibration before temperature.

A DHT11 error is handled earlier and prevents the remaining alert logic from running in that loop.

Result

The Multi-Sensor Industrial Warning Panel demonstrates how Arduino UNO can integrate gas, vibration, temperature and humidity sensors into one monitoring experiment.

The system uses programmed thresholds and digital conditions to control a red LED, green LED, buzzer and LCD warning messages.

Sensor information is also sent to Serial Monitor for observation.

The experiment illustrates multi-sensor integration, threshold-based decisions, error detection and electronic status indication.
