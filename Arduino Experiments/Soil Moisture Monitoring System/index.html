Aim

To design and develop a Soil Moisture Monitoring System using Arduino UNO, an analog soil moisture sensor, a red LED, a green LED and a buzzer.

The system monitors soil moisture values and compares them with a programmed threshold to indicate dry and wet conditions through visual and audible signals.

About the Experiment

The Soil Moisture Monitoring System demonstrates how Arduino UNO reads an analog sensor and controls different indicators based on the reading.

The soil moisture sensor is inserted into the soil to detect changes in its electrical characteristics associated with moisture.

The module sends an analog signal to Arduino pin A0.

Arduino converts the analog signal into a digital number using analogRead().

For Arduino UNO, analogRead() typically returns a value between 0 and 1023.

The original sketch uses a threshold value of 600.

When the reading is greater than 600, Arduino interprets the soil as dry.

In this condition, the red LED and buzzer turn ON, while the green LED remains OFF.

When the reading is 600 or below, Arduino interprets the soil as wet.

In this condition, the green LED turns ON, while the red LED and buzzer remain OFF.

Arduino prints the sensor reading and the detected soil condition in Serial Monitor at 9600 baud.

The measurement cycle repeats every one second.

Important:

The supplied program assumes that higher analog values represent drier soil.

Actual sensor values depend on the sensor type, circuit and soil conditions.

The threshold of 600 should be calibrated using dry and moist soil samples before relying on the displayed condition.

This experiment does not contain a water pump or automatic irrigation system.

Analog Soil Moisture Measurement

The analog sensor output is connected to Arduino A0.

Arduino uses analogRead() to convert the sensor voltage into a numerical reading.

On Arduino UNO, the default 10-bit conversion range is 0 to 1023.

Dry Soil Condition

The source sketch classifies readings above 600 as dry.

Dry Soil Logic:

moistureValue > 600

Red LED = ON

Green LED = OFF

Buzzer = ON

Wet Soil Condition

If the reading is 600 or less, the sketch identifies the soil as wet.

Wet Soil Logic:

moistureValue <= 600

Red LED = OFF

Green LED = ON

Buzzer = OFF

Threshold Comparison

The dryThreshold variable is set to 600.

Arduino compares every new sensor reading against this fixed value.

The threshold is not automatically calibrated by the program.

Serial Monitoring

Arduino prints the analog reading and a message identifying the soil condition.

The code repeats this process every one second.

A0 Analog moisture input
600 Programmed threshold
9600 Serial baud rate
1 second Monitoring interval
Calibration Tip:

Test the sensor in dry and moist soil, record both analog readings, and confirm that the programmed threshold separates those conditions.

Different sensor modules may produce different ranges or an opposite response direction.

Procedure

  1. Place Arduino UNO, soil moisture sensor, red LED, green LED, two 220Ω resistors, buzzer and breadboard on the working surface.
  2. Connect the soil moisture sensor's VCC terminal to Arduino 5V.
  3. Connect the sensor GND to Arduino GND.
  4. Connect the sensor analog output AO to Arduino A0.
  5. Leave the digital DO terminal unconnected, if it exists.
  6. Connect the red LED anode to D8 through a 220Ω resistor.
  7. Connect the red LED cathode to GND.
  8. Connect the green LED anode to D9 through a separate 220Ω resistor.
  9. Connect the green LED cathode to GND.
  10. Connect the buzzer positive terminal to D10, if suitable for direct drive.
  11. Connect the buzzer negative terminal to GND.
  12. Verify all connections and component polarity.
  13. Open Arduino IDE.
  14. Create a sketch named Soil_Moisture_Monitoring_System.ino.
  15. Copy the complete Arduino code from Explore the Code.
  16. Select Arduino Uno and the correct port.
  17. Verify and upload the program.
  18. Open Serial Monitor at 9600 baud.
  19. Insert the sensing portion into dry soil.
  20. Observe the analog moisture value in Serial Monitor.
  21. If the reading is greater than 600, verify the red LED and buzzer response.
  22. Place the sensor in moist soil without immersing the controller electronics.
  23. Observe the new analog reading.
  24. If the reading is 600 or less, verify that the green LED turns ON and the buzzer turns OFF.
  25. Compare the readings obtained from dry and moist soil.
  26. Confirm that the sensor's actual response agrees with the sketch's threshold logic.
  27. Repeat the experiment with different moisture levels and record the results.

Result

The Soil Moisture Monitoring System demonstrates how Arduino UNO can read an analog soil moisture sensor and control visual and audible indicators.

The measured analog value is compared with a threshold of 600.

Readings above 600 activate the red LED and buzzer.

Readings at or below 600 activate the green LED.

Soil moisture readings and condition messages are printed to Serial Monitor, demonstrating analog sensor interfacing, threshold comparison and automatic indicator control.
