Aim

To develop an IR-based object detection alarm using Arduino UNO, a three-pin IR sensor module, a buzzer and a red LED.

When an object is detected, the buzzer sounds and the LED turns ON. When the object is not detected, both outputs remain OFF.

About the Experiment

The IR Beam Break Alarm experiment demonstrates how Arduino UNO responds to a digital signal from an infrared obstacle sensor.

The three-pin IR sensor module detects a nearby object using infrared light reflection.

A typical reflective IR module contains an infrared transmitter and infrared receiver.

Infrared light emitted by the transmitter may reflect from an object back to the receiver.

The module processes the received signal and provides a digital output to Arduino.

In the supplied experiment, the IR sensor's OUT terminal is connected to Arduino digital pin D2.

The program assumes that the sensor output becomes LOW when an object is detected.

When Arduino detects LOW, it turns ON the red LED connected to D9 and activates the buzzer connected to D8.

When the sensor output is HIGH, Arduino turns both components OFF.

The detected object status is also printed in Serial Monitor at 9600 baud.

Sensor Type: The uploaded source uses a three-pin reflective IR obstacle sensor. This is different from a true through-beam break sensor that uses separate transmitter and receiver units. This experiment detects nearby objects rather than measuring interruption of a separate IR beam.

Infrared Detection

A reflective IR sensor emits infrared light toward the detection area.

When an object is positioned within the sensor's detection range, some infrared light may reflect back toward the receiver.

The module processes the reflected signal to determine the state of its digital output.

Digital Input

Arduino reads the IR module's OUT terminal through digital pin D2.

The program uses digitalRead() to determine whether the signal is HIGH or LOW.

Object Detected

When the digital output becomes LOW, the program assumes an object has been detected.

Arduino drives pins D8 and D9 HIGH to activate the buzzer and LED.

No Object Detected

When the IR module returns HIGH, Arduino drives both outputs LOW and the alarm turns OFF.

Procedure

  1. Place Arduino UNO, the IR sensor, buzzer, LED and breadboard on the working surface.
  2. Identify the three IR sensor terminals: VCC, GND and OUT.
  3. Verify the sensor's operating voltage.
  4. Connect the IR sensor VCC to Arduino 5V if compatible.
  5. Connect the IR sensor GND to Arduino GND.
  6. Connect the IR sensor OUT terminal to digital pin D2.
  7. Identify the positive and negative terminals of the buzzer.
  8. Check that the buzzer is suitable for direct Arduino pin drive.
  9. Connect buzzer positive to digital pin D8 if suitable.
  10. Connect buzzer negative to Arduino GND.
  11. Place the red LED on the breadboard.
  12. Connect the red LED anode to D9 through a 220Ω resistor.
  13. Connect the red LED cathode to Arduino GND.
  14. Check the complete circuit and component polarity.
  15. Open Arduino IDE.
  16. Create a new sketch named IR_Beam_Break_Alarm.ino.
  17. Copy the complete Arduino program from Explore the Code.
  18. Select Arduino Uno and the correct communication port.
  19. Verify and upload the program.
  20. Open Serial Monitor at 9600 baud.
  21. Keep the detection area clear and observe the outputs.
  22. Move an object toward the IR sensor.
  23. Observe the red LED and buzzer when detection occurs.
  24. Remove the object from the detection area.
  25. Confirm that the LED and buzzer switch OFF.
  26. Compare the responses with the status messages in Serial Monitor.

Expected Output

When no object is detected, the IR sensor's output is expected to be HIGH.

The red LED remains OFF and the buzzer does not sound.

When an object enters the detection range, the sensor output becomes LOW.

Arduino activates the buzzer and illuminates the red LED.

When the object moves away, the sensor returns HIGH and both outputs turn OFF.

Result

The IR Beam Break Alarm experiment demonstrates object detection using Arduino UNO and a digital IR sensor module.

The program turns ON a red LED and buzzer when the IR sensor reports object detection.

Both outputs turn OFF when the sensor reports no object, while Serial Monitor displays the corresponding status.
