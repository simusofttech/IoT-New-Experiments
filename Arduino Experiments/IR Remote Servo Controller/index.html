Aim

To control the angular position of a servo motor using an IR remote, IR receiver and Arduino UNO.

About the Experiment

In this experiment, the IR remote sends commands to an IR receiver connected to the Arduino UNO. Arduino reads the received command and moves the servo motor to a predefined angle.

The program uses five remote buttons to move the servo to 0°, 45°, 90°, 135° and 180°.

Procedure

  1. Connect the IR receiver signal pin to Arduino digital pin 11.
  2. Connect the servo signal wire to Arduino digital pin 9.
  3. Connect the IR receiver and servo VCC pins to 5V.
  4. Connect all GND connections to Arduino GND.
  5. Connect the Arduino UNO to the computer using the USB cable.
  6. Open Arduino IDE.
  7. Install the IRremote library if required.
  8. Enter the program given below.
  9. Select Arduino UNO from Tools → Board.
  10. Select the correct COM port.
  11. Verify and upload the program.
  12. Open Serial Monitor at 9600 baud.
  13. Press the remote buttons and observe the servo position.

Arduino Code

IR_Remote_Servo_Controller.ino 
#include <IRremote.hpp>
#include <Servo.h>

#define IR_RECEIVE_PIN 11
#define SERVO_PIN 9

Servo myServo;

void setup()
{
  Serial.begin(9600);

  // Start IR Receiver
  IrReceiver.begin(IR_RECEIVE_PIN, ENABLE_LED_FEEDBACK);

  // Attach Servo
  myServo.attach(SERVO_PIN);

  // Initial servo position
  myServo.write(90);

  Serial.println("IR Remote Servo Controller Ready");
}

void loop()
{
  if (IrReceiver.decode())
  {
    byte command = IrReceiver.decodedIRData.command;

    Serial.print("Command = ");
    Serial.println(command);

    switch(command)
    {
      // Button 1
      case 16:
        myServo.write(0);
        Serial.println("Servo Angle = 0 degrees");
        break;

      // Button 2
      case 17:
        myServo.write(45);
        Serial.println("Servo Angle = 45 degrees");
        break;

      // Button 3
      case 18:
        myServo.write(90);
        Serial.println("Servo Angle = 90 degrees");
        break;

      // Button 4
      case 20:
        myServo.write(135);
        Serial.println("Servo Angle = 135 degrees");
        break;

      // Button 5
      // Replace 21 with the actual command for button 5
      case 21:
        myServo.write(180);
        Serial.println("Servo Angle = 180 degrees");
        break;
    }

    delay(200);

    // Ready for next IR command
    IrReceiver.resume();
  }
}
The uploaded experiment notes mention that the command for Button 5 may need to be replaced with the actual command value used by your IR remote.

Result

The IR Remote Servo Controller experiment was successfully implemented. The servo motor moves to predefined angles according to the commands received from the IR remote.
