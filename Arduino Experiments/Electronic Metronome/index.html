Electronic Metronome

← Arduino Experiments Aim Components Connections Circuit Working Procedure Code Result

Aim

To create an electronic metronome using Arduino UNO, a 10 kΩ potentiometer, two push buttons and an active buzzer, with adjustable tempo from 40 to 200 BPM.

About the Experiment

The potentiometer controls the metronome tempo between 40 and 200 BPM. Two push buttons are used to increase or decrease the BPM in steps of 5.

Arduino calculates the interval between beats and activates the buzzer for a short beep at the selected tempo. The current BPM can also be viewed in the Serial Monitor.

Procedure

  1. Connect the potentiometer left pin to 5V.
  2. Connect the potentiometer middle pin (wiper) to A0.
  3. Connect the potentiometer right pin to GND.
  4. Connect the increase push button between D2 and GND.
  5. Connect the decrease push button between D3 and GND.
  6. Connect the active buzzer positive terminal to D8.
  7. Connect the buzzer negative terminal to GND.
  8. Connect Arduino UNO to the computer.
  9. Open Arduino IDE.
  10. Enter the code given below.
  11. Select Arduino UNO from Tools → Board.
  12. Select the correct COM port.
  13. Verify and upload the program.
  14. Open Serial Monitor at 9600 baud.
  15. Rotate the potentiometer or use the buttons to adjust the tempo.

Arduino Code

Electronic_Metronome.ino 
// ========================================
// Electronic Metronome
// Arduino UNO R3
// ========================================

const int buttonUp = 2;
const int buttonDown = 3;

const int potPin = A0;
const int buzzer = 8;

int bpm = 80;

unsigned long lastBeat = 0;
unsigned long lastButtonTime = 0;

const unsigned long debounceTime = 200;

void setup() {

  pinMode(buttonUp, INPUT_PULLUP);
  pinMode(buttonDown, INPUT_PULLUP);

  pinMode(buzzer, OUTPUT);
  digitalWrite(buzzer, LOW);

  Serial.begin(9600);

  Serial.println("Electronic Metronome");
  Serial.print("BPM: ");
  Serial.println(bpm);
}

void loop() {

  // Potentiometer controls BPM
  int potValue = analogRead(potPin);
  bpm = map(potValue, 0, 1023, 40, 200);

  // Increase BPM button
  if (digitalRead(buttonUp) == LOW) {
    if (millis() - lastButtonTime > debounceTime) {
      bpm = bpm + 5;
      if (bpm > 200) {
        bpm = 200;
      }

      lastButtonTime = millis();

      Serial.print("BPM: ");
      Serial.println(bpm);
    }
  }

  // Decrease BPM button
  if (digitalRead(buttonDown) == LOW) {
    if (millis() - lastButtonTime > debounceTime) {
      bpm = bpm - 5;
      if (bpm < 40) {
        bpm = 40;
      }

      lastButtonTime = millis();

      Serial.print("BPM: ");
      Serial.println(bpm);
    }
  }

  // Calculate beat interval
  unsigned long interval = 60000UL / bpm;

  // Generate metronome beat
  if (millis() - lastBeat >= interval) {
    lastBeat = millis();

    digitalWrite(buzzer, HIGH);
    delay(70);
    digitalWrite(buzzer, LOW);
  }
}

Expected Output

The buzzer produces short, evenly spaced beeps according to the selected BPM. Rotating the potentiometer changes the tempo between 40 and 200 BPM.

Potentiometer: 40–200 BPM
D2 Button: Increase BPM by 5
D3 Button: Decrease BPM by 5
Serial Monitor: Displays current BPM

Result

The Electronic Metronome experiment was implemented using Arduino UNO, two push buttons, a 10 kΩ potentiometer and an active buzzer. The buzzer produces beats according to the selected tempo.
