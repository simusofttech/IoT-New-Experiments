Aim

To create an electronic metronome using Arduino UNO, a 10 kΩ potentiometer, two push buttons and an active buzzer.

The experiment demonstrates tempo adjustment between 40 and 200 beats per minute (BPM) and generation of regularly spaced audible beats.

About the Experiment

The Electronic Metronome demonstrates how Arduino UNO can generate rhythmic beats at a selected tempo.

A 10 kΩ potentiometer provides an adjustable analog signal to Arduino A0.

Arduino converts the potentiometer reading into a BPM value from 40 to 200.

Two push buttons are connected to D2 and D3. They are programmed to increase or decrease the BPM by 5.

Arduino calculates the interval between beats using the selected BPM.

An active buzzer connected to D8 produces a short 70-millisecond beep whenever the beat interval is reached.

The initial BPM and button-adjusted BPM values are printed in Serial Monitor at 9600 baud.

Code Behavior: In the original sketch, BPM is recalculated from the potentiometer at the start of every loop. Consequently, a button's +5 or −5 adjustment is overwritten on the next loop. The supplied program has been preserved unchanged. Permanent button-based tempo adjustment would require a code change.

Tempo Selection

The potentiometer controls the base tempo. Arduino maps its analog value from 0–1023 to 40–200 BPM.

Button Adjustment

Button D2 increases BPM by 5, while Button D3 decreases BPM by 5.

Each button action is limited by a 200-millisecond timing check in the program.

However, the next loop recalculates BPM from the potentiometer, so the adjustment does not remain stored.

Beat Interval Calculation

Formula:

Beat Interval (ms) = 60000 / BPM

BPM Beat Interval
40 1500 ms
60 1000 ms
80 750 ms
120 500 ms
200 300 ms

Buzzer Operation

Arduino compares the current millis() value with the previous beat time.

When the interval is reached, it turns the buzzer ON for 70 milliseconds and then turns it OFF.

Procedure

  1. Place Arduino UNO, the potentiometer, push buttons, buzzer and breadboard on the working surface.
  2. Identify the three potentiometer terminals.
  3. Connect its left terminal to Arduino 5V.
  4. Connect the middle terminal (wiper) to A0.
  5. Connect its right terminal to GND.
  6. Connect the Increase push button between D2 and GND.
  7. Connect the Decrease push button between D3 and GND.
  8. Verify the buzzer's electrical requirements.
  9. Connect the buzzer positive terminal to D8 if suitable for direct pin drive.
  10. Connect its negative terminal to GND.
  11. Check all circuit connections.
  12. Open Arduino IDE.
  13. Create a sketch named Electronic_Metronome.ino.
  14. Copy the complete Arduino program from Explore the Code.
  15. Select Arduino Uno and the correct port.
  16. Verify and upload the program.
  17. Open Serial Monitor at 9600 baud.
  18. Rotate the potentiometer slowly to change the metronome tempo.
  19. Observe how frequently the buzzer beeps.
  20. Press the Increase and Decrease buttons and observe their temporary BPM adjustments.
  21. Compare the audible beat intervals at lower and higher BPM.

Expected Output

The buzzer generates short beats according to the selected BPM.

Rotating the potentiometer changes the tempo within the range 40–200 BPM.

Button presses can temporarily change the BPM calculation by +5 or −5.

Result

The Electronic Metronome experiment demonstrates rhythmic beat generation using Arduino UNO, a potentiometer, two push buttons and an active buzzer.

Arduino reads the potentiometer, calculates a BPM value and activates the buzzer at the corresponding time intervals.
