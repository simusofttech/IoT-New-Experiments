Aim

To design and develop a Morse Code Translator using Arduino UNO R3, a Push Button, LED, Buzzer and 16×2 I2C LCD Display.

The system converts short and long button presses into Morse code symbols and translates the entered patterns into English letters.

The decoded text is displayed on the LCD, while an LED and buzzer provide visual and audible feedback.

About the Experiment

Morse code is a communication system that represents letters using combinations of short signals called dots and long signals called dashes.

In this experiment, a push button is used to enter Morse code symbols manually.

The Arduino measures the duration of each button press. A short press represents a dot (.), while a long press represents a dash (-).

The Arduino stores the entered symbols and compares them with a Morse code reference table.

After a pause of approximately two seconds, the entered Morse pattern is converted into the corresponding English letter.

A longer pause of approximately five seconds is interpreted as a space between words.

The LCD shows the current Morse pattern and the most recently decoded text.

The complete recent decoded text is also printed to the Serial Monitor.

Timing Settings:
  • Short Press: Less than 400 ms
  • Long Press: 400 ms or more
  • Letter Gap: 2000 ms
  • Word Gap: 5000 ms

Important Pin Summary:
  • Push Button → A0 to GND
  • LED → D7 through 220Ω
  • Buzzer → D8
  • LCD SDA → A4
  • LCD SCL → A5
  • LCD I2C Address → 0x27

All circuit components must share a common GND.

Electrical Precautions:

Disconnect power before changing any circuit connections. Observe LED and buzzer polarity.

Use a low-current active buzzer compatible with direct Arduino GPIO drive. If the buzzer requires more current, use a suitable driver.

The LCD commonly uses I2C address 0x27, but some modules use 0x3F. Confirm the address when required.

The Arduino measures how long the button remains pressed and converts the duration into a dot or dash.

Dot and Dash Detection

Presses shorter than 400 ms are recognized as dots. Presses lasting 400 ms or longer are recognized as dashes.

Letter Decoding

After a two-second pause, the Arduino compares the stored Morse pattern with its lookup table and identifies the corresponding letter from A to Z.

Word Separation

If no additional symbol is entered for five seconds, a space is added between words.

LCD Display

The first row displays the current Morse pattern. The second row displays the most recently decoded text.

Procedure

  1. Place the Arduino UNO and breadboard on a stable surface.
  2. Connect one push button terminal to Arduino A0.
  3. Connect the other switched button terminal to GND.
  4. Connect the LED anode to D7 through a 220Ω resistor.
  5. Connect the LED cathode to Arduino GND.
  6. Connect the buzzer positive terminal to D8.
  7. Connect the buzzer negative terminal to GND.
  8. Connect the LCD VCC to Arduino 5V.
  9. Connect the LCD GND to Arduino GND.
  10. Connect LCD SDA to A4.
  11. Connect LCD SCL to A5.
  12. Verify all circuit connections.
  13. Open Arduino IDE.
  14. Install the LiquidCrystal_I2C library compatible with lcd.init() and lcd.backlight().
  15. Create a sketch named Morse_Code_Translator.ino.
  16. Copy the complete program from Explore the Code.
  17. Select Arduino Uno under Tools → Board.
  18. Select the correct communication port.
  19. Verify and upload the program.
  20. Open Serial Monitor at 9600 baud.
  21. Press the button briefly and release it to enter a dot.
  22. Hold the button longer than 400 ms to enter a dash.
  23. Wait approximately two seconds after completing a Morse pattern.
  24. Observe the decoded letter on the LCD.
  25. Enter additional letters to form a word.
  26. Wait approximately five seconds to add a space between words.

Result

The Morse Code Translator demonstrates how Arduino UNO can measure push button press duration and convert the resulting dot and dash patterns into English letters.

The entered Morse pattern and decoded text are displayed on the 16×2 I2C LCD.

The LED and buzzer provide visual and audible feedback during button presses.

Letters can be combined into words by using the configured letter and word pauses.
