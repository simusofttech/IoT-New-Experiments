Mini Morse Code Trainer

← Arduino Experiments Aim Components Connections Working Procedure Code Result

Aim

To create a simple Morse code trainer using Arduino UNO, a push button, LED and buzzer.

About the Experiment

The push button is used to enter Morse code. Arduino checks how long the button is pressed.

A short press is treated as a dot (.) and a long press is treated as a dash (-). The LED and buzzer turn ON while the button is pressed.

Procedure

  1. Connect the push button between A0 and GND.
  2. Connect the LED anode to D7 through a 220Ω resistor.
  3. Connect the LED cathode to GND.
  4. Connect the buzzer positive terminal to D8 and negative terminal to GND.
  5. Upload the Arduino code.
  6. Open Serial Monitor at 9600 baud.
  7. Try short and long button presses.

Arduino Code

Mini_Morse_Code_Trainer.ino 
// Pin connections
int button = A0;
int led = 7;
int buzzer = 8;

// 400 milliseconds separates dot and dash
int dotDashTime = 400;

void setup()
{
  pinMode(button, INPUT_PULLUP);
  pinMode(led, OUTPUT);
  pinMode(buzzer, OUTPUT);

  Serial.begin(9600);
}

void loop()
{
  // Check if button is pressed
  if (digitalRead(button) == LOW)
  {
    // Remember start time
    unsigned long startTime = millis();

    // Turn LED and buzzer ON
    digitalWrite(led, HIGH);
    tone(buzzer, 1000);

    // Wait until button is released
    while (digitalRead(button) == LOW)
    {
      delay(5);
    }

    // Turn LED and buzzer OFF
    digitalWrite(led, LOW);
    noTone(buzzer);

    // Calculate how long the button was pressed
    unsigned long pressTime = millis() - startTime;

    // Short press = dot
    if (pressTime < dotDashTime)
    {
      Serial.println(".");
    }
    else
    {
      // Long press = dash
      Serial.println("-");
    }

    delay(100);
  }
}

Expected Output

A short button press prints a dot (.) and a long button press prints a dash (-). The LED and buzzer remain ON while the button is pressed.

Result

The Mini Morse Code Trainer experiment successfully distinguishes short and long button presses and converts them into Morse code dots and dashes.
