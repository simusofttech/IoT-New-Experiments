Joystick-Controlled Two Servo Motors

Aim

Control two servo motors independently using the X and Y axes of an analog joystick.

About the Experiment

Control two servo motors independently using the X and Y axes of an analog joystick. This educational experiment demonstrates sensor input, microcontroller processing and output control.

Components Required

Arduino UNO R3Quantity: 1
Analog Joystick ModuleQuantity: 1
SG90 Servo MotorQuantity: 2
BreadboardQuantity: 1
Jumper WiresQuantity: As required

Circuit Connections

Joystick GNDGND
Joystick HORZA0
Joystick VERTA1
Servo 1 signalD9
Servo 2 signalD10
Servo V+Regulated 5V supply appropriate for both servos
Servo GNDCommon GND with Arduino

For physical hardware, two servos may exceed the Arduino's 5V output current. Use a suitable regulated servo supply with common ground.

Circuit Diagram

Working Principle

Joystick X/Y → Analog inputs A0/A1 → Angle mapping → Servos D9/D10

Procedure

  1. Gather the components and verify their pin labels.
  2. Connect the components as shown in the Circuit Connections table.
  3. Open Arduino IDE and select Arduino UNO.
  4. Enter the SOP sketch in the code section below.
  5. Verify and upload the code to the board.
  6. Test the input and observe the output response.

#include <Servo.h> Servo servoX;Servo servoY; const int joystickX = A0;const int joystickY = A1;const int servoXPin = 9;const int servoYPin = 10; void setup() { servoX.attach(servoXPin); servoY.attach(servoYPin); // Start both servos at center servoX.write(90); servoY.write(90); delay(500);} void loop() { int xValue = analogRead(joystickX); int yValue = analogRead(joystickY); int angleX = map(xValue, 0, 1023, 0, 180); int angleY = map(yValue, 0, 1023, 0, 180); angleX = constrain(angleX, 0, 180); angleY = constrain(angleY, 0, 180); servoX.write(angleX); servoY.write(angleY); delay(15);}
