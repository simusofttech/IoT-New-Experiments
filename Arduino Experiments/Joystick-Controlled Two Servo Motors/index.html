Aim

To control two SG90 servo motors independently using the horizontal and vertical movements of an analog joystick connected to Arduino UNO.

The joystick X-axis controls Servo X, while the Y-axis controls Servo Y.

Both joystick readings are converted into commanded servo angles between 0° and 180°.

About the Experiment

The Joystick-Controlled Two Servo Motors experiment demonstrates controlling two actuators using a single analog input device.

An analog joystick module contains two potentiometers that change resistance as the joystick moves along the horizontal and vertical axes.

The module produces two analog voltage signals called VRx and VRy.

These signals are connected to Arduino analog pins A0 and A1.

Arduino reads the joystick X and Y values using analogRead().

Each reading normally ranges from 0 to 1023 for an Arduino UNO operating with its default analog reference.

The map() function converts the readings into servo angle commands ranging from 0° to 180°.

Servo X is connected to digital pin D9, while Servo Y is connected to D10.

The Servo library generates position-control signals for both motors.

The joystick can therefore control the two servo positions independently and simultaneously.

On startup, Arduino commands both servos to their center positions of 90°.

Important: The supplied sketch does not use the joystick's built-in push-button switch (SW). Only the X and Y analog signals are used. The program also does not print readings to Serial Monitor.

Joystick Operation

The joystick contains two variable resistive elements arranged along perpendicular axes.

Horizontal movement changes the voltage from VRx, while vertical movement changes the voltage from VRy.

Reading Analog Signals

Arduino reads both analog signals using analogRead().

Each input is represented by an integer between 0 and 1023.

Converting Readings into Angles

The map() function converts the joystick reading into an angular command.

Source Formulas:

angleX = map(xValue, 0, 1023, 0, 180)

angleY = map(yValue, 0, 1023, 0, 180)

constrain() keeps each angle in the range 0–180.

Independent Servo Control

The X-axis reading controls Servo X through D9.

The Y-axis reading controls Servo Y through D10.

Moving the joystick diagonally changes both analog readings and commands both servos to move.

Joystick Left / Right Changes Servo X
Joystick Up / Down Changes Servo Y
Joystick Center Approximately 90° Each
Diagonal Movement Changes Both Servos
Actual Servo Position: The sketch commands angles between 0° and 180°, but the available movement depends on the servo model. Do not force either servo beyond its physical movement limits.

Procedure

  1. Place Arduino UNO, the analog joystick, two SG90 servos and breadboard on a stable surface.
  2. Identify the joystick pins: VCC, GND, VRx, VRy and SW.
  3. Connect joystick VCC to Arduino 5V.
  4. Connect joystick GND to Arduino GND.
  5. Connect the joystick horizontal output VRx to A0.
  6. Connect the joystick vertical output VRy to A1.
  7. Leave the joystick switch pin SW unconnected.
  8. Connect Servo X signal wire to D9.
  9. Connect Servo Y signal wire to D10.
  10. Connect both servo power terminals to a suitable regulated 5V supply.
  11. Connect both servo GND wires to common ground.
  12. Ensure the Arduino and servo supply share a common ground reference.
  13. Verify the servo supply current rating and check all connections.
  14. Open Arduino IDE.
  15. Ensure the Servo library is available.
  16. Create a sketch named Joystick_Controlled_Two_Servo_Motors.ino.
  17. Copy the complete Arduino program from Explore the Code.
  18. Select Arduino Uno and the correct communication port.
  19. Verify and upload the Arduino sketch.
  20. Observe both servos initially moving to the commanded 90° position.
  21. Move the joystick horizontally and observe Servo X.
  22. Move the joystick vertically and observe Servo Y.
  23. Move the joystick diagonally and observe both servos.
  24. Release the joystick and observe the resulting center positions.
  25. Repeat with different joystick positions to test smooth servo control.
