Aim

To control the brightness of a red LED according to the force applied to an FSR402 Force Sensitive Resistor using Arduino UNO R3.

The system measures the sensor signal through analog input A0 and uses PWM output D9 to adjust LED brightness.

About the Experiment

The Force Sensitive LED Controller demonstrates how Arduino can control LED brightness based on applied force.

The FSR402 is a force-sensitive resistor whose resistance changes when pressure is applied to its sensing surface.

The FSR402 and a 10 kΩ resistor form a voltage-divider circuit.

Arduino reads the voltage at the divider's junction using analog input A0.

The analogRead() function returns a digital value between 0 and 1023.

The map() function converts this value into a PWM brightness value between 0 and 255.

Arduino sends the calculated PWM value to digital pin D9 using analogWrite().

As the force on the sensor increases, the voltage at A0 generally increases, producing a brighter LED.

Serial Monitor displays both the raw FSR402 reading and calculated LED brightness value.

Important: The program maps the ADC reading directly to LED brightness. It does not calculate actual force in newtons or calibrated pressure. The relationship between applied force and sensor resistance is nonlinear, so the displayed values represent relative readings.

Force-Sensitive Resistance

The FSR402 changes its electrical resistance when force is applied to the sensing area.

As the resistance changes, the voltage at A0 changes because of the voltage-divider circuit.

Analog-to-Digital Conversion

Arduino UNO uses a 10-bit analog-to-digital converter for analogRead().

The resulting value ranges from 0 to 1023.

Brightness Mapping

The Arduino sketch maps the ADC reading to a PWM output value between 0 and 255.

Program Formula:

brightness = map(fsrValue, 0, 1023, 0, 255)

The constrain() function keeps the value within 0–255.

PWM Control

analogWrite() changes the duty cycle of the signal on pin D9.

A low duty cycle produces a dimmer LED, while a high duty cycle produces a brighter LED.

No / Low Force LED OFF or Very Dim
Light Force Low LED Brightness
Medium Force Medium LED Brightness
Higher Force Higher LED Brightness

Procedure

  1. Place Arduino UNO R3, the FSR402, resistors, red LED and breadboard on a stable surface.
  2. Identify the two FSR402 terminals.
  3. Connect the first FSR402 terminal to Arduino 5V.
  4. Connect the second FSR402 terminal to the A0 sensing junction.
  5. Connect one terminal of the 10 kΩ resistor to the same A0 junction.
  6. Connect the other 10 kΩ resistor terminal to Arduino GND.
  7. Connect the red LED anode to D9 through a 220Ω resistor.
  8. Connect the red LED cathode to Arduino GND.
  9. Verify all circuit connections and LED polarity.
  10. Open Arduino IDE.
  11. Create a sketch named Force_Sensitive_LED_Controller.ino.
  12. Copy the complete Arduino program from Explore the Code.
  13. Select Arduino Uno and the correct port.
  14. Verify and upload the Arduino program.
  15. Open Serial Monitor at 9600 baud.
  16. Observe the initial FSR reading and LED brightness.
  17. Apply gentle pressure to the FSR402.
  18. Observe the LED brightness increasing as force increases.
  19. Reduce the force applied to the sensor.
  20. Observe the LED becoming dimmer.
  21. Compare the sensor values and PWM brightness readings in Serial Monitor.
  22. Avoid bending or overloading the FSR402 beyond its manufacturer's recommended limits.

Explore more: FSR402 Voltage Divider

The FSR402 is a variable resistance sensor.

A 10 kΩ resistor is used with it to create a voltage-divider circuit.

The junction voltage is measured by Arduino A0.

Explore more: PWM Brightness

PWM stands for Pulse Width Modulation.

Arduino UNO supports PWM output on pin D9.

analogWrite() accepts values from 0 to 255.

A value of 0 means the output stays LOW. A value of 255 means the output stays HIGH.

Intermediate values change the duty cycle, producing different perceived LED brightness.

Expected Output

After Arduino starts, the LED brightness changes according to the FSR402 sensor reading.

Without significant force, the LED is normally OFF or very dim.

Applying additional force generally increases the raw sensor value and the calculated PWM brightness.

The program continuously displays the sensor reading and calculated brightness in Serial Monitor.

Result

The Force Sensitive LED Controller demonstrates LED brightness control using Arduino UNO and an FSR402 Force Sensitive Resistor.

Arduino reads the force-sensitive voltage through analog input A0, converts it into a PWM brightness value and controls the red LED through digital pin D9.

The sensor and brightness values are also displayed in Serial Monitor.
