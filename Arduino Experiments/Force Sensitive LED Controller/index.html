Force Sensitive LED Controller

← Arduino Experiments Aim Components Connections Circuit Working Procedure Code Result

Aim

To control the brightness of an LED according to the force applied to an FSR402 force-sensitive resistor using Arduino UNO.

About the Experiment

The FSR402 sensor changes its resistance according to the force applied to its surface.

Arduino reads the sensor value through analog pin A0 and converts that reading into a PWM brightness value for the LED connected to D9.

Components Required

Arduino UNO R3 (×1)

Main controller for reading force and controlling LED brightness.

FSR402 (×1)

Force-sensitive resistor used to detect applied pressure.

LED (×1)

Brightness changes according to the applied force.

10KΩ Resistor (×1)

Forms the voltage divider with the FSR402.

220Ω Resistor (×1)

Limits current through the LED.

Breadboard (×1)

Used for assembling the circuit.

Jumper Wires

Used for making electrical connections.

The FSR402 and 10KΩ resistor form a voltage divider. Arduino reads the divider output on A0.

Working Principle

Arduino Starts
↓
FSR402 continuously senses applied force
↓
Arduino reads the sensor value from A0
↓
Sensor value is mapped from 0–1023 to 0–255
↓
PWM output is sent to LED on D9
↓
More force → Higher sensor value
↓
Higher value → Brighter LED

Procedure

  1. Connect one terminal of the FSR402 to 5V.
  2. Connect the other FSR402 terminal to Arduino A0.
  3. Connect one terminal of the 10KΩ resistor to A0.
  4. Connect the other terminal of the 10KΩ resistor to GND.
  5. Connect the LED anode to D9 through a 220Ω resistor.
  6. Connect the LED cathode to GND.
  7. Connect Arduino UNO to the computer using USB.
  8. Open Arduino IDE.
  9. Enter the program given below.
  10. Select Arduino UNO from Tools → Board.
  11. Select the correct COM port.
  12. Verify and upload the program.
  13. Open Serial Monitor at 9600 baud.
  14. Apply different amounts of pressure to the FSR402.
  15. Observe the LED brightness and force value in Serial Monitor.

Arduino Code

Force_Sensitive_LED_Controller.ino 
// ======================================
// FORCE SENSITIVE LED CONTROLLER
// Arduino UNO R3 + FSR402
// ======================================

const int fsrPin = A0;
const int ledPin = 9;

void setup() {

  pinMode(ledPin, OUTPUT);

  Serial.begin(9600);
}

void loop() {

  // Read force from FSR402
  int forceValue = analogRead(fsrPin);

  // Display sensor value
  Serial.print("Force Value: ");
  Serial.println(forceValue);

  // Convert force value to LED brightness
  int brightness = map(forceValue, 0, 1023, 0, 255);

  // Keep brightness within valid range
  brightness = constrain(brightness, 0, 255);

  // Control LED brightness
  analogWrite(ledPin, brightness);

  delay(50);
}

Expected Output

The LED brightness changes according to the amount of force applied to the FSR402 sensor.

No force: LED OFF or very dim
Light pressure: LED becomes brighter
More pressure: LED brightness increases further
Serial Monitor: Displays the FSR402 sensor value

Result

The Force Sensitive LED Controller experiment was implemented using Arduino UNO and an FSR402 sensor. Greater applied force produces a higher analog reading and increases the LED brightness.
