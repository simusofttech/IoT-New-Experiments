Force Sensitive LED Controller

Arduino UNO practical experiment

Aim

To control the brightness of an LED according to the force applied to an FSR402 Force Sensitive Resistor using Arduino UNO R3.

About the Experiment

The FSR402 changes its resistance when pressure is applied to its sensing surface. The Arduino reads this change as an analog value using pin A0.

The analog sensor value is converted into a PWM value from 0 to 255. Arduino then uses PWM pin D9 to change the brightness of the red LED. More force produces a higher sensor value and therefore a brighter LED.

Circuit Connections

Procedure

  1. Place Arduino UNO R3, FSR402, resistors and the red LED on the breadboard setup.
  2. Connect one FSR402 terminal to 5V.
  3. Connect the second FSR402 terminal to the A0 sensing junction.
  4. Connect the 10KΩ resistor between the A0 sensing junction and GND.
  5. Connect the red LED anode to D9 through the 220Ω resistor.
  6. Connect the red LED cathode to GND.
  7. Open Arduino IDE and enter the program shown below.
  8. Select Arduino UNO and the correct port.
  9. Verify and upload the program.
  10. Open Serial Monitor at 9600 baud.
  11. Apply different pressure levels to the FSR402.
  12. Observe the sensor reading and corresponding LED brightness.

1. Define the pins

A0 is used for the FSR402 analog input, while D9 is used as the PWM output for the LED.

Explore more: FSR voltage divider

The FSR402 does not provide a direct voltage by itself. The 10KΩ resistor forms a voltage divider so Arduino can measure the change in resistance as a changing analog voltage on A0.

Expected Output

The red LED becomes brighter as more force is applied to the FSR402. Serial Monitor continuously displays the force sensor value and the calculated LED brightness.

No / very low force: LED OFF or very dim
Light pressure: LED glows at low brightness
More pressure: LED becomes brighter

Result

The Force Sensitive LED Controller was successfully implemented. The Arduino reads the FSR402 sensor and varies the LED brightness according to the amount of force applied.
