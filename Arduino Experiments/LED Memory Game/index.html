Aim

To develop an interactive LED Memory Game using Arduino UNO, four LEDs, four push buttons and a buzzer.

The player observes a randomly generated LED sequence and repeats the same sequence by pressing the corresponding push buttons.

The game increases in difficulty with each successful level, up to a maximum of 20 levels.

About the Experiment

The LED Memory Game is an interactive electronics experiment that tests the player's visual memory and ability to recognize repeating patterns.

Arduino controls four LEDs connected to digital pins D8, D9, D10 and D11.

Four push buttons, connected to pins D2 through D5, allow the player to enter a response.

Each button corresponds to one LED.

The buzzer connected to D12 produces different musical tones for sequence playback, correct answers, incorrect answers and game completion.

At the beginning, Arduino creates a random sequence of 20 LED identifiers, each ranging from 0 to 3.

The game begins with only the first LED in the sequence.

The player watches the flashing LED and presses the matching button.

If the response is correct, Arduino plays a success sound and advances to the next level.

Each higher level displays one additional LED in the sequence.

If any button is incorrect, the buzzer plays an error tone, all four LEDs flash, and the game starts again from Level 1 with a new sequence.

Successfully completing Level 20 triggers a winning animation and restarts the game with a new sequence.

Important: The push buttons use Arduino's internal INPUT_PULLUP resistors. Each button connects between its digital input pin and GND. A pressed button therefore reads LOW. No additional external pull-up resistors are required for the specified wiring.

LED Resistors: Each LED must have its own 220Ω resistor connected in series.

The source places the resistors between the LED cathodes and ground. A series resistor can also be placed on the anode side, but the circuit diagram should match the documented wiring.

Push Buttons: Verify which legs are internally connected on the four-pin buttons. Incorrect button orientation can cause an input to remain permanently LOW.

Random Sequence Generation

Arduino generates a sequence of twenty values using random(0, 4).

Each value corresponds to one of the four LEDs.

LED Selection:

0 → LED 1

1 → LED 2

2 → LED 3

3 → LED 4

The program initializes the pseudorandom generator using analogRead(A0). The randomness depends on the signal present at A0 and is not guaranteed to be unpredictable.

LED Sequence Display

The showSequence() function flashes the LEDs one at a time according to the stored sequence.

Each LED remains ON for 400 milliseconds and is followed by a 200 millisecond pause.

A different tone accompanies each LED identifier.

Player Input

The player repeats the sequence using the four push buttons.

Arduino waits for each button press, reads its index and compares it with the corresponding stored sequence value.

A correctly matched button briefly flashes its LED and produces a tone.

Incorrect Answer

When the player presses a wrong button, checkPlayerInput() returns false.

The program plays a 300 Hz error tone, flashes all four LEDs three times, resets the level to 1 and generates a new sequence.

Winning the Game

After completing Level 20, winGame() performs a three-cycle LED animation with ascending buzzer tones.

The game then generates a new sequence and restarts from Level 1.

Game Timing:

Sequence playback: 400 ms ON + 200 ms OFF per LED.

Correct input feedback: 200 ms LED ON, followed by 100 ms delay.

Debounce pause: 30 ms before waiting for button release.

Procedure

  1. Place Arduino UNO, four LEDs, four push buttons, four 220Ω resistors and the buzzer on the work surface.
  2. Place the LEDs in a clear row or square pattern on the breadboard.
  3. Connect LED 1 anode to Arduino D8.
  4. Connect LED 2 anode to Arduino D9.
  5. Connect LED 3 anode to Arduino D10.
  6. Connect LED 4 anode to Arduino D11.
  7. Connect each LED cathode to ground through its own 220Ω resistor.
  8. Connect Button 1 between D2 and GND.
  9. Connect Button 2 between D3 and GND.
  10. Connect Button 3 between D4 and GND.
  11. Connect Button 4 between D5 and GND.
  12. Connect the buzzer positive terminal to D12 if its electrical requirements permit direct drive.
  13. Connect buzzer negative to GND.
  14. Verify LED polarity, resistor positions and button terminal orientation.
  15. Open Arduino IDE.
  16. Create a sketch named LED_Memory_Game.ino.
  17. Copy the complete Arduino sketch from Explore the Code.
  18. Select Arduino Uno and the correct port.
  19. Verify and upload the program.
  20. Listen for the startup sound.
  21. Watch the first flashing LED carefully.
  22. Press its matching push button.
  23. If correct, observe the success sound and next level.
  24. Watch the longer sequence and repeat it using the buttons.
  25. Continue to higher levels by repeating each sequence correctly.
  26. Press an incorrect button intentionally to observe the error sound and flashing LEDs.
  27. Observe the game restarting at Level 1 with a new sequence.
  28. Continue playing to test the level progression and sound feedback.

The program stores twenty randomly selected LED identifiers in an array.

Each round displays only the first level number of elements in that array.

When the level increases, the player must repeat one extra element.

Explore more: INPUT_PULLUP

INPUT_PULLUP enables the Arduino's internal pull-up resistor.

An unpressed button normally reads HIGH.

When pressed, the corresponding input connects to GND and reads LOW.

Explore more: Button Debouncing

Mechanical push buttons can create rapid electrical transitions when pressed or released.

The sketch waits 30 milliseconds after detecting a LOW signal and then waits for the button to be released.

This is a simple delay-based approach. It is not a complete debouncing algorithm for every situation.

Explore more: Buzzer Tones

tone() generates a signal with a selected frequency.

The game assigns 500 Hz, 700 Hz, 900 Hz and 1100 Hz to the four LED identifiers.

Other tone patterns indicate success, failure and winning.

Expected Output

When Arduino starts, a short ascending startup tone sequence is produced.

After startup, one randomly selected LED flashes with its corresponding tone.

The player presses the matching button. If correct, the game plays a success sound and proceeds to Level 2.

Level 2 displays two LED flashes, and the player must press two matching buttons in the correct order.

Each level adds one more element to the displayed sequence.

Important: The original program contains no Serial.begin() or Serial.print() statements. It does not display scores or levels on Serial Monitor. All feedback is provided through the LEDs and buzzer. The player must remember the current level by observing the game sequence.

Result

The LED Memory Game experiment demonstrates an interactive memory game using Arduino UNO, four LEDs, four push buttons and a buzzer.

Arduino generates a random LED sequence and checks whether the player repeats the sequence correctly.

Correct answers increase the difficulty level, while incorrect answers trigger an error indication and restart the game.

The experiment demonstrates how digital inputs, digital outputs, arrays, loops, random numbers and sound generation can be combined to create an interactive electronic game.
