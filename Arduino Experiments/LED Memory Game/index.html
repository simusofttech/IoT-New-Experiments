Arduino Project No. 2

LED Memory Game

← Arduino Projects Aim Components Connections Circuit Working Procedure Code Result

Aim

To create an LED Memory Game using Arduino UNO, four LEDs, four push buttons and a buzzer, where the player watches an LED sequence and repeats the same sequence using the matching buttons.

About the Project

Arduino generates a random sequence using four LEDs. The player must remember the order and press the corresponding push buttons in the same sequence.

Each successful round increases the level and makes the sequence longer. A wrong button press activates the buzzer and restarts the game from Level 1.

Components Required

Arduino UNO R3 (×1)

Main controller for generating the sequence and checking player input.

LEDs (×4)

Display the memory sequence to the player.

Push Buttons (×4)

Used by the player to repeat the LED sequence.

Buzzer (×1)

Provides sound feedback for sequence, correct, wrong and win events.

220Ω Resistors (×4)

Limit current through the LEDs.

Breadboard (×1)

Used for assembling the circuit.

Jumper Wires

Used for making all electrical connections.

Procedure

  1. Connect LEDs 1 to 4 to Arduino pins D8, D9, D10 and D11.
  2. Connect each LED to GND through a 220Ω resistor.
  3. Connect push buttons 1 to 4 to Arduino pins D2, D3, D4 and D5.
  4. Connect the other terminal of each push button to GND.
  5. Connect the buzzer positive terminal to D12 and negative terminal to GND.
  6. Connect Arduino UNO to the computer.
  7. Open Arduino IDE.
  8. Enter the program given below.
  9. Select Arduino UNO from Tools → Board.
  10. Select the correct COM port.
  11. Verify and upload the program.
  12. Watch the LED sequence carefully.
  13. Press the matching buttons in the same order.
  14. Continue to the next level when the sequence is repeated correctly.

Arduino Code

LED_Memory_Game.ino 
// ======================================
// LED MEMORY GAME
// Arduino UNO R3
// ======================================

// LED pins
const int ledPins[] = {8, 9, 10, 11};

// Button pins
const int buttonPins[] = {2, 3, 4, 5};

// Buzzer pin
const int buzzerPin = 12;

// Maximum sequence length
const int maxLevel = 20;

// Stores the random LED sequence
int sequence[maxLevel];

// Current level
int level = 1;

// ======================================
// SETUP
// ======================================
void setup() {

  // Set LED pins as OUTPUT
  for (int i = 0; i < 4; i++) {
    pinMode(ledPins[i], OUTPUT);
    digitalWrite(ledPins[i], LOW);
  }

  // Set button pins as INPUT_PULLUP
  for (int i = 0; i < 4; i++) {
    pinMode(buttonPins[i], INPUT_PULLUP);
  }

  pinMode(buzzerPin, OUTPUT);
  digitalWrite(buzzerPin, LOW);

  // Randomize sequence
  randomSeed(analogRead(A0));

  // Create first sequence
  for (int i = 0; i < maxLevel; i++) {
    sequence[i] = random(0, 4);
  }

  // Start game
  delay(1000);
  playStartSound();
  delay(500);
}

// ======================================
// MAIN LOOP
// ======================================
void loop() {

  // Show the sequence to the player
  showSequence();

  delay(300);

  // Ask player to repeat sequence
  if (checkPlayerInput()) {

    // Correct answer
    correctSound();

    // Move to next level
    level++;

    // Maximum level reached
    if (level > maxLevel) {

      winGame();

      level = 1;

      // Create a new sequence
      for (int i = 0; i < maxLevel; i++) {
        sequence[i] = random(0, 4);
      }

      delay(1000);
    }

    delay(700);
  }

  else {

    // Wrong answer
    wrongSound();

    // Restart game
    level = 1;

    // Create a new sequence
    for (int i = 0; i < maxLevel; i++) {
      sequence[i] = random(0, 4);
    }

    delay(1000);
  }
}

// ======================================
// SHOW LED SEQUENCE
// ======================================
void showSequence() {

  for (int i = 0; i < level; i++) {

    int led = sequence[i];

    digitalWrite(ledPins[led], HIGH);

    tone(buzzerPin, 500 + (led * 200));

    delay(400);

    digitalWrite(ledPins[led], LOW);

    noTone(buzzerPin);

    delay(200);
  }
}

// ======================================
// CHECK PLAYER INPUT
// ======================================
bool checkPlayerInput() {

  for (int i = 0; i < level; i++) {

    int pressedButton = waitForButton();

    // Check if correct button was pressed
    if (pressedButton != sequence[i]) {
      return false;
    }

    // Show the selected LED
    digitalWrite(ledPins[pressedButton], HIGH);

    tone(buzzerPin, 500 + (pressedButton * 200));

    delay(200);

    digitalWrite(ledPins[pressedButton], LOW);

    noTone(buzzerPin);

    delay(100);
  }

  return true;
}

// ======================================
// WAIT FOR BUTTON
// ======================================
int waitForButton() {

  while (true) {

    for (int i = 0; i < 4; i++) {

      if (digitalRead(buttonPins[i]) == LOW) {

        delay(30); // Debounce

        // Wait until button is released
        while (digitalRead(buttonPins[i]) == LOW) {
          delay(5);
        }

        return i;
      }
    }
  }
}

// ======================================
// START SOUND
// ======================================
void playStartSound() {

  tone(buzzerPin, 600);
  delay(150);

  tone(buzzerPin, 800);
  delay(150);

  tone(buzzerPin, 1000);
  delay(200);

  noTone(buzzerPin);
}

// ======================================
// CORRECT SOUND
// ======================================
void correctSound() {

  tone(buzzerPin, 1000);
  delay(150);

  tone(buzzerPin, 1400);
  delay(200);

  noTone(buzzerPin);
}

// ======================================
// WRONG SOUND
// ======================================
void wrongSound() {

  tone(buzzerPin, 300);
  delay(500);

  noTone(buzzerPin);

  // Flash all LEDs
  for (int i = 0; i < 3; i++) {

    for (int j = 0; j < 4; j++) {
      digitalWrite(ledPins[j], HIGH);
    }

    delay(150);

    for (int j = 0; j < 4; j++) {
      digitalWrite(ledPins[j], LOW);
    }

    delay(150);
  }
}

// ======================================
// WIN GAME
// ======================================
void winGame() {

  for (int i = 0; i < 3; i++) {

    for (int j = 0; j < 4; j++) {
      digitalWrite(ledPins[j], HIGH);
    }

    tone(buzzerPin, 800 + i * 300);

    delay(250);

    for (int j = 0; j < 4; j++) {
      digitalWrite(ledPins[j], LOW);
    }

    noTone(buzzerPin);

    delay(150);
  }
}

Expected Output

The game begins by flashing one LED. The player presses the matching button. At each successful level, the sequence becomes one step longer.

Correct sequence: level increases.
Wrong button: buzzer sounds, all LEDs flash, and the game restarts from Level 1.
Maximum level: 20.

Result

The LED Memory Game was implemented using Arduino UNO, four LEDs, four push buttons and a buzzer. The player repeats increasingly longer LED sequences, and the game restarts when an incorrect button is pressed.
