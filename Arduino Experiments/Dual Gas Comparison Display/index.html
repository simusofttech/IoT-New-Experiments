Arduino Experiment No. 3

Dual Gas Comparison Display

← Arduino Experiments Aim Components Connections Working Procedure Code Result

Aim

To read and compare the values of an MQ-2 gas sensor and an MQ-135 gas sensor using Arduino UNO, and display both readings and the higher value on a 16×2 I2C LCD.

About the Experiment

The Arduino continuously reads the MQ-2 sensor on analog pin A0 and the MQ-135 sensor on analog pin A1. The two readings are shown on the first line of the LCD.

The second LCD line indicates whether the MQ-2 value is higher, the MQ-135 value is higher, or both values are equal.

LCD

The experiment uses a 16×2 I2C LCD based on MCP23008 and the Adafruit_LiquidCrystal library. The LCD object is created as Adafruit_LiquidCrystal lcd(0), corresponding to MCP23008 address 0x20.

Procedure

  1. Place the Arduino UNO, MQ-2, MQ-135, LCD, resistors and breadboard on the working area.
  2. Connect the MQ-2 pins according to the connection table above.
  3. Connect the MQ-2 signal to Arduino A0.
  4. Connect the MQ-135 analog signal to Arduino A1.
  5. Connect the MCP23008-based 16×2 I2C LCD according to your module wiring.
  6. Connect the Arduino UNO to the computer.
  7. Open Arduino IDE.
  8. Install the Adafruit_LiquidCrystal library if required.
  9. Enter the program given below.
  10. Select Arduino UNO from Tools → Board.
  11. Select the correct COM port.
  12. Click Verify and then Upload.
  13. Open the Serial Monitor at 9600 baud.
  14. Observe the MQ-2 and MQ-135 readings on the LCD and Serial Monitor.
  15. Check the second LCD line to see which gas sensor value is higher.

Arduino Code

Dual_Gas_Comparison_Display.ino 
#include <Wire.h>
#include <Adafruit_LiquidCrystal.h>

// MCP23008 address 0x20
// In Adafruit_LiquidCrystal:
// 0 = 0x20
Adafruit_LiquidCrystal lcd(0);

const int MQ2_PIN = A0;
const int MQ135_PIN = A1;

void setup()
{
  Serial.begin(9600);

  // Start 16x2 LCD
  lcd.begin(16, 2);
  lcd.clear();

  lcd.setCursor(0, 0);
  lcd.print("Dual Gas Sensor");

  lcd.setCursor(0, 1);
  lcd.print("Starting...");

  delay(2000);
  lcd.clear();
}

void loop()
{
  // Read gas sensors
  int mq2Value = analogRead(MQ2_PIN);
  int mq135Value = analogRead(MQ135_PIN);

  // -------------------------
  // SERIAL MONITOR
  // -------------------------
  Serial.print("MQ-2 = ");
  Serial.print(mq2Value);

  Serial.print(" | MQ-135 = ");
  Serial.println(mq135Value);

  // -------------------------
  // LCD LINE 1
  // -------------------------
  lcd.setCursor(0, 0);

  lcd.print("M2:");
  lcd.print(mq2Value);

  lcd.print(" M135:");
  lcd.print(mq135Value);

  lcd.print(" ");

  // -------------------------
  // LCD LINE 2
  // -------------------------
  lcd.setCursor(0, 1);

  if (mq2Value > mq135Value)
  {
    lcd.print("MQ-2 Higher ");
  }
  else if (mq135Value > mq2Value)
  {
    lcd.print("MQ-135 Higher ");
  }
  else
  {
    lcd.print("Values Equal ");
  }

  delay(500);
}

Expected Output

The first LCD line displays both sensor readings in a compact format, for example:

Line 1: M2:817 M135:670
Line 2: MQ-2 Higher

If the MQ-135 value becomes greater, the second line changes to MQ-135 Higher. If both readings are the same, it displays Values Equal.

Result

The Dual Gas Comparison Display experiment reads values from the MQ-2 and MQ-135 gas sensors, shows both readings on the 16×2 I2C LCD, and indicates which sensor has the higher value.
