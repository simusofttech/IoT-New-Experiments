Aim

To develop a gas-sensor monitoring experiment using Arduino UNO, an analog gas sensor and a 16×2 I²C LCD.

The system reads the gas sensor's analog output, displays the raw reading on the LCD and prints the same value to Serial Monitor.

About the Experiment

The Gas Sensor Monitoring System demonstrates how Arduino UNO can read and display an analog signal from a gas sensor.

The analog output of the gas sensor connects to Arduino pin A0.

Arduino reads the sensor using the analogRead() function, which returns a value between 0 and 1023 on Arduino UNO.

The measured value is displayed on a 16×2 I²C LCD and also printed to Serial Monitor at a baud rate of 9600.

The reading is refreshed approximately every 500 milliseconds.

The sketch supports two library configurations selected using a preprocessor definition: TINKERCAD and real hardware.

Important: The displayed Gas Value is a raw analog-to-digital converter reading, not a calibrated gas concentration in ppm. The original sketch does not include gas identification, concentration calibration, thresholds or an alarm.

Gas Sensor Input

The sensor module provides an analog signal that is read through Arduino A0.

Analog Reading

Arduino uses analogRead(A0) to obtain a raw 10-bit ADC value.

Serial Monitor Output

The program prints Gas Value followed by the measured ADC number at 9600 baud.

LCD Display

The first LCD row displays Gas Value: and the second row displays the numerical ADC reading.

Library Selection

When TINKERCAD is defined, LiquidCrystal_I2C is used.

When the definition is commented out, the code uses Adafruit_LiquidCrystal.

Important: These two library branches are not interchangeable with every I²C LCD backpack. The real hardware must match the selected library.

Procedure

  1. Place Arduino UNO, the analog gas sensor, LCD and breadboard on the working surface.
  2. Identify the sensor's exact model and terminals.
  3. Check the gas sensor module's required supply voltage.
  4. Connect the sensor analog output (AO) to Arduino A0.
  5. Connect sensor GND to Arduino GND.
  6. Connect sensor VCC to its compatible supply.
  7. Connect the LCD VCC to its compatible supply.
  8. Connect LCD GND to Arduino GND.
  9. Connect LCD SDA to A4.
  10. Connect LCD SCL to A5.
  11. Verify all circuit connections.
  12. Open Arduino IDE or the intended simulator.
  13. For the Tinkercad configuration, leave #define TINKERCAD enabled.
  14. For the specified Adafruit real-hardware LCD, comment out #define TINKERCAD.
  15. Ensure the selected LCD library is installed and compatible.
  16. Create a sketch named Gas_Sensor_Monitoring_System.ino.
  17. Copy the complete Arduino program from Explore the Code.
  18. Select Arduino Uno and the appropriate port.
  19. Verify and upload the program.
  20. Open Serial Monitor at 9600 baud.
  21. Allow the gas sensor to stabilize as required by its manufacturer.
  22. Observe the Gas Value on the LCD and Serial Monitor.
  23. Confirm that the readings update approximately every 500 milliseconds.
