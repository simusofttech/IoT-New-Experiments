Aim

To create a radar-style distance scanning system using Arduino UNO R3, an HC-SR04 ultrasonic sensor on an SG90 servo, a red LED and a buzzer. The system scans 0°–180° and activates alerts for detections within 60 cm.

About the Experiment

An SG90 servo rotates the HC-SR04 ultrasonic sensor from 0° to 180° and back. At each angle, Arduino measures the distance in centimetres. Readings over 60 cm are changed to 0, and the LED and buzzer are switched ON only for readings from 1 to 60 cm.

The Arduino prints comma-separated angle,distance readings at 9600 baud. A compatible Processing visualizer may be connected separately; its program is not provided in the SOP.

Working Principle

Start Arduino
↓
Sweep the servo 0° to 180°
↓
Transmit ultrasonic pulse
↓
Calculate distance from echo
↓
1–60 cm: LED and buzzer ON
↓
Outside detection range: LED and buzzer OFF
↓
Send angle,distance at 9600 baud
↓
Sweep 180° to 0° and repeat

The formula is distance = echo pulse duration × 0.034 / 2, with time measured in microseconds. The supplied sketch uses pulseIn() without an explicit timeout, so a missing echo can delay the sweep.

Procedure

  1. Mount the HC-SR04 ultrasonic sensor securely on the SG90 servo arm.
  2. Connect HC-SR04 VCC to 5V and GND to GND.
  3. Connect TRIG to D10 and ECHO to D11.
  4. Connect servo signal to D9. Supply suitable servo power and share ground with Arduino.
  5. Connect red LED anode to D7 through a 220Ω resistor, and cathode to GND.
  6. Connect the compatible low-current buzzer (+) to D8 and (−) to GND.
  7. Verify connections with power disconnected, then power the system.
  8. Open Arduino IDE and use its Servo library.
  9. Create Arduino_Radar_System.ino and copy the complete Explore the Code program.
  10. Select Arduino Uno and the correct port; verify and upload.
  11. Open Serial Monitor at 9600 baud and observe angle,distance output.
  12. Test an object between 1–60 cm and check both warning outputs.
  13. Move it beyond 60 cm and confirm both outputs switch OFF.
  14. Observe continuous forward and reverse sweeping.

Result

The Arduino Radar System demonstrates automated ultrasonic scanning and threshold-based alerts. It continuously moves the sensor across the scan arc, calculates object distances, and provides visual, audible and serial feedback.

What You Learn

  • Using the HC-SR04 ultrasonic distance sensor.
  • Using Servo.h to control an SG90 motor.
  • Sweeping angles from 0° to 180° and back.
  • Calculating distance using ultrasonic echo duration.
  • Applying a 60 cm detection threshold.
  • Controlling LEDs and buzzers from digital pins.
  • Using comma-separated Serial Monitor output at 9600 baud.
  • Understanding common ground and appropriate servo power.
