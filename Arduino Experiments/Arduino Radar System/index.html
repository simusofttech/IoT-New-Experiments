Aim

To create an Arduino-based radar-style scanning system using an ultrasonic sensor mounted on a servo motor.

The system measures object distance, scans between 0° and 180°, and activates an LED and buzzer when an object is detected within 60 cm.

About the Experiment

The Ultrasonic Radar Detection System uses an Arduino UNO, HC-SR04 ultrasonic sensor, SG90 servo motor, red LED and buzzer.

The ultrasonic sensor is mounted on the servo motor so that it can scan the surrounding area.

Arduino rotates the servo from 0° to 180° and then back to 0°. At each position, it sends an ultrasonic pulse and measures the reflected echo.

The echo duration is converted into an approximate distance in centimetres.

When an object is detected between 1 cm and 60 cm, the red LED and buzzer turn ON.

The system also transmits angle and distance information through Serial communication at 9600 baud.

Important: The Arduino sketch produces serial angle-and-distance values. A separate Processing application would be needed to display those values as a graphical radar screen. The uploaded file does not contain the Processing program.

Distance Measurement

Arduino sends a short trigger pulse to the HC-SR04. The sensor transmits an ultrasonic wave and waits for its echo.

The program measures the echo duration and calculates the approximate distance.

Distance Formula:

Distance (cm) = Echo Duration (µs) × 0.034 ÷ 2

Detection Threshold

If the detected distance is greater than 60 cm, the program sets the reported distance value to zero.

Valid readings from 1 cm to 60 cm activate the LED and buzzer.

Procedure

  1. Place the Arduino UNO and breadboard on a stable surface.
  2. Mount the HC-SR04 ultrasonic sensor securely on the SG90 servo motor arm.
  3. Connect HC-SR04 VCC to 5V.
  4. Connect HC-SR04 GND to GND.
  5. Connect HC-SR04 TRIG to D10.
  6. Connect HC-SR04 ECHO to D11.
  7. Connect the servo signal wire to D9.
  8. Connect the servo to an appropriate 5V power source.
  9. Ensure the servo and Arduino share a common ground.
  10. Connect the red LED anode to D7 through a 220Ω resistor.
  11. Connect the LED cathode to GND.
  12. Connect the compatible low-current buzzer positive terminal to D8.
  13. Connect the buzzer negative terminal to GND.
  14. Verify all connections before powering the circuit.
  15. Open Arduino IDE.
  16. Create a sketch named Arduino_Radar_System.ino.
  17. Copy the complete Arduino program from Explore the Code.
  18. Select Arduino Uno and the correct communication port.
  19. Verify and upload the sketch.
  20. Open Serial Monitor at 9600 baud.
  21. Observe the servo scanning from 0° to 180° and back.
  22. Place an object within the 1–60 cm detection range.
  23. Observe the red LED and buzzer activating.
  24. Move the object beyond 60 cm and confirm that both indicators turn OFF.

Result

Ultrasonic Radar Detection System demonstrates automatic ultrasonic distance scanning using a servo motor.

It measures the distance of nearby objects and activates a red LED and buzzer when objects are detected within 60 cm.

The system also sends angle and distance readings through Serial communication.
