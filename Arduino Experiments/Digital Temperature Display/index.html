Aim

To measure temperature using an LM35 temperature sensor connected to Arduino UNO and display the temperature in degrees Celsius on a 16×2 I²C LCD and Serial Monitor.

About the Experiment

The Digital Temperature Display experiment demonstrates how an Arduino UNO can measure and display temperature using the LM35 analog temperature sensor.

The LM35 provides an analog voltage proportional to the surrounding temperature.

Arduino reads this voltage through analog input A0 using the analogRead() function.

The analog-to-digital converter produces a value from 0 to 1023. The program converts this reading into voltage using a nominal 5V ADC reference.

Since the LM35 produces approximately 10 millivolts per degree Celsius, the voltage is converted into temperature.

The measured temperature is shown on a 16×2 I²C LCD and also printed in Serial Monitor at 9600 baud.

The display and Serial Monitor readings are refreshed approximately once every second.

Important: The original sketch assumes a nominal 5V analog reference and uses an LCD I²C address of 0x27. The LCD module and installed LiquidCrystal_I2C library must be compatible with these settings.

Temperature Measurement

The LM35 is an analog temperature sensor that provides an output voltage proportional to temperature.

Its nominal sensitivity is 10 mV per degree Celsius.

Analog-to-Digital Conversion

Arduino uses analogRead(A0) to obtain a digital value corresponding to the sensor output voltage.

Voltage Formula:

Voltage = ADC Reading × (5.0 / 1023.0)

Temperature Formula:

Temperature (°C) = Voltage × 100

LCD Display

The measured temperature is displayed with one digit after the decimal point followed by the degree Celsius symbol.

Serial Monitor

Arduino prints the measured temperature through Serial communication at 9600 baud.

Procedure

  1. Place Arduino UNO and the breadboard on a stable surface.
  2. Identify the LM35 VCC, VOUT and GND terminals using its datasheet.
  3. Connect LM35 VCC to Arduino 5V.
  4. Connect LM35 VOUT to Arduino A0.
  5. Connect LM35 GND to Arduino GND.
  6. Connect the I²C LCD VCC to Arduino 5V.
  7. Connect the I²C LCD GND to Arduino GND.
  8. Connect LCD SDA to Arduino A4.
  9. Connect LCD SCL to Arduino A5.
  10. Verify the circuit connections before applying power.
  11. Open Arduino IDE.
  12. Install the compatible LiquidCrystal_I2C library.
  13. Create a sketch named Digital_Temperature_Display.ino.
  14. Copy the complete Arduino program from Explore the Code.
  15. Select Arduino Uno and the correct communication port.
  16. Verify and upload the program.
  17. Open Serial Monitor at 9600 baud.
  18. Observe the measured temperature on the LCD display.
  19. Compare the displayed value with the Serial Monitor reading.
  20. Observe how the readings change as the sensor temperature changes.

Result

The Digital Temperature Display experiment demonstrates temperature measurement using Arduino UNO, an LM35 temperature sensor and a 16×2 I²C LCD.
