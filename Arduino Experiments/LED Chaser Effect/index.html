Aim

To create a continuous forward-and-reverse LED chaser effect using Arduino UNO R3, eight LEDs and eight 220Ω resistors.

Arduino controls the LEDs sequentially through digital pins D2 to D9, producing a moving light animation.

About the Experiment

The LED Chaser Effect experiment demonstrates how Arduino UNO can control multiple LEDs using digital output pins and programming loops.

Eight LEDs are connected to Arduino digital pins D2 through D9.

Each LED has its own 220Ω current-limiting resistor to help prevent excessive current flow.

The Arduino sketch stores all eight digital pin numbers in an array named leds[].

During initialization, Arduino configures every LED pin as OUTPUT and turns all LEDs OFF.

The first for loop turns the LEDs ON and OFF one after another, starting from LED 1 and continuing to LED 8.

After reaching LED 8, the second for loop moves the light backward through LED 7 to LED 2.

Once the reverse sequence is complete, the program automatically starts again from LED 1.

This creates a continuous back-and-forth moving light effect.

Each LED stays ON for approximately 150 milliseconds before switching OFF.

Important: Only one LED is commanded ON at a time in the supplied sketch. Each LED switches OFF before the next LED switches ON. No external sensor, buzzer or display is required.

Digital Output Control

Arduino sets each LED pin as OUTPUT using pinMode().

digitalWrite(pin, HIGH) switches the connected LED ON, while digitalWrite(pin, LOW) switches it OFF.

Forward Movement

A for loop starts with array index 0 and increments until all eight LEDs have been activated.

Forward Sequence:

LED 1 → LED 2 → LED 3 → LED 4 → LED 5 → LED 6 → LED 7 → LED 8

Reverse Movement

The second for loop starts from array index 6 and moves backward to array index 1.

This avoids repeating LED 8 at the turning point and LED 1 immediately before the next forward pass.

Reverse Sequence:

LED 7 → LED 6 → LED 5 → LED 4 → LED 3 → LED 2

LED Timing

delay(150) holds each active LED ON for 150 milliseconds.

The OFF operation happens immediately after the delay.

Continuous Sequence:

1 → 2 → 3 → 4 → 5 → 6 → 7 → 8 → 7 → 6 → 5 → 4 → 3 → 2 → 1 → ...

There are 14 LED activations per complete forward-and-reverse cycle. The programmed delays total approximately 2.1 seconds per cycle, excluding small instruction-processing overhead.

Procedure

  1. Place Arduino UNO, eight LEDs, eight 220Ω resistors and a breadboard on the working surface.
  2. Arrange all eight LEDs in a straight line on the breadboard.
  3. Identify the anode and cathode of each LED.
  4. Connect LED 1 anode to D2 through a 220Ω resistor.
  5. Connect LED 2 anode to D3 through a 220Ω resistor.
  6. Connect LED 3 anode to D4 through a 220Ω resistor.
  7. Connect LED 4 anode to D5 through a 220Ω resistor.
  8. Connect LED 5 anode to D6 through a 220Ω resistor.
  9. Connect LED 6 anode to D7 through a 220Ω resistor.
  10. Connect LED 7 anode to D8 through a 220Ω resistor.
  11. Connect LED 8 anode to D9 through a 220Ω resistor.
  12. Connect all eight LED cathodes to Arduino GND using the breadboard ground rail.
  13. Verify every resistor and LED connection.
  14. Open Arduino IDE.
  15. Create a sketch named LED_Chaser_Effect.ino.
  16. Copy the complete Arduino program from Explore the Code.
  17. Select Arduino Uno and the correct communication port.
  18. Verify and upload the program.
  19. Observe the LEDs turning ON one after another from LED 1 to LED 8.
  20. Observe the pattern moving backward from LED 7 to LED 2.
  21. Confirm the forward-and-reverse pattern repeats continuously.
  22. Experiment by changing delay(150) to a smaller or larger value to observe the effect on chasing speed.

Result

The LED Chaser Effect experiment demonstrates sequential control of eight LEDs using Arduino UNO.

By combining arrays, for loops, digitalWrite() and delay(), the program creates a continuous forward-and-reverse moving light pattern.

The experiment also demonstrates how changing software timing modifies the speed of an LED animation.
