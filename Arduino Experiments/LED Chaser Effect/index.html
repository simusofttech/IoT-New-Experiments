LED Chaser Effect

← Arduino Experiments Aim Components Connections Circuit Working Procedure Code Result

Aim

To create a moving LED chaser effect using Arduino UNO, eight LEDs and eight 220Ω resistors.

About the Experiment

In this experiment, eight LEDs are connected to Arduino digital pins D2 to D9. Arduino turns the LEDs ON and OFF one after another to create a moving light effect.

After reaching LED 8, the sequence moves back toward LED 1 and repeats continuously.

Components Required

Arduino UNO R3 (×1)

Main controller for switching the LEDs in sequence.

LEDs (×8)

Create the moving chaser light pattern.

220Ω Resistors (×8)

Limit current through each LED.

Breadboard (×1)

Used for assembling the LED circuit.

Jumper Wires

Used for all electrical connections.

Working Principle

Arduino Starts
↓
All LEDs are initially OFF
↓

↓

↓

↓
Sequence moves back toward LED 1
↓

LED sequence: LED 1 → LED 2 → LED 3 → LED 4 → LED 5 → LED 6 → LED 7 → LED 8
Delay: 150 ms between LED steps

Procedure

  1. Connect LED 1 anode to Arduino pin D2 through a 220Ω resistor.
  2. Connect LED 2 anode to D3 through a 220Ω resistor.
  3. Connect LED 3 anode to D4 through a 220Ω resistor.
  4. Connect LED 4 anode to D5 through a 220Ω resistor.
  5. Connect LED 5 anode to D6 through a 220Ω resistor.
  6. Connect LED 6 anode to D7 through a 220Ω resistor.
  7. Connect LED 7 anode to D8 through a 220Ω resistor.
  8. Connect LED 8 anode to D9 through a 220Ω resistor.
  9. Connect all LED cathodes to GND.
  10. Connect Arduino UNO to the computer using USB.
  11. Open Arduino IDE.
  12. Enter the program given below.
  13. Select Arduino UNO from Tools → Board.
  14. Select the correct COM port.
  15. Verify and upload the program.
  16. Observe the LEDs moving forward and backward in sequence.

Arduino Code

LED_Chaser_Effect.ino 
// ======================================
// LED CHASER EFFECT
// Arduino UNO R3
// ======================================

const int leds[] = {2, 3, 4, 5, 6, 7, 8, 9};

const int numberOfLEDs = 8;

void setup() {

  // Set all LED pins as OUTPUT
  for (int i = 0; i < numberOfLEDs; i++) {

    pinMode(leds[i], OUTPUT);

    digitalWrite(leds[i], LOW);
  }
}

void loop() {

  // Move from LED 1 to LED 8
  for (int i = 0; i < numberOfLEDs; i++) {

    digitalWrite(leds[i], HIGH);

    delay(150);

    digitalWrite(leds[i], LOW);
  }

  // Move back from LED 8 to LED 1
  for (int i = numberOfLEDs - 2; i > 0; i--) {

    digitalWrite(leds[i], HIGH);

    delay(150);

    digitalWrite(leds[i], LOW);
  }
}

Expected Output

The LEDs light up one by one from LED 1 to LED 8 and then move back toward LED 1, creating a continuous chasing light effect.

The delay(150) value controls the speed of the LED movement. A smaller delay makes the chase faster, while a larger delay makes it slower.

Result

The LED Chaser Effect experiment was implemented using Arduino UNO and eight LEDs. The LEDs turn ON and OFF sequentially to create a continuous forward-and-backward moving light effect.
