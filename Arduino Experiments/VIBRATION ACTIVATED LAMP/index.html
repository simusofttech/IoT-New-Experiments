Aim

To design a Vibration Activated Lamp experiment using Arduino UNO R3, a digital vibration sensor module, a red LED and a 220Ω resistor.

The system automatically turns the LED ON when the digital sensor indicates vibration and turns it OFF when the signal returns to its normal state.

About the Experiment

Vibration Activated Lamp is a simple sensor-based automation experiment. It demonstrates how mechanical vibration can control an electronic output through Arduino UNO.

The digital vibration sensor module detects mechanical movement or vibration and produces a HIGH or LOW signal at its digital output terminal.

The sensor's digital output is connected to Arduino D2. A red LED is connected to Arduino D8 through a 220Ω current-limiting resistor.

Arduino continuously reads the digital sensor value using digitalRead().

The original program interprets HIGH as vibration detected. In that condition, Arduino switches ON the red LED and prints the detection status to Serial Monitor.

The program waits 200 milliseconds after detecting vibration. If the sensor signal becomes LOW on a later check, Arduino switches OFF the LED.

Serial Monitor operates at 9600 baud and helps students observe vibration detection events.

Sensor Polarity:

The source sketch assumes that HIGH means vibration detected.

Some vibration modules have active-LOW outputs. Their behavior depends on the sensor and comparator circuit.

Confirm the actual module's output polarity before relying on the LED indication. The original sketch is preserved without changing its detection condition.

Digital Vibration Detection

The vibration sensor module provides a digital output to Arduino pin D2.

Arduino calls digitalRead(VIBRATION_PIN) to determine whether the signal is HIGH or LOW.

Vibration Detected

When vibrationState is HIGH, the source enters its vibration detection branch.

Detection Condition:

vibrationState == HIGH

Red LED: ON

Serial: Vibration detection message

Delay: 200 milliseconds

No Vibration

When vibrationState is LOW, Arduino executes the else branch and switches the LED OFF.

The original sketch does not print a no-vibration message. It simply continues checking the sensor.

Serial Monitoring

The sketch prints a title banner once during setup.

Whenever the sensor is read as HIGH, Arduino prints the vibration status, LED status and a separator line.

If the signal remains HIGH across multiple readings, the program repeats the messages after each 200 ms delay.

Detection and Delay

The 200 ms delay occurs only in the vibration-detected branch.

There is no programmed delay in the no-vibration branch.

Short vibration pulses may be missed while the sketch is waiting inside delay().

Sensor Behavior Note:

The sensor's digital output must be HIGH during vibration for the preserved sketch to behave as intended.

If a particular module uses active-LOW signaling, its LED behavior will appear reversed until the sensor logic is adjusted to match that module.

Procedure

  1. Arrange the Arduino UNO, vibration sensor module, red LED, 220Ω resistor, breadboard and jumper wires.
  2. Identify the VCC, GND and DO terminals of the vibration sensor module.
  3. Connect the sensor VCC to Arduino 5V, after confirming the module's voltage rating.
  4. Connect the sensor GND to Arduino GND.
  5. Connect the sensor digital output DO to Arduino D2.
  6. Insert the red LED into the breadboard.
  7. Connect the red LED anode to Arduino D8 through a 220Ω resistor.
  8. Connect the red LED cathode to GND.
  9. Verify all connections and LED polarity.
  10. Open Arduino IDE.
  11. Create a sketch named Vibration_Activated_Lamp.ino.
  12. Copy the complete Arduino program from Explore the Code.
  13. Select Arduino Uno and the correct communication port.
  14. Verify and upload the program.
  15. Open Serial Monitor at 9600 baud.
  16. Observe the startup banner printed by Arduino.
  17. Keep the vibration sensor still and observe whether its output is LOW.
  18. When the output is LOW, verify that the LED remains OFF.
  19. Gently tap or shake the vibration sensor module.
  20. When its output is HIGH, verify that the red LED turns ON.
  21. Observe the vibration detection messages in Serial Monitor.
  22. Stop moving the sensor and observe whether the LED switches OFF.
  23. If the module has a sensitivity adjustment, calibrate it according to its specifications.
  24. Repeat the test with different gentle vibrations and record the response.
Sensor Polarity Note:

The supplied program treats HIGH as vibration detected. If the particular module uses LOW to indicate vibration, the physical response will differ from this expected behavior.

The program does not measure vibration strength, frequency or acceleration.

Result

The Vibration Activated Lamp experiment demonstrates how Arduino UNO can read the digital output of a vibration sensor and control a red LED according to the input state.

When the sensor output is HIGH, Arduino turns the LED ON and prints the vibration status in Serial Monitor.

When the sensor output is LOW, Arduino switches the LED OFF.

The experiment demonstrates digital sensor interfacing, conditional programming, LED control and serial status monitoring.
