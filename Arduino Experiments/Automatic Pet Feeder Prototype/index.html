Automatic Pet Feeder Prototype

← Arduino Experiments Aim Components Connections Working Procedure Code Result

Aim

To create an automatic pet feeder prototype using Arduino UNO, a push button, servo motor, buzzer and I²C LCD.

About the Experiment

The feeder waits for the push button to be pressed.

When the button is pressed, the buzzer gives a short beep, the LCD shows the feeding status and the servo opens the food dispensing mechanism for 1.5 seconds.

Components Required

Procedure

  1. Connect the push button between D2 and GND.
  2. Connect the buzzer to D8 and GND.
  3. Connect the servo signal wire to D9.
  4. Connect the servo VCC to 5V and GND to GND.
  5. Connect LCD SDA to A4 and SCL to A5.
  6. Upload the Arduino code.
  7. Press the button and observe the feeding cycle.

Arduino Code

Automatic_Pet_Feeder_Prototype.ino 
#include <Adafruit_LiquidCrystal.h>
#include <Servo.h>

// Create LCD and Servo objects
Adafruit_LiquidCrystal lcd(0);
Servo feederServo;

// Pin connections
int button = 2;
int buzzer = 8;
int servoPin = 9;

void setup()
{
  pinMode(button, INPUT_PULLUP);
  pinMode(buzzer, OUTPUT);

  feederServo.attach(servoPin);

  // Keep feeder closed at start
  feederServo.write(0);

  lcd.begin(16, 2);
  lcd.setBacklight(1);

  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Pet Feeder");

  lcd.setCursor(0, 1);
  lcd.print("Ready");

  delay(2000);

  showReadyMessage();
}

void loop()
{
  // Check if feed button is pressed
  if (digitalRead(button) == LOW)
  {
    lcd.clear();
    lcd.setCursor(0, 0);
    lcd.print("Dispensing Food");

    // Short confirmation beep
    tone(buzzer, 1000);
    delay(300);
    noTone(buzzer);

    // Open feeder
    feederServo.write(90);

    delay(1500);

    // Close feeder
    feederServo.write(0);

    delay(500);

    lcd.clear();
    lcd.setCursor(0, 0);
    lcd.print("Food Dispensed");

    lcd.setCursor(0, 1);
    lcd.print("Thank You!");

    delay(2000);

    showReadyMessage();

    // Wait until button is released
    while (digitalRead(button) == LOW)
    {
      delay(10);
    }

    delay(200);
  }
}

void showReadyMessage()
{
  lcd.clear();

  lcd.setCursor(0, 0);
  lcd.print("Press Button");

  lcd.setCursor(0, 1);
  lcd.print("to Feed");
}

Expected Output

Pressing the button starts one feeding cycle. The buzzer beeps, the servo opens to 90° for 1.5 seconds, then returns to 0°. The LCD shows the current feeding status.

Result

The Automatic Pet Feeder Prototype experiment controls a simple food dispensing mechanism using a servo motor, push button, buzzer and LCD.
