Aim

To design a Digital IR Remote LED Controller using Arduino UNO R3, an infrared remote, a VS1838B IR receiver, and three LEDs.

The experiment controls Green, Red, and Yellow LEDs using programmed remote button commands.

About the Experiment

An infrared remote sends coded light signals when a button is pressed.

The VS1838B infrared receiver detects these signals and passes the decoded information to Arduino UNO.

In this experiment, the IR receiver output is connected to digital pin D2.

Arduino uses the IRremote library to identify the received command.

Depending on the command, the program controls three LEDs connected to digital pins D8, D9, and D10.

Five remote commands are programmed. They select the Green LED, Red LED, Yellow LED, all LEDs ON, or all LEDs OFF.

The received command values and corresponding status messages are printed in Serial Monitor at 9600 baud.

This experiment demonstrates wireless control using infrared communication, digital output control, and conditional decision-making.

Important:

Different IR remotes may transmit different command values.

The command values used in the original sketch must match your actual remote.

The source specifically identifies the Yellow LED command 0x1F as a value that may need replacement after testing Button 6.

Infrared Communication

The remote emits infrared pulses that represent different button commands.

The VS1838B receiver converts these signals into an electrical signal for Arduino D2.

Receiving a Command

The IRremote library uses IrReceiver.decode() to determine whether a command has been received.

The command is retrieved from the decoded IR data.

Command Comparison

Arduino compares the received command against five predefined command constants.

Remote Button Command Value Operation
Button 1 0x0D Green LED ON
Button 2 0x0E All LEDs ON
Button 3 0x0A All LEDs OFF
Button 5 0x1B Red LED ON
Button 6 0x1F Yellow LED ON

LED Control

The program uses digitalWrite() to set each LED output HIGH or LOW.

The Green, Red, and Yellow LED selection commands switch the other LEDs OFF.

The All ON command activates all three LEDs simultaneously.

The All OFF command switches all three LEDs OFF.

Serial Monitor

Each nonzero decoded command is printed in hexadecimal format.

For recognized commands, the corresponding LED status message is printed.

Receiving the Next Command

After processing the current command, the program calls IrReceiver.resume().

This allows the receiver to accept the next infrared command.

Important Program Behavior:

The original sketch ignores command value zero.

If a nonzero command does not match any programmed value, it is printed but does not change the LED states.

The decoded command bytes must be checked against the actual remote being used.

Procedure

  1. Arrange Arduino UNO, IR remote, VS1838B receiver, three LEDs, three 220Ω resistors, breadboard, and jumper wires.
  2. Identify the receiver's VCC, GND, and OUT terminals.
  3. Connect IR receiver VCC to Arduino 5V.
  4. Connect IR receiver GND to Arduino GND.
  5. Connect IR receiver OUT to Arduino D2.
  6. Connect the Green LED anode to D8 through a 220Ω resistor.
  7. Connect the Red LED anode to D9 through another 220Ω resistor.
  8. Connect the Yellow LED anode to D10 through another 220Ω resistor.
  9. Connect all LED cathodes to GND.
  10. Verify all component connections and polarities.
  11. Open Arduino IDE.
  12. Install the IRremote library using Library Manager.
  13. Create a sketch named Digital_IR_Remote_LED_Controller.ino.
  14. Copy the complete code from Explore the Code.
  15. Select Arduino Uno and the correct port.
  16. Verify and upload the sketch.
  17. Open Serial Monitor at 9600 baud.
  18. Point the IR remote toward the receiver.
  19. Press Button 1 and observe the Green LED.
  20. Press Button 2 and observe all LEDs turning ON.
  21. Press Button 3 and observe all LEDs turning OFF.
  22. Press Button 5 and observe the Red LED.
  23. Press Button 6 and observe the Yellow LED.
  24. Compare the commands printed in Serial Monitor with the predefined values.
  25. If a command differs, update the corresponding command constant.

Important:

The examples assume the remote sends the command values defined in the sketch.

Serial.println(command, HEX) normally omits unnecessary leading zeros. For example, 0x0D may appear as D after the printed 0x prefix.

The Yellow LED command may need adjustment according to the actual remote.

Result

The Digital IR Remote LED Controller demonstrates wireless control of three LEDs using Arduino UNO and an infrared remote.

The IR receiver sends the detected commands to Arduino, which compares them against predefined values and updates the corresponding LED outputs.

Serial Monitor displays the received hexadecimal command and current LED status.

The experiment demonstrates infrared communication, digital output control, conditional logic, and multiple-device selection.
