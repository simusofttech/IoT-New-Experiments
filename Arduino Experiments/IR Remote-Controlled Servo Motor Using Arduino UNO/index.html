Aim

To control the angular position of a servo motor wirelessly using Arduino UNO, a VS1838B infrared receiver and an IR remote control.

The experiment demonstrates positioning the servo at five predefined angles: 0°, 45°, 90°, 135° and 180°.

About the Experiment

The IR Remote-Controlled Servo Motor experiment demonstrates wireless control of a servo using infrared signals.

The IR remote control transmits encoded infrared commands when a button is pressed.

The VS1838B IR receiver detects the modulated infrared signal and sends information to Arduino UNO.

The IRremote library is used to decode the received signal and obtain the corresponding command.

Arduino compares the received command with five programmed hexadecimal command values.

Each recognized command corresponds to one servo position.

The Servo library generates the control signal required to move the motor to the selected angle.

The servo initially moves to 90° when Arduino starts.

Every decoded command is also printed to Serial Monitor in hexadecimal format at 9600 baud.

Important: The hexadecimal command values in the sketch are specific to the intended IR remote. Different remote controls may transmit different command values. Verify the received values using Serial Monitor and update the switch cases if necessary.

Infrared Signal Reception

When a remote-control button is pressed, an encoded infrared signal is transmitted.

The VS1838B receives the modulated IR signal and passes information to Arduino through D11.

IR Command Decoding

The IRremote library processes the signal and identifies the received command.

The program stores the decoded command as an 8-bit value.

Servo Angle Selection

The switch statement checks the command and selects one of five positions.

IR Command Servo Angle
0x18 0°
0x7A 45°
0x10 90°
0x38 135°
0x5A 180°

Servo Movement

The Servo library sends position-control pulses to the motor.

motor.write() commands the servo to move to the selected angle.

0° Command 0x18
45° Command 0x7A
90° Command 0x10
135° Command 0x38
180° Command 0x5A

Serial Monitor Feedback

The program prints every decoded command in hexadecimal format.

If a command does not match any case, the sketch prints that command but does not change the servo position.

Important: Servo movement is limited by the actual model's supported mechanical range. Do not force a servo beyond its physical stops. Not every servo can safely achieve a full 180° movement.

Procedure

  1. Place Arduino UNO, the VS1838B receiver, servo and breadboard on a stable surface.
  2. Identify the IR receiver's signal, VCC and GND pins using its datasheet.
  3. Connect the receiver signal pin to D11.
  4. Connect the receiver VCC to a compatible supply voltage.
  5. Connect receiver GND to Arduino GND.
  6. Connect the servo signal wire to D9.
  7. Connect the servo power wires to a suitable regulated supply and common ground.
  8. Verify all connections before powering the circuit.
  9. Ensure the IR remote is ready for operation.
  10. Open Arduino IDE.
  11. Install a compatible version of the IRremote library.
  12. Ensure the Servo library is available.
  13. Create a sketch named IR_Remote_Controlled_Servo_Motor.ino.
  14. Copy the Arduino program from Explore the Code.
  15. Select Arduino Uno and the correct port.
  16. Verify and upload the sketch.
  17. Open Serial Monitor at 9600 baud.
  18. Observe the servo moving to its initial 90° position.
  19. Point the IR remote toward the receiver.
  20. Press a button and observe the hexadecimal command printed in Serial Monitor.
  21. Confirm that the received code matches one of the programmed command values.
  22. Press the buttons assigned to 0°, 45°, 90°, 135° and 180°.
  23. Observe the corresponding servo movements.
  24. If a remote button produces a different code, update its switch-case value before testing again.
  25. Repeat the experiment to confirm reliable wireless control.
