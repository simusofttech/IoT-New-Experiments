1. Load libraries

The program loads libraries for I²C communication, DHT22, BMP180 and SSD1306 OLED control.

Explore more: shared I²C pins

The BMP180 and OLED both use GPIO 21 for SDA and GPIO 22 for SCL.

I²C allows multiple compatible devices to share the same SDA and SCL wires.

Working Principle

The FSR detects the force applied to its surface.
The sensor circuit converts the force into a changing analog voltage.
Arduino reads the voltage through analog pin A0.
If the sensor reading exceeds 100, the servo rotates to 90°.
When the force is removed and the reading falls below the threshold, the servo returns
to 0°.

Procedure

Connect the FSR to A0 using the 10kΩ resistor as shown in the connection table.
Connect the servo signal wire to D9 and its power wires correctly.
Connect Arduino UNO R3 to the computer using a computer connection.
Open Arduino IDE and install the Servo library if it is not already available.
Enter the program and select Arduino UNO R3 and the correct COM port.
Upload the program.
Open the Serial Monitor and set the baud rate to 9600.
Apply pressure to the FSR and observe the servo movement.
Release the pressure and confirm that the servo returns to 0°.
