Aim

Control an SG90 servo using a force-sensitive resistor: rotate to 90° when pressure exceeds the threshold and return to 0° when released.

About the Experiment

Control an SG90 servo using a force-sensitive resistor: rotate to 90° when pressure exceeds the threshold and return to 0° when released. This practical demonstrates sensor interfacing, digital and analog input/output and Arduino programming.

Components Required

Arduino UNO R3 (×1)

Force Sensitive Resistor (×1)

SG90 Servo Motor (×1)

10kΩ Resistor (×1)

Breadboard (×1)

Jumper Wires (×As required)

Working Principle

Pressure on FSR → Analog A0 → Threshold 100 → Servo at 90° or 0°

Procedure

  1. Place the components on a breadboard and check the connections table.
  2. Connect the components to the Arduino UNO R3 using jumper wires.
  3. Open Arduino IDE, select Arduino UNO and install the libraries used in the code.
  4. Verify and upload the program.
  5. Observe the output and test the experiment's input conditions.
