Aim

To simulate a two-product vending machine with product selection, ₹5 credit increments, purchase verification, stock management, LCD messages and a servo-controlled gate.

About the Experiment

Five push buttons select Product A or B, add ₹5 credit, buy or cancel. Product A costs ₹10 with initial stock 5; Product B costs ₹15 with initial stock 3. The servo opens a shared gate only after valid payment and stock verification. Two LEDs indicate stock of two or fewer.

The SOP specifies an external servo supply if needed; share Arduino ground with supply ground. The mechanical flap is deliberately omitted from component cards. Stock is stored in RAM and resets after restart.

Procedure

  1. Arrange the Arduino UNO and components on a breadboard.
  2. Connect each component exactly as shown in the Circuit Connections table.
  3. Double-check polarity, signal pins, and common ground.
  4. Open Arduino IDE and select Arduino UNO and the correct port.
  5. Install required libraries if the sketch uses them.
  6. Copy the complete code from Explore the Code and upload it.
  7. Test each input and observe the output, display and Serial Monitor.

Expected Output

A purchase needs ₹10; B needs ₹15. Each credit press adds ₹5. Successful purchases cycle the servo and decrease stock. At stock ≤2, the corresponding LED turns ON.
