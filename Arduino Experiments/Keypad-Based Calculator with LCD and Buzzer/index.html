Aim

To build a four-function electronic calculator using Arduino UNO, a 4×4 matrix keypad, a 16×2 I²C LCD and a buzzer.

The calculator accepts two numbers and performs addition, subtraction, multiplication or division according to the selected keypad operation.

The result is displayed on the LCD, while the buzzer confirms each keypress.

About the Experiment

The Keypad-Based Calculator with LCD and Buzzer demonstrates how Arduino can process user input and perform basic mathematical calculations.

A 4×4 matrix keypad provides numeric keys from 0 to 9, operation keys A–D, a calculate key (#) and a clear key (*).

The first entered number is stored in the String variable num1.

After selecting an arithmetic operation, the second number is stored in num2.

The Arduino converts the entered number strings into numeric values using toFloat().

A switch statement performs the selected arithmetic operation.

Pressing # calculates and displays the result on the second LCD row, formatted to two decimal places.

Pressing * clears the entered values and prepares the calculator for another operation.

Every recognized keypad press activates the buzzer briefly, providing audible feedback.

Calculator Limitations: The original program accepts only the digit keys 0–9 for number entry. It does not support entering decimal points or negative signs directly. Each number is limited to eight entered digits. This is a basic two-operand calculator, not a scientific calculator.

Keypad Pinout: Verify the actual keypad ribbon pin order before wiring. Its physical connections may not follow a simple R1–R4, C1–C4 sequence.

LCD Address: The original code uses I²C address 0x27. Confirm that your LCD module uses the same address.

Buzzer: The sketch switches D10 HIGH for 60 ms. A suitable active buzzer can generate a beep from this signal. Verify its operating current before direct pin connection.

Keypad Input

The Keypad library scans the four rows and four columns to identify the pressed key.

Numeric keys build the two operand strings used for the calculation.

Arithmetic Operations

Key Operation Example
A Addition (+) 12 + 8 = 20
B Subtraction (−) 12 − 8 = 4
C Multiplication (×) 12 × 8 = 96
D Division (÷) 12 ÷ 8 = 1.5

Number Storage

The program stores the first number in num1 and the second number in num2.

A char variable named operation stores the selected arithmetic symbol.

Calculation

When # is pressed, the program calls calculate().

The entered values are converted using toFloat(), and a switch statement selects the requested operation.

Buzzer Feedback

Every detected keypress calls beep().

The buzzer pin is driven HIGH for 60 milliseconds and then LOW.

Error Handling

If the user attempts to divide by zero, the program displays an error message instead of a result.

Display Behavior: The LCD has only 16 characters per row. Long expressions can exceed the visible display width. The supplied program does not include horizontal scrolling or automatic formatting for oversized expressions.

Procedure

  1. Place Arduino UNO, the 4×4 keypad, LCD, buzzer and breadboard on a stable work surface.
  2. Identify the keypad row and column terminals.
  3. Connect keypad R1 to Arduino D9.
  4. Connect keypad R2 to Arduino D8.
  5. Connect keypad R3 to Arduino D7.
  6. Connect keypad R4 to Arduino D6.
  7. Connect keypad C1 to Arduino D5.
  8. Connect keypad C2 to Arduino D4.
  9. Connect keypad C3 to Arduino D3.
  10. Connect keypad C4 to Arduino D2.
  11. Connect LCD VCC to a compatible 5V supply.
  12. Connect LCD GND to Arduino GND.
  13. Connect LCD SDA to Arduino A4.
  14. Connect LCD SCL to Arduino A5.
  15. Connect the buzzer positive terminal to D10 if suitable for direct pin drive.
  16. Connect buzzer negative to Arduino GND.
  17. Verify all wiring, keypad terminal order and component polarity.
  18. Open Arduino IDE.
  19. Install the Keypad and compatible LiquidCrystal_I2C libraries.
  20. Create a sketch named Keypad_Based_Calculator_with_LCD_and_Buzzer.ino.
  21. Copy the complete program from Explore the Code.
  22. Select Arduino Uno and the correct port.
  23. Verify and upload the Arduino sketch.
  24. Observe the startup message on the LCD.
  25. Press 1 and then 2 to enter the first number 12.
  26. Press A to select addition.
  27. Press 8 to enter the second number.
  28. Press # to calculate the result.
  29. Confirm that the LCD displays the result 20.00.
  30. Press * to clear the calculator.
  31. Repeat using B, C and D to test the other operations.
  32. Attempt division by zero and observe the error message.
  33. Confirm that each recognized keypress produces an audible beep.

Expected Output

After Arduino starts, the LCD displays the welcome screen for approximately two seconds.

The calculator then displays Enter Number: and waits for keypad input.

Each numeric key updates the entered expression.

Pressing A, B, C or D selects the corresponding arithmetic operation.

Pressing # calculates the result when both operands are available.

Result

The Keypad-Based Calculator with LCD and Buzzer experiment demonstrates basic arithmetic processing using Arduino UNO and a 4×4 matrix keypad.

The user can enter two numbers, select an operation and calculate a result.

The LCD displays expressions and results, while the buzzer provides audible keypress feedback.

The program also detects division by zero and displays an error message.
