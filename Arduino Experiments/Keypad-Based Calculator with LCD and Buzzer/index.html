Aim

Perform arithmetic calculations using a 4×4 keypad, 16×2 I2C LCD and buzzer.

About the Experiment

Perform arithmetic calculations using a 4×4 keypad, 16×2 I2C LCD and buzzer. This practical demonstrates sensor interfacing, digital and analog input/output and Arduino programming.

Components Required

Arduino UNO R3 (×1)

4×4 Matrix Keypad (×1)

16×2 I2C LCD Display (×1)

Buzzer (×1)

Working Principle

Digits → Operation A/B/C/D → Second number → # calculates → LCD result → * resets

Procedure

  1. Place the components on a breadboard and check the connections table.
  2. Connect the components to the Arduino UNO R3 using jumper wires.
  3. Open Arduino IDE, select Arduino UNO and install the libraries used in the code.
  4. Verify and upload the program.
  5. Observe the output and test the experiment's input conditions.
