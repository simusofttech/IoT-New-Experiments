Digital Weighing Force Indicator

← Arduino Experiments Aim Components Connections Working Procedure Code Result

Aim

To build a relative-force indicator using a Force Sensor, Arduino UNO, a 10 kΩ resistor and a 16×2 I²C LCD.

About the Experiment

The Force Sensor behaves as a variable resistor. Together with a fixed 10 kΩ resistor, it forms a voltage divider connected to Arduino analog pin A0.

Arduino reads the analog voltage, averages 20 samples for a steadier value, converts the result to a relative 0–100% force indication, and displays both the raw reading and force percentage on the I²C LCD.

Arduino UNO R3 (×1)

Procedure

  1. Connect one terminal of the Force Sensor to Arduino 5V.
  2. Connect the other Force Sensor terminal to Arduino A0.
  3. Connect one terminal of the 10 kΩ resistor to the same A0 junction.
  4. Connect the other terminal of the 10 kΩ resistor to GND.
  5. Connect the I²C LCD VCC to 5V.
  6. Connect the I²C LCD GND to GND.
  7. Connect the I²C LCD SDA pin to A4.
  8. Connect the I²C LCD SCL pin to A5.
  9. Connect Arduino UNO to the computer.
  10. Open Arduino IDE.
  11. Install the LiquidCrystal_I2C library if required.
  12. Enter the program given below.
  13. Select Arduino UNO and the correct COM port.
  14. Verify and upload the program.
  15. Apply different amounts of force to the sensor.
  16. Observe the raw value and relative force percentage on the LCD.

Arduino Code

Digital_Weighing_Force_Indicator.ino 
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);

const int forceSensorPin = A0;

void setup()
{
  lcd.init();
  lcd.backlight();

  lcd.setCursor(0, 0);
  lcd.print("FORCE INDICATOR");

  lcd.setCursor(0, 1);
  lcd.print("Starting...");

  delay(2000);

  lcd.clear();
}

void loop()
{
  long total = 0;

  // Average 20 readings for a steadier display
  for (int i = 0; i < 20; i++)
  {
    total += analogRead(forceSensorPin);
    delay(2);
  }

  int sensorValue = total / 20;

  // Relative force indication
  int forcePercent = map(sensorValue, 0, 1023, 0, 100);

  forcePercent = constrain(forcePercent, 0, 100);

  lcd.setCursor(0, 0);
  lcd.print("RAW: ");
  lcd.print(sensorValue);
  lcd.print(" ");

  lcd.setCursor(0, 1);
  lcd.print("FORCE: ");
  lcd.print(forcePercent);
  lcd.print("% ");

  delay(100);
}

Expected Output

Applying force to the sensor changes the analog reading at A0. The LCD displays the averaged raw ADC value and the corresponding relative force percentage.

LCD Line 1: RAW sensor value
LCD Line 2: Relative FORCE percentage
Force Scale: 0–100% relative indication

Result

The Digital Weighing Force Indicator experiment was implemented using Arduino UNO, a Force Sensor, a 10 kΩ resistor and a 16×2 I²C LCD. Applied force changes the sensor reading, which is converted into a relative 0–100% indication and displayed on the LCD.
