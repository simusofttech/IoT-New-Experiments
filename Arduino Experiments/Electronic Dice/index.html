Electronic Dice

← Arduino Experiments Aim Components Connections Circuit Working Procedure Code Result

Aim

To create an electronic dice using Arduino UNO, a push button and a single-digit common-anode 7-segment display.

About the Experiment

The display initially shows 1. When the push button is pressed, Arduino rapidly shows different numbers from 1 to 6 to create a dice-rolling effect.

After the rolling sequence, Arduino generates a random number from 1 to 6 and displays the final dice result on the 7-segment display. The same result is also shown on the Serial Monitor.

Procedure

  1. Connect display segment A to D2 through a 220Ω resistor.
  2. Connect display segment B to D3 through a 220Ω resistor.
  3. Connect display segment C to D4 through a 220Ω resistor.
  4. Connect display segment D to D5 through a 220Ω resistor.
  5. Connect display segment E to D6 through a 220Ω resistor.
  6. Connect display segment F to D7 through a 220Ω resistor.
  7. Connect display segment G to D8 through a 220Ω resistor.
  8. Connect the common anode of the display to Arduino 5V.
  9. Connect one terminal of the push button to A0.
  10. Connect the other terminal of the push button to GND.
  11. Connect Arduino UNO to the computer.
  12. Open Arduino IDE.
  13. Enter the program given below.
  14. Select Arduino UNO and the correct COM port.
  15. Verify and upload the program.
  16. Open Serial Monitor at 9600 baud.
  17. Press the push button and observe the electronic dice roll.

Arduino Code

Electronic_Dice.ino 
#define SEG_A 2
#define SEG_B 3
#define SEG_C 4
#define SEG_D 5
#define SEG_E 6
#define SEG_F 7
#define SEG_G 8

#define BUTTON_PIN A0

void displayNumber(int number)
{
  // Turn all segments OFF
  digitalWrite(SEG_A, HIGH);
  digitalWrite(SEG_B, HIGH);
  digitalWrite(SEG_C, HIGH);
  digitalWrite(SEG_D, HIGH);
  digitalWrite(SEG_E, HIGH);
  digitalWrite(SEG_F, HIGH);
  digitalWrite(SEG_G, HIGH);

  switch (number)
  {
    case 1:
      digitalWrite(SEG_B, LOW);
      digitalWrite(SEG_C, LOW);
      break;

    case 2:
      digitalWrite(SEG_A, LOW);
      digitalWrite(SEG_B, LOW);
      digitalWrite(SEG_D, LOW);
      digitalWrite(SEG_E, LOW);
      digitalWrite(SEG_G, LOW);
      break;

    case 3:
      digitalWrite(SEG_A, LOW);
      digitalWrite(SEG_B, LOW);
      digitalWrite(SEG_C, LOW);
      digitalWrite(SEG_D, LOW);
      digitalWrite(SEG_G, LOW);
      break;

    case 4:
      digitalWrite(SEG_B, LOW);
      digitalWrite(SEG_C, LOW);
      digitalWrite(SEG_F, LOW);
      digitalWrite(SEG_G, LOW);
      break;

    case 5:
      digitalWrite(SEG_A, LOW);
      digitalWrite(SEG_C, LOW);
      digitalWrite(SEG_D, LOW);
      digitalWrite(SEG_F, LOW);
      digitalWrite(SEG_G, LOW);
      break;

    case 6:
      digitalWrite(SEG_A, LOW);
      digitalWrite(SEG_C, LOW);
      digitalWrite(SEG_D, LOW);
      digitalWrite(SEG_E, LOW);
      digitalWrite(SEG_F, LOW);
      digitalWrite(SEG_G, LOW);
      break;
  }
}

void setup()
{
  pinMode(SEG_A, OUTPUT);
  pinMode(SEG_B, OUTPUT);
  pinMode(SEG_C, OUTPUT);
  pinMode(SEG_D, OUTPUT);
  pinMode(SEG_E, OUTPUT);
  pinMode(SEG_F, OUTPUT);
  pinMode(SEG_G, OUTPUT);

  pinMode(BUTTON_PIN, INPUT_PULLUP);

  Serial.begin(9600);

  // Randomize the random number
  randomSeed(analogRead(A1));

  // Initial dice value
  displayNumber(1);

  Serial.println("ELECTRONIC DICE");
  Serial.println("Press the button to roll.");
}

void loop()
{
  // Button pressed
  if (digitalRead(BUTTON_PIN) == LOW)
  {
    delay(50);

    if (digitalRead(BUTTON_PIN) == LOW)
    {
      // Dice rolling effect
      for (int i = 0; i < 10; i++)
      {
        int rollingNumber = random(1, 7);

        displayNumber(rollingNumber);

        delay(80 + i * 20);
      }

      // Generate final random number
      int diceNumber = random(1, 7);

      displayNumber(diceNumber);

      Serial.print("Dice Result: ");
      Serial.println(diceNumber);

      // Wait until button is released
      while (digitalRead(BUTTON_PIN) == LOW)
      {
        delay(10);
      }

      delay(200);
    }
  }
}

Expected Output

The display initially shows 1. When the push button is pressed, rapidly changing values create a rolling effect before the final random dice result from 1 to 6 is displayed.

Initial Display: 1
Button Press: Starts dice roll
Final Result: Random value from 1 to 6

Result

The Electronic Dice experiment was implemented using Arduino UNO, a push button and a common-anode 7-segment display. Each button press generates and displays a random dice value from 1 to 6.
