Aim

To create an electronic dice using Arduino UNO, a push button and a single-digit common-cathode 7-segment display.

Pressing the button generates a rolling-number animation followed by a random dice result from 1 to 6.

About the Experiment

Electronic Dice is an Arduino experiment that simulates rolling a six-sided dice.

A single-digit common-cathode 7-segment display shows the generated dice number.

At startup, the display initially shows 1.

When the push button is pressed, Arduino displays several changing random numbers between 1 and 6.

The rolling animation gradually slows down before the final random number is selected.

The selected number is displayed on the 7-segment display and printed to Serial Monitor.

The system then waits for the push button to be released before accepting another roll.

Important: The program uses pseudo-random number generation through random() and randomSeed(). It is intended for educational dice simulation.

Button Detection

The push button connects between Arduino A0 and GND. INPUT_PULLUP keeps the normal reading HIGH.

Pressing the button produces a LOW signal and starts the roll.

Rolling Animation

Arduino generates 15 temporary random values between 1 and 6.

The delay increases during successive numbers, creating a slowing dice-rolling effect.

Final Dice Result

After the animation, Arduino generates a new random number from 1 to 6.

This number remains on the display until the next roll begins.

Procedure

  1. Place Arduino UNO and the breadboard on a stable working surface.
  2. Verify that the 7-segment display is common-cathode.
  3. Identify the physical segment pins A–G.
  4. Place the display on the breadboard.
  5. Connect segment A to D2 through a 220Ω resistor.
  6. Connect segment B to D3 through a 220Ω resistor.
  7. Connect segment C to D4 through a 220Ω resistor.
  8. Connect segment D to D5 through a 220Ω resistor.
  9. Connect segment E to D6 through a 220Ω resistor.
  10. Connect segment F to D7 through a 220Ω resistor.
  11. Connect segment G to D8 through a 220Ω resistor.
  12. Connect the display's common-cathode pins to GND.
  13. Connect the push button between A0 and GND.
  14. Verify all connections and component polarity.
  15. Open Arduino IDE.
  16. Create a sketch named Electronic_Dice.ino.
  17. Copy the complete corrected sketch from Explore the Code.
  18. Select Arduino Uno and the correct communication port.
  19. Verify and upload the program.
  20. Open Serial Monitor at 9600 baud.
  21. Observe the initial display value of 1.
  22. Press the button to start a dice roll.
  23. Observe the changing display values.
  24. Record the final number between 1 and 6.
  25. Compare the final display with Serial Monitor.
  26. Repeat the roll several times.

Result

The Electronic Dice experiment demonstrates a push-button controlled dice simulation using Arduino UNO and a common-cathode 7-segment display.

Each valid button press generates a rolling animation followed by a random number from 1 to 6.

The final result appears on the display and in Serial Monitor.
