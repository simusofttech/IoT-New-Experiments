Aim

To demonstrate automatic light direction indication using three simulated light-intensity values and a servo motor controlled by Arduino UNO.

The system compares left, center and right values and rotates the servo toward the direction with the highest value.

About the Experiment

Automatic Light Direction Indication demonstrates how Arduino UNO can compare three light-intensity values and rotate a servo motor accordingly.

The circuit includes three LDR sensing circuits representing the left, center and right directions.

The existing Arduino program generates simulated light-intensity readings using the random() function every two seconds.

Arduino compares these readings and identifies the direction having the highest value.

The servo motor moves smoothly toward 30° for left, 90° for center, or 150° for right.

Important: The supplied Arduino program uses randomly generated values. It does not read actual light intensity from the connected LDRs. The physical LDR circuits are shown for hardware learning, while this program demonstrates simulated direction selection.

Smooth Servo Movement

Instead of immediately jumping to the target angle, the Arduino increases or decreases the current angle one degree at a time.

A 15-millisecond delay is used between movement commands, creating a gradual rotation.

Procedure

  1. Place the Arduino UNO and breadboard on a stable surface.
  2. Connect the left LDR voltage-divider circuit to Arduino A0.
  3. Connect the center LDR circuit to Arduino A1.
  4. Connect the right LDR circuit to Arduino A2.
  5. Use one 10kΩ resistor for each LDR circuit.
  6. Connect all required ground connections.
  7. Connect the servo signal wire to D9.
  8. Connect servo VCC to a suitable regulated 5V supply.
  9. Connect servo GND to the common ground.
  10. Verify the complete circuit connections.
  11. Open Arduino IDE.
  12. Create the sketch Automatic_Light_Direction_Indication.ino.
  13. Copy the complete program from Explore the Code.
  14. Select Arduino Uno under Tools → Board.
  15. Select the correct communication port.
  16. Verify and upload the Arduino sketch.
  17. Open Serial Monitor at 9600 baud.
  18. Observe the three randomly generated light values.
  19. Observe the selected direction and corresponding servo movement.
  20. Verify the servo moves smoothly toward 30°, 90° or 150°.
  21. Observe that new simulated values are generated every two seconds.

Result

The Automatic Light Direction Indication experiment demonstrates comparison of three simulated light-intensity values and directional servo control.

Arduino identifies the largest simulated value and smoothly moves the servo toward 30°, 90° or 150°.

The existing program does not read actual LDR sensor values.
