Rain Alert Indicator

Aim

Detect rain with a rain sensor plate and alert with a red LED and active buzzer.

About the Experiment

Detect rain with a rain sensor plate and alert with a red LED and active buzzer. This educational experiment demonstrates sensor input, microcontroller processing and output control.

Components Required

Arduino UNO R3Quantity: 1
Rain Sensor Module (plate + comparator)Quantity: 1
Red LEDQuantity: 1
220Ω ResistorQuantity: 1

BreadboardQuantity: 1

Circuit Connections

Buzzer −GND

The sketch assumes active-LOW sensor output. Check the module's output polarity and adjust the comparator threshold. Keep electronics dry; wet only the sensing plate.

Circuit Diagram

Working Principle

Rain sensor DO → Arduino D2 → Rain detection → LED D8 + Buzzer D9

Procedure

  1. Gather the components and verify their pin labels.
  2. Connect the components as shown in the Circuit Connections table.
  3. Open Arduino IDE and select Arduino UNO.
  4. Enter the SOP sketch in the code section below.
  5. Verify and upload the code to the board.
  6. Test the input and observe the output response.

#define RAIN_SENSOR 2#define LED_PIN 8#define BUZZER_PIN 9 void setup() { Serial.begin(9600); pinMode(RAIN_SENSOR, INPUT); pinMode(LED_PIN, OUTPUT); pinMode(BUZZER_PIN, OUTPUT); digitalWrite(LED_PIN, LOW); digitalWrite(BUZZER_PIN, LOW); Serial.println("RAIN DETECTOR SYSTEM READY");} void loop() { int rainStatus = digitalRead(RAIN_SENSOR); // This sketch assumes DO is LOW when rain is detected. if (rainStatus == LOW) { Serial.println("STATUS: RAIN DETECTED"); digitalWrite(LED_PIN, HIGH); digitalWrite(BUZZER_PIN, HIGH); } else { Serial.println("STATUS: NO RAIN"); digitalWrite(LED_PIN, LOW); digitalWrite(BUZZER_PIN, LOW); } delay(500);}

Expected Output

Dry sensor: LED and buzzer OFF. Rain detected: red LED and buzzer ON.

Result

Dry sensor: LED and buzzer OFF. Rain detected: red LED and buzzer ON. The experiment demonstrates the intended input-to-output control.
