Programmable Electronic Control Console

← Arduino Experiments Aim Components Connections Working Procedure Code Result

Aim

To create a programmable electronic control console using Arduino UNO, a 4×4 keypad, LCD, 4-digit display, relay and buzzer.

About the Experiment

The 4×4 keypad is used to enter different commands. Arduino reads each key and performs the assigned action.

The LCD shows the selected operation and system status. The relay and buzzer can be controlled using different keypad keys.

Components Required

Arduino UNO R3 (×1)

Main controller for the control console.

4×4 Keypad (×1)

Used to enter commands and select operations.

LCD1602 I²C (×1)

Displays commands, values and system status.

Included in the control console display system.

SPDT Relay (×1)

Provides key and alert sounds.

Working Principle

Arduino Starts
↓
LCD shows System Ready
↓
User presses a keypad key
↓
Arduino reads the selected key
↓
Assigned relay, buzzer or display action is performed
↓
LCD shows the selected operation or system status
Key 1: Relay ON
Key 2: Relay OFF
Key 3: Buzzer ON
Key 4: Buzzer OFF
Keys 5–9: Show selected key
Key 0: Reset system
Key A: Display 1234
Key B: Display 0000
Key C: Relay + buzzer
Key D: Relay OFF + buzzer alert
Key *: Clear display
Key #: Show relay status

Procedure

  1. Connect keypad rows R1–R4 to D2–D5.
  2. Connect keypad columns C1–C4 to D6–D9.
  3. Connect LCD SDA to A4 and SCL to A5.
  4. Connect the 4-digit display SDA to A4 and SCK to A5.
  5. Connect relay control to D10.
  6. Connect buzzer positive terminal to D11 and negative terminal to GND.
  7. Connect all required 5V and GND connections.
  8. Open Arduino IDE.
  9. Install the Keypad and LiquidCrystal_I2C libraries if required.
  10. Enter the Arduino program given below.
  11. Upload the program to Arduino UNO.
  12. Press different keypad keys and observe the LCD, relay and buzzer response.

Arduino Code

Programmable_Electronic_Control_Console.ino 
#include <Keypad.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// LCD
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Keypad size
const byte rows = 4;
const byte cols = 4;

// Keypad buttons
char keys[rows][cols] =
{
  {'1', '2', '3', 'A'},
  {'4', '5', '6', 'B'},
  {'7', '8', '9', 'C'},
  {'*', '0', '#', 'D'}
};

// Keypad connections
byte rowPins[rows] = {2, 3, 4, 5};
byte colPins[cols] = {6, 7, 8, 9};

// Create keypad
Keypad keypad = Keypad(
  makeKeymap(keys),
  rowPins,
  colPins,
  rows,
  cols
);

// Output pins
int relay = 10;
int buzzer = 11;

void setup()
{
  pinMode(relay, OUTPUT);
  pinMode(buzzer, OUTPUT);

  // Start with relay and buzzer OFF
  digitalWrite(relay, LOW);
  digitalWrite(buzzer, LOW);

  // Start LCD
  lcd.init();
  lcd.backlight();

  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Control Console");

  lcd.setCursor(0, 1);
  lcd.print("System Ready");

  delay(2000);

  lcd.clear();
  lcd.print("Press Key");
}

void loop()
{
  // Read keypad
  char key = keypad.getKey();

  // Run only when a key is pressed
  if (key)
  {
    // Short beep
    digitalWrite(buzzer, HIGH);
    delay(80);
    digitalWrite(buzzer, LOW);

    // Key 1 = Relay ON
    if (key == '1')
    {
      digitalWrite(relay, HIGH);

      lcd.clear();
      lcd.print("RELAY: ON");

      lcd.setCursor(0, 1);
      lcd.print("Key 1");
    }

    // Key 2 = Relay OFF
    else if (key == '2')
    {
      digitalWrite(relay, LOW);

      lcd.clear();
      lcd.print("RELAY: OFF");

      lcd.setCursor(0, 1);
      lcd.print("Key 2");
    }

    // Key 3 = Buzzer ON
    else if (key == '3')
    {
      digitalWrite(buzzer, HIGH);

      lcd.clear();
      lcd.print("BUZZER: ON");

      lcd.setCursor(0, 1);
      lcd.print("Key 3");
    }

    // Key 4 = Buzzer OFF
    else if (key == '4')
    {
      digitalWrite(buzzer, LOW);

      lcd.clear();
      lcd.print("BUZZER: OFF");

      lcd.setCursor(0, 1);
      lcd.print("Key 4");
    }

    // Keys 5 to 9
    else if (key >= '5' && key <= '9')
    {
      lcd.clear();
      lcd.print("Selected Key:");

      lcd.setCursor(0, 1);
      lcd.print(key);
    }

    // Key 0 = Reset
    else if (key == '0')
    {
      digitalWrite(relay, LOW);
      digitalWrite(buzzer, LOW);

      lcd.clear();
      lcd.print("SYSTEM RESET");

      lcd.setCursor(0, 1);
      lcd.print("Relay: OFF");
    }

    // Key A
    else if (key == 'A')
    {
      lcd.clear();
      lcd.print("Value:");

      lcd.setCursor(0, 1);
      lcd.print("1234");
    }

    // Key B
    else if (key == 'B')
    {
      lcd.clear();
      lcd.print("Value:");

      lcd.setCursor(0, 1);
      lcd.print("0000");
    }

    // Key C
    else if (key == 'C')
    {
      digitalWrite(relay, HIGH);

      lcd.clear();
      lcd.print("RELAY + BUZZER");

      lcd.setCursor(0, 1);
      lcd.print("ACTIVE");

      digitalWrite(buzzer, HIGH);
      delay(500);
      digitalWrite(buzzer, LOW);
    }

    // Key D
    else if (key == 'D')
    {
      digitalWrite(relay, LOW);

      lcd.clear();
      lcd.print("RELAY OFF");

      lcd.setCursor(0, 1);
      lcd.print("BUZZER ALERT");

      digitalWrite(buzzer, HIGH);
      delay(500);
      digitalWrite(buzzer, LOW);
    }

    // * = Clear LCD
    else if (key == '*')
    {
      lcd.clear();
      lcd.print("Display Cleared");

      lcd.setCursor(0, 1);
      lcd.print("Press Key");
    }

    // # = Show relay status
    else if (key == '#')
    {
      lcd.clear();
      lcd.print("SYSTEM STATUS");

      lcd.setCursor(0, 1);

      if (digitalRead(relay) == HIGH)
      {
        lcd.print("Relay: ON");
      }
      else
      {
        lcd.print("Relay: OFF");
      }
    }

    delay(200);
  }
}

Expected Output

Pressing different keypad keys performs different control operations. The LCD displays the selected command and system status while the relay and buzzer respond according to the programmed key.

2: Relay OFF
3: Buzzer ON

D: Relay OFF + Alert

Result

The Programmable Electronic Control Console experiment was implemented using Arduino UNO and a 4×4 keypad. Different keypad commands control the relay and buzzer while the LCD displays the selected operation and system status.
