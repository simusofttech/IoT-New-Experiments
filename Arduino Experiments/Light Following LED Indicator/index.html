Light Following LED Indicator

← Arduino Experiments Aim Components Connections Working Procedure Code Result

Aim

To compare light intensity from the left and right sides using two LDR sensors and indicate the brighter side using LEDs.

About the Experiment

Two LDR sensors detect light from the left and right sides.

Arduino compares both readings. The LED on the side receiving more light turns ON. If both sides have the same light level, both LEDs remain OFF.

Components Required

Arduino UNO R3 (×1)

Main controller for comparing light readings.

LDR (×2)

Detects light intensity.

LED (×2)

Indicates the brighter side.

10KΩ Resistor (×2)

Used with the LDR voltage divider.

220Ω Resistor (×2)

Limits current through the LEDs.

Breadboard (×1)

Used to assemble the LDR and LED circuits.

Used for electrical connections.

Working Principle

Arduino reads both LDRs
↓
Compare Left and Right readings
↓
Left is brighter → Left LED ON
Right is brighter → Right LED ON
Equal light → Both LEDs OFF

Procedure

  1. Connect the left LDR circuit to A1.
  2. Connect the right LDR circuit to A0.
  3. Connect the left LED to D7 through a 220Ω resistor.
  4. Connect the right LED to D8 through a 220Ω resistor.
  5. Upload the Arduino code.
  6. Open Serial Monitor at 9600 baud.
  7. Change the light falling on each LDR and observe the LEDs.

Arduino Code

Light_Following_LED_Indicator.ino 
// LDR pins
int leftLDR = A1;
int rightLDR = A0;

// LED pins
int leftLED = 7;
int rightLED = 8;

void setup()
{
  pinMode(leftLED, OUTPUT);
  pinMode(rightLED, OUTPUT);

  Serial.begin(9600);
}

void loop()
{
  // Read both LDR sensors
  int leftLight = analogRead(leftLDR);
  int rightLight = analogRead(rightLDR);

  // Show readings
  Serial.print("Left: ");
  Serial.print(leftLight);

  Serial.print("  Right: ");
  Serial.println(rightLight);

  // More light on left side
  if (leftLight > rightLight)
  {
    digitalWrite(leftLED, HIGH);
    digitalWrite(rightLED, LOW);
  }

  // More light on right side
  else if (rightLight > leftLight)
  {
    digitalWrite(leftLED, LOW);
    digitalWrite(rightLED, HIGH);
  }

  // Same light on both sides
  else
  {
    digitalWrite(leftLED, LOW);
    digitalWrite(rightLED, LOW);
  }

  delay(200);
}

Expected Output

If the left LDR senses more light, the left LED turns ON. If the right LDR senses more light, the right LED turns ON. If both readings are equal, both LEDs remain OFF.

Result

The Light Following LED Indicator experiment compares light from two directions and indicates the brighter side using LEDs.
