Arduino Project No. 1

Digital Tone Generator

← Arduino Projects Aim Components Connections Circuit Working Procedure Code Result

Aim

To create a Digital Tone Generator using Arduino UNO, a 10 kΩ potentiometer and an active buzzer, where rotating the potentiometer changes the pitch of the sound.

About the Project

The potentiometer provides an analog value to Arduino through pin A0. Arduino converts this value into a sound frequency between 100 Hz and 2000 Hz.

The buzzer connected to digital pin 8 produces the corresponding tone. Rotating the potentiometer changes the frequency and therefore changes the pitch.

Procedure

  1. Place the Arduino UNO, potentiometer, buzzer and breadboard on the working area.
  2. Connect the left pin of the potentiometer to 5V.
  3. Connect the middle pin (wiper) of the potentiometer to A0.
  4. Connect the right pin of the potentiometer to GND.
  5. Connect the positive terminal of the active buzzer to digital pin 8.
  6. Connect the negative terminal of the buzzer to GND.
  7. Connect the Arduino UNO to the computer using USB.
  8. Open Arduino IDE.
  9. Enter the program given below.
  10. Select Arduino UNO from Tools → Board.
  11. Select the correct COM port.
  12. Click Verify and then Upload.
  13. Rotate the potentiometer and observe the change in buzzer pitch.

Arduino Code

Digital_Tone_Generator.ino 
const int potPin = A0;
const int buzzerPin = 8;

void setup () {
  pinMode(buzzerPin, OUTPUT);
}

void loop() {
  int potValue = analogRead(potPin);

  // Convert potentiometer value (0–1023)
  // into frequency (100–2000 Hz)
  int frequency = map(potValue, 0, 1023, 100, 2000);

  // Generate tone
  tone(buzzerPin, frequency);

  delay(20);
}

Expected Output

When the potentiometer is rotated, the buzzer pitch changes continuously. One direction produces a lower tone while the opposite direction produces a higher tone.

Potentiometer value: 0–1023
Output frequency: 100–2000 Hz

Result

The Digital Tone Generator project was implemented using Arduino UNO, a 10 kΩ potentiometer and an active buzzer. Rotating the potentiometer changes the tone frequency and therefore changes the pitch of the sound.
