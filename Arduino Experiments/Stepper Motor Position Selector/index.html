Aim

To create a keypad-controlled motor position selection experiment using Arduino UNO, a 4×4 matrix keypad, a 16×2 I²C LCD, an L293D motor driver and a motor.

The user enters a numerical target position using the keypad. Arduino compares the target with a software position counter and commands forward or reverse motor movement.

About the Experiment

The Stepper Motor Position Selector demonstrates keypad input, LCD status display, motor direction control and simulated position tracking using Arduino UNO.

A 4×4 matrix keypad allows numerical target values to be entered. The program accepts up to six digits before confirmation.

Pressing the hash key (#) converts the entered number into a target position and starts the movement procedure.

The LCD displays the current and target position.

Arduino compares the entered target with currentPosition, which begins at zero.

If the target is greater than the current position, the motor is driven forward.

If the target is smaller, the motor is driven in reverse.

The program increments or decrements the currentPosition variable once every 100 milliseconds until the target is reached.

The motor stops at the end of the software counting sequence, and the LCD shows TARGET REACHED.

Additional keypad keys provide commands for clearing input, displaying positions, stopping the motor and resetting the position counter.

Important Hardware Clarification:

Although the experiment is named Stepper Motor Position Selector, the supplied sketch uses one L293D H-bridge channel with EN1, IN1 and IN2.

This is direction control suitable for a compatible two-terminal DC motor, not complete stepper-motor phase control.

The sketch does not read an encoder, limit switch or any other position feedback. Its currentPosition is a simulated software counter, not a measurement of physical position.

The original sketch has been preserved without silently replacing the motor-control logic.

L293D Hardware Notes:

The table retains the signal names and Arduino pin assignments from the uploaded source.

For a bare L293D integrated circuit, EN1, IN1, IN2, OUT1, OUT2, logic supply, motor supply and ground must be connected to their correct physical IC pins.

Driver boards may have different terminal labels or integrated enable jumpers. Follow the actual board's pinout.

The motor supply must match both the motor and driver's voltage and current ratings. The motor-supply ground must be common with Arduino ground.

A conventional four-wire bipolar stepper motor cannot be properly positioned by only one H-bridge channel. This sketch provides no stepping sequence.

Keypad Input

Arduino scans a 4×4 matrix keypad using the Keypad library.

Numeric keys allow entry of up to six digits. These digits are stored temporarily as a String.

When # is pressed, the entered String is converted to a long target-position value.

Keypad Control Functions

Key Function
0–9 Enter numerical target
# Confirm target and execute movement
* Clear typed input and stop motor output
A Set current software position to zero
B Stop motor output
C Display current and target positions
D Reset current position counter to zero

Forward Motor Control

When targetPosition is greater than currentPosition, motorForward() sets EN1 HIGH, IN1 HIGH and IN2 LOW.

The software counter increases by one after every programmed 100 ms delay until it reaches the target.

Reverse Motor Control

When the target is less than the current counter, motorReverse() sets EN1 HIGH, IN1 LOW and IN2 HIGH.

The software counter decreases by one after each 100 ms interval until it reaches the target.

Target Reached

When the counter equals the target, Arduino disables the motor output and displays TARGET REACHED.

It then returns to the regular LCD status view.

Software Position Tracking

Simulated Counter Formula:

Forward: currentPosition = currentPosition + 1

Reverse: currentPosition = currentPosition - 1

The counter changes once per nominal 100 ms interval. It is not linked to an encoder, physical step or measured angle.

100 ms Counter update delay
6 digits Maximum target input length
0x27 LCD I²C address
2 directions Forward and reverse control
Control Limitation:

moveToTarget() uses blocking while loops.

During a movement loop, the code does not call keypad.getKey().

Consequently, pressing B or * during movement does not immediately interrupt the motor. Those commands are only processed once the loop returns to keypad scanning.

A true position-controlled implementation would need appropriate motor stepping or position feedback and an interruptible control loop.

The keypad is not read during these loops. The stop command therefore does not work as an immediate emergency stop during a long movement.

Result

The Stepper Motor Position Selector experiment demonstrates how Arduino UNO can accept a numerical target from a 4×4 keypad, display position information on a 16×2 I²C LCD, and command a motor driver in forward and reverse directions.

The current position is represented using a software counter that changes once per programmed 100 ms interval.

The motor command stops when the simulated current position matches the entered target.

This demonstrates keypad interfacing, target comparison, direction control and simulated position tracking.

Actual stepper positioning or closed-loop physical positioning is not implemented by the supplied sketch.

Arduino Code

Stepper_Motor_Position_Selector.ino 
#include <Keypad.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);

// KEYPAD
const byte ROWS = 4;
const byte COLS = 4;

char keys[ROWS][COLS] =
{
  {'1','2','3','A'},
  {'4','5','6','B'},
  {'7','8','9','C'},
  {'*','0','#','D'}
};

byte rowPins[ROWS] = {4, 5, 6, 7};
byte colPins[COLS] = {8, 9, 10, 11};

Keypad keypad = Keypad(
  makeKeymap(keys),
  rowPins,
  colPins,
  ROWS,
  COLS
);

// MOTOR DRIVER
const int EN1 = 12;
const int IN1 = 13;
const int IN2 = A0;

// POSITION
long currentPosition = 0;
long targetPosition = 0;

String inputNumber = "";

void setup()
{
  pinMode(EN1, OUTPUT);
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);

  motorStop();

  lcd.init();
  lcd.backlight();

  lcd.setCursor(0, 0);
  lcd.print("POSITION SELECT");

  lcd.setCursor(0, 1);
  lcd.print("Enter Target");

  delay(2000);

  showTarget();
}

void loop()
{
  char key = keypad.getKey();

  if (key)
  {
    // Numerical target entry
    if (key >= '0' && key <= '9')
    {
      if (inputNumber.length() < 6)
      {
        inputNumber += key;

        lcd.clear();
        lcd.setCursor(0, 0);
        lcd.print("Target:");
        lcd.print(inputNumber);

        lcd.setCursor(0, 1);
        lcd.print("#=GO *=CLEAR");
      }
    }

    // Confirm target
    else if (key == '#')
    {
      if (inputNumber.length() > 0)
      {
        targetPosition = inputNumber.toInt();
        inputNumber = "";

        lcd.clear();
        lcd.setCursor(0, 0);
        lcd.print("Target:");
        lcd.print(targetPosition);

        moveToTarget();
      }
    }

    // Clear target input
    else if (key == '*')
    {
      inputNumber = "";
      motorStop();
      showTarget();
    }

    // Zero current position
    else if (key == 'A')
    {
      motorStop();
      currentPosition = 0;

      lcd.clear();
      lcd.setCursor(0, 0);
      lcd.print("Position ZERO");

      lcd.setCursor(0, 1);
      lcd.print("Current: 0");

      delay(1200);
      showTarget();
    }

    // Stop motor
    else if (key == 'B')
    {
      motorStop();

      lcd.clear();
      lcd.setCursor(0, 0);
      lcd.print("MOTOR STOPPED");

      lcd.setCursor(0, 1);
      lcd.print("Current:");
      lcd.print(currentPosition);

      delay(1200);
      showTarget();
    }

    // Show current position
    else if (key == 'C')
    {
      motorStop();

      lcd.clear();
      lcd.setCursor(0, 0);
      lcd.print("Current:");
      lcd.print(currentPosition);

      lcd.setCursor(0, 1);
      lcd.print("Target:");
      lcd.print(targetPosition);

      delay(1200);
      showTarget();
    }

    // Reset position counter
    else if (key == 'D')
    {
      motorStop();
      currentPosition = 0;

      lcd.clear();
      lcd.setCursor(0, 0);
      lcd.print("COUNTER RESET");

      lcd.setCursor(0, 1);
      lcd.print("Current: 0");

      delay(1200);
      showTarget();
    }
  }
}

void moveToTarget()
{
  if (targetPosition == currentPosition)
  {
    motorStop();

    lcd.clear();
    lcd.setCursor(0, 0);
    lcd.print("TARGET REACHED");

    lcd.setCursor(0, 1);
    lcd.print("Pos:");
    lcd.print(currentPosition);

    delay(1200);
    showTarget();
    return;
  }

  // Move forward
  if (targetPosition > currentPosition)
  {
    motorForward();

    while (currentPosition < targetPosition)
    {
      // Simulation step:
      // Increase one position unit per step.
      currentPosition++;

      lcd.setCursor(0, 0);
      lcd.print("Moving Forward ");

      lcd.setCursor(0, 1);
      lcd.print("Pos:");
      lcd.print(currentPosition);
      lcd.print(" ");

      delay(100);
    }
  }

  // Move reverse
  else
  {
    motorReverse();

    while (currentPosition > targetPosition)
    {
      // Simulation step:
      // Decrease one position unit per step.
      currentPosition--;

      lcd.setCursor(0, 0);
      lcd.print("Moving Reverse ");

      lcd.setCursor(0, 1);
      lcd.print("Pos:");
      lcd.print(currentPosition);
      lcd.print(" ");

      delay(100);
    }
  }

  motorStop();

  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("TARGET REACHED");

  lcd.setCursor(0, 1);
  lcd.print("Pos:");
  lcd.print(currentPosition);

  delay(1200);

  showTarget();
}

void motorForward()
{
  digitalWrite(EN1, HIGH);
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
}

void motorReverse()
{
  digitalWrite(EN1, HIGH);
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, HIGH);
}

void motorStop()
{
  digitalWrite(EN1, LOW);
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, LOW);
}

void showTarget()
{
  lcd.clear();

  lcd.setCursor(0, 0);
  lcd.print("Target:");
  lcd.print(targetPosition);

  lcd.setCursor(0, 1);
  lcd.print("Current:");
  lcd.print(currentPosition);
}
