Aim

To create an electronic safe using Arduino UNO, a 4×4 keypad, a servo motor, a 16×2 I²C LCD and a buzzer.

The system checks a four-digit PIN and operates a servo-based locking mechanism when the correct PIN is entered.

About the Experiment

The Electronic Safe with Keypad demonstrates a password-controlled locking mechanism using Arduino UNO.

A 4×4 matrix keypad is used to enter a four-digit PIN. A 16×2 I²C LCD displays the entry prompt and system status.

The entered PIN digits are hidden on the LCD using asterisk characters.

Pressing the # key checks the entered PIN against the stored password.

When the correct PIN is entered, the servo moves from 0° to 90° to represent unlocking the safe.

The LCD shows Access Granted and the buzzer generates a success sound.

An incorrect PIN displays Access Denied and activates the error sound.

When the safe is unlocked, pressing * moves the servo to its locked position.

Default PIN: 1234

This is an educational demonstration, not a security-rated safe. The PIN is stored directly in the Arduino sketch, and no failed-attempt lockout is implemented.

PIN Entry

Arduino reads each pressed key using keypad.getKey().

Numeric keys are added to the entered PIN until four digits have been entered.

The LCD displays asterisks instead of the actual entered digits.

PIN Verification

Pressing # starts the verification process.

The entered four-character PIN is compared with the stored default PIN using strcmp().

Correct PIN

When the PIN matches, Arduino moves the servo to 90° and displays Access Granted.

The buzzer generates two programmed success tones.

Incorrect PIN

When the PIN does not match, the LCD displays Wrong PIN and Access Denied.

The buzzer generates three error tones.

Locking the Safe

Pressing * while the safe is unlocked returns the servo to 0°.

Unlocked Position 90°

PIN Behavior: The original sketch clears the entered PIN when the safe is relocked or when an incorrect PIN is entered. After successful unlocking, the entered PIN remains stored until the safe is locked. The A, B, C and D keys are ignored.

Procedure

  1. Place Arduino UNO, the keypad, servo motor, LCD and buzzer on a stable surface.
  2. Identify the keypad rows and columns.
  3. Connect keypad rows R1–R4 to D2–D5.
  4. Connect keypad columns C1–C4 to D6–D9.
  5. Connect the servo signal wire to D10.
  6. Connect servo VCC to a suitable regulated 5V supply.
  7. Connect servo GND to the common ground.
  8. Connect buzzer positive to D11 if suitable for direct pin drive.
  9. Connect buzzer negative to GND.
  10. Connect LCD VCC to Arduino 5V.
  11. Connect LCD GND to Arduino GND.
  12. Connect LCD SDA to Arduino A4.
  13. Connect LCD SCL to Arduino A5.
  14. Verify all connections, including the keypad terminal order.
  15. Open Arduino IDE.
  16. Install the required Keypad, Servo and LiquidCrystal_I2C libraries.
  17. Create a sketch named Electronic_Safe_with_Keypad.ino.
  18. Copy the complete Arduino code from Explore the Code.
  19. Select Arduino Uno and the correct communication port.
  20. Verify and upload the program.
  21. Observe the Enter PIN message on the LCD.
  22. Enter 1234 and press #.
  23. Observe Access Granted and the servo moving to 90°.
  24. Press * to lock the safe again.
  25. Enter an incorrect four-digit PIN and press #.
  26. Observe the Access Denied message and error buzzer pattern.

Explore more: Matrix Keypad

A 4×4 matrix keypad has four row lines and four column lines.

The Keypad library scans the rows and columns to identify which key is pressed.

Explore more: PIN Security

The program stores its PIN as a character array. strcmp() compares the entered PIN with the stored PIN.

LCD masking hides the digits from casual observation, but it does not protect the stored PIN from someone who can inspect the program.

Sound Feedback:

Correct PIN: two programmed success tones.

Incorrect PIN: three programmed error tones.

Locking: one short programmed tone.

Distinct pitches require a suitable buzzer, typically a passive buzzer.

Result

The Electronic Safe with Keypad experiment demonstrates four-digit PIN verification using Arduino UNO and a 4×4 matrix keypad.

A correct PIN moves the servo to the unlocked position and displays Access Granted.

An incorrect PIN activates the error response. Pressing * while unlocked returns the servo to the locked position.
