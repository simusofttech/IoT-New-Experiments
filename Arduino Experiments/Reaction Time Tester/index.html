Aim

To design and develop a Reaction Time Tester using Arduino UNO R3, a push button, LED, buzzer and an I²C 4-digit 7-segment display.

The experiment measures the time between a visual start signal and a user's response using the push button.

The measured reaction time is displayed in milliseconds on the 4-digit display.

About the Experiment

The Reaction Time Tester is an interactive Arduino experiment designed to measure how quickly a user responds to a visual stimulus.

At the start of each round, Arduino waits for a random duration before activating the LED and buzzer.

The random delay varies from approximately 2 to 5 seconds. This reduces the ability to predict exactly when the start signal will appear.

The red or standard LED connected to D8 provides a visual start signal.

The buzzer connected to D9 produces a short audible signal when the LED is activated.

The user presses a push button connected to D2 as quickly as possible after the start signal.

Arduino uses millis() to measure the elapsed time between the recorded start timestamp and the button press.

The calculated reaction time is displayed on a 4-digit 7-segment display using I²C communication.

The display is expected to use an HT16K33 controller at I²C address 0x70.

After the button is pressed, Arduino switches OFF the LED and produces a 200-millisecond result beep.

The reaction time remains displayed for three seconds before another round begins.

Important Timing Detail:

In the original sketch, the start timestamp is recorded after the 100 ms start buzzer pulse.

Therefore, the measured interval begins about 100 ms after the LED first turns ON.

The program also does not implement a dedicated false-start check during the random waiting period.

These characteristics are preserved because the original code has not been modified.

Required Arduino Libraries:

The original program includes Wire.h for I²C communication.

Wire is part of the standard Arduino environment for Arduino UNO.

No separate 7-segment display library is used because the sketch writes HT16K33 commands directly over I²C.

Confirm that the display module has a compatible HT16K33 interface before testing.

Display Compatibility:

The Arduino sketch assumes an HT16K33 display backpack using address 0x70.

A bare 4-digit 7-segment display cannot be connected using only VCC, GND, SDA and SCL.

A TM1637 module is also different and is not compatible with the original HT16K33 commands.

Verify the actual display module and its digit mapping before using the sketch.

Connection Summary:
  • Push Button → D2 and GND
  • LED Anode → D8 through 220Ω
  • LED Cathode → GND
  • Buzzer Positive → D9
  • Buzzer Negative → GND
  • HT16K33 Display SDA → A4
  • HT16K33 Display SCL → A5
  • HT16K33 Display VCC → 5V
  • HT16K33 Display GND → GND

Use an active buzzer that is electrically safe for Arduino pin control. A higher-current buzzer requires a suitable driver.

Random Waiting Period

The sketch uses random(2000, 5000) to generate an unpredictable delay.

The selected value ranges from 2000 up to 4999 milliseconds.

This is approximately two to five seconds.

Start Signal

After the random wait, Arduino switches the LED ON and activates the buzzer.

The buzzer remains active for 100 ms, after which it is switched OFF.

The program then records the startTime value using millis().

Reaction Time Measurement

The program waits until the button input becomes LOW.

While waiting, Arduino continuously calculates and displays the elapsed time up to the programmed display limit.

Formula:

Reaction Time = Button Press Timestamp − Recorded Start Timestamp

The result is measured in milliseconds.

Reaction Time Display

The displayNumber() function separates the measured value into four decimal digits.

Each digit is converted into a 7-segment pattern using the digitCode array.

The segment data is then transmitted to the HT16K33 display controller through I²C.

Display Range

The displayNumber() function limits displayed results to a maximum of 9999.

Measurements exceeding this value are shown as 9999, even if the actual elapsed time was longer.

Result Confirmation

When the button is pressed, Arduino turns OFF the LED, displays the result and sounds the buzzer for 200 ms.

The display keeps the result visible for three seconds.

2–5 s Random waiting period
100 ms Start buzzer pulse
9999 ms Maximum display value
3 s Result display duration
Timing Limitation:

The original code records startTime after the initial 100 ms buzzer delay.

As a result, the calculated interval is not measured from the exact instant the LED first illuminates.

There is also no dedicated early-press rejection logic.

Procedure

  1. Place Arduino UNO, push button, LED, 220Ω resistor, buzzer, HT16K33 4-digit display and breadboard on the working surface.
  2. Identify the push button's switched terminals.
  3. Connect one button terminal to D2.
  4. Connect the other button terminal to GND.
  5. Connect the LED anode to D8 through a 220Ω resistor.
  6. Connect the LED cathode to GND.
  7. Connect the buzzer positive terminal to D9 if suitable for direct drive.
  8. Connect the buzzer negative terminal to GND.
  9. Identify the four pins on the HT16K33 display module.
  10. Connect the display VCC to Arduino 5V.
  11. Connect the display GND to GND.
  12. Connect display SDA to A4.
  13. Connect display SCL to A5.
  14. Verify that the display address is 0x70 and the controller is HT16K33-compatible.
  15. Check all electrical connections before applying power.
  16. Open Arduino IDE.
  17. Create a sketch named Reaction_Time_Tester.ino.
  18. Copy the complete Arduino code from Explore the Code.
  19. Select Arduino Uno and the correct port.
  20. Verify and upload the sketch.
  21. Keep the push button released while the test is being prepared.
  22. Wait for the random delay and observe the LED and buzzer start signal.
  23. Press the button as quickly as possible after the start signal.
  24. Observe the reaction time on the 4-digit display.
  25. Listen for the result confirmation beep.
  26. Observe the displayed result for three seconds.
  27. Release the button and repeat the test.
  28. Compare reaction times across multiple trials.

Result

The Reaction Time Tester experiment demonstrates how Arduino UNO can measure the time between a programmed start timestamp and a user's push button response.

The system generates a random waiting interval, activates the LED and buzzer as start indicators, and calculates the elapsed time using millis().

The measured value is sent to a compatible HT16K33 I²C 4-digit 7-segment display.

This experiment demonstrates button interfacing, random timing, elapsed-time calculation, digital output control and I²C display communication.
