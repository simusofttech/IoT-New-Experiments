Reaction Time Tester

← Arduino Experiments Aim Components Connections Circuit Working Procedure Code Result

Aim

To measure the user's reaction time using Arduino UNO, a push button, LED, buzzer and a 4-digit 7-segment display.

About the Experiment

The system waits for a random time before giving a start signal using the LED and buzzer. The user must press the push button as quickly as possible.

Arduino measures the elapsed time in milliseconds and displays the reaction time on the 4-digit 7-segment display.

Arduino UNO R3 (×1)

Procedure

  1. Connect the push button between D2 and GND.
  2. Connect the LED anode to D8 through a 220Ω resistor.
  3. Connect the LED cathode to GND.
  4. Connect the buzzer positive terminal to D9 and negative terminal to GND.
  5. Connect the 4-digit display VCC to 5V and GND to GND.
  6. Connect the display SDA pin to A4.
  7. Connect the display SCL pin to A5.
  8. Connect Arduino UNO to the computer using USB.
  9. Open Arduino IDE.
  10. Enter the program given below.
  11. Select Arduino UNO from Tools → Board.
  12. Select the correct COM port.
  13. Verify and upload the program.
  14. Wait for the LED and buzzer start signal.
  15. Press the button as quickly as possible.
  16. Read the reaction time from the 4-digit display.

Arduino Code

Reaction_Time_Tester.ino 
#include <Wire.h>

#define DISPLAY_ADDRESS 0x70

const int buttonPin = 2;
const int ledPin = 8;
const int buzzerPin = 9;

// Segment codes
const byte digitCode[10] = {
  0x3F, // 0
  0x06, // 1
  0x5B, // 2
  0x4F, // 3
  0x66, // 4
  0x6D, // 5
  0x7D, // 6
  0x07, // 7
  0x7F, // 8
  0x6F  // 9
};

void setup() {

  pinMode(buttonPin, INPUT_PULLUP);
  pinMode(ledPin, OUTPUT);
  pinMode(buzzerPin, OUTPUT);

  digitalWrite(ledPin, LOW);
  digitalWrite(buzzerPin, LOW);

  Wire.begin();

  // HT16K33 oscillator ON
  Wire.beginTransmission(DISPLAY_ADDRESS);
  Wire.write(0x21);
  Wire.endTransmission();

  // Display ON, blinking OFF
  Wire.beginTransmission(DISPLAY_ADDRESS);
  Wire.write(0x81);
  Wire.endTransmission();

  // Maximum brightness
  Wire.beginTransmission(DISPLAY_ADDRESS);
  Wire.write(0xEF);
  Wire.endTransmission();

  clearDisplay();

  randomSeed(analogRead(A3));
}

void loop() {

  // Wait until button is released
  while (digitalRead(buttonPin) == LOW) {
    delay(10);
  }

  clearDisplay();

  // Random waiting time
  delay(random(2000, 5000));

  // -----------------------------
  // START SIGNAL
  // -----------------------------
  digitalWrite(ledPin, HIGH);
  digitalWrite(buzzerPin, HIGH);

  delay(100);

  digitalWrite(buzzerPin, LOW);

  unsigned long startTime = millis();

  // Wait for button press
  while (digitalRead(buttonPin) == HIGH) {

    unsigned long currentTime = millis();

    unsigned long time = currentTime - startTime;

    if (time <= 9999) {
      displayNumber(time);
    }
  }

  // -----------------------------
  // STOP
  // -----------------------------
  unsigned long reactionTime = millis() - startTime;

  digitalWrite(ledPin, LOW);

  displayNumber(reactionTime);

  // Result beep
  digitalWrite(buzzerPin, HIGH);

  delay(200);

  digitalWrite(buzzerPin, LOW);

  // Keep result for 3 seconds
  delay(3000);
}

// =================================
// DISPLAY NUMBER
// =================================
void displayNumber(unsigned long number) {

  if (number > 9999) {
    number = 9999;
  }

  int d1 = number / 1000;
  int d2 = (number / 100) % 10;
  int d3 = (number / 10) % 10;
  int d4 = number % 10;

  byte buffer[16] = {0};

  // HT16K33 4-digit backpack positions
  buffer[0] = digitCode[d1];
  buffer[2] = digitCode[d2];
  buffer[6] = digitCode[d3];
  buffer[8] = digitCode[d4];

  // Send to display
  Wire.beginTransmission(DISPLAY_ADDRESS);
  Wire.write(0x00);

  for (int i = 0; i < 16; i++) {
    Wire.write(buffer[i]);
  }

  Wire.endTransmission();
}

// =================================
// CLEAR DISPLAY
// =================================
void clearDisplay() {

  byte buffer[16] = {0};

  Wire.beginTransmission(DISPLAY_ADDRESS);
  Wire.write(0x00);

  for (int i = 0; i < 16; i++) {
    Wire.write(buffer[i]);
  }

  Wire.endTransmission();
}

Expected Output

After a random delay, the LED turns ON and the buzzer gives a short beep. The user presses the button as quickly as possible.

Start signal: LED ON + short beep
Measurement: Reaction time in milliseconds
Display range: Up to 9999 ms
Result: Shown for 3 seconds

Result

The Reaction Time Tester experiment was implemented using Arduino UNO, a push button, LED, buzzer and a 4-digit 7-segment display. The system measures and displays the user's reaction time in milliseconds.
