Gas Leakage Warning System

← Arduino Experiments Aim Components Connections Working Procedure Code Result

Aim

To detect gas leakage using a bare six-pin MQ-2 gas sensor with Arduino UNO and provide visual and audible warning using red and green LEDs and a buzzer.

About the Experiment

Arduino reads the analog signal from the MQ-2 sensor through A0 and compares the reading with a starting threshold value of 400.

When the reading is greater than 400, the warning condition is activated: the red LED turns ON, the green LED turns OFF, and the buzzer sounds continuously. When the reading is 400 or below, the system remains in the normal condition.

Procedure

  1. Connect MQ-2 H1 to Arduino 5V.
  2. Connect MQ-2 H2 to Arduino GND.
  3. Connect MQ-2 A1 and A2 to Arduino 5V.
  4. Join MQ-2 B1 and B2 to form the common output node.
  5. Connect the common output node to Arduino A0.
  6. Connect one side of the 10 kΩ resistor to the common output node.
  7. Connect the other side of the 10 kΩ resistor to GND.
  8. Connect the red LED anode to D8 through a 220Ω resistor.
  9. Connect the red LED cathode to GND.
  10. Connect the green LED anode to D9 through a 220Ω resistor.
  11. Connect the green LED cathode to GND.
  12. Connect the buzzer positive terminal to D10 and negative terminal to GND.
  13. Connect Arduino UNO to the computer.
  14. Open Arduino IDE.
  15. Enter the program given below.
  16. Select Arduino UNO and the correct COM port.
  17. Verify and upload the program.
  18. Open Serial Monitor at 9600 baud.
  19. Observe the LEDs, buzzer and sensor values.

Arduino Code

Gas_Leakage_Warning_System.ino 
/*
  Gas Leakage Warning System

  CONTROLLER: Arduino UNO R3
  SENSOR: Bare six-pin MQ-2

  MQ-2 analog output node -> A0
  Red LED -> D8 through 220 ohm resistor
  Green LED -> D9 through 220 ohm resistor
  Buzzer -> D10

  The threshold is a starting value for simulation.
*/

#define GAS_SENSOR_PIN A0
#define RED_LED_PIN 8
#define GREEN_LED_PIN 9
#define BUZZER_PIN 10

// Starting threshold for Tinkercad
const int GAS_THRESHOLD = 400;

void setup() {

  // Configure pin modes
  pinMode(GAS_SENSOR_PIN, INPUT);
  pinMode(RED_LED_PIN, OUTPUT);
  pinMode(GREEN_LED_PIN, OUTPUT);
  pinMode(BUZZER_PIN, OUTPUT);

  // Start Serial Monitor
  Serial.begin(9600);

  // Initial normal state
  digitalWrite(RED_LED_PIN, LOW);
  digitalWrite(GREEN_LED_PIN, HIGH);
  noTone(BUZZER_PIN);

  Serial.println("================================");
  Serial.println(" GAS LEAKAGE WARNING SYSTEM");
  Serial.println("================================");
  Serial.println("System Initializing...");

  delay(2000);

  Serial.println("System Ready");
  Serial.println("--------------------------------");
}

void loop() {

  // Read analog value from MQ-2
  int gasValue = analogRead(GAS_SENSOR_PIN);

  // Convert ADC reading to voltage
  float voltage = gasValue * (5.0 / 1023.0);

  // Print sensor information
  Serial.print("MQ-2 Sensor Value: ");
  Serial.println(gasValue);

  Serial.print("Sensor Voltage: ");
  Serial.print(voltage, 2);
  Serial.println(" V");

  // Compare reading with threshold
  if (gasValue > GAS_THRESHOLD) {

    // WARNING CONDITION
    digitalWrite(RED_LED_PIN, HIGH);
    digitalWrite(GREEN_LED_PIN, LOW);

    // Activate buzzer
    tone(BUZZER_PIN, 1000);

    Serial.println("STATUS: WARNING");
    Serial.println("GAS LEAKAGE DETECTED!");

  } else {

    // NORMAL CONDITION
    digitalWrite(RED_LED_PIN, LOW);
    digitalWrite(GREEN_LED_PIN, HIGH);

    // Turn off buzzer
    noTone(BUZZER_PIN);

    Serial.println("STATUS: NORMAL");
  }

  Serial.println("--------------------------------");

  // Wait 500 milliseconds
  delay(500);
}

Expected Output

In the normal condition, the green LED remains ON and the buzzer is silent. When the MQ-2 analog reading rises above 400, the red LED turns ON and the buzzer sounds continuously.

Gas Value ≤ 400: Green LED ON, Red LED OFF, Buzzer OFF
Gas Value > 400: Red LED ON, Green LED OFF, Buzzer ON
Serial Monitor: Shows sensor value, voltage and system status

Result

The Gas Leakage Warning System experiment was implemented using Arduino UNO, a bare six-pin MQ-2 sensor, red and green LEDs, and a buzzer. The system indicates normal or warning conditions according to the programmed gas threshold.
