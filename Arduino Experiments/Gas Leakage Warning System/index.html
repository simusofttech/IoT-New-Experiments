Aim

To design and demonstrate a Gas Leakage Warning System using Arduino UNO R3, MQ-2 Gas Sensor, 16×2 I2C LCD, Red LED, Green LED and Buzzer.

The system monitors analog gas sensor readings and automatically activates visual and audible warning indicators when the sensor reading reaches or exceeds the configured threshold.

About the Experiment

The Gas Leakage Warning System demonstrates how an Arduino UNO can monitor an MQ-2 gas sensor and respond to changes in its output.

The MQ-2 sensor responds to certain combustible gases and smoke. Its analog output is connected to Arduino pin A0.

Arduino reads the analog sensor value between 0 and 1023 and compares it with a threshold value of 350.

When the reading is below 350, the Green LED remains ON, indicating normal status.

When the reading reaches or exceeds 350, the Red LED and Buzzer turn ON, and the Green LED turns OFF.

A 16×2 I2C LCD displays the gas sensor value and current status, while the Serial Monitor prints readings and messages at 9600 baud.

Important: The threshold of 350 is an example demonstration value. It does not represent a calibrated gas concentration. This educational system must not replace a certified gas alarm.

  • LCD SDA → A4
  • LCD SCL → A5
  • Buzzer → D8
  • Red LED → D7 through 220Ω
  • Green LED → D6 through 220Ω
  • LCD I2C Address → 0x27

All devices share a common ground. Connect power only after verifying the circuit wiring.

Electrical Precautions:

The MQ-2 sensor module requires a suitable 5V supply. The buzzer must be a low-current type compatible with direct GPIO drive.

If the buzzer requires more current than the Arduino output can supply, use an appropriate driver circuit.

Working Principle

The system reads analog data from the MQ-2 sensor and compares it with a predefined threshold. The Arduino then updates the LEDs, buzzer and LCD according to the sensor reading.

Normal Condition

Below the threshold, the Green LED remains ON while the Red LED and Buzzer remain OFF.

Warning Condition

At or above the threshold, the Red LED and Buzzer turn ON. The Green LED turns OFF.

LCD Display

The first row displays the raw gas sensor reading, and the second row displays NORMAL or GAS WARNING.

Procedure

  1. Place the Arduino UNO and breadboard on a stable surface.
  2. Connect MQ-2 VCC to Arduino 5V.
  3. Connect MQ-2 GND to Arduino GND.
  4. Connect MQ-2 AO to Arduino A0.
  5. Connect LCD VCC to Arduino 5V.
  6. Connect LCD GND to Arduino GND.
  7. Connect LCD SDA to A4.
  8. Connect LCD SCL to A5.
  9. Connect the buzzer positive terminal to D8.
  10. Connect buzzer negative terminal to GND.
  11. Connect the Red LED anode to D7 through a 220Ω resistor.
  12. Connect the Red LED cathode to GND.
  13. Connect the Green LED anode to D6 through another 220Ω resistor.
  14. Connect the Green LED cathode to GND.
  15. Verify all power and ground connections.
  16. Open Arduino IDE.
  17. Install the LiquidCrystal_I2C library compatible with lcd.init() and lcd.backlight().
  18. Create a sketch named Gas_Leakage_Warning_System.ino.
  19. Copy the complete Arduino program from the Code section.
  20. Select Arduino Uno under Tools → Board.
  21. Select the correct COM port.
  22. Verify and upload the program.
  23. Open Serial Monitor at 9600 baud.
  24. Allow the MQ-2 sensor to warm up properly.
  25. Observe gas sensor values on the LCD and Serial Monitor.
  26. In a suitable simulator, vary the sensor value across the threshold of 350.
  27. Verify normal and warning conditions.
Safety: Do not deliberately release flammable gas to test this system. For classroom threshold testing, use an appropriate simulator.

Result

The Gas Leakage Warning System demonstrates how an Arduino UNO can monitor MQ-2 analog readings and activate warning indicators based on a configurable threshold.

Under normal conditions, the Green LED is ON. When the sensor reading reaches or exceeds the threshold, the Red LED and Buzzer activate.

The LCD displays the current gas sensor value and status, while the Serial Monitor reports the reading and system condition.
