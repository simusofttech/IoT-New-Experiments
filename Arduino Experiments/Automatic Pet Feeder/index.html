Automatic Pet Feeder

← Arduino Experiments Aim Components Connections Working Procedure Code Result

Aim

To create an automatic pet feeder using Arduino UNO, a push button, I²C LCD, buzzer and servo motor to dispense food when the button is pressed.

About the Experiment

The system waits for the user to press the feed button. When pressed, the buzzer gives a short beep, the servo opens the feeding mechanism, and the LCD displays the feeding status.

After dispensing food, the servo returns to its original position and the system becomes ready for the next feeding cycle.

Components Required

Arduino UNO R3 (×1)

Main controller for the feeding sequence.

Push Button (×1)

Starts the food dispensing cycle.

LCD 16×2 I²C (×1)

Displays feeding status messages.

Buzzer (×1)

Provides a short feeding confirmation sound.

Servo Motor (×1)

Opens and closes the food dispensing mechanism.

Procedure

  1. Connect one side of the push button to D2 and the other side to GND.
  2. Connect the servo signal wire to D9, VCC to 5V and GND to GND.
  3. Connect the buzzer positive terminal to D8 and negative terminal to GND.
  4. Connect LCD VCC to 5V and GND to GND.
  5. Connect LCD SDA to A4 and SCL to A5.
  6. Connect Arduino UNO to the computer and open Arduino IDE.
  7. Enter the program given below.
  8. Select Arduino UNO and the correct COM port.
  9. Verify and upload the program.
  10. Press the button and observe the LCD, buzzer and servo.

Arduino Code

Automatic_Pet_Feeder.ino 
#include <Adafruit_LiquidCrystal.h>
#include <Servo.h>

Adafruit_LiquidCrystal lcd(0);
Servo feederServo;

#define BUTTON_PIN 2
#define BUZZER_PIN 8
#define SERVO_PIN 9

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  pinMode(BUZZER_PIN, OUTPUT);

  feederServo.attach(SERVO_PIN);
  feederServo.write(0);

  lcd.begin(16, 2);
  lcd.setBacklight(1);

  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Pet Feeder");
  lcd.setCursor(0, 1);
  lcd.print("Ready");

  delay(2000);

  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Press Button");
  lcd.setCursor(0, 1);
  lcd.print("to Feed");
}

void loop() {
  if (digitalRead(BUTTON_PIN) == LOW) {

    lcd.clear();
    lcd.setCursor(0, 0);
    lcd.print("Dispensing Food");

    tone(BUZZER_PIN, 1000);
    delay(300);
    noTone(BUZZER_PIN);

    feederServo.write(90);
    delay(1500);

    feederServo.write(0);
    delay(500);

    lcd.clear();
    lcd.setCursor(0, 0);
    lcd.print("Food Dispensed");
    lcd.setCursor(0, 1);
    lcd.print("Thank You!");

    delay(2000);

    lcd.clear();
    lcd.setCursor(0, 0);
    lcd.print("Press Button");
    lcd.setCursor(0, 1);
    lcd.print("to Feed");

    while (digitalRead(BUTTON_PIN) == LOW) {
      delay(10);
    }

    delay(200);
  }
}

Expected Output

The LCD initially shows that the feeder is ready. Pressing the button starts one food dispensing cycle.

Ready: "Press Button to Feed"
Button Press: Buzzer beeps and servo opens to 90°
Dispensing Time: 1.5 seconds
Completion: Servo returns to 0° and LCD shows "Food Dispensed"

Result

The Automatic Pet Feeder experiment was implemented using Arduino UNO, a push button, I²C LCD, buzzer and servo motor. Pressing the button starts a feeding cycle, operates the servo, gives a buzzer indication, and updates the LCD with the current feeding status.
