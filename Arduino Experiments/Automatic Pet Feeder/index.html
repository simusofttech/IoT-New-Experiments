Aim

To create an automatic pet feeder using Arduino UNO, a push button, an I²C LCD, a buzzer and a servo motor to dispense food when the button is pressed.

About the Experiment

The Automatic Pet Feeder uses an Arduino UNO to operate a button-controlled food dispensing mechanism.

The system waits for the push button to be pressed. When a button press is detected, Arduino starts one complete feeding sequence.

A buzzer provides a short confirmation beep and a servo motor rotates to open the dispensing mechanism.

The 16×2 I²C LCD displays status messages throughout the feeding process.

After dispensing, the servo returns to its original position and the system becomes ready for the next feeding cycle.

Important: This is a button-triggered feeding demonstration, not a time-scheduled feeder. The Arduino sketch controls a servo position for a fixed interval; it does not measure the quantity of food dispensed.

Button Operation

The program uses Arduino's internal pull-up resistor, so no external pull-up resistor is required.

When the button is pressed, the input becomes LOW and the feeding cycle begins.

Dispensing Operation

The buzzer sounds at 1000 Hz for approximately 300 milliseconds.

The servo rotates from 0° to 90°, waits 1.5 seconds and returns to 0°.

LCD Feedback

The LCD displays the current status, including readiness, dispensing and completion.

Important Timing:
  • Startup Ready Message: 2 seconds
  • Buzzer: 300 milliseconds
  • Servo Open Time: 1.5 seconds
  • Servo Return Delay: 500 milliseconds
  • Completion Message: 2 seconds

Procedure

  1. Place the Arduino UNO and breadboard on a stable surface.
  2. Connect one side of the push button to Arduino D2.
  3. Connect the opposite button side to GND.
  4. Verify the button's internal terminal pairs to avoid connecting two permanently common pins.
  5. Connect the servo signal wire to D9.
  6. Connect the servo to a suitable regulated 5V supply.
  7. Connect servo ground and Arduino ground together.
  8. Connect the buzzer positive terminal to D8.
  9. Connect the buzzer negative terminal to GND.
  10. Connect LCD VCC to 5V.
  11. Connect LCD GND to GND.
  12. Connect LCD SDA to Arduino A4.
  13. Connect LCD SCL to Arduino A5.
  14. Verify the LCD library matches your particular I²C LCD hardware.
  15. Confirm all connections before applying power.
  16. Open Arduino IDE.
  17. Create the sketch Automatic_Pet_Feeder.ino.
  18. Copy the complete code from Explore the Code.
  19. Select Arduino Uno and the correct communication port.
  20. Verify and upload the program.
  21. Check that the LCD displays the ready message.
  22. Press the button and observe the buzzer, servo movement and LCD status.
  23. Confirm that the servo returns to its original position.

Result

The Automatic Pet Feeder experiment demonstrates a push-button-controlled dispensing sequence using Arduino UNO.

Pressing the button activates the buzzer and servo, while the LCD displays the current feeding status.

Once the dispensing cycle is complete, the servo returns to its initial position and the system becomes ready again.
