Aim

To design and develop a Rain Alert Indicator using Arduino UNO R3, a rain sensor module, a red LED and an active buzzer.

The system detects the presence of rain or water on a sensing plate and produces both visual and audible alerts when the programmed rain detection condition occurs.

About the Experiment

The Rain Alert Indicator is an Arduino-based monitoring experiment designed to identify the presence of water on a rain sensing plate.

The rain sensor module consists of a sensing plate and a comparator circuit board.

The sensing plate contains conductive tracks. When water bridges these tracks, the electrical resistance across the plate changes.

The comparator module converts the sensing plate response into a digital HIGH or LOW output signal.

Arduino UNO reads this digital signal through pin D2.

In the supplied sketch, a LOW signal represents rain or water detection.

When rain is detected, Arduino switches ON the red LED connected to pin D8 and the active buzzer connected to pin D9.

When the sensor output is HIGH, the program considers the sensing plate dry and turns both alert components OFF.

The detection status is also displayed in Serial Monitor at 9600 baud.

The system checks the sensor repeatedly with a 500-millisecond delay between checks.

Important:

The supplied program assumes the rain sensor module is active-LOW.

The digital detection threshold can usually be adjusted using the potentiometer on the comparator module.

The experiment detects moisture on the plate. It does not calculate rainfall intensity, rainfall volume or weather forecasts.

Rain Detection Principle

The rain sensor plate contains closely spaced conductive tracks.

When water droplets contact the plate, electrical resistance between the tracks changes.

The comparator module responds to this change and generates a digital output.

Active-LOW Detection

The original sketch compares the rain sensor reading against LOW.

Rain Detected:

Sensor DO = LOW

Red LED = ON

Active Buzzer = ON

Serial Message: STATUS: RAIN DETECTED

Dry Condition

When the sensing plate is dry and the comparator output is HIGH, the program executes the else block.

No Rain:

Sensor DO = HIGH

Red LED = OFF

Active Buzzer = OFF

Serial Message: STATUS: NO RAIN

Sensor Threshold Adjustment

Many rain sensor comparator boards have a small potentiometer.

Rotating the potentiometer changes the switching threshold for the digital output.

This allows the sensor's response to moisture to be adjusted during testing.

The sketch does not use the analog AO output or calculate a numerical moisture percentage.

Continuous Monitoring

Arduino reads the sensor in each loop iteration.

After updating the outputs and Serial Monitor, the program waits for 500 ms before checking again.

D2 Rain sensor input
D8 LED output
D9 Buzzer output
500 ms Monitoring delay

Procedure

  1. Place Arduino UNO, the rain sensor module, red LED, 220Ω resistor, active buzzer and breadboard on a dry work surface.
  2. Identify the VCC, GND, DO and AO terminals on the rain sensor module.
  3. Connect the sensing plate to the comparator board using its connector.
  4. Connect sensor VCC to Arduino 5V.
  5. Connect sensor GND to Arduino GND.
  6. Connect the sensor digital output DO to Arduino D2.
  7. Leave the sensor analog AO pin unconnected.
  8. Place the red LED on the breadboard.
  9. Connect the LED anode to D8 through a 220Ω resistor.
  10. Connect the LED cathode to GND.
  11. Connect the active buzzer positive terminal to D9 if suitable for direct drive.
  12. Connect the buzzer negative terminal to GND.
  13. Verify all wiring and component polarity.
  14. Open Arduino IDE.
  15. Create a sketch named Rain_Alert_Indicator.ino.
  16. Copy the complete Arduino program from Explore the Code.
  17. Select Arduino Uno and the correct communication port.
  18. Verify and upload the Arduino program.
  19. Open Serial Monitor at 9600 baud.
  20. Keep the sensing plate completely dry.
  21. Verify that the red LED and buzzer remain OFF when the sensor reports HIGH.
  22. Observe the STATUS: NO RAIN message in Serial Monitor.
  23. Carefully place a small amount of clean water on the sensing plate.
  24. Observe the sensor's digital output and confirm that it becomes LOW.
  25. Verify that the red LED switches ON and the buzzer sounds.
  26. Observe the STATUS: RAIN DETECTED message in Serial Monitor.
  27. Remove the water and carefully dry the sensing plate.
  28. Verify that the red LED and buzzer switch OFF again.
  29. If necessary, adjust the comparator module's potentiometer to obtain a reliable detection threshold.
  30. Repeat the test to observe the sensor's response to wet and dry conditions.

Important:

The source sketch uses no LCD or OLED display. All textual output appears in the Serial Monitor.

The sensor is checked repeatedly after a 500 ms delay, so the visible and audible alert updates are not instantaneous.

The actual switching point depends on the module's comparator calibration.

Result

The Rain Alert Indicator demonstrates the detection of water or moisture using a rain sensor module connected to Arduino UNO R3.

When the sensor produces a LOW digital output, Arduino activates the red LED and active buzzer.

When the sensor output is HIGH, both warning indicators remain OFF.

The detection status is printed to Serial Monitor, demonstrating digital sensor interfacing, conditional logic and automatic alert control.
