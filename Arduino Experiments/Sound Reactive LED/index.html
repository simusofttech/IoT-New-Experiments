Aim

To design and develop a Sound Reactive LED experiment using Arduino UNO R3, an analog sound sensor and three LED indicators.

The experiment compares the analog sensor reading against two programmed thresholds and lights one, two or three LEDs according to the detected range.

About the Experiment

The Sound Reactive LED experiment demonstrates how Arduino can respond to changes in an analog sound sensor signal.

An analog sound sensor module uses a microphone and supporting circuitry to produce a voltage that changes in response to sound-related signals.

The module's analog output is connected to Arduino pin A0.

Arduino reads the sensor using analogRead().

On Arduino UNO, the analog-to-digital converter normally produces values between 0 and 1023.

The original program divides this range into three categories using the thresholds 256 and 512.

If the reading is below 256, Arduino lights only LED 1.

If the reading is between 256 and 511, the program lights LEDs 1 and 2.

If the reading is 512 or above, all three LEDs turn ON.

Arduino prints the sensor reading and the selected category to Serial Monitor at 9600 baud.

The measurement repeats every 200 milliseconds.

Important:

The programmed LOW, MEDIUM and HIGH categories are based on raw analog readings, not measured decibels.

Real microphone modules can differ in sensitivity, output voltage and signal conditioning. Some produce rapidly varying audio waveforms, so a single analog sample does not reliably represent sound loudness.

The thresholds should be verified against the actual sensor readings. The sketch does not calculate a peak, average or RMS sound level.

If using Wokwi, any custom sound simulation chip is a simulator element rather than an additional physical component.

Analog Sensor Reading

The sound sensor is connected to A0. Arduino uses analogRead() to sample its voltage.

The resulting integer is stored in the soundLevel variable.

This value is compared with the two fixed thresholds.

LOW Category

If soundLevel is below 256, only LED 1 turns ON.

Condition: soundLevel < 256

LED 1: ON

LED 2: OFF

LED 3: OFF

MEDIUM Category

If the first condition is false but soundLevel is below 512, both LED 1 and LED 2 illuminate.

Condition: 256 ≤ soundLevel < 512

LED 1: ON

LED 2: ON

LED 3: OFF

HIGH Category

When soundLevel is 512 or above, the final else block turns ON all three LEDs.

Condition: soundLevel ≥ 512

LED 1: ON

LED 2: ON

LED 3: ON

Serial Monitoring

Arduino prints both the raw analog value and a message indicating which LED combination has been selected.

A separator line is printed after every measurement cycle.

Monitoring Interval

The original sketch uses delay(200) at the end of its loop.

This causes a nominal pause of 200 ms between measurements.

A0 Analog sensor input
256 Medium threshold
512 High threshold
200 ms Programmed delay
Sensor Calibration:

Thresholds 256 and 512 come directly from the uploaded code.

They do not automatically correspond to quiet, moderate and loud sound in real-world units.

Observe the raw sensor values under different sound conditions to determine whether these thresholds work for the selected microphone module.

Procedure

  1. Place the Arduino UNO, sound sensor, three LEDs, three 220Ω resistors, breadboard and jumper wires on the working surface.
  2. Identify the sensor's VCC, GND and AO terminals.
  3. Connect VCC to the supply specified for the sensor module.
  4. Connect the sensor GND to Arduino GND.
  5. Connect the sensor AO to Arduino A0.
  6. Insert LED 1 into the breadboard.
  7. Connect LED 1 anode to D8 through a 220Ω resistor.
  8. Connect LED 1 cathode to GND.
  9. Connect LED 2 anode to D9 through another 220Ω resistor.
  10. Connect LED 2 cathode to GND.
  11. Connect LED 3 anode to D10 through the third 220Ω resistor.
  12. Connect LED 3 cathode to GND.
  13. Verify the component polarities, resistor connections and common ground.
  14. Open Arduino IDE.
  15. Create a new sketch named Sound_Reactive_LED.ino.
  16. Copy the complete Arduino program from Explore the Code.
  17. Select Arduino Uno and the correct communication port.
  18. Verify and upload the sketch.
  19. Open Serial Monitor at 9600 baud.
  20. Check that the startup message appears.
  21. Observe the analog reading while the surrounding environment is relatively quiet.
  22. Produce a sound near the sensor, such as clapping or speaking.
  23. Observe changes in the raw sensor reading and the three LEDs.
  24. Compare the readings against thresholds 256 and 512.
  25. Confirm that the LED patterns match the programmed ranges.
  26. Repeat the test with different sound conditions.
  27. If the categories do not respond as intended, record readings for later threshold calibration.

Result

The Sound Reactive LED experiment demonstrates how Arduino UNO can read an analog sound sensor and control three LEDs according to programmed threshold ranges.

Readings below 256 activate one LED; readings between 256 and 511 activate two LEDs; and readings of 512 or above activate all three.

The analog reading and corresponding category are printed to Serial Monitor.

The experiment demonstrates analog input reading, conditional logic, multiple digital outputs and serial monitoring.
