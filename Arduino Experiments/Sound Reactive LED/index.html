Aim

To indicate low, medium and high sound sensor readings using three LEDs connected to Arduino UNO.

About the Experiment

The analog sound sensor sends a voltage to A0. The Arduino compares the reading with thresholds 256 and 512 and illuminates one, two, or three LEDs.

Physical sound sensor thresholds require calibration. Wokwi's custom sound chip is a simulation component, not additional hardware.

Procedure

  1. Arrange the Arduino UNO and components on a breadboard.
  2. Connect each component exactly as shown in the Circuit Connections table.
  3. Double-check polarity, signal pins, and common ground.
  4. Open Arduino IDE and select Arduino UNO and the correct port.
  5. Install required libraries if the sketch uses them.
  6. Copy the complete code from Explore the Code and upload it.
  7. Test each input and observe the output, display and Serial Monitor.
