Sound Reactive LED

Aim

Indicate low, medium, and high sound levels with three LEDs using an analog sound sensor.

About the Experiment

Indicate low, medium, and high sound levels with three LEDs using an analog sound sensor. This educational experiment demonstrates sensor input, microcontroller processing and output control.

Components Required

Arduino UNO R3Quantity: 1
Analog Sound Sensor ModuleQuantity: 1
LEDQuantity: 3
220Ω ResistorQuantity: 3
BreadboardQuantity: 1
Jumper WiresQuantity: As required

Circuit Connections

Component PinConnection
Sound sensor VCC5V or module-rated supply
Sound sensor GNDGND
Sound sensor AOA0
LED 1 anodeD8 through 220Ω resistor
LED 2 anodeD9 through 220Ω resistor
LED 3 anodeD10 through 220Ω resistor
All LED cathodesGND

The threshold values 256 and 512 are from the SOP; calibrate with Serial Monitor for the physical sensor. The Wokwi custom chip simulates sound and is not a physical component.

Circuit Diagram

Working Principle

Sound sensor AO → Arduino A0 → Threshold comparison → 1, 2, or 3 LEDs

Procedure

  1. Gather the components and verify their pin labels.
  2. Connect the components as shown in the Circuit Connections table.
  3. Open Arduino IDE and select Arduino UNO.
  4. Enter the SOP sketch in the code section below.
  5. Verify and upload the code to the board.
  6. Test the input and observe the output response.

const int SOUND_PIN = A0;const int LED1 = 8;const int LED2 = 9;const int LED3 = 10; // Arduino analogRead range: 0-1023const int MEDIUM_THRESHOLD = 256;const int HIGH_THRESHOLD = 512; void setup() { Serial.begin(9600); pinMode(LED1, OUTPUT); pinMode(LED2, OUTPUT); pinMode(LED3, OUTPUT); digitalWrite(LED1, LOW); digitalWrite(LED2, LOW); digitalWrite(LED3, LOW); Serial.println("SOUND REACTIVE LED SYSTEM READY");} void loop() { int soundLevel = analogRead(SOUND_PIN); Serial.print("Sound Level = "); Serial.println(soundLevel); if (soundLevel < MEDIUM_THRESHOLD) { digitalWrite(LED1, HIGH); digitalWrite(LED2, LOW); digitalWrite(LED3, LOW); Serial.println("LOW SOUND -> LED 1 ON"); } else if (soundLevel < HIGH_THRESHOLD) { digitalWrite(LED1, HIGH); digitalWrite(LED2, HIGH); digitalWrite(LED3, LOW); Serial.println("MEDIUM SOUND -> LED 1 + LED 2 ON"); } else { digitalWrite(LED1, HIGH); digitalWrite(LED2, HIGH); digitalWrite(LED3, HIGH); Serial.println("HIGH SOUND -> LED 1 + LED 2 + LED 3 ON"); } Serial.println("--------------------------------"); delay(200);}
