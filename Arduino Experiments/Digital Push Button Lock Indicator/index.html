Digital Push Button Lock Indicator

← Arduino Experiments Aim Components Connections Circuit Working Procedure Code Result

Aim

To create a simple digital lock indicator using Arduino UNO, two push buttons and three LEDs to indicate Locked, Access Granted and Access Denied states.

About the Experiment

The system starts in the Locked state with the red LED ON. The user must press Button 1 first and then Button 2.

If the correct sequence is entered, the green LED turns ON to indicate Access Granted. If Button 1 is pressed again instead of Button 2, the yellow LED flashes to indicate Access Denied. After either result, the system returns to the Locked state.

Components Required

Arduino UNO R3 (×1)

Main controller for reading the button sequence and controlling the LEDs.

Push Buttons (×2)

Used to enter the two-button lock sequence.

LEDs (×3)

Red for Locked, Green for Access Granted and Yellow for Access Denied.

220Ω Resistors (×3)

Limit current through the three LEDs.

Breadboard (×1)

Used for assembling the circuit.

Jumper Wires

Used for electrical connections.

Procedure

  1. Connect Button 1 between Arduino pin D2 and GND.
  2. Connect Button 2 between Arduino pin D3 and GND.
  3. Connect the red LED anode to D8 through a 220Ω resistor.
  4. Connect the green LED anode to D9 through a 220Ω resistor.
  5. Connect the yellow LED anode to D10 through a 220Ω resistor.
  6. Connect all LED cathodes to GND.
  7. Connect Arduino UNO to the computer using USB.
  8. Open Arduino IDE.
  9. Enter the program given below.
  10. Select Arduino UNO from Tools → Board.
  11. Select the correct COM port.
  12. Verify and upload the program.
  13. Observe the red LED after startup.
  14. Press Button 1 followed by Button 2 and observe the green LED.
  15. Press Button 1 twice and observe the yellow LED flashing.

Arduino Code

Digital_Push_Button_Lock_Indicator.ino 
// ======================================
// DIGITAL PUSH BUTTON LOCK INDICATOR
// Arduino UNO R3
// ======================================

// Push buttons
const int button1 = 2;
const int button2 = 3;

// LEDs
const int redLED = 8;
const int greenLED = 9;
const int yellowLED = 10;

// ======================================
// SETUP
// ======================================
void setup() {

  pinMode(button1, INPUT_PULLUP);
  pinMode(button2, INPUT_PULLUP);

  pinMode(redLED, OUTPUT);
  pinMode(greenLED, OUTPUT);
  pinMode(yellowLED, OUTPUT);

  // Start in LOCKED state
  digitalWrite(redLED, HIGH);
  digitalWrite(greenLED, LOW);
  digitalWrite(yellowLED, LOW);
}

// ======================================
// LOOP
// ======================================
void loop() {

  // Wait for first button
  if (digitalRead(button1) == LOW) {

    delay(50);

    // Wait until button is released
    while (digitalRead(button1) == LOW) {
      delay(5);
    }

    // First button is correct
    // Now wait for Button 2
    waitForSecondButton();
  }
}

// ======================================
// CHECK SECOND BUTTON
// ======================================
void waitForSecondButton() {

  while (true) {

    // Correct sequence: Button 1 → Button 2
    if (digitalRead(button2) == LOW) {

      delay(50);

      while (digitalRead(button2) == LOW) {
        delay(5);
      }

      accessGranted();
      return;
    }

    // If Button 1 is pressed again, sequence is wrong
    if (digitalRead(button1) == LOW) {

      delay(50);

      while (digitalRead(button1) == LOW) {
        delay(5);
      }

      accessDenied();
      return;
    }
  }
}

// ======================================
// ACCESS GRANTED
// ======================================
void accessGranted() {

  digitalWrite(redLED, LOW);
  digitalWrite(yellowLED, LOW);

  // Green LED ON
  digitalWrite(greenLED, HIGH);

  delay(3000);

  // Return to LOCKED state
  digitalWrite(greenLED, LOW);
  digitalWrite(redLED, HIGH);
}

// ======================================
// ACCESS DENIED
// ======================================
void accessDenied() {

  digitalWrite(redLED, LOW);
  digitalWrite(greenLED, LOW);

  // Yellow LED flashes
  for (int i = 0; i < 3; i++) {

    digitalWrite(yellowLED, HIGH);
    delay(300);

    digitalWrite(yellowLED, LOW);
    delay(300);
  }

  // Return to LOCKED state
  digitalWrite(redLED, HIGH);
}

Expected Output

When the system starts, the red LED remains ON to indicate the Locked state. Entering the correct Button 1 → Button 2 sequence turns the green LED ON for 3 seconds.

Startup: Red LED ON – Locked
Button 1 → Button 2: Green LED ON – Access Granted
Button 1 → Button 1: Yellow LED flashes – Access Denied

Result

The Digital Push Button Lock Indicator experiment was implemented using Arduino UNO, two push buttons and three LEDs. The system indicates Locked, Access Granted and Access Denied states according to the button sequence entered by the user.
