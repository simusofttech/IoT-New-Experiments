Aim

To create a simple digital lock indicator using Arduino UNO, two push buttons and three LEDs to indicate Locked, Access Granted and Access Denied states.

About the Experiment

The Digital Push Button Lock Indicator demonstrates a two-button security sequence using Arduino UNO.

The system starts in the Locked state with the red LED ON.

The user must first press Button 1 and then press Button 2.

When the correct sequence is entered, the green LED turns ON for three seconds to indicate Access Granted.

If Button 1 is pressed again instead of Button 2, the yellow LED flashes three times to indicate Access Denied.

After either result, the system automatically returns to the Locked state.

Important: This experiment is an electronic lock-status indicator only. It does not physically lock or unlock a door.

Important: Both push buttons use INPUT_PULLUP. Each button connects between its Arduino input and GND.

A pressed button produces a LOW input signal.

Locked Red LED ON
Access Granted Green LED ON for 3 seconds
Access Denied Yellow LED flashes 3 times

Correct Sequence

Button 1 followed by Button 2 activates the Access Granted state.

Incorrect Sequence

Button 1 followed by Button 1 activates the Access Denied state.

The original program waits indefinitely for a second button after Button 1 is pressed. It does not include a timeout.

Procedure

  1. Place the Arduino UNO and breadboard on a stable surface.
  2. Connect Button 1 between Arduino D2 and GND.
  3. Connect Button 2 between Arduino D3 and GND.
  4. Connect the red LED anode to D8 through a 220Ω resistor.
  5. Connect the green LED anode to D9 through a 220Ω resistor.
  6. Connect the yellow LED anode to D10 through a 220Ω resistor.
  7. Connect all LED cathodes to GND.
  8. Verify all circuit connections and LED polarity.
  9. Open Arduino IDE.
  10. Create the sketch Digital_Push_Button_Lock_Indicator.ino.
  11. Copy the complete Arduino program from Explore the Code.
  12. Select Arduino Uno and the correct communication port.
  13. Verify and upload the program.
  14. Observe the red LED after startup.
  15. Press Button 1 followed by Button 2.
  16. Observe the green LED turning ON for 3 seconds.
  17. Press Button 1 twice.
  18. Observe the yellow LED flashing three times.
  19. Verify the system returns to Locked after each result.
