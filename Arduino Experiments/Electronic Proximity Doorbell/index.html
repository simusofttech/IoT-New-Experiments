Electronic Proximity Doorbell

← Arduino Experiments Aim Components Connections Working Procedure Code Result

Aim

To build an electronic proximity doorbell using Arduino UNO, an ultrasonic sensor, a servo motor and a buzzer that activates when a person or object comes within 40 cm.

About the Experiment

The ultrasonic sensor continuously measures the distance of an approaching person or object. When the measured distance is 40 cm or less, Arduino activates the doorbell.

The buzzer produces a two-tone beep sequence and the servo performs two bell strikes. Once the object moves beyond 40 cm, the system becomes ready for a new detection.

Procedure

  1. Connect ultrasonic VCC to 5V and GND to GND.
  2. Connect ultrasonic TRIG to D9.
  3. Connect ultrasonic ECHO to D10.
  4. Connect the servo signal wire to D6.
  5. Connect the servo VCC to 5V and GND to GND.
  6. Connect the buzzer positive terminal to D8.
  7. Connect the buzzer negative terminal to GND.
  8. Connect Arduino UNO to the computer.
  9. Open Arduino IDE.
  10. Enter the program given below.
  11. Select Arduino UNO from Tools → Board.
  12. Select the correct COM port.
  13. Verify and upload the program.
  14. Open Serial Monitor at 9600 baud.
  15. Move an object toward the ultrasonic sensor.
  16. Observe the buzzer and servo when the distance becomes 40 cm or less.

Arduino Code

Electronic_Proximity_Doorbell.ino 
#include <Servo.h>

// PIN DEFINITIONS
#define SERVO_PIN 6
#define BUZZER_PIN 8
#define TRIG_PIN 9
#define ECHO_PIN 10

// SERVO SETTINGS
#define REST_ANGLE 30
#define STRIKE_ANGLE 110

Servo bellServo;

// DETECTION SETTINGS
#define DETECTION_DISTANCE 40

bool personDetected = false;

void setup()
{
  Serial.begin(9600);

  // Servo
  bellServo.attach(SERVO_PIN);
  bellServo.write(REST_ANGLE);

  // Buzzer
  pinMode(BUZZER_PIN, OUTPUT);
  noTone(BUZZER_PIN);

  // Ultrasonic sensor
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);

  Serial.println("Electronic Proximity Doorbell");
  Serial.println("Physical Ultrasonic Detection");
  Serial.println("--------------------------------");

  delay(1000);
}

float getDistance()
{
  // Make sure trigger starts LOW
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);

  // Send ultrasonic pulse
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);

  // Read echo time
  long duration = pulseIn(ECHO_PIN, HIGH);

  // Convert time to distance in cm
  float distance = duration * 0.0343 / 2;

  return distance;
}

void beepDoorbell()
{
  Serial.println("Buzzer: BEEP!");

  // First beep
  tone(BUZZER_PIN, 1000);
  delay(250);
  noTone(BUZZER_PIN);

  delay(150);

  // Second beep
  tone(BUZZER_PIN, 1500);
  delay(350);
  noTone(BUZZER_PIN);

  delay(150);
}

void operateBell()
{
  Serial.println("Servo: Ringing Bell");

  // First strike
  bellServo.write(STRIKE_ANGLE);
  delay(400);

  bellServo.write(REST_ANGLE);
  delay(300);

  // Second strike
  bellServo.write(STRIKE_ANGLE);
  delay(400);

  bellServo.write(REST_ANGLE);
  delay(500);

  Serial.println("Servo: Returned to Rest Position");
}

void activateDoorbell()
{
  Serial.println("PERSON / OBJECT DETECTED!");

  beepDoorbell();

  operateBell();

  Serial.println("Doorbell Operation Completed");
  Serial.println("--------------------------------");
}

void loop()
{
  // Read actual physical distance
  float distance = getDistance();

  Serial.print("Actual Distance: ");
  Serial.print(distance);
  Serial.println(" cm");

  // OBJECT WITHIN 40 CM
  if (distance <= DETECTION_DISTANCE &&
      personDetected == false)
  {
    personDetected = true;

    activateDoorbell();
  }

  // OBJECT MOVED AWAY
  if (distance > DETECTION_DISTANCE)
  {
    personDetected = false;

    bellServo.write(REST_ANGLE);

    noTone(BUZZER_PIN);

    Serial.println("System Ready for New Detection");
  }

  Serial.println("--------------------------------");

  delay(200);
}

Expected Output

When an object comes within 40 cm, the buzzer produces a two-tone sound and the servo performs two bell strikes. The system waits for the object to move away before allowing the next detection.

Within 40 cm: Doorbell activates
Buzzer: 1000 Hz beep followed by 1500 Hz beep
Servo: Two strikes between 30° and 110°
Beyond 40 cm: System resets for the next detection

Result

The Electronic Proximity Doorbell experiment was implemented using Arduino UNO, an ultrasonic sensor, a buzzer and a servo motor. The doorbell activates automatically when a person or object comes within 40 cm and resets after the object moves away.
