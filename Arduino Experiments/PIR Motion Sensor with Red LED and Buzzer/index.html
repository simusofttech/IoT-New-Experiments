Aim

To design a PIR Motion Sensor with Red LED and Buzzer experiment using Arduino UNO, an HC-SR501 PIR sensor, a red LED, a 220Ω resistor and a buzzer.

The experiment detects motion using the PIR sensor and activates a visual and audible indication whenever the sensor output becomes HIGH.

About the Experiment

A PIR sensor detects changes in infrared radiation within its field of view.

The HC-SR501 module processes the sensor signal and produces a digital output.

The output is normally LOW when no motion is reported and HIGH when motion is detected.

Arduino UNO reads the sensor through digital pin D8.

A red LED connected to D2 provides visual indication.

A buzzer connected to D3 provides the audible alert.

When Arduino detects HIGH on D8, it switches ON both the LED and buzzer.

When the signal returns to LOW, both outputs are switched OFF.

The Serial Monitor prints the corresponding status messages at 9600 baud.

This experiment demonstrates digital sensor input, conditional logic, visual indication, audible feedback and automatic monitoring.

Important:

PIR sensors detect changes in infrared radiation rather than directly measuring physical distance.

The HC-SR501 may require an initial stabilization period after being powered ON.

Its output hold time and retriggering mode can affect how long the LED and buzzer remain activated.

PIR Sensor Operation

The HC-SR501 detects changes in infrared radiation from objects within its detection area.

The sensor module converts this information into a digital output.

Digital Signal Reading

Arduino reads the sensor output on D8 using digitalRead().

The result is stored in sensorState.

Motion Detected

If sensorState is HIGH, the program enters the motion-detected branch.

Arduino writes HIGH to D2 and D3, turning ON the LED and suitable buzzer.

A detection message is printed in Serial Monitor.

No Motion

If sensorState is LOW, Arduino switches OFF both outputs.

The corresponding no-motion status is also printed in Serial Monitor.

Repeated Monitoring

The program waits 100 milliseconds after processing the sensor state.

It then begins the next reading in loop().

Sensor Stabilization

After applying power, the PIR module may need time to stabilize.

During this period, readings may change unexpectedly.

The sensor's own delay and retrigger settings influence the output duration.

Important Source-Code Behavior

The original sketch prints a status line on every loop iteration, not only when motion state changes.

Therefore Serial Monitor may show repeated identical lines while the PIR state remains constant.

Procedure

  1. Arrange Arduino UNO, HC-SR501 PIR sensor, red LED, 220Ω resistor, buzzer, breadboard and jumper wires.
  2. Identify the VCC, OUT and GND terminals of the PIR module.
  3. Connect PIR VCC to Arduino 5V.
  4. Connect PIR GND to Arduino GND.
  5. Connect PIR OUT to digital pin D8.
  6. Insert the red LED into the breadboard.
  7. Connect the LED anode to D2 through a 220Ω resistor.
  8. Connect the LED cathode to GND.
  9. Connect a suitable low-current buzzer positive terminal to D3.
  10. Connect the buzzer negative terminal to GND.
  11. Verify all wiring connections and polarities.
  12. Open Arduino IDE.
  13. Create a sketch named PIR_Motion_Sensor_with_Red_LED_and_Buzzer.ino.
  14. Copy the Arduino program from Explore the Code.
  15. Select Arduino Uno and the correct communication port.
  16. Verify and upload the sketch.
  17. Allow the PIR module to stabilize. Depending on the module, this may take approximately 30–60 seconds.
  18. Open Serial Monitor at 9600 baud.
  19. Remain still outside the detection area.
  20. Observe the LED and buzzer when the PIR output is LOW.
  21. Move in front of the PIR sensor.
  22. Observe the red LED turning ON.
  23. Listen for the audible buzzer indication.
  24. Check the Motion Detected status in Serial Monitor.
  25. Stop moving and allow the PIR output to return to LOW.
  26. Check that the LED and buzzer turn OFF.
  27. Repeat the test with different movement positions.

Output Timing

The Arduino sketch contains delay(100) at the end of loop().

The PIR module may keep its output HIGH for longer than 100 ms.

Therefore the alarm duration depends primarily on the PIR module's actual output state.

Output Notes:

Serial messages are printed repeatedly while the state remains HIGH or LOW.

The sketch does not implement a separate alarm timeout.

Actual PIR response depends on sensor stabilization, sensitivity, installation and module settings.

The original code controls the buzzer using a steady digital HIGH signal.

Result

The PIR Motion Sensor with Red LED and Buzzer experiment demonstrates digital motion detection using Arduino UNO.

When the PIR sensor output is HIGH, Arduino activates the red LED and buzzer.

When the sensor output returns to LOW, both outputs switch OFF.

Serial Monitor displays the corresponding sensor and output status.

The experiment demonstrates sensor interfacing, conditional logic, output control and repeated monitoring.
