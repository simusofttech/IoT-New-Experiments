Aim

Detect motion with a PIR sensor and activate a red LED and buzzer.

About the Experiment

Detect motion with a PIR sensor and activate a red LED and buzzer. The Arduino UNO processes the inputs and controls the connected outputs according to the supplied program.

Working Principle

The PIR sensor detects changes in infrared radiation caused by a moving person.
When motion is detected, the sensor sends a HIGH signal to digital pin D8.
The Arduino turns ON the red LED connected to D2.
The buzzer connected to D3 sounds an alarm.
When the sensor output returns to LOW, the LED and buzzer turn OFF.

Procedure

Connect the PIR sensor, red LED, and buzzer according to the connection table.
Connect the Arduino UNO R3 to the computer using a computer connection.
Open the Arduino IDE and enter the program.
Select Arduino UNO R3 and the correct COM port.
Upload the program to the Arduino.
Wait approximately 30–60 seconds for the PIR sensor to stabilize.
Move in front of the sensor and observe the LED and buzzer.
Check the Serial Monitor at 9600 baud to view the detection messages.
