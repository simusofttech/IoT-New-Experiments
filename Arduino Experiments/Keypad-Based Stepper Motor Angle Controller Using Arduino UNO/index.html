1. Load libraries

The program loads libraries for I²C communication, DHT22, BMP180 and SSD1306 OLED control.

Try it: Upload the program, open Serial Monitor at 115200 baud and observe how temperature, humidity and pressure values change.

Working Principle

Enter an angle using the keypad, press # to rotate, * to clear, A to set zero, B to stop, C to inspect the current position and D to reset the counter.

Procedure

  1. Assemble the components using the connection table.
  2. Install the necessary Arduino libraries.
  3. Select Arduino UNO in the Arduino IDE.
  4. Upload the sketch and test the input and output behaviour.

Expected Output

Enter an angle using the keypad, press # to rotate, * to clear, A to set zero, B to stop, C to inspect the current position and D to reset the counter.

Result

The system responds to the specified input by controlling the connected outputs.
