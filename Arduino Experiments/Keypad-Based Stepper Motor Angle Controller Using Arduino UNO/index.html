Aim

To control the rotation angle of a 28BYJ-48 Stepper Motor using Arduino UNO, a 4×4 Matrix Keypad, ULN2003 Motor Driver and 16×2 I2C LCD Display.

The user can enter a target angle between 0° and 360° and command the stepper motor to move to the selected angular position.

About the Experiment

The Keypad-Based Stepper Motor Angle Controller demonstrates how an Arduino UNO can control the angular movement of a stepper motor using keypad input.

The user enters the required rotation angle using a 4×4 Matrix Keypad. The entered value is displayed on a 16×2 I2C LCD.

When the user presses the # key, the Arduino converts the entered angle into the required number of motor steps.

The ULN2003 Motor Driver receives control signals from Arduino and energizes the coils of the 28BYJ-48 Stepper Motor.

The motor rotates toward the selected target angle, while the LCD displays the estimated current and target positions.

Additional keypad functions allow the user to clear input, stop movement, display current position and reset the software angle reference.

Important: The displayed position is calculated from commanded motor steps. It is not measured by a physical encoder.

Motor Power Requirement:

The SOP specifies a suitable motor power supply for the 28BYJ-48 and ULN2003 driver.

A regulated supply matching the motor's rated voltage and current is required. The motor must not be powered directly from Arduino GPIO pins.

Connect the motor supply ground to Arduino GND.

Angle Conversion

The SOP uses approximately 4096 half-steps for one complete 360° output-shaft rotation.

The target step position is calculated using:

Target Steps = Target Angle × 4096 / 360

Motor Movement

The ULN2003 driver energizes the stepper motor coils in an eight-state half-step sequence.

The Arduino tracks commanded steps to estimate the motor angle. This is open-loop positioning.

Keypad Operation

Key Function
0–9 Enter target angle
# Confirm angle and move motor
* Clear entered value
A Set software position reference to 0°
B Request motor stop
C Display current and target angles
D Reset software position and target
Important: Keys A and D reset software position values. They do not physically move the motor to a mechanical zero point.

Procedure

  1. Connect the 28BYJ-48 Stepper Motor to the ULN2003 Motor Driver.
  2. Connect ULN2003 IN1 to Arduino D12.
  3. Connect ULN2003 IN2 to Arduino D13.
  4. Connect ULN2003 IN3 to Arduino A0.
  5. Connect ULN2003 IN4 to Arduino A1.
  6. Connect the driver to a suitable regulated motor power supply.
  7. Connect the motor power supply GND to Arduino GND.
  8. Connect keypad rows R1–R4 to Arduino D4–D7.
  9. Connect keypad columns C1–C4 to Arduino D8–D11.
  10. Connect LCD VCC to Arduino 5V.
  11. Connect LCD GND to Arduino GND.
  12. Connect LCD SDA to Arduino A4.
  13. Connect LCD SCL to Arduino A5.
  14. Check all connections before applying power.
  15. Open Arduino IDE.
  16. Install the Keypad library.
  17. Install a compatible LiquidCrystal_I2C library.
  18. Create a sketch named Keypad_Stepper_Angle_Controller.ino.
  19. Copy the complete Arduino program from Explore the Code.
  20. Select Arduino Uno under Tools → Board.
  21. Select the correct communication port.
  22. Verify and upload the program.
  23. Wait for the LCD to display the target and current angles.
  24. Enter an angle such as 90 using the keypad.
  25. Press # to start motor movement.
  26. Observe the motor rotate toward the selected target.
  27. Press C to display current and target angle values.
  28. Use B to request a stop while the motor is moving.
  29. Use A or D to reset the software position reference as described in the SOP.

The program estimates the angular position using commanded steps.

It does not measure the actual shaft angle with a position sensor.

Actual accuracy depends on the motor gearing, calibration, mechanical loading and missed steps.

Result

The Keypad-Based Stepper Motor Angle Controller demonstrates how Arduino UNO can accept an angle entered through a 4×4 Matrix Keypad and generate the corresponding stepper motor movement.

The ULN2003 Motor Driver controls the 28BYJ-48 Stepper Motor using an eight-state half-step sequence.

The LCD displays the selected target and estimated current angular position.

The experiment illustrates keypad-based control, stepper motor interfacing, angle-to-step conversion and position tracking.
