Aim

To control the angular movement of a 28BYJ-48 stepper motor using Arduino UNO, a ULN2003 motor driver, a 4×4 matrix keypad and a 16×2 I²C LCD.

The user can enter a target angle from 0° to 360° through the keypad. Arduino converts the angle into motor steps and controls the stepper motor accordingly.

About the Experiment

The Keypad-Based Stepper Motor Angle Controller demonstrates how Arduino can perform position-based motor control using user-entered commands.

A stepper motor rotates in small increments known as steps. By controlling the number and direction of these steps, Arduino estimates the angular position of the motor.

The experiment uses a 28BYJ-48 stepper motor driven through a ULN2003 motor driver module.

The ULN2003 driver switches the motor coils according to control signals received from Arduino UNO.

The 4×4 keypad allows the user to enter a target angle and issue movement commands.

The program converts the angle into the corresponding number of motor steps using an approximate value of 4096 half-steps per revolution.

During movement, Arduino updates the estimated current position and displays the information on the 16×2 I²C LCD.

When the requested position is reached, the motor coil outputs are switched OFF and the LCD displays TARGET REACHED.

The keypad also provides functions for clearing the input, requesting a stop, displaying the current position and resetting software position values.

Important: The experiment uses open-loop positioning. The displayed current angle is calculated from commanded steps, not measured by an encoder or position sensor. Missed steps may cause actual and displayed positions to differ.

Angle-to-Step Conversion

The source uses approximately 4096 half-steps for one complete output-shaft revolution.

Target Steps:

Target Steps = (Target Angle × 4096) / 360

Arduino performs this calculation using integer arithmetic, which truncates fractional steps.

Half-Step Sequence

The program stores eight coil activation patterns in stepSequence.

The ULN2003 board uses these signals to switch motor coil currents in sequence. Changing the step index in one direction commands forward motion; reversing it commands reverse motion.

Software Position Tracking: The controller increments or decrements currentPosition after every commanded step. It does not verify physical shaft movement.

During movement, only the B key is checked by the motion loop. Other keypad functions are processed after movement finishes.

Procedure

  1. Place the Arduino UNO, stepper motor, driver, keypad and LCD on the working surface.
  2. Connect the 28BYJ-48 motor to its matching ULN2003 connector.
  3. Connect ULN2003 IN1 to Arduino D12.
  4. Connect ULN2003 IN2 to Arduino D13.
  5. Connect ULN2003 IN3 to Arduino A0.
  6. Connect ULN2003 IN4 to Arduino A1.
  7. Connect the ULN2003 board to a suitable regulated motor supply.
  8. Connect the motor supply ground to Arduino GND.
  9. Connect keypad rows R1–R4 to Arduino D4–D7 respectively.
  10. Connect keypad columns C1–C4 to Arduino D8–D11 respectively.
  11. Connect LCD VCC and GND to compatible 5V and GND terminals.
  12. Connect LCD SDA to Arduino A4 and SCL to A5.
  13. Verify wiring, keypad terminal order and motor supply polarity.
  14. Open Arduino IDE.
  15. Install the Keypad library and a compatible LiquidCrystal_I2C library.
  16. Create a sketch named Keypad_Stepper_Angle_Controller.ino.
  17. Copy the complete Arduino code from Explore the Code.
  18. Select Arduino Uno and the correct communication port.
  19. Verify and upload the program.
  20. Observe the LCD startup message.
  21. Enter 90 on the keypad.
  22. Press # to command the motor to approximately 90°.
  23. Observe the current angle estimate on the LCD.
  24. Enter 180, press # and observe further movement.
  25. Try 360 and press # to command approximately one full output-shaft revolution relative to software zero.
  26. Press C to display target and current positions.
  27. During movement, press B to request a stop.
  28. Press * to clear the entered angle.
  29. Use A or D only when you understand their software-reference reset behavior.

Explore more: Half-Step Control

An eight-state half-step sequence changes the energization pattern of the motor coils.

The ULN2003 driver supplies the required switching current.

The original program waits 2 milliseconds after each commanded step. Motor response depends on mechanical load, supply voltage and motor capability.

Explore more: Motor Position

The variables currentPosition and targetPosition represent software tracking values.

Without an encoder or homing sensor, Arduino cannot determine whether the motor actually reaches the expected mechanical position.

Keys A and D change the software coordinate values without mechanically returning the shaft to zero.

Explore more: Keypad Stop

While moveToTarget() runs, Arduino repeatedly checks the keypad for B.

If B is detected, the motor outputs turn OFF, the LCD displays MOTOR STOPPED, and the movement function returns.

The program does not monitor all keypad commands during motor movement.

Result

The Keypad-Based Stepper Motor Angle Controller demonstrates target-position commands using Arduino UNO, a 4×4 keypad, a ULN2003 motor driver and a 28BYJ-48 stepper motor.

The entered target angle is converted into motor steps, and Arduino applies a half-step sequence to rotate toward the target.

The 16×2 I²C LCD displays the requested angle and estimated current position. The keypad also allows stopping motion and resetting software tracking values.
