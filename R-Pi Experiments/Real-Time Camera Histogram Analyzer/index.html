Aim

To develop a Real-Time Camera Histogram Analyzer using a Raspberry Pi 4 Model B and OV5647 CSI camera that captures live images, calculates the grayscale brightness histogram, measures minimum, maximum and average pixel brightness, and classifies the scene as DARK, NORMAL or BRIGHT.

About the Experiment

The Real-Time Camera Histogram Analyzer demonstrates digital image processing, grayscale conversion, pixel-intensity analysis and histogram visualization on Raspberry Pi.

The Raspberry Pi 4 Model B captures live video through the OV5647 CSI camera using the Picamera2 library.

OpenCV converts each captured color frame into a grayscale image whose pixel intensities range from 0 to 255.

A 256-bin histogram is calculated to show the distribution of brightness values within the current image.

NumPy calculates minimum, maximum and average brightness values for each frame.

The average brightness determines whether the scene is classified as DARK, NORMAL or BRIGHT.

The experiment displays two OpenCV windows: one showing the live camera image with brightness measurements, and another displaying the grayscale histogram.

Understanding Grayscale Brightness

Pixel Intensity Meaning
0 Black
1–254 Different shades of gray
255 White
Important:

Image brightness depends on scene illumination, camera exposure, gain and other image-processing settings.

DARK, NORMAL and BRIGHT are software classifications based on grayscale image values. They are not calibrated illuminance measurements in lux.

The thresholds 70 and 180 may be adjusted after testing different lighting conditions.

Connection Procedure

  1. Switch off the Raspberry Pi before handling the camera connector.
  2. Locate the Raspberry Pi camera CSI connector.
  3. Connect the OV5647 camera using its compatible camera ribbon connection.
  4. Check the ribbon orientation and connector locking mechanism.
  5. Power on the Raspberry Pi after securing the connection.
  6. Verify the camera is detected before running the program.
Connection Note:

The CSI camera is connected through the dedicated camera interface. No separate Raspberry Pi GPIO signals are required for the image-analysis program.

Avoid inserting or removing the camera connection while the Raspberry Pi is powered.

Camera Frame Capture

Picamera2 configures the camera for 640 × 480 capture using an RGB888 image stream.

Grayscale Conversion

OpenCV converts the live color image into grayscale, producing one intensity value for each pixel.

Histogram Generation

OpenCV groups pixel values into 256 histogram bins, corresponding to intensities from 0 to 255.

Brightness Statistics

NumPy calculates the minimum, maximum and average pixel intensity from the grayscale image.

Scene Classification

An average below 70 is DARK, an average above 180 is BRIGHT, and intermediate values are classified NORMAL.

Histogram Display

The histogram frequencies are normalized for drawing and displayed as a white brightness curve against a dark background.

Live Monitoring

The analyzer displays a live camera window showing brightness statistics, and a separate histogram window showing the intensity distribution.

Procedure

  1. Arrange the Raspberry Pi 4 Model B, OV5647 CSI camera and Raspberry Pi power supply.
  2. Switch off the Raspberry Pi before connecting the camera.
  3. Connect the OV5647 camera to the Raspberry Pi CSI connector.
  4. Check that the ribbon connection is correctly oriented and secured.
  5. Power on the Raspberry Pi.
  6. Boot Raspberry Pi OS.
  7. Verify camera detection using rpicam-hello -t 0.
  8. Install Picamera2, OpenCV and NumPy.
  9. Open Terminal.
  10. Create the experiment directory using mkdir -p ~/Desktop/camera_histogram.
  11. Navigate to the experiment directory.
  12. Copy the Python code from Explore the Code.
  13. Save the program as histogram.py.
  14. Run python3 histogram.py in a graphical desktop session.
  15. Check that the camera starts successfully.
  16. Observe the Live Camera window.
  17. Observe the Brightness Histogram window.
  18. Cover the camera to produce a dark scene.
  19. Observe the change in average brightness and DARK classification.
  20. Point the camera toward a normally illuminated scene.
  21. Observe the NORMAL classification when the average is within the configured range.
  22. Point the camera toward a brighter scene and observe the histogram distribution.
  23. Observe BRIGHT classification when the average exceeds 180.
  24. Compare the minimum, maximum and average brightness values.
  25. Press Q while an OpenCV window has focus to stop the analyzer.
