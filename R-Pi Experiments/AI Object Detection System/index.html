Aim

To build a Raspberry Pi based real-time AI object detection and counting system using a USB camera, OpenCV, YOLO11n and a Flask web dashboard.

About the Experiment

The Raspberry Pi 4 receives live video from a USB camera and uses OpenCV to capture frames.

A pretrained YOLO11n model detects supported object classes, displays bounding boxes and confidence values, and updates object counts.

A Flask web dashboard displays the live camera, current object, confidence, total detections and a live object-count graph.

Procedure

  1. Connect the USB camera to any Raspberry Pi USB port.
  2. Power the Raspberry Pi using the Raspberry Pi power supply.
  3. Confirm that the camera is available as /dev/video0.
  4. Create and activate the Python virtual environment.
  5. Install OpenCV, PyTorch, Torchvision, Ultralytics and Flask.
  6. Place yolo11n.pt in the project folder.
  7. Save the program as pi_yolo_web.py.
  8. Run python pi_yolo_web.py.
  9. Open the Raspberry Pi IP address on port 5000 in a browser.
  10. Place supported objects in front of the camera and observe detections and counts.
