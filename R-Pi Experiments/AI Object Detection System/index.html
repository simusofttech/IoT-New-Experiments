Aim

To develop a Raspberry Pi-based real-time AI Object Detection System using a Raspberry Pi 4 Model B, USB camera, OpenCV, a pretrained YOLO11n model and a Flask web dashboard.

The experiment detects supported object classes, displays bounding boxes and confidence values, counts detection events and visualizes results through a live dashboard.

About the Experiment

The AI Object Detection System demonstrates computer vision, neural-network inference, real-time image processing and browser-based monitoring using Raspberry Pi 4.

A USB camera captures video frames. OpenCV retrieves the images and passes them to a pretrained YOLO11n model for object detection.

YOLO11n identifies objects belonging to the categories supported by its trained weights. For every detected object, the system provides a class label, confidence value and bounding box.

The program counts detection events by object class. A two-second interval prevents the same class from incrementing the counter on every video frame.

A Flask web server displays the camera feed, current object, detection confidence, total event count and a live bar graph of counts grouped by class.

Object Detection and Counting

Stage Operation
Image Capture USB camera captures live frames
AI Inference YOLO11n processes the frame
Confidence Filter Accept detections with confidence of at least 0.65
Bounding Box Draw class label and detection box
Event Counter Count the same class no more than once every 2 seconds
Dashboard Display live video, counts and graph
Important: The system performs event-style object counting, not unique-object tracking. A continuously visible object may be counted again after the two-second interval. Individual objects are not assigned tracking IDs.

Image Acquisition

OpenCV captures video frames from the USB camera connected to the Raspberry Pi.

YOLO Inference

Each frame is processed using the pretrained YOLO11n model with a configured inference size of 320 pixels.

Object Identification

YOLO returns detection results containing object labels, confidence values and bounding-box coordinates.

Event Counting

A dictionary tracks the most recent counted time for each detected class. The count increases only after the two-second interval for that class has elapsed.

Live Video Stream

OpenCV encodes the annotated images into JPEG frames. Flask streams them to the browser in MJPEG format.

Live Graph

The Flask dashboard requests the current count data as JSON. JavaScript generates a bar for each recorded object class.

Procedure

  1. Arrange the Raspberry Pi 4 Model B, USB webcam and Raspberry Pi power supply.
  2. Connect the USB camera to a Raspberry Pi USB port.
  3. Connect the approved Raspberry Pi power supply.
  4. Boot Raspberry Pi OS.
  5. Check camera availability using ls /dev/video*.
  6. Confirm that the desired camera device is /dev/video0.
  7. Open a terminal and create a Python virtual environment.
  8. Activate the environment.
  9. Install Flask, OpenCV and Ultralytics with compatible dependencies.
  10. Place yolo11n.pt in the experiment directory.
  11. Save the complete Python code as pi_yolo_web.py.
  12. Run python pi_yolo_web.py.
  13. Observe the model-loading messages.
  14. Confirm that the USB camera opens successfully.
  15. Run hostname -I to identify the Raspberry Pi network address.
  16. Open http://RASPBERRY_PI_IP:5000 in a browser on the same network.
  17. Observe the live camera feed.
  18. Place supported objects in front of the camera.
  19. Verify the object labels, bounding boxes and confidence values.
  20. Observe the total detection-event count.
  21. Check the class-wise count graph.
  22. Stop the Python program using Ctrl+C.
