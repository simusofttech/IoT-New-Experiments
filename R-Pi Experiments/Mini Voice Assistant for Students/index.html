Mini Voice Assistant for Students

Display and manage school announcements through a local web application

Aim

Build an offline, rule-based voice assistant that recognizes student questions through a USB microphone and answers using Vosk and a local question-and-answer list.

About the Experiment

Raspberry Pi 4 Model B records spoken questions using a USB microphone. Vosk converts audio into text offline, and Python matches the text to predefined student-friendly answers. Answers are displayed in the terminal. eSpeak-NG audio output is optional and requires a configured audio device; no Bluetooth speaker is included.

Procedure

  1. Connect the USB microphone to Raspberry Pi 4B.
  2. Check the microphone with arecord -l. Test it using arecord -D plughw:3,0 -f S16_LE -r 16000 -c 1 -d 5 mic_test.wav; adjust the device number as needed.
  3. Install packages: sudo apt update, then sudo apt install -y python3-venv python3-pip python3-dev build-essential alsa-utils espeak-ng unzip.
  4. Create ~/Mini_Voice_Assistant and run python3 -m venv venv, source venv/bin/activate, and pip install vosk.
  5. Download vosk-model-small-en-us-0.15 from the Vosk model website, extract it and rename the model directory to model.
  6. Save the program as main.py. Change MIC_DEVICE if necessary.
  7. Run python main.py. Ask supported student questions; answers appear in the terminal.
  8. Say stop, exit, quit or goodbye, or press Ctrl+C to stop.

Expected Output

Expected Output

The terminal shows the listening prompt, recognized student question and matching answer. Unknown questions receive a fallback response. Spoken output is optional and needs a configured system audio output.

Result

An offline voice assistant recognizes questions from a USB microphone and displays predefined answers without a Bluetooth speaker component.
