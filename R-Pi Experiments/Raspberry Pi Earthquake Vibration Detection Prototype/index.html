Raspberry Pi Earthquake / Vibration Detection Prototype

Aim

To build an educational Raspberry Pi vibration monitor that reads acceleration from an MPU6050, calculates short-window RMS vibration, activates a servo and buzzer when the threshold is exceeded, and records data to CSV.

About the Experiment

The MPU6050 GY-521 sends X/Y/Z acceleration data to the Raspberry Pi over I²C.

The program estimates gravity/orientation, subtracts it from the measured acceleration, calculates changing acceleration magnitude, and then calculates an approximately one-second RMS value.

When RMS stays above the alert threshold, GPIO18 moves the servo and GPIO23 activates the buzzer. The project is an educational prototype, not a certified earthquake warning or prediction device.

Procedure

  1. Connect MPU6050 VCC to 3.3 V, GND to GND, SDA to GPIO2 and SCL to GPIO3.
  2. Connect the SG90 signal wire to GPIO18 and keep the servo ground common with Raspberry Pi ground.
  3. Connect the buzzer control to GPIO23 using the appropriate driver / module for the buzzer.
  4. Enable I²C using raspi-config and reboot.
  5. Verify the MPU6050 using sudo i2cdetect -y 1.
  6. Create ~/Desktop/Earthquake_Detection_System/logs and the virtual environment described in the SOP.
  7. Install smbus2 and verify the required libraries.
  8. Save the Python program as main.py.
  9. Run python main.py.
  10. Create gentle controlled vibrations near the sensor and observe the RMS graph, servo and buzzer.
  11. Press Ctrl+C to stop safely.

Expected Output

The live graph displays recent RMS acceleration values. When vibration remains above the configured alert threshold, the buzzer turns ON and the servo moves to the alert position.

Each acceleration sample, RMS value and alert state is saved in a timestamped CSV file.

Result

The prototype successfully measures vibration with the MPU6050, calculates RMS acceleration, activates the alert outputs when the configured condition is met, and records the measurements to CSV.

What You Learn

  • Calculating RMS vibration.
  • Using hysteresis and hold times for stable alerts.
  • Controlling a servo and buzzer from Raspberry Pi.
  • Logging sensor data to CSV and plotting live values.
