Aim

Demonstrate webcam-based face and eye detection with LCD status and LED/buzzer alert after approximately two seconds without detected eyes.

About the Experiment

OpenCV Haar cascades search for faces and eyes. gpiozero controls an LED and a buzzer while an I²C LCD reports status. Missed detection from lighting, glasses or head movement can create false alerts.

Code source status: SOP-based reconstruction of fatigue_monitor.py (the SOP formats the code across multiple columns). Review this against the installed file before replacing a working version. Educational demonstration only; not a certified fatigue or driver-safety detector.

Working Principle

USB camera frames
↓
OpenCV grayscale image
↓
Face and eye cascade detection
↓
Eyes seen → alert OFF
↓
No eyes for 2 seconds → LED and buzzer ON
↓
Display status on LCD

Procedure

  1. Connect the 16×2 I²C LCD to GPIO2/GPIO3, power and GND.
  2. Wire LED GPIO23 through the approved 220Ω resistor to GND; buzzer GPIO24 to GND using a suitable low-current buzzer.
  3. Connect USB webcam and start Raspberry Pi.
  4. Activate source ~/lcd-venv/bin/activate.
  5. Open ~/driver-fatigue and check both Haar cascade XML files in cascades/.
  6. Confirm I²C LCD address 0x27.
  7. Run python fatigue_monitor.py.
  8. Watch camera preview and LCD during an indoor bench test only.
  9. Press Q to stop and confirm the LED and buzzer are OFF.
