Aim

To develop an AI-Based Fruit Sorting System using a Raspberry Pi 4 Model B, USB camera, trained YOLO11m model, and two SG90 servo motors.

The experiment identifies Strawberry and Pear in the camera view and directs them toward their assigned sorting paths using independently controlled servo motors.

About the Experiment

The AI-Based Fruit Sorting System demonstrates the integration of computer vision, object detection and motorized sorting using a Raspberry Pi.

A USB camera captures live images from a fixed fruit inspection area. The Raspberry Pi processes these images using a trained YOLO11m fruit and vegetable detection model.

The system specifically uses Pear class 25 and Strawberry class 31. Other object classes are ignored for sorting.

When Strawberry is detected, the left SG90 servo connected to GPIO17 moves to the sorting position. When Pear is detected, the right SG90 servo connected to GPIO18 operates.

For more responsive video display, the Raspberry Pi performs inference every fourth camera frame at an AI input size of 320 × 320 pixels.

If multiple target fruits appear in the same inference result, the program selects the target with the highest confidence score for the sorting action.

Model Compatibility:

The trained file best.pt must have Pear and Strawberry assigned to class IDs 25 and 31 respectively.

If the model uses different class IDs, the sorting logic must be updated to match the actual trained model.

The original program can activate a servo repeatedly when the same fruit remains visible. This is a demonstration sorting system; a real conveyor implementation would need object tracking or a separate fruit-position sensor to prevent repeated sorting.

Hardware Precaution:

Do not connect the servo power wires to Raspberry Pi GPIO signal pins.

Use a regulated 5V servo supply with adequate current capacity and connect its ground to Raspberry Pi GND.

Verify that both sorting mechanisms can move freely without mechanical obstruction or servo stalling.

Camera Capture

The USB camera captures live video at a requested resolution of 640 × 480 pixels.

YOLO Fruit Detection

YOLO11m performs AI inference at 320 × 320 pixels on every fourth captured frame.

Target Classification

The program considers only class 25 for Pear and class 31 for Strawberry. Other classes are ignored.

Highest-Confidence Selection

When multiple matching detections are present, the highest-confidence target is selected for the next sorting action.

Servo Movement

The selected servo moves to the configured sorting position of 0.65 in GPIOZero's normalized servo-value range.

After 0.6 seconds, the servo returns to its HOME position of 0.0.

Live Display

An OpenCV window displays the accepted fruit labels, confidence scores and bounding boxes.

Procedure

  1. Arrange the Raspberry Pi 4 Model B, USB camera, two SG90 servo motors, regulated supply and jumper wires.
  2. Connect the USB camera to a Raspberry Pi USB port.
  3. Connect the left servo signal wire to GPIO17, physical pin 11.
  4. Connect the right servo signal wire to GPIO18, physical pin 12.
  5. Connect both servo VCC wires to the suitable regulated 5V supply.
  6. Connect both servo ground wires to the external supply GND.
  7. Connect the external supply GND to Raspberry Pi GND.
  8. Verify the wiring and mechanical sorting paths.
  9. Boot Raspberry Pi OS.
  10. Create the experiment directory using mkdir -p ~/AI_Fruit_Tracking/models.
  11. Navigate to ~/AI_Fruit_Tracking.
  12. Create the Python virtual environment fruit_env.
  13. Install the required Python packages and a compatible GPIO backend.
  14. Place the trained best.pt model inside the models directory.
  15. Verify that the trained model assigns class 25 to Pear and class 31 to Strawberry.
  16. Copy the Python program from Explore the Code.
  17. Save the program as fruit_sorting.py.
  18. Run python fruit_sorting.py using a desktop environment that supports OpenCV windows.
  19. Confirm that the USB camera opens and the AI model loads.
  20. Place a Strawberry within the sorting area.
  21. Verify Strawberry detection and left servo movement.
  22. Place a Pear within the sorting area.
  23. Verify Pear detection and right servo movement.
  24. Observe labels and confidence values in the live camera window.
  25. Press Q to stop the program.
  26. Confirm the servos return HOME and are released.

Explore More: Servo Values

GPIOZero Servo uses normalized values. The configured HOME value is 0.0 and SORT value is 0.65. These are not angle measurements in degrees.

Explore More: Frame Skipping

Running inference every fourth frame reduces processing workload compared with running inference on every frame.

Result

The AI-Based Fruit Sorting System demonstrates fruit recognition and servo-based sorting using Raspberry Pi 4, USB camera and a trained YOLO11m model.

Strawberry detections activate the left servo on GPIO17, while Pear detections activate the right servo on GPIO18. Other object classes are ignored.

The experiment demonstrates integration of AI object detection and independently controlled physical sorting outputs.
