Aim

To build a Raspberry Pi based AI fruit sorting system that detects Strawberry and Pear using a USB camera and automatically sends each fruit to its assigned sorting path using two servo motors.

About the Experiment

The Raspberry Pi 4 receives live video from a fixed USB camera and runs a YOLO11m fruit and vegetable detector.

The program uses Pear class 25 and Strawberry class 31. Strawberry activates the left sorting servo on GPIO17, while Pear activates the right sorting servo on GPIO18.

To keep the camera display responsive, inference runs at 320 × 320 on every fourth camera frame while the camera operates at 640 × 480.

Components Required

Raspberry Pi 4 Model B (×1)

Runs YOLO inference, camera processing and servo control.

USB Camera (×1)

Captures the fruits in the fixed sorting area.

SG90 Servo Motor (×2)

Left servo sorts Strawberry and right servo sorts Pear.

5 V Power Supply (×1)

Provides stable 5 V power for the sorting setup.

Jumper Wires

Used for servo signal, power and common-ground connections.

Procedure

  1. Connect the USB camera to a Raspberry Pi USB port.
  2. Connect the left sorting servo signal to GPIO17 and the right sorting servo signal to GPIO18.
  3. Power the two servos from a stable regulated 5 V supply and connect the supply ground to Raspberry Pi ground.
  4. Create ~/AI_Fruit_Tracking and a fruit_env virtual environment with system site packages.
  5. Install the required Raspberry Pi Python packages and Ultralytics as described in the SOP.
  6. Place best.pt in ~/AI_Fruit_Tracking/models/ and verify Pear is class 25 and Strawberry is class 31.
  7. Save the program as fruit_sorting.py and run python fruit_sorting.py.
  8. Place Strawberry and Pear in the sorting area and verify the correct servo operates.
  9. Press Q to stop safely.

Expected Output

A detected Strawberry activates the left servo and returns it to HOME after sorting.

A detected Pear activates the right servo and returns it to HOME.

Other detected classes are ignored, while the live window shows the accepted fruit label and confidence.

Result

The AI-Based Fruit Sorting System successfully detects Strawberry and Pear and operates the assigned left or right servo to sort the fruit into the correct path.

What You Learn

  • Running YOLO object detection on Raspberry Pi.
  • Using class IDs to trigger different physical outputs.
  • Controlling two servo motors independently with GPIOZero.
  • Reducing AI workload by detecting every fourth camera frame.
  • Selecting the highest-confidence target when multiple fruits are visible.
  • Using a common ground with an external servo supply.
