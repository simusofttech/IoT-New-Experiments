Aim

To build a Raspberry Pi based voice controlled servo system that records spoken commands using a USB microphone, converts the speech into text and moves an SG90 servo to programmed positions.

About the Experiment

The Raspberry Pi 4 records a short voice command through a USB microphone using ALSA arecord.

SpeechRecognition converts the recorded WAV audio into text using Google Speech Recognition.

The Python program compares the recognized text with supported commands and uses lgpio PWM on GPIO18 to control the SG90 servo.

Components Required

Procedure

  1. Connect the SG90 signal wire to GPIO18 / physical pin 12.
  2. Connect the SG90 ground and 5V connections as shown in the supplied circuit diagram.
  3. Connect the USB microphone to any Raspberry Pi USB port.
  4. Power ON the Raspberry Pi.
  5. Create the project folder ~/voice_servo.
  6. Create and activate the servo_env Python virtual environment.
  7. Install SpeechRecognition and lgpio, and make sure ALSA arecord and FLAC are available.
  8. Use arecord -l to verify the USB microphone and confirm the configured device.
  9. Save the final program as voice_servo.py.
  10. Run python voice_servo.py.
  11. Speak OPEN, CLOSE, LEFT, RIGHT, CENTER/CENTRE or STOP and observe the servo response.
