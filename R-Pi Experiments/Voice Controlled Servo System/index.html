Aim

To develop a voice-controlled servo motor experiment using a Raspberry Pi 4 Model B, USB microphone and SG90 servo motor. The system records spoken instructions, converts speech into text and rotates the servo to predetermined angles.

About the Experiment

The Voice Controlled Servo System combines audio recording, speech recognition, Python command processing and servo motor control.

The Raspberry Pi records spoken commands through a USB microphone using the ALSA arecord utility.

Each recording lasts four seconds and is saved temporarily as a WAV audio file.

The SpeechRecognition library sends the recorded audio to Google Speech Recognition and receives recognized text.

The Python program identifies supported instructions and generates 50 Hz servo-control PWM through GPIO18 using the lgpio library.

OPEN, CLOSE, LEFT, RIGHT and CENTER/CENTRE move the servo to their programmed positions. STOP exits the program.

Important:

The configured microphone device plughw:3,0 is taken from the supplied experiment. Its actual ALSA number may be different on another Raspberry Pi. Verify it using arecord -l.

Google Speech Recognition requires network access. Recognition may fail because of background noise, microphone quality or connection problems.

Voice Recording

The microphone captures speech through ALSA arecord. A four-second 8 kHz mono recording is saved as a temporary WAV file.

Speech-to-Text Conversion

The SpeechRecognition library reads the WAV recording and uses Google Speech Recognition to obtain the spoken text.

Command Processing

The recognized text is converted to lowercase and compared with the supported commands.

Servo PWM Control

The program converts the requested angle into a pulse between 1000 and 2000 microseconds at a frequency of 50 Hz.

Servo Movement

The SG90 rotates to the requested position. The program holds the position for approximately one second before recording the next command.

Exit Operation

The STOP voice command ends the main loop, stops PWM output, releases GPIO resources and removes the temporary recording file.

Procedure

  1. Arrange the Raspberry Pi 4 Model B, SG90 servo motor, USB microphone and jumper wires.
  2. Connect the SG90 signal wire to GPIO18, physical pin 12.
  3. Connect servo VCC to a suitable regulated 5V source.
  4. Connect the servo ground to the supply ground and Raspberry Pi common ground.
  5. Connect the USB microphone to a Raspberry Pi USB port.
  6. Check the complete circuit before supplying power.
  7. Boot Raspberry Pi OS.
  8. Open Terminal.
  9. Create the experiment directory using mkdir -p ~/voice_servo.
  10. Open the directory using cd ~/voice_servo.
  11. Create a Python virtual environment named servo_env.
  12. Activate the virtual environment.
  13. Install SpeechRecognition and lgpio using a compatible package installation method.
  14. Ensure ALSA arecord and FLAC utilities are available.
  15. Run arecord -l to identify the USB microphone.
  16. Update MIC_DEVICE if the microphone device differs from plughw:3,0.
  17. Copy the full Python program from Explore the Code.
  18. Save it as voice_servo.py.
  19. Run python voice_servo.py.
  20. Observe the servo moving to the initial 90° position.
  21. Wait for the terminal message Listening....
  22. Speak OPEN clearly and observe the 150° position.
  23. Try CLOSE, LEFT, RIGHT and CENTER/CENTRE.
  24. Verify that the recognized command and target angle appear in the terminal.
  25. Speak STOP to terminate the program.
  26. Confirm the GPIO PWM output is released.

Result

The Voice Controlled Servo System demonstrates speech-controlled movement of an SG90 servo motor using Raspberry Pi 4.

Voice commands are recorded through a USB microphone, converted into text using SpeechRecognition and matched to programmed servo angles.

The Raspberry Pi generates 50 Hz PWM signals on GPIO18 to control the servo position and releases the GPIO resources when the program exits.
