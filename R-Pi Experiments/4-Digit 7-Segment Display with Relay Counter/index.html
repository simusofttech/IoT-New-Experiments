Aim

To develop a 4-Digit 7-Segment Display with Relay Counter using Raspberry Pi 4 Model B to control a relay, count each completed ON/OFF switching cycle and display the count from 0000 to 9999 using a multiplexed four-digit seven-segment display.

About the Experiment

The 4-Digit 7-Segment Display with Relay Counter demonstrates GPIO output control, relay switching, numeric display interfacing, time-based counting and display multiplexing.

The Raspberry Pi controls a 5V relay module using GPIO23. The relay is configured as an active-LOW module, meaning a LOW control signal activates the relay.

The program switches the relay ON for approximately 0.5 seconds and OFF for approximately 0.5 seconds.

During both phases, the four-digit display shows the current count.

After one completed relay ON/OFF cycle, the counter increases by one.

The count starts from 0000 and advances to 9999. After 9999, the counter returns to 0000.

The four-digit display uses multiplexing. The Raspberry Pi rapidly selects each digit and sends the corresponding segment pattern.

Eight 1kΩ resistors are used as current-limiting resistors for segments A–G and the decimal point.

Display Compatibility:

The original program assumes active-HIGH segment signals and active-LOW digit selection signals.

This logic is consistent with a suitably driven common-cathode multiplexed display, but actual display pinout and driver polarity must be checked.

The eight 1kΩ resistors limit segment current and may produce relatively low brightness, especially when multiplexed.

Important Wiring Requirements:

Connect each of the eight segment-control lines through its individual 1kΩ resistor.

Do not directly connect display digit common terminals to GPIO without verifying the current requirements. Use a compatible digit-driver stage. Its input polarity must match the active-LOW digit selection used by the Python code.

Identify the exact display part number, common-anode or common-cathode type, and physical pinout before connecting it. GPIO labels such as DIG1 and Segment A are signal names, not the display's physical package pins.

Confirm that the relay module accepts 3.3V control signals. A 5V relay power supply does not automatically guarantee 3.3V input compatibility.

GPIO Initialization

The Raspberry Pi assigns eight GPIO pins to the seven-segment lines and decimal point, four GPIO pins to digit selection and GPIO23 to relay control.

Seven-Segment Patterns

A Python dictionary stores the segment patterns required to display digits 0 through 9.

Display Multiplexing

The program switches OFF all digit selects, updates the segment pattern, then activates the selected digit.

The program repeats this sequence for all four digits with a nominal 2-millisecond delay per digit.

Relay Switching

The relay turns ON when GPIO23 goes LOW and turns OFF when GPIO23 goes HIGH.

Cycle Counting

One complete ON/OFF sequence increases the count by one.

Counter Reset

After the counter reaches 9999, the next increment resets it to 0000.

Procedure

  1. Arrange the Raspberry Pi 4 Model B, four-digit display, eight 1kΩ resistors, one relay module, breadboard and jumper wires.
  2. Check the exact display model, pinout and common configuration.
  3. Determine the suitable digit-driver arrangement based on the display current requirements.
  4. Verify that the digit-driver control polarity matches the original active-LOW software signals.
  5. Connect Segment A through 1kΩ to GPIO5.
  6. Connect Segment B through 1kΩ to GPIO6.
  7. Connect Segment C through 1kΩ to GPIO13.
  8. Connect Segment D through 1kΩ to GPIO19.
  9. Connect Segment E through 1kΩ to GPIO26.
  10. Connect Segment F through 1kΩ to GPIO16.
  11. Connect Segment G through 1kΩ to GPIO20.
  12. Connect the decimal-point control line through 1kΩ to GPIO21.
  13. Connect digit-selection control signals to GPIO12, GPIO17, GPIO27 and GPIO22 through the verified driver stage.
  14. Connect the relay module IN to GPIO23.
  15. Connect the relay supply and ground according to its module specifications.
  16. Verify that Raspberry Pi GPIO is protected from 5V signals and excessive current.
  17. Power on the Raspberry Pi and boot Raspberry Pi OS.
  18. Verify that Python 3 and a compatible RPi.GPIO implementation are available.
  19. Create the Python file relay_counter.py.
  20. Copy the full program from Explore the Code.
  21. Run python3 relay_counter.py.
  22. Observe the relay switching ON and OFF.
  23. Check that the four-digit display shows the current count.
  24. Verify that the count increments after each complete cycle.
  25. Press Ctrl+C to stop the program.
  26. Confirm that the relay and digit-selection outputs are deactivated.
