4-Digit 7-Segment Display with Relay Counter

Count relay switching cycles on a four-digit display

← R-Pi Experiments Aim Components Connections Circuit Working Procedure Code Result

Aim

To count relay ON/OFF cycles from 0000 to 9999 using a Raspberry Pi 4B and a multiplexed 4-digit 7-segment display.

About the Experiment

The Raspberry Pi drives the display segment and digit lines and controls a 5V relay using GPIO23. Each completed ON/OFF cycle increases the count by one.

Working Principle

Relay ON → Show Count → Relay OFF → Show Count → Increment Count → Repeat

The eight 1kΩ resistors limit segment current and can make the display dimmer than the original 330Ω design. Confirm the display type and safe digit-driving hardware before wiring.

Procedure

  1. Verify the display pinout, common configuration, and suitable GPIO digit drivers.
  2. Connect A–G and DP to GPIO5, 6, 13, 19, 26, 16, 20, 21 through eight 1kΩ resistors.
  3. Connect DIG1–DIG4 to the GPIO12, 17, 27, 22 control signals through suitable digit drivers.
  4. Connect relay VCC to 5V, GND to ground, and IN to GPIO23; verify 3.3V GPIO compatibility.
  5. Save the program as relay_counter.py and run with Python 3.
  6. Observe relay cycling and the count advancing from 0000 to 9999.

Expected Output

Expected Output

The relay alternates ON and OFF for approximately 0.5 seconds each. The four-digit display shows the current count and increments after each complete cycle, wrapping to 0000 after 9999.

Result
