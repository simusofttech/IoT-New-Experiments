Fail-Safe Relay State Monitor

Monitor relay state using green and red indicators with a safe OFF condition

← R-Pi Experiments Aim Components Connections Circuit Working Procedure Code Result

Aim

To monitor and indicate the state of a 5V relay using a Raspberry Pi 4B, with a green LED for relay ON and a red LED for relay OFF or safe state.

About the Experiment

The Raspberry Pi controls the relay through GPIO23 and uses GPIO24 and GPIO25 for green and red status LEDs.

When the relay is ON, the green LED turns ON. When the relay is OFF, the red LED turns ON. If the program is interrupted or stops, the relay is returned to the safe OFF state.

Procedure

  1. Connect the relay module VCC to 5V Pin 2 and GND to Pin 6.
  2. Connect the relay IN pin to GPIO23 / physical Pin 16.
  3. Connect the green LED through a 220Ω resistor to GPIO24 / physical Pin 18.
  4. Connect the red LED through a 220Ω resistor to GPIO25 / physical Pin 22.
  5. Connect both LED cathodes to GND / physical Pin 20.
  6. Save the program as relay_monitor.py.
  7. Run the Python program.
  8. Observe the relay ON state with the green LED ON for three seconds.
  9. Observe the relay OFF safe state with the red LED ON for three seconds.
  10. Press Ctrl+C and verify that the relay returns to the safe OFF state.

Expected Output

The relay remains ON for three seconds while the green LED is ON.

The relay then switches OFF for three seconds while the red LED is ON.

The sequence repeats continuously.

If the program stops, the relay is forced OFF and the red LED indicates the safe state.

Result

The Raspberry Pi successfully controls and monitors the relay state while returning the relay to the safe OFF condition when the program stops.
