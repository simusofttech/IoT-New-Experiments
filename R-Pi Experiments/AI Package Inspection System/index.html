Aim

To build a Raspberry Pi based AI package inspection system that uses a USB camera and YOLO11 ONNX model to classify packages and control two SG90 servo motors for automatic sorting.

About the Experiment

The Raspberry Pi 4 Model B captures packages using a USB camera and performs local YOLO11 ONNX inference.

The model classifies each package as Good package, damage, or package without lable. Good packages pass without servo movement. Damaged packages activate the GPIO18 servo, while packages without a lable activate the GPIO19 servo.

A Flask web dashboard provides the live camera view, current detection, confidence, PASS/REJECT state, servo action, counters and detection history.

Components Required

Raspberry Pi 4 Model B (×1)

Main controller that runs the AI model, GPIO control and Flask dashboard.

USB Webcam / Camera (×1)

Captures package images for real-time inspection.

SG90 Servo Motor (×2)

One servo rejects damaged packages and the second rejects no-label packages.

Procedure

  1. Connect the USB camera to a Raspberry Pi USB port.
  2. Connect the damage sorter servo signal to GPIO18 / physical pin 12.
  3. Connect the no-label sorter servo signal to GPIO19 / physical pin 35.
  4. Install Raspberry Pi OS with Python 3 and create the package_env virtual environment.
  5. Install Flask, OpenCV, NumPy, ONNX Runtime, GPIOZero and lgpio.
  6. Place best.onnx inside the project models folder.
  7. Save the program as camera_web.py and run it.
  8. Use hostname -I to find the Raspberry Pi IP address.
  9. Open http://<RASPBERRY_PI_IP>:5000 in a browser.
  10. Place packages in front of the camera and observe PASS/REJECT operation and servo sorting.

Expected Output

Good packages are displayed as PASS and neither servo moves.

Damaged packages are displayed as REJECT and the GPIO18 servo activates for about one second.

Packages without a lable are displayed as REJECT and the GPIO19 servo activates for about one second.

The Flask dashboard shows the live camera, confidence, current status, counters, servo action and detection log.

Result

The Raspberry Pi AI Package Inspection System successfully performs real-time package classification using a YOLO11 ONNX model and controls separate servo sorting actions for damaged and no-label packages while providing a live Flask dashboard.
