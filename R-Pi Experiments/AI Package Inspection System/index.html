Aim

To develop a Raspberry Pi-based AI Package Inspection System using a Raspberry Pi 4 Model B, USB camera, YOLO11 ONNX model and two SG90 servo motors for automatic package classification and sorting.

The experiment detects good packages, damaged packages and packages without labels, then performs suitable PASS or REJECT actions.

About the Experiment

The AI Package Inspection System uses computer vision and an object-detection model to identify package conditions.

The Raspberry Pi 4 Model B captures video frames using a USB webcam. The frames are processed through a trained YOLO11 ONNX model using ONNX Runtime.

The model classifies each detected package into one of three classes: Good package, damage, or package without lable.

A good package receives a PASS status and does not activate either sorting servo.

A damaged package receives REJECT status and activates the SG90 servo connected to GPIO18. A package without a label receives REJECT status and activates the second servo on GPIO19.

A Flask web dashboard provides a live camera view, detection class, confidence score, PASS/REJECT status, servo action, package counters and detection history.

Image Acquisition

The USB camera captures frames at a configured resolution of 640×480 pixels.

AI Model Inference

The image is resized to 640×640, converted to RGB, normalized and provided to ONNX Runtime.

Object Detection

The system extracts bounding boxes, class scores and confidence values. Non-Maximum Suppression reduces overlapping detections.

Servo Sorting

For detected damage, the GPIO18 servo moves to the configured rejection position. For packages without a label, the GPIO19 servo operates. Both return to their rest position.

Dashboard Monitoring

Flask serves an MJPEG live camera stream, detection information, confidence scores, servo status, counters and recent event history.

Procedure

  1. Arrange the Raspberry Pi 4 Model B, USB camera, two SG90 servos and jumper wires.
  2. Connect the USB camera to a Raspberry Pi USB port.
  3. Connect the damage servo signal to GPIO18, physical pin 12.
  4. Connect the no-label servo signal to GPIO19, physical pin 35.
  5. Provide a suitable regulated supply for both servos.
  6. Connect servo power grounds to the Raspberry Pi's common ground.
  7. Install Raspberry Pi OS and Python 3.
  8. Create and activate the Python virtual environment named package_env.
  9. Install Flask, OpenCV, NumPy, ONNX Runtime, GPIOZero and lgpio.
  10. Place the trained best.onnx model in the configured models directory.
  11. Save the Python program as camera_web.py.
  12. Verify the model input and output formats.
  13. Run python camera_web.py in the virtual environment.
  14. Use hostname -I to identify the Raspberry Pi IP address.
  15. Open http://RASPBERRY_PI_IP:5000 on a browser on the same network.
  16. Place a good package in front of the camera.
  17. Observe PASS status without servo activation.
  18. Place a damaged package in view and verify GPIO18 servo movement.
  19. Test a package without a label and verify GPIO19 servo movement.
  20. Observe detection confidence, counters and log entries.
  21. Verify the three-second detection cooldown.

Result

The AI Package Inspection System demonstrates Raspberry Pi-based computer vision, YOLO11 ONNX package classification and servo-controlled rejection logic.

The system assigns PASS status to good packages and REJECT status to damaged and no-label packages, using GPIO18 and GPIO19 for the corresponding sorting mechanisms.

The Flask dashboard provides live visual monitoring, detection confidence, sorting information, counters and event history.
