Aim

To design and implement a Dual-Touch Mode Selector using Raspberry Pi 4 Model B, two TTP223 capacitive touch sensors and two LED indicators to select and display different operating modes without mechanical switches.

About the Experiment

The Dual-Touch Mode Selector demonstrates a capacitive touch-based control system using Raspberry Pi and Python.

Two TTP223 touch sensor modules act as digital inputs. Each touch sensor detects a finger on its touch pad and generates a digital signal.

Touch Sensor 1 selects Mode 1. The Raspberry Pi turns ON the red LED and switches OFF the green LED.

Touch Sensor 2 selects Mode 2. The Raspberry Pi turns ON the green LED and switches OFF the red LED.

The selected mode is printed in the terminal for observation.

The program waits for the active touch sensor to be released before accepting another selection from that sensor.

The system maintains the selected LED state after the finger is removed. A different mode is selected only when its corresponding sensor is touched.

Input Logic:

This implementation assumes standard TTP223 modules configured for active-HIGH, momentary output.

If the touch module is configured for active-LOW or toggle operation, its input handling must be adjusted.

Electrical Safety:

Raspberry Pi GPIO inputs are not 5V tolerant. The uploaded circuit listed 5V power for the touch modules, but this revised wiring uses 3.3V with compatible TTP223 modules.

Verify the actual sensor board operates reliably from 3.3V and produces a 3.3V-compatible output.

The 220Ω resistors must remain in series with the individual LEDs. Never connect an LED directly between GPIO and ground without current limiting.

Capacitive Touch Detection

The TTP223 module detects changes in capacitance when a finger touches its sensing surface.

Digital Input Reading

GPIO17 and GPIO27 read digital signals from Touch Sensor 1 and Touch Sensor 2.

Mode 1 Operation

Touching Sensor 1 activates the red LED, deactivates the green LED and prints Mode 1 Selected in the terminal.

Mode 2 Operation

Touching Sensor 2 activates the green LED, deactivates the red LED and prints Mode 2 Selected in the terminal.

Mode Retention

After a touch is released, the currently selected LED remains ON until another mode is selected or the program stops.

Program Cleanup

When the program stops, both LEDs are turned OFF and GPIOZero device resources are released.

Procedure

  1. Arrange the Raspberry Pi, two TTP223 touch modules, red LED, green LED, two 220Ω resistors, breadboard and jumper wires.
  2. Verify that the TTP223 modules support 3.3V operation and have active-HIGH momentary outputs.
  3. Connect Touch Sensor 1 OUT to GPIO17, physical pin 11.
  4. Connect Touch Sensor 2 OUT to GPIO27, physical pin 13.
  5. Connect both sensor VCC terminals to Raspberry Pi 3.3V.
  6. Connect both sensor GND terminals to a common ground.
  7. Connect the red LED anode through a 220Ω resistor to GPIO22, physical pin 15.
  8. Connect the green LED anode through a 220Ω resistor to GPIO23, physical pin 16.
  9. Connect both LED cathodes to ground.
  10. Verify the complete wiring before powering the system.
  11. Boot Raspberry Pi OS.
  12. Open Terminal.
  13. Install GPIOZero if not already available.
  14. Create the Python file dual_touch_mode.py.
  15. Copy the complete Python program from Explore the Code.
  16. Run python3 dual_touch_mode.py.
  17. Touch Sensor 1 and observe that the red LED turns ON.
  18. Remove your finger and confirm that the selected mode remains active.
  19. Touch Sensor 2 and observe that the green LED turns ON while the red LED turns OFF.
  20. Repeat mode selection to verify both sensors.
  21. Observe the selected mode messages in the terminal.
  22. Press Ctrl+C to stop the program.
  23. Verify that both LEDs turn OFF.

Result

The Dual-Touch Mode Selector demonstrates touch-based operating-mode selection using Raspberry Pi 4 Model B, two TTP223 capacitive touch sensors and red and green LEDs.

Touch Sensor 1 selects Mode 1 and activates the red LED. Touch Sensor 2 selects Mode 2 and activates the green LED. The corresponding selection is displayed in the terminal.
