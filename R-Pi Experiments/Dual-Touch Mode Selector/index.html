Dual-Touch Mode Selector

Choose between two modes using touch sensors and LED indicators

← R-Pi Experiments Aim Components Connections Circuit Working Procedure Code Result

Aim

To demonstrate selecting two operating modes with TTP223 touch sensors and a Raspberry Pi 4B, using red and green LEDs as indicators.

About the Experiment

Touch Sensor 1 selects Mode 1 and turns ON the red LED while switching OFF the green LED. Touch Sensor 2 selects Mode 2 and turns ON the green LED while switching OFF the red LED. The selected mode is also printed in the terminal.

Working Principle

Touch Sensor 1 → Mode 1 → Red LED ON
Touch Sensor 2 → Mode 2 → Green LED ON

The program checks both touch inputs continuously and changes the LED states when a touch is detected.

Procedure

  1. Connect the first TTP223 OUT to GPIO17 and the second TTP223 OUT to GPIO27.
  2. Connect their VCC pins to 5V and GND pins to a common ground.
  3. Connect the red LED anode through a 220Ω resistor to GPIO22 and the green LED anode through a 220Ω resistor to GPIO23. Connect both cathodes to GND.
  4. Ensure the TTP223 OUT voltage is safe for the Raspberry Pi 3.3V GPIO inputs; use suitable level shifting if necessary.
  5. Install python3-gpiozero if needed, then save the program as dual_touch_mode.py.
  6. Run python3 dual_touch_mode.py.
  7. Touch the first sensor to select Mode 1 and the second sensor to select Mode 2.
  8. Press Ctrl+C to stop and turn both LEDs OFF.
