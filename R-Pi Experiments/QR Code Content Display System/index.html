Aim

To develop a QR Code Content Display System using a Raspberry Pi 4 Model B and USB webcam to capture QR codes, decode embedded information using OpenCV, and display the decoded content in real time on the live camera window and terminal.

About the Experiment

The QR Code Content Display System demonstrates QR code detection, image processing and data decoding using a Raspberry Pi 4 Model B.

A USB webcam continuously captures video frames. OpenCV processes each frame using the built-in QRCodeDetector.

When a QR code is successfully detected and decoded, the system draws a green boundary around the QR code and displays a detection message.

The decoded content may contain ordinary text, a URL or another QR-encoded data string. The program displays this content as text rather than opening any embedded links.

The full decoded content is printed in the terminal when it differs from the previously decoded value.

A shortened version of the decoded content is displayed directly over the live camera image.

When no QR code is decoded, the camera window displays Searching for QR code...

Important:

The experiment uses OpenCV's built-in QR decoder. No separate QR decoding library is needed.

Actual camera resolution, format and frame rate depend on the webcam and driver. The configured values are requests, not guaranteed measured performance.

This program uses detectAndDecode() to process one QR code at a time. It does not automatically open a decoded URL.

Connection Procedure

  1. Connect the USB webcam to an available Raspberry Pi USB port.
  2. Connect the Raspberry Pi power supply.
  3. Boot Raspberry Pi OS.
  4. Verify that the webcam is available at /dev/video0.
  5. Position the QR code in front of the webcam for testing.
Connection Note: The webcam communicates through USB. No additional GPIO wiring is required. The QR code is a test target, not an electronic module connected to the Pi.

USB Camera Capture

The webcam captures video using OpenCV's V4L2 camera interface. The software requests MJPEG, 640 × 480 resolution and 30 FPS.

QR Code Detection

The QRCodeDetector examines each captured frame for a recognizable QR pattern.

QR Content Decoding

The detector decodes the information stored in the QR code and returns the content as a Python string.

Boundary Drawing

When the QR corner coordinates are available, OpenCV draws a green outline around the code.

Terminal Output

The complete decoded content is printed when a different QR value is recognized.

Camera Overlay

The camera window displays QR DETECTED and a shortened form of the decoded content. When no readable code is detected, it displays Searching for QR code...

Procedure

  1. Arrange the Raspberry Pi 4 Model B, USB webcam, power supply and test QR code.
  2. Connect the USB webcam to the Raspberry Pi.
  3. Power on the Raspberry Pi and boot Raspberry Pi OS.
  4. Open a graphical desktop session.
  5. Open Terminal.
  6. Check the camera using ls /dev/video*.
  7. Verify that the webcam is accessible as /dev/video0.
  8. Install Python 3 and OpenCV if required.
  9. Create the experiment folder QR_Code_Project.
  10. Open the experiment folder in Terminal.
  11. Copy the complete Python code from Explore the Code.
  12. Save the code as main.py.
  13. Run python3 main.py.
  14. Observe the live camera window displaying Searching for QR code....
  15. Hold the test QR code in front of the webcam.
  16. Keep all four corners of the QR code visible.
  17. Ensure sufficient lighting and correct camera focus.
  18. Check for the green boundary around the detected code.
  19. Observe the message QR DETECTED.
  20. Read the decoded content in the camera window.
  21. Observe the complete decoded content in Terminal.
  22. Test another QR code containing different text.
  23. Press Q to close the program.
  24. Confirm the camera has been released.

Explore More: QRCodeDetector

OpenCV QRCodeDetector performs QR code detection and decoding without an additional QR library.

Explore More: MJPEG

MJPEG compresses camera frames as JPEG images. The program requests this format through V4L2.

Explore More: QR Content

A QR code may contain text, links or other data. This program displays the content as text.

Explore More: Detection Points

QRCodeDetector returns corner coordinates for detected QR codes. OpenCV uses them to draw the green outline.

Explore More: Repeated Scans

The last successfully decoded value is stored. The terminal prints only when the newly decoded value differs from it.
