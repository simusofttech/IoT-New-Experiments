QR Code Content Display System

Scan a QR code using a USB webcam and display the decoded content using Raspberry Pi

← R-Pi Experiments Aim Components Connections Circuit Working Procedure Code Result

Aim

To build a Raspberry Pi based QR Code Content Display System that captures QR codes using a USB webcam, decodes the embedded information with OpenCV, and displays the result in a live camera window.

About the Experiment

The system continuously captures video from a USB webcam connected to the Raspberry Pi. OpenCV's QRCodeDetector scans each camera frame, detects a QR code, decodes its stored content, draws a green boundary around the code and displays the decoded information on the live camera view.

The tested camera device is /dev/video0, with 640×480 MJPEG at 30 FPS. No separate QR decoding library is required because the program uses OpenCV's built-in QR code detector.

Procedure

  1. Connect the USB webcam to the Raspberry Pi.
  2. Connect the Raspberry Pi to the display output and power supply.
  3. Confirm that the webcam appears as /dev/video0.
  4. Install Python 3, OpenCV and NumPy if required.
  5. Create the project folder QR_Code_Project.
  6. Save the program below as main.py.
  7. Run the program using python3 main.py.
  8. The live window initially displays Searching for QR code....
  9. Show the supplied QR code to the webcam with all four corners visible.
  10. When detected, the program draws a green boundary and displays the decoded content.
  11. Press Q to stop the application.

Expected Output

The live camera window shows Searching for QR code... until a QR code is detected. After detection, a green boundary appears around the QR code, QR DETECTED is displayed, and the decoded content appears on the camera view and in the terminal.

Result

The QR Code Content Display System successfully captures QR codes using a USB webcam, decodes their embedded data using OpenCV QRCodeDetector, and displays the decoded result in real time.
