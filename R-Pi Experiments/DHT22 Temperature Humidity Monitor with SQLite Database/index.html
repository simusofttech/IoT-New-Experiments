Aim

To develop a DHT22 Temperature & Humidity Monitor with SQLite Database using Raspberry Pi 4 Model B for measuring environmental temperature and relative humidity, storing timestamped readings, generating a temperature graph, and announcing the all-time maximum recorded temperature.

About the Experiment

This experiment demonstrates temperature and humidity monitoring using a DHT22 sensor interfaced with Raspberry Pi 4 Model B.

The DHT22 communicates with the Raspberry Pi through GPIO17 and provides temperature measurements in degrees Celsius and relative humidity in percentage.

The system reads sensor values every five seconds. Each valid reading is stored in a local SQLite database named sensor_data.db.

The database stores the timestamp, temperature and humidity for each measurement. Previously recorded data is preserved between runs.

When monitoring stops, Matplotlib generates a temperature-history graph named temperature_graph.png.

The program then calculates the total stored readings, maximum recorded temperature and average recorded humidity.

Finally, eSpeak-NG announces the all-time maximum temperature retrieved from the database.

Important:

The all-time maximum refers to the highest temperature stored in the local SQLite database, including readings from previous runs.

This experiment does not create a live browser dashboard. Its graphical output is generated when the monitoring program stops.

To hear the eSpeak-NG voice announcement, the Raspberry Pi needs a configured audio output device.

A bare four-pin DHT22 sensor normally requires a pull-up resistor on DATA. Some three-pin modules already include it.

Circuit Connections

DHT22 Pin Raspberry Pi Connection Function
VCC 3.3V / Physical Pin 1 Sensor supply
DATA / OUT GPIO17 / Physical Pin 11 Digital sensor data
GND GND / Physical Pin 6 Common ground
Connection Note:

The sensor should use 3.3V-compatible wiring. Check whether the actual DHT22 module already contains a DATA pull-up resistor before adding an external one.

Procedure

  1. Arrange the Raspberry Pi 4 Model B, DHT22 sensor and jumper wires.
  2. Connect DHT22 VCC to Raspberry Pi 3.3V, physical pin 1.
  3. Connect DHT22 DATA to GPIO17, physical pin 11.
  4. Connect DHT22 GND to physical pin 6.
  5. Check whether the sensor requires an external DATA pull-up resistor.
  6. Power on the Raspberry Pi.
  7. Boot Raspberry Pi OS.
  8. Create the folder ~/Desktop/SQLite_Sensor_Database.
  9. Create and activate the Python virtual environment specified in the SOP.
  10. Install Adafruit CircuitPython DHT, Blinka and Matplotlib.
  11. Install eSpeak-NG for the voice announcement.
  12. Copy the Python program from Explore the Code.
  13. Save the program as main.py.
  14. Run python main.py.
  15. Observe temperature and humidity measurements approximately every five seconds.
  16. Allow the program to collect several valid sensor readings.
  17. Press Ctrl+C to stop monitoring.
  18. Check the generated sensor_data.db database.
  19. Open temperature_graph.png to view the temperature history.
  20. Check the terminal for the database summary.
  21. Listen to the maximum-temperature announcement.
