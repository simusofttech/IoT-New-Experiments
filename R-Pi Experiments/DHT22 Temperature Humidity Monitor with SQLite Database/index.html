DHT22 Temperature & Humidity Monitor with SQLite Database

← R-Pi Experiments Aim Components Connections Circuit Working Procedure Code Result

Aim

To read temperature and humidity from a DHT22 sensor using Raspberry Pi 4B, save timestamped readings in SQLite, generate a temperature graph on shutdown, display a database summary, and announce the all-time maximum temperature.

About the Experiment

The DHT22 sensor is connected to GPIO17. The Raspberry Pi reads temperature and humidity every five seconds.

Each valid reading is stored in sensor_data.db with its timestamp. When the program stops, it generates temperature_graph.png, prints a database summary and speaks the all-time maximum temperature using eSpeak-NG.

Components Required

Raspberry Pi 4 Model B (×1)

Reads the DHT22 sensor and manages the SQLite database.

DHT22 Temperature & Humidity Sensor (×1)

Provides stable power to the Raspberry Pi.

Jumper Wires

Connect the DHT22 module to the GPIO header.

Procedure

  1. Connect DHT22 VCC to Raspberry Pi 3.3 V / Physical Pin 1.
  2. Connect DHT22 DATA to GPIO17 / Physical Pin 11.
  3. Connect DHT22 GND to Raspberry Pi GND / Physical Pin 6.
  4. Create ~/Desktop/SQLite_Sensor_Database and activate the virtual environment described in the SOP.
  5. Install adafruit-circuitpython-dht and matplotlib.
  6. Save the program as main.py.
  7. Run python main.py.
  8. Observe temperature and humidity readings printed every five seconds.
  9. Press Ctrl+C to stop monitoring.
  10. Open temperature_graph.png to view the stored temperature history.
