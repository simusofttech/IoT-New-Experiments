Aim

To build a low-cost time-lapse camera system using Raspberry Pi 4 Model B and a USB webcam that automatically captures photographs at fixed intervals and combines the captured images into an MP4 video using FFmpeg.

About the Experiment

The Raspberry Pi Time-Lapse Camera demonstrates automatic image capture, scheduled photography and video generation using Raspberry Pi.

A USB webcam provides still images through the Linux Video4Linux2 interface.

A Python program calls the fswebcam command at predefined intervals to save JPEG photographs.

Each photograph receives a sequential number and timestamp in its filename.

In the SOP's tested configuration, the webcam captures an image every five seconds over approximately sixty seconds.

After image capture, FFmpeg combines the photographs in filename order to create a short H.264 MP4 video.

The resulting video plays the captured moments rapidly, allowing slow changes to be observed over a shorter duration.

Applications

  • Plant growth and seed germination.
  • Greenhouse observation.
  • Construction or model progress recording.
  • Cloud movement and sky observation.
  • Sunrise and sunset recording.
  • Documenting science experiments.
  • Recording 3D-printing progress.

Important:

The Python script handles automatic photo capture. FFmpeg video conversion is performed separately after the images have been captured.

The number of photographs may vary if fswebcam takes longer to capture frames or the Raspberry Pi is busy.

Use a new or empty photos directory for each recording to avoid mixing old images into the output video.

Procedure

  1. Arrange the Raspberry Pi 4 Model B and USB webcam.
  2. Connect the USB webcam to Raspberry Pi.
  3. Power on the Raspberry Pi and boot Raspberry Pi OS.
  4. Open Terminal.
  5. Update the package list:
sudo apt update
  1. Install fswebcam, FFmpeg and V4L2 utilities:
sudo apt install -y fswebcam ffmpeg v4l-utils
  1. Check the connected USB devices:
lsusb
ls -l /dev/video*
v4l2-ctl --list-devices
  1. Confirm the webcam device path. The tested SOP uses /dev/video0.
  2. Capture a single test photograph:
fswebcam -d /dev/video0 -r 640x480 --no-banner ~/test_photo.jpg
  1. Check that the test photo was saved:
ls -lh ~/test_photo.jpg
file ~/test_photo.jpg
  1. Create the project directory and photos folder:
mkdir -p ~/timelapse_camera/photos
cd ~/timelapse_camera
  1. Create the Python program:
nano ~/timelapse_camera/timelapse.py
  1. Copy the complete Python code from Explore the Code.
  2. Paste it into the file and save using Ctrl+O, Enter, then Ctrl+X.
  3. Run the time-lapse program:
cd ~/timelapse_camera
python3 timelapse.py
  1. Allow the program to capture photographs for approximately one minute.
  2. Inspect the saved images:
ls -lh ~/timelapse_camera/photos
  1. Count the JPEG files:
find ~/timelapse_camera/photos -maxdepth 1 -type f -name '*.jpg' | wc -l
  1. Once capture is complete, convert the JPEG sequence into MP4:
ffmpeg -framerate 4 \
-pattern_type glob \
-i '/home/pi/timelapse_camera/photos/*.jpg' \
-c:v libx264 -pix_fmt yuv420p \
'/home/pi/timelapse_camera/timelapse_video.mp4'
Path Note: The FFmpeg command above uses the SOP's /home/pi home directory. If your Raspberry Pi username is different, replace /home/pi with your actual home path.
  1. Check the generated MP4 file:
ls -lh ~/timelapse_camera/timelapse_video.mp4
  1. Verify the video using ffprobe:
ffprobe -v error \
-show_entries format=duration,size \
-of default=noprint_wrappers=1 \
~/timelapse_camera/timelapse_video.mp4
  1. Play the video using an installed video player, such as VLC:
vlc ~/timelapse_camera/timelapse_video.mp4
  1. Verify that the time-lapse shows the captured scene progressing rapidly.
  2. Move or archive old photos before starting a new recording.
