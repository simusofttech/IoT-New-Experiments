Raspberry Pi Time-Lapse Camera

Aim

Build a time-lapse camera using Raspberry Pi 4 and a USB webcam. Capture JPEG images automatically at five-second intervals for approximately one minute and use FFmpeg to make an MP4 video.

About the Experiment

The Python program calls fswebcam to capture images at 640×480 resolution into ~/timelapse_camera/photos. Each file has a sequence number and timestamp. After acquisition, an FFmpeg command reads the JPEG sequence in filename order and encodes H.264 MP4 at 4 frames per second. With 12 frames, the video lasts about three seconds. The camera must be accessible through a V4L2 device such as /dev/video0.

Source verification note:

The capture source reproduces the logic and settings in the SOP, with Python indentation normalized from its page layout. The FFmpeg conversion is a separate terminal command in the SOP, not part of timelapse.py.

Procedure

  1. Connect USB webcam to Raspberry Pi and attach the rated Raspberry Pi supply.
  2. Install tools: sudo apt update; sudo apt install -y fswebcam ffmpeg v4l-utils.
  3. Identify the webcam using lsusb and v4l2-ctl --list-devices.
  4. Capture a test JPEG with fswebcam -d /dev/video0 -r 640x480 --no-banner ~/test_photo.jpg.
  5. Create ~/timelapse_camera/photos and save the code as ~/timelapse_camera/timelapse.py.
  6. Run python3 ~/timelapse_camera/timelapse.py.
  7. Verify approximately 12 numbered JPEG photos were saved.
  8. Use ffmpeg -framerate 4 -pattern_type glob -i '/home/pi/timelapse_camera/photos/*.jpg' -c:v libx264 -pix_fmt yuv420p '/home/pi/timelapse_camera/timelapse_video.mp4'.
  9. Check the file with ffprobe and play it using a suitable video player.
  10. Use a clean photos directory for a new recording so old photos are not mixed into the output.

Expected Output

At five-second intervals for approximately 60 seconds, the script usually saves roughly 12 JPEG files named photo_0001_YYYYMMDD_HHMMSS.jpg etc. FFmpeg at 4 fps creates an H.264 MP4 of about three seconds with 12 frames. The SOP reports successful capture of 12 images and a 3.0-second output video.

Result

When the camera and capture tools operate as described, JPEG images can be stored at scheduled intervals and converted into MP4 video. The referenced SOP documents a successful 12-image test and a 3-second video.
