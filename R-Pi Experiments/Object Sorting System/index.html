Aim

To build a Raspberry Pi based computer-vision system that captures an object using a USB webcam, performs YOLOv5n ONNX inference, and displays the detected object class and software sorting recommendation.

About the Experiment

The Object Sorting System uses a Raspberry Pi 4B, USB webcam, OpenCV and ONNX Runtime. The webcam captures an object, the software preprocesses the frame and the YOLOv5n ONNX model identifies the detected class.

The detected class, confidence value and software recommendation are displayed on screen. This experiment does not use a conveyor belt or automatic mechanical sorting mechanism.

Procedure

  1. Connect the USB webcam to the Raspberry Pi.
  2. Power the Raspberry Pi using the Raspberry Pi power supply.
  3. Create the ObjectSorting project directory and virtual environment.
  4. Install OpenCV, NumPy and ONNX Runtime.
  5. Place the verified yolov5n.onnx model inside the models folder.
  6. Confirm that the USB webcam is available as /dev/video0.
  7. Save the Python program below as main.py.
  8. Activate the virtual environment.
  9. Run python main.py.
  10. Place one object clearly in front of the webcam.
  11. Observe the detected class, confidence and recommendation displayed on screen.
  12. Press Q to stop the program.

Expected Output

The camera window opens and displays the detected object name, confidence value and the software sorting recommendation. When no supported object is detected, the system shows NO OBJECT DETECTED.

Result

The Raspberry Pi successfully captures live video, performs YOLOv5n ONNX inference and displays object-detection results in real time.
