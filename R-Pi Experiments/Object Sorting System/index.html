Aim

To develop an Object Sorting System using Raspberry Pi 4 Model B, USB webcam, OpenCV, YOLOv5n ONNX model and ONNX Runtime to detect objects, display their class names and confidence scores, and recommend suitable sorting bins through software.

About the Experiment

The Object Sorting System demonstrates computer vision, real-time object recognition and software-based sorting recommendations.

The Raspberry Pi 4 Model B captures live video through a USB webcam connected to the USB interface.

OpenCV preprocesses each camera frame and converts the image into a format compatible with the YOLOv5n ONNX model.

The model performs inference using ONNX Runtime with the CPU Execution Provider.

The program analyzes prediction confidence values and bounding boxes, then applies Non-Maximum Suppression to remove overlapping detections.

Each detected object is identified using its class label. The software recommends a sorting bin using a manually defined mapping.

The detected object name, confidence percentage, bounding box and bin recommendation are displayed on the live camera window.

The system does not perform physical sorting. It does not use servo motors, conveyor belts or automatic sorting gates.

Model Compatibility:

The Python program expects raw YOLOv5 detection predictions containing bounding-box coordinates, objectness confidence and 80 class scores.

Different YOLOv5 ONNX exports may have different output layouts or built-in NMS. Verify the actual model's input and output shapes.

The original image preprocessing directly resizes to 640 × 640 rather than applying letterbox padding. This may affect detection accuracy compared with the model's original training preprocessing.

Camera Capture

OpenCV captures live frames from the USB webcam using V4L2.

Image Preprocessing

The camera frame is resized to 640 × 640 pixels, converted from BGR to RGB, normalized to floating-point values and rearranged into NCHW tensor format.

ONNX Model Inference

ONNX Runtime runs the YOLOv5n model and returns candidate object detections.

Confidence Filtering

The program multiplies objectness confidence by the selected class confidence and applies the 0.45 threshold.

Non-Maximum Suppression

NMS removes overlapping detection boxes according to the configured threshold.

Software Sorting

The detected class is compared with the manual bin mapping. Supported classes receive a defined recommendation, while other classes receive BLACK BIN / UNKNOWN.

Output Display

The OpenCV window shows the object label, confidence percentage, bounding box and sorting recommendation.

Procedure

  1. Arrange the Raspberry Pi 4 Model B, USB webcam and Raspberry Pi power supply.
  2. Connect the USB webcam to the Raspberry Pi.
  3. Power the Raspberry Pi and boot Raspberry Pi OS.
  4. Open Terminal.
  5. Check the webcam using ls /dev/video*.
  6. Verify that the desired webcam is accessible as /dev/video0.
  7. Create the ObjectSorting experiment directory.
  8. Create a models subdirectory.
  9. Create and activate a Python virtual environment.
  10. Install OpenCV, NumPy and ONNX Runtime.
  11. Place the trained yolov5n.onnx file inside the models directory.
  12. Check that the model supports the expected 640 × 640 input and raw YOLOv5 detection output.
  13. Copy the complete Python code from Explore the Code.
  14. Save the code as main.py.
  15. Run python main.py in a graphical desktop session.
  16. Verify that the webcam opens successfully.
  17. Place a bottle in front of the webcam.
  18. Observe the BLUE BIN recommendation if the bottle is detected.
  19. Repeat with apple, orange and banana.
  20. Observe the class label and confidence value.
  21. Test an object that is not included in the manual bin mapping.
  22. Observe BLACK BIN / UNKNOWN when another supported class is detected.
  23. Press Q to stop the program.
  24. Confirm that the webcam and OpenCV window close.

Result

The Object Sorting System demonstrates real-time computer vision using Raspberry Pi 4 Model B, USB webcam, OpenCV and YOLOv5n ONNX inference.

The program detects supported objects, displays their labels, confidence percentages and bounding boxes, and generates software sorting recommendations using a predefined Python dictionary.

The experiment demonstrates the integration of object detection and classification-based decision-making without mechanical sorting.
