Camera Image Metadata Manager Using Raspberry Pi

Display and manage school announcements through a local web application

← R-Pi Experiments Aim Components Connections Circuit Working Procedure Code Result

Aim

To capture images with a USB webcam connected to Raspberry Pi 4B, save them using timestamp-based filenames and maintain capture information in a JSON metadata file.

About the Experiment

The Raspberry Pi uses OpenCV to show a live webcam preview. Pressing SPACE captures a JPEG photograph. Python records the image name, date, time, resolution, format and file size in camera_images/metadata.json. Each capture adds a new metadata entry.

Components Required

Raspberry Pi 4 Model B (×1)

Runs OpenCV, captures webcam frames and stores image metadata.

USB Webcam (×1)

Captures live images over a USB connection.

Working Principle

USB Webcam → OpenCV Video Capture → Live Preview → SPACE Key → Timestamped JPEG → Image Properties → metadata.json

Each saved JPEG contains the photograph, while metadata.json records the details of all successfully captured images.

Procedure

  1. Connect the USB webcam to a Raspberry Pi USB port and start Raspberry Pi OS desktop.
  2. Run sudo apt update, sudo apt install -y python3 python3-opencv and sudo apt install -y v4l-utils.
  3. Verify OpenCV with python3 -c "import cv2; print(cv2.__version__)".
  4. Run v4l2-ctl --list-devices and check the webcam path. The SOP uses /dev/video1.
  5. Save the code as camera.py and adjust CAMERA_DEVICE if necessary.
  6. Run python3 camera.py from the graphical desktop.
  7. Press SPACE to save an image and append its metadata; press Q to exit.
  8. Inspect the camera_images folder for JPEG files and metadata.json.

Expected Output

A live USB webcam preview appears. Pressing SPACE creates a file such as image_20261009_120530_123456.jpg and prints its filename, date, time, resolution, size and save location. The file camera_images/metadata.json stores the corresponding records.
