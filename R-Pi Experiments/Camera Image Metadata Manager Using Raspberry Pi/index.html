Aim

To develop a Camera Image Metadata Manager using Raspberry Pi 4 Model B and USB webcam to capture photographs, save them as JPEG images with timestamp-based filenames and automatically maintain the capture information in a JSON metadata file.

About the Experiment

The Camera Image Metadata Manager demonstrates image capture, digital file management, automatic filename generation and structured metadata storage using Raspberry Pi and Python.

A USB webcam captures live video frames through OpenCV using the V4L2 camera interface.

The program requests a camera resolution of 1280 × 720 pixels, MJPEG capture format and 30 frames per second.

The live webcam preview appears in an OpenCV display window.

When the user presses SPACE, the program captures the current camera frame and saves it as a JPEG photograph.

Each photograph receives a filename containing the capture date, time and microseconds.

This naming approach reduces the likelihood of two photographs having the same filename.

After saving an image, the program collects information such as image name, capture date, capture time, camera type, image resolution, width, height, file format and file size.

All capture records are maintained in metadata.json inside the camera_images directory.

When the program starts, it loads existing metadata records, allowing new captures to be added to the previously saved history.

Important:

The program records capture information in an external JSON file. It does not insert these records into the JPEG EXIF metadata.

The saved image resolution is measured from the actual captured frame, which may differ from the requested 1280 × 720 setting if the webcam does not support it.

Camera Initialization

OpenCV opens the USB webcam using the V4L2 interface and requests MJPEG capture at 1280 × 720 resolution and 30 FPS.

Live Preview

The program continuously reads camera frames and displays them in an OpenCV window.

Image Capture

When SPACE is pressed, the current video frame is saved as a JPEG image using cv2.imwrite().

Timestamp Filename

Python datetime generates a filename containing the current date, time and microseconds.

Metadata Collection

Python determines the actual image dimensions from the captured frame and reads the JPEG file size from storage.

JSON Storage

Each successful capture creates a dictionary containing the image information.

The dictionary is appended to the existing list of metadata records and saved as metadata.json.

Program Shutdown

Pressing Q closes the camera preview and releases the webcam resources.

Procedure

  1. Arrange the Raspberry Pi 4 Model B and USB webcam.
  2. Connect the USB webcam to the Raspberry Pi.
  3. Boot Raspberry Pi OS and open the graphical desktop.
  4. Open Terminal.
  5. Update the package list:
sudo apt update
  1. Install Python 3 and OpenCV:
sudo apt install -y python3 python3-opencv
  1. Install camera inspection tools:
sudo apt install -y v4l-utils
  1. Verify the OpenCV installation:
python3 -c "import cv2; print(cv2.__version__)"
  1. List available webcam devices:
v4l2-ctl --list-devices
  1. Identify the correct webcam path. The supplied program uses /dev/video1.
  2. Create an experiment directory.
  3. Open a text editor or Python IDE.
  4. Create the Python file camera.py.
  5. Copy the complete program from Explore the Code.
  6. Save the program as camera.py.
  7. If the webcam device is different, change CAMERA_DEVICE in the script.
  8. Run the program:
python3 camera.py
  1. Observe the live webcam preview.
  2. Place an object in front of the webcam.
  3. Press SPACE to capture a photograph.
  4. Check the terminal for the saved image filename.
  5. Verify that the photograph is saved inside camera_images.
  6. Open metadata.json and inspect the capture information.
  7. Capture several additional images using SPACE.
  8. Verify that each successful capture adds a new JSON record.
  9. Press Q to stop the program.
  10. Run the program again and confirm that previous metadata entries are retained.

Explore More: OpenCV

OpenCV provides VideoCapture for reading webcam frames, imshow for live preview and imwrite for saving images.

Explore More: V4L2

Video4Linux2 is a Linux interface used to communicate with supported video devices.

Explore More: MJPEG

MJPEG represents video as a sequence of JPEG-compressed images. The webcam must support this capture format.

Explore More: Timestamp Filenames

The datetime module generates filenames containing date, time and microseconds. This helps distinguish successive captures.

Explore More: JSON Metadata

JSON stores structured information in a human-readable format. Each image record is represented as a Python dictionary.

Explore More: File Size

The os.path.getsize() function reads the stored JPEG file size in bytes. Dividing by 1024 gives the value in KiB, displayed as KB in the program.

Result

The Camera Image Metadata Manager demonstrates capturing photographs using Raspberry Pi 4 Model B and USB webcam.

Images are saved automatically using timestamp-based filenames. Capture details such as image name, date, time, resolution, format and file size are recorded in metadata.json.

Existing metadata records are loaded when the program starts, allowing additional images to be recorded in the same file.
