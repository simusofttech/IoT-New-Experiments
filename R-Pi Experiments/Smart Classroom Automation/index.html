Smart Classroom Automation

Raspberry Pi classroom monitoring and automatic light/fan control

Aim

To build a Raspberry Pi based smart classroom system that detects classroom presence using a USB webcam, monitors temperature using DHT11, automatically controls a light and 5V fan, and displays system status on a 16×2 I2C LCD.

About the Experiment

The Smart Classroom Automation experiment uses Raspberry Pi 4B, a USB webcam with YuNet detection, DHT11, 16×2 I2C LCD, two relay channels, buzzer and push button.

No person forces the light and fan OFF. When a person is present, the light turns ON. The fan turns ON at 25.5 °C or above and OFF at 24.5 °C or below. The buzzer gives a short event beep.

Procedure

  1. Connect the DHT11, I2C LCD, two relay modules, buzzer and push button using the table above.
  2. Connect the 5V fan through the fan relay. Do not power the fan directly from a GPIO pin.
  3. Connect the USB webcam to the Raspberry Pi.
  4. Enable I2C and verify LCD address 0x27.
  5. Create the SmartClassroom Python virtual environment and install the required packages.
  6. Place the YuNet model in the project models folder.
  7. Save the program below as main.py.
  8. Run main.py and verify empty-room operation.
  9. Place a person in front of the webcam and verify automatic light control.
  10. Test the DHT11 temperature threshold and fan relay.
  11. Press the push button to acknowledge/reset the current event state.

Expected Output

When the classroom is empty, the LCD shows Classroom Empty and the temperature while light and fan are OFF. When a person is detected, the light turns ON. The fan responds to DHT11 temperature thresholds and the buzzer gives a short event beep.

Result

The Smart Classroom Automation experiment integrates presence detection, temperature sensing, LCD status, relay-based light/fan control, buzzer notification and push-button acknowledgement.
