Aim

To develop a Raspberry Pi-based Smart Classroom Automation system that uses a USB webcam with YuNet face detection to infer classroom presence, monitors temperature using DHT11, automatically controls a light and 5V DC fan through relay modules, and displays operating status on a 16×2 I²C LCD.

About the Experiment

The Smart Classroom Automation experiment combines computer vision, environmental sensing, relay-based automation and LCD monitoring using a Raspberry Pi 4 Model B.

A USB webcam captures frames from the classroom. The YuNet neural-network model identifies visible faces, which are used as an indication that a person is present.

When no face is detected, the system switches the classroom light and fan OFF.

When a face is detected, the light relay turns ON. The DHT11 sensor then provides the temperature used for fan control.

The fan switches ON when temperature reaches 25.5°C or above and switches OFF when temperature falls to 24.5°C or below.

The difference between the ON and OFF thresholds provides hysteresis, preventing rapid fan switching near a single temperature value.

The 16×2 I²C LCD shows classroom presence status and the latest measured temperature.

A buzzer produces a short notification when the system detects a new presence event.

The push button resets the presence-event notification state, allowing another notification event.

Detection Limitation:

This experiment uses face detection rather than full-body people detection. A person facing away from the camera may not be detected, resulting in an incorrect empty-room decision.

The system is suitable for supervised educational demonstrations, not safety-critical occupancy control.

Electrical Safety:

Raspberry Pi GPIO pins are 3.3V logic and must not receive 5V signals. Many PCF8574 LCD backpacks operate at 5V and may require an I²C level shifter.

Never connect a fan or light load directly to a GPIO output. Verify relay polarity, contact ratings and module compatibility.

For classroom demonstrations, use low-voltage loads. Mains-powered lighting must only be wired by qualified personnel.

Face Detection

The USB webcam supplies live images to OpenCV. The YuNet model examines each frame and returns face detections.

Light Automation

When a face is detected, GPIO27 activates the light relay. Otherwise the relay is turned OFF.

Temperature Monitoring

DHT11 provides the current temperature to Raspberry Pi through GPIO4.

Fan Hysteresis

When presence is detected, the fan switches ON at 25.5°C and switches OFF at 24.5°C.

Between these thresholds, the fan retains its previous state.

LCD Display

The 16×2 LCD shows either Classroom Empty or Person Present and the temperature value.

Buzzer and Button

The buzzer generates an 80-millisecond beep when a new presence event is detected. The push button re-arms the notification state.

Procedure

  1. Arrange the Raspberry Pi 4 Model B, USB webcam, DHT11, 16×2 I²C LCD, two relay modules, buzzer, push button, 5V fan, breadboard and jumper wires.
  2. Connect the DHT11 DATA pin to GPIO4, physical pin 7.
  3. Connect the LCD SDA to GPIO2 and SCL to GPIO3 using a compatible voltage-level arrangement.
  4. Connect the light relay control input to GPIO27, physical pin 13.
  5. Connect the fan relay control input to GPIO25, physical pin 22.
  6. Connect the buzzer control to GPIO24 using an appropriate driver if needed.
  7. Connect the push button between GPIO18 and GND.
  8. Connect the fan to a suitable external regulated 5V supply through the fan relay contacts.
  9. Connect a safe demonstration light load through the light relay.
  10. Connect the USB webcam.
  11. Verify all wiring and power connections.
  12. Boot Raspberry Pi OS.
  13. Enable I²C and verify the LCD address using i2cdetect -y 1.
  14. Verify the camera device using ls /dev/video*.
  15. Create the SmartClassroom project directory.
  16. Create and activate a Python virtual environment.
  17. Install the compatible OpenCV, GPIO, DHT11 and LCD libraries.
  18. Place the YuNet ONNX model inside the project models directory.
  19. Save the complete Python script as main.py.
  20. Run python main.py.
  21. Observe the initial empty-classroom state.
  22. Stand facing the webcam and check face detection.
  23. Verify that the light relay activates.
  24. Test the DHT11 temperature logic and fan switching.
  25. Observe the LCD status and notification beep.
  26. Press the push button to re-arm the presence notification.
  27. Use Ctrl+C to stop the program and verify relay cleanup.

Explore More: YuNet

YuNet detects faces in a camera image. Detecting a face is different from detecting every person in a room.

Explore More: Fan Hysteresis

The fan switches ON at 25.5°C and OFF at 24.5°C, reducing frequent relay switching near the threshold.

Explore More: Active-LOW Relays

In the source circuit, writing LOW activates a relay and writing HIGH deactivates it. Verify this behavior on the actual module.

Explore More: I²C LCD

The 16×2 LCD uses an I²C interface, normally through a PCF8574 expander.

Explore More: Push Button

GPIO18 uses an internal pull-up. Pressing the button pulls the input LOW and resets the notification-event flag.

Result

The Smart Classroom Automation experiment demonstrates face-detection-based presence monitoring, DHT11 temperature sensing, relay-controlled light and fan operation, LCD status display and buzzer notification.

The program turns the light ON when a face is detected, switches the fan according to temperature thresholds, and turns both outputs OFF when no face is detected.

The experiment demonstrates the use of computer vision and sensor-based automation for an educational classroom prototype.
