Aim

To build a Raspberry Pi based AI material counting system that detects and counts nine electronic and mechanical component classes using a USB camera and a trained YOLO11 model exported to ONNX.

About the Experiment

The complete workflow is performed on the Raspberry Pi: public annotated datasets are downloaded, combined into one 9-class YOLO dataset, used to train YOLO11n, validated and exported to ONNX.

The final lightweight program uses ONNX Runtime and a USB camera to detect Resistor, Capacitor, Diode, Transistor, LED, Bolt, Nut, Screw and Washer.

Each accepted detection is shown with a bounding box and material label. The program also displays individual counts and the total number of accepted detections currently visible in the camera frame.

Procedure

  1. Connect the USB camera to the Raspberry Pi and confirm that it appears as /dev/video0.
  2. Create ~/AI_Material_Counting and download the two annotated datasets described in the SOP.
  3. Run the dataset combination script to map the source datasets into the final nine classes and create training and validation splits.
  4. Check that every class is represented in both training and validation before training.
  5. Create train_env, install CPU-only PyTorch and Ultralytics, then train YOLO11n using the supplied data.yaml.
  6. Validate the model, test the material classes, and export best.pt to best.onnx.
  7. Create the lightweight material_env and install ONNX Runtime.
  8. Copy best.onnx to ~/AI_Material_Counting/best.onnx.
  9. Save the final program as material_counter.py.
  10. Run python material_counter.py.
  11. Place supported materials in front of the camera, verify their labels and counts, and press Q to stop.

The TOTAL value equals the number of accepted detections currently visible in the frame.

Result

The AI-Based Material Counting System successfully uses a trained 9-class YOLO11 model exported to ONNX to identify materials from a USB camera and display individual class counts and the total number of accepted detections.

What You Learn

  • Combining multiple annotated YOLO datasets into one class map.
  • Training YOLO11n on Raspberry Pi using CPU-only PyTorch.
  • Validating and exporting a trained model to ONNX.
  • Running ONNX Runtime inference on Raspberry Pi.
  • Using non-maximum suppression to reduce overlapping detections.
  • Counting detected material classes in each live camera frame.
