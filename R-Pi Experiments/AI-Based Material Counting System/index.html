Aim

To develop an AI-Based Material Counting System using Raspberry Pi 4 Model B, USB camera and a trained nine-class YOLO11 object-detection model exported to ONNX.

The experiment detects electronic and mechanical components in live camera frames, draws bounding boxes, and displays individual class counts and the total number of accepted detections currently visible.

About the Experiment

The AI-Based Material Counting System demonstrates the application of computer vision, artificial intelligence and real-time object detection for counting small materials.

The training workflow described in the experiment uses annotated datasets that are combined into a common nine-class YOLO dataset.

YOLO11n is trained and validated using the prepared dataset. The trained model is then exported from best.pt to best.onnx.

The final lightweight application uses ONNX Runtime with the CPU Execution Provider to perform object detection on the Raspberry Pi.

A USB camera continuously captures images of electronic and mechanical materials.

The trained model recognizes nine material classes: Resistor, Capacitor, Diode, Transistor, LED, Bolt, Nut, Screw and Washer.

Each accepted detection is labeled with its class name and confidence score. A green bounding box is drawn around the detected object.

The program counts the accepted detections belonging to each class and displays the result in an information panel on the live camera view.

The total represents the number of accepted detections in the current camera frame. It is not a cumulative count of unique objects across time.

Counting Logic

Preprocessing Resize, convert to RGB, normalize and rearrange
ONNX Inference Detect the nine trained material classes
Confidence Filtering Remove predictions below 0.10 confidence
NMS Reduce overlapping detections
Class Counting Count accepted detections by material class
Output Display boxes, labels, individual counts and TOTAL
Important:

The final Python program expects an ONNX export with nine class scores and four bounding-box coordinates per prediction.

The code assumes the trained model uses the same nine-class order shown above.

The 0.10 confidence threshold is retained from the supplied experiment. It is relatively low and may allow false-positive detections.

This experiment counts detected instances in each frame. It does not provide unique-object tracking or an accumulated count across multiple frames.

Connection Procedure

  1. Connect the USB camera to an available Raspberry Pi USB port.
  2. Power on the Raspberry Pi using its suitable power supply.
  3. Boot Raspberry Pi OS.
  4. Check the camera device using ls /dev/video*.
  5. Confirm that the selected camera is accessible as /dev/video0.
  6. Position the materials within the camera's field of view.
Connection Note:

The system uses a USB camera only. No Raspberry Pi GPIO connections are required for the final object counting program.

Dataset Preparation

Annotated source datasets are combined and their class labels are mapped to the nine material categories.

Model Training

YOLO11n is trained and validated using the combined dataset. The trained weights are exported to ONNX.

Live Image Capture

A USB camera provides continuous video frames to the Raspberry Pi.

AI Inference

The program preprocesses each frame and runs the trained best.onnx model using ONNX Runtime.

Detection Filtering

Predictions below the configured confidence threshold are removed. NMS suppresses overlapping detections.

Material Counting

Accepted detections are grouped by their class labels using Python Counter.

Live Output

The camera window displays a bounding box and label for each detected object, together with individual material counts and the total number of accepted detections.

Procedure

  1. Arrange the Raspberry Pi 4 Model B, USB camera and Raspberry Pi power supply.
  2. Connect the USB camera to the Raspberry Pi.
  3. Boot Raspberry Pi OS.
  4. Verify the USB camera at /dev/video0.
  5. Create the experiment directory ~/AI_Material_Counting.
  6. Download the annotated source datasets specified in the experiment SOP.
  7. Run the dataset-combination script supplied in the SOP.
  8. Map the original labels to the required nine-class order.
  9. Create and verify training and validation splits.
  10. Prepare the YOLO training configuration data.yaml.
  11. Create the training environment train_env.
  12. Install compatible CPU-only PyTorch and Ultralytics packages.
  13. Train the YOLO11n model using the prepared dataset.
  14. Validate the trained model and check class predictions.
  15. Export best.pt to best.onnx.
  16. Create the lightweight inference environment material_env.
  17. Install OpenCV, NumPy and ONNX Runtime.
  18. Place the exported model at ~/AI_Material_Counting/best.onnx.
  19. Copy the Python code from Explore the Code.
  20. Save the script as material_counter.py.
  21. Verify that the model output uses the expected nine-class format.
  22. Run python material_counter.py in a graphical desktop session.
  23. Place a resistor in front of the camera and check its detection label.
  24. Repeat with other supported materials.
  25. Place several materials in the frame simultaneously.
  26. Compare the individual counts with the visible detected objects.
  27. Verify that TOTAL equals the number of accepted detections.
  28. Press Q to stop monitoring.
  29. Confirm that the camera and OpenCV window close.

Result

The program identifies accepted material detections, displays bounding boxes and class labels, and calculates individual class counts and a current-frame total.
