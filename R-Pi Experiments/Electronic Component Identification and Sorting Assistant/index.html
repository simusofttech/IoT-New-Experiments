Aim

Classify resistor, capacitor, inductor and transistor samples using a USB camera, a local ViT AI model and a Flask dashboard.

About the Experiment

The USB camera supplies frames to local AI inference. Scores estimate four component types, but are not calibrated accuracy guarantees. No mechanical sorter is part of the implementation.

The script shown is the SOP's reference implementation, not necessarily identical to the installed and tested app.py. Check the trained local model files.

Working Principle

USB camera → OpenCV frame → image processor → local ViT model → score prediction → browser dashboard

Procedure

  1. Connect webcam and suitable Pi power.
  2. Verify models/config.json, models/preprocessor_config.json and models/model.safetensors are available.
  3. Activate project virtual environment and verify Python packages.
  4. Run the existing tested python app.py on the Pi.
  5. Open http://PI-IP:5000 from a device on the same local network.
  6. Place one component in camera view and click Capture & Identify.
  7. Observe the class scores and compare with known samples.
