Aim

To develop a Raspberry Pi-based AI People Counting System using a Raspberry Pi 4 Model B, USB camera, pretrained YOLO11n object detection model and 1.3-inch SH1106 I²C OLED.

The system detects people in real time, calculates the current number of visible people, displays the count on the OLED and provides a Flask live camera dashboard.

About the Experiment

The People Counting System demonstrates AI-based person detection using a Raspberry Pi and a USB camera.

The camera captures real-time video, and a pretrained YOLO11n model processes the frames to identify people. The program filters detections to YOLO class 0, representing the person category.

The total number of person bounding boxes detected in the current frame becomes the live people count.

A 1.3-inch SH1106 OLED connected through I²C displays the people count and current operating status. The display refreshes approximately every 0.5 seconds.

A Flask dashboard hosted by the Raspberry Pi displays the live camera stream with person bounding boxes and the current count.

People Counting Logic

Camera Condition Displayed Count
No person detected 0
One person detected 1
Three people detected 3
One of three people leaves the view 2, if both remaining people are detected
Important: This experiment counts people currently visible in the camera frame. It does not maintain a cumulative visitor count, identify individuals or track entries and exits.

Current People Count

The number of detected person bounding boxes in the current frame determines the displayed count.

Procedure

  1. Arrange Raspberry Pi 4 Model B, USB camera, 1.3-inch SH1106 OLED, jumper wires and Raspberry Pi power supply.
  2. Connect the USB camera to a Raspberry Pi USB port.
  3. Connect OLED VCC to 3.3V, physical pin 1.
  4. Connect OLED GND to physical pin 6.
  5. Connect OLED SDA to GPIO2, physical pin 3.
  6. Connect OLED SCL to GPIO3, physical pin 5.
  7. Verify all connections before powering the system.
  8. Boot Raspberry Pi OS.
  9. Enable I²C using Raspberry Pi configuration tools.
  10. Confirm the OLED is visible at address 0x3C using i2cdetect -y 1.
  11. Connect and verify the USB camera.
  12. Create and activate the people_env Python virtual environment.
  13. Install Ultralytics, OpenCV, Flask, Pillow, NumPy and luma.oled.
  14. Create a models folder.
  15. Place yolo11n.pt inside the models folder.
  16. Copy the Python code from Explore the Code.
  17. Save the program as people_counter.py.
  18. Run python people_counter.py.
  19. Observe the initial count on the SH1106 OLED.
  20. Identify the Raspberry Pi IP address using hostname -I.
  21. Open http://RASPBERRY_PI_IP:5000 in a browser on the same network.
  22. Observe the live camera stream.
  23. Stand in front of the camera and check whether the count becomes 1.
  24. Introduce additional people into the camera view and compare the count.
  25. Move out of view and observe the updated count.
  26. Compare OLED and dashboard readings.
  27. Stop the program using Ctrl+C.

Explore More: YOLO11n

YOLO11n is a compact object detection model. The code restricts inference results to the person category.

Explore More: SH1106 OLED

The SH1106 is a monochrome display controller. The luma.oled library is used for drawing text and graphics.

Explore More: I²C

I²C uses SDA and SCL communication lines. Raspberry Pi GPIO2 is SDA and GPIO3 is SCL.

Explore More: Live Counting

The system counts detected people in the current frame. This is not a total visitor counter.

Explore More: Flask

Flask serves the dashboard page, a JSON count endpoint and a live MJPEG video stream.

Result

The People Counting System demonstrates real-time person detection using YOLO11n, OpenCV and Raspberry Pi 4.

The system calculates the number of people currently visible in the camera frame and displays the count on a 1.3-inch SH1106 OLED.

A Flask dashboard provides live camera monitoring, person bounding boxes and the current people count.
