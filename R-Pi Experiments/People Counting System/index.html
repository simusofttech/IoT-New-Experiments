Aim

To build a Raspberry Pi based AI people counting system that detects people in real time, displays the current count on an SH1106 OLED and provides a Flask live dashboard.

About the Experiment

The Raspberry Pi 4 captures live video from a USB camera and uses a pretrained YOLO11n model to detect the person class.

The current number of visible people is displayed locally on a 1.3-inch SH1106 I²C OLED.

A Flask web dashboard provides the live camera with person bounding boxes and the current people count.

Components Required

Raspberry Pi 4 Model B (×1)

Runs the camera, YOLO11n people detection, OLED control and Flask dashboard.

USB Camera / Webcam (×1)

Captures the live scene for people detection.

1.3" SH1106 I²C OLED (×1)

Displays the current people count locally.

Raspberry Pi Power Supply (×1)

Provides power to the Raspberry Pi.

Jumper Wires (×4)

Connect the OLED to power and I²C pins.

Procedure

  1. Connect the USB camera to any Raspberry Pi USB port.
  2. Connect the SH1106 OLED VCC to 3.3V and GND to Raspberry Pi GND.
  3. Connect OLED SDA to GPIO2 / physical pin 3.
  4. Connect OLED SCL to GPIO3 / physical pin 5.
  5. Enable I²C on the Raspberry Pi and confirm the OLED address is 0x3C.
  6. Create and activate the people_env virtual environment.
  7. Install Ultralytics, OpenCV, Flask, NumPy and luma.oled.
  8. Prepare models/yolo11n.pt.
  9. Save the main program as people_counter.py and run it.
  10. Open http://<RASPBERRY_PI_IP>:5000 from a device on the same network.

1. Load the libraries

The program imports OpenCV, YOLO, Flask, OLED libraries, Pillow, threading and time.

Explore more: system operation

The system uses YOLO class 0 for people, a 0.40 confidence threshold, 320-pixel YOLO input and updates the OLED approximately every 0.5 seconds.

Check your understanding
  • Which GPIO is OLED SDA? GPIO2 / Physical Pin 3
  • Which GPIO is OLED SCL? GPIO3 / Physical Pin 5
  • What is the OLED I²C address? 0x3C
  • Which YOLO class is used for people? Class 0

Try it: Run python people_counter.py, stand in front of the USB camera and compare the live web count with the count shown on the OLED.

Expected Output

The OLED displays the current number of visible people and ACTIVE status.

The web dashboard displays the current people count.

The live camera shows YOLO person bounding boxes.

The count updates as people enter or leave the camera view.

Result

The People Counting System successfully detects visible people using YOLO11n on Raspberry Pi 4, displays the live count on an SH1106 OLED and provides a Flask web dashboard.

What You Learn

  • Using YOLO11n for person-only detection.
  • Interfacing an SH1106 OLED through Raspberry Pi I²C.
  • Displaying real-time sensor/AI information locally and remotely.
  • Streaming annotated camera frames through Flask.
  • Using Python threads for real-time AI processing.
