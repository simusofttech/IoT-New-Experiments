Aim

To capture photos automatically at selected intervals using Raspberry Pi 4 and a USB webcam, then convert them into a time-lapse MP4 video.

About the Experiment

The Raspberry Pi captures a sequence of 640×480 images from a USB webcam using fswebcam every five seconds for approximately one minute. The saved JPEG files are then combined into an H.264 MP4 video using FFmpeg.

Procedure

  1. Connect a supported USB webcam to a Raspberry Pi USB port. There are no GPIO connections.
  2. Boot Raspberry Pi OS and open a terminal. Confirm the correct camera node using lsusb and v4l2-ctl --list-devices.
  3. Install dependencies with sudo apt update and sudo apt install -y fswebcam ffmpeg v4l-utils.
  4. Test capture using fswebcam -d /dev/video0 -r 640x480 --no-banner ~/test_photo.jpg.
  5. Create ~/timelapse_camera/photos, then save the complete Python code as ~/timelapse_camera/timelapse.py.
  6. Run python3 ~/timelapse_camera/timelapse.py. Expect approximately 12 JPEG files.
  7. Convert photos to MP4 using the FFmpeg command shown below.
  8. Verify the video using ffprobe; view it using VLC or another supported player.

Convert images to MP4

ffmpeg -framerate 4 -pattern_type glob \
-i '/home/pi/timelapse_camera/photos/*.jpg' \
-c:v libx264 -pix_fmt yuv420p \
'/home/pi/timelapse_camera/timelapse_video.mp4'

Expected Output

The default one-minute capture typically yields around 12 JPEG images at 640×480. Encoding at four frames per second produces an approximately three-second MP4 video.

Result

The SOP reports successful webcam detection, 12 photos captured over approximately one minute, and a 3-second MP4 video generated using FFmpeg.
