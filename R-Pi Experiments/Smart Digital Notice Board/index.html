Aim

To develop a Smart Digital Notice Board using Raspberry Pi 4 Model B, Flask and SQLite to display school announcements on a digital screen and allow staff to add, edit and delete notices through a browser-based administration interface.

About the Experiment

The Smart Digital Notice Board demonstrates the integration of web development, database management and digital information display using Raspberry Pi.

The Raspberry Pi runs a Flask web server, which hosts a public notice display and an administrative notice-management page.

The public display shows a school heading, live date and time, and announcement cards.

When multiple active notices are available, the display automatically rotates the notices every eight seconds.

The public page refreshes every 30 seconds to retrieve newly added or updated notices.

Staff can open the administration interface at /admin to create, edit and delete notice records.

The application stores all notice records locally in a SQLite database named notices.db.

Each notice includes a category, title, message and optional expiry date.

Expired notices are hidden from the public display but remain available on the administration page.

Important:

The original Flask administration page does not include user authentication.

Therefore, anyone who can access the administration URL may be able to modify or delete notices.

Use the application only on a controlled, trusted local network. Do not expose port 5000 directly to the public internet.

Components Required

Raspberry Pi 4 Model B (×1)

Hosts the Flask web application, public notice display and SQLite database.

Additional Setup Requirements from SOP:

For the standalone HDMI-based demonstration, the SOP also specifies a compatible Raspberry Pi power supply, Raspberry Pi OS storage, an HDMI monitor or TV, a compatible HDMI cable, and keyboard/mouse for setup.

Wi-Fi or Ethernet may be used to access the administration page from another device on the same local network.

These are setup peripherals, not GPIO-connected sensors.

Software Requirements:
  • Raspberry Pi OS
  • Python 3
  • Flask
  • SQLite through Python sqlite3
  • HTML, CSS and JavaScript
  • Chromium or another supported browser

Connection Procedure

  1. Connect the HDMI display to the Raspberry Pi HDMI0 port.
  2. Connect the Raspberry Pi power supply.
  3. Boot Raspberry Pi OS.
  4. Connect the Raspberry Pi to a trusted local network if remote administration is required.
  5. Start the Flask application.
  6. Open the public notice board in a browser.
Connection Note:

The notice board is a software-based application. It does not use GPIO-connected sensors, relays or actuators.

Flask Web Server

The Raspberry Pi runs a Flask application on port 5000.

SQLite Database

Notice records are stored locally in notices.db. Saved data remains available after the application is restarted.

Public Notice Display

Flask retrieves active announcements and renders them in the display page.

Notice Rotation

JavaScript changes the displayed notice every eight seconds when multiple announcements are available.

Automatic Refresh

The public page reloads every 30 seconds to retrieve updated notices.

Administration Page

Staff use the browser administration page to add, edit and delete notices.

Expiry Filtering

Notices whose expiry dates have passed are hidden from the public display. They remain stored in the database.

Procedure

  1. Arrange the Raspberry Pi 4 Model B and the display peripherals specified in the SOP.
  2. Connect the HDMI monitor or TV to HDMI0.
  3. Power on the Raspberry Pi.
  4. Boot Raspberry Pi OS.
  5. Open Terminal.
  6. Create the experiment directory:
mkdir -p ~/Smart_Digital_Notice_Board
cd ~/Smart_Digital_Notice_Board
  1. Check the installed Python version.
  2. Create a Python virtual environment:
python3 --version
python3 -m venv venv
source venv/bin/activate
  1. Install Flask into the virtual environment:
python -m pip install --upgrade pip
python -m pip install Flask
python -m flask --version
  1. Create the file main.py inside the experiment folder.
  2. Copy the complete Python code from Explore the Code.
  3. Paste the Python code into main.py.
  4. Save the file.
  5. Run the application:
cd ~/Smart_Digital_Notice_Board
source venv/bin/activate
python main.py
  1. Open http://127.0.0.1:5000/ to view the notice display.
  2. Open http://127.0.0.1:5000/admin to manage notices.
  3. Check that the first run creates notices.db.
  4. Verify that the three sample announcements appear.
  5. Add a new announcement using the administration page.
  6. Check that the announcement appears on the public display after refresh.
  7. Edit the announcement and verify the updated content.
  8. Set an expiry date and verify the filtering behavior.
  9. Delete a test announcement using the administration page.
  10. Verify that notices rotate every eight seconds.
  11. Verify that the public page refreshes every 30 seconds.
  12. Stop the Flask application using Ctrl+C.
  13. Restart the application and verify that saved notices remain in the database.

Access from Another Device

To find the Raspberry Pi local IP address: 

hostname -I

Use the Raspberry Pi's current IP address in the browser on a device connected to the same trusted network.

Database Backup

cd ~/Smart_Digital_Notice_Board

cp notices.db notices_backup_$(date +%Y%m%d_%H%M%S).db

Back up the database regularly, preferably after stopping the application.

Result

The Smart Digital Notice Board demonstrates a browser-based school announcement system using Raspberry Pi 4, Flask and SQLite.

The application displays active announcements with a live clock, automatically rotates notices and supports adding, editing and deleting notices through the administration page.

SQLite preserves the notice records between application restarts.
