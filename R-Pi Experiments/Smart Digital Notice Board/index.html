Smart Digital Notice Board

Display and manage school announcements through a local web application

← R-Pi Experiments Aim Components Connections Circuit Working Procedure Code Result

Aim

To build a browser-based school notice board using Raspberry Pi 4B, Flask, and SQLite for displaying and managing announcements.

About the Experiment

A Flask web application displays school announcements with a live date and time. Teachers can add, edit, and delete notices through an administration page. Notices are stored locally in notices.db.

Notices rotate every 8 seconds, the display refreshes every 30 seconds, and expired notices are hidden from the public view.

Components Required

Raspberry Pi 4 Model B (×1)

Hosts the Flask application, notice display, and SQLite database.

Working Principle

Raspberry Pi → Flask Web Server → SQLite Database
↓
Public Display / Admin Page → Add, Edit, Delete Notices

The public display reads active notices, rotates cards every 8 seconds and refreshes every 30 seconds. The admin page manages notices stored in SQLite.

Procedure

  1. Set up Raspberry Pi OS and connect the Pi to a display using HDMI0.
  2. Open a terminal and create a folder: mkdir -p ~/Smart_Digital_Notice_Board.
  3. Enter the folder: cd ~/Smart_Digital_Notice_Board.
  4. Create a virtual environment: python3 -m venv venv.
  5. Activate it: source venv/bin/activate.
  6. Install Flask: python -m pip install Flask.
  7. Save the complete code shown below as main.py.
  8. Start the app: python main.py.
  9. Open http://127.0.0.1:5000/ for notices and http://127.0.0.1:5000/admin to manage them.
  10. Verify notice rotation, expiry dates and database persistence; stop the server with Ctrl+C.

Expected Output

Expected Output

The monitor displays the school heading, live date/time and rotating notice cards. Staff can add, edit or delete notices at /admin. Notices remain saved in notices.db after the browser closes or the Pi restarts.

Result

The Raspberry Pi hosts a digital notice board with a public display, browser-based notice management, and persistent SQLite storage.

What You Learn

  • Running a Flask web server on Raspberry Pi.
  • Storing and retrieving records with SQLite.
  • Building an admin interface to manage notices.
  • Using HTML, CSS and JavaScript for dynamic browser displays.
  • Managing local network access and application data.
