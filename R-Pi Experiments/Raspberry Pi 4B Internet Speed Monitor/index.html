Aim

To monitor internet speed and network quality on a Raspberry Pi 4B, save periodic measurements to CSV and display results in a browser dashboard.

About the Experiment

The Raspberry Pi 4B measures download, upload, idle ping, loaded latency, jitter and packet loss using the installed Ookla Speedtest CLI. A systemd timer runs a Python monitor every 10 minutes and writes its measurements to a CSV file. Flask serves a browser dashboard on port 5001.

↓
dashboard displays graphs and results at port 5001.

Procedure

  1. Start Raspberry Pi OS and connect the board to the internet.
  2. Verify network access with hostname -I and ping -c 3 1.1.1.1.
  3. Check that the Ookla Speedtest CLI and Flask are installed.
  4. Confirm the existing speed_monitor.py, app.py and templates/dashboard.html are present at the documented paths.
  5. Run speed_monitor.py manually to verify it appends a result to speed_history.csv.
  6. Configure the SOP's oneshot systemd service and the timer with OnCalendar=*:0/10.
  7. Reload systemd, enable the timer, and verify it is active.
  8. Configure and enable internet-speed-dashboard.service for app.py on port 5001.
  9. Open http://:5001 from a browser on the same trusted LAN and inspect the latest results.
  10. Download the CSV from the dashboard; check journalctl logs if a test fails.

Expected Output

The dashboard shows current download/upload speeds, ping, averages, charts, recent results and a CSV download. The browser page refreshes every 60 seconds; tests are scheduled every 10 minutes.

Result
