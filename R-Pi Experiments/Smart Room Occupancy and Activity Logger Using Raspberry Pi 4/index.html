Aim

Detect room motion using a USB webcam, log session start/end and duration in CSV, and show status in a local dashboard without saving video.

About the Experiment

OpenCV detects changed pixels between camera frames. New motion logs ACTIVITY_START; after 60 seconds of inactivity it logs ACTIVITY_END. A Flask browser dashboard refreshes data every 3 seconds.

Code source status: SOP-based reconstructed reference app.py. The source SOP uses multi-column formatting; verify reconstructed Python against the deployed tested script before replacing it.

Log activity start
↓
After 60s stillness log activity end
↓
Flask status + recent CSV events

Procedure

  1. Connect the USB webcam and Raspberry Pi USB-C supply.
  2. In terminal open ~/smart-room-logger.
  3. Activate venv using source venv/bin/activate.
  4. Verify imports of cv2 and Flask.
  5. Run python app.py.
  6. Open http://PI-IP:5000 from the trusted local network.
  7. Move within camera view to trigger activity start.
  8. Stop movement and wait approximately 65–70 seconds for activity end.
  9. Stop using Ctrl+C.
