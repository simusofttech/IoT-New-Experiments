Aim

To detect room movement using a USB webcam, record activity start and end times, calculate approximate session durations, and display recent events on a local web dashboard without saving continuous video.

About the Experiment

Raspberry Pi 4 processes USB webcam frames using OpenCV. Consecutive frames are resized, converted to grayscale and blurred before their pixel differences are compared.

Motion starts an activity session and creates an ACTIVITY_START record in activity_log.csv. Further motion refreshes the inactivity timer. After 60 seconds without detected motion, an ACTIVITY_END record stores the end time and session duration.

Flask serves a local dashboard that refreshes every three seconds. Frames are processed in memory and discarded.

Detection: This system detects movement rather than counting people. A stationary person may not produce motion, and lighting changes can trigger detection. Session duration includes the inactivity waiting period.

Working Principle

USB Webcam Captures Frames
↓
Resize to 320 × 240, Grayscale and Blur
↓
Compare Frames and Count Changed Pixels
↓
Motion Starts or Continues an Activity Session
↓
60 Seconds Without Motion Ends the Session
↓
Save CSV Events and Update the Dashboard

The binary difference threshold is 25 and the motion threshold is 1500 changed pixels. The program uses time.monotonic() for the inactivity timer and local timestamps for CSV records.

Procedure

  1. Connect the USB webcam and compatible Raspberry Pi power supply.
  2. Open the terminal and run mkdir -p ~/smart-room-logger, then cd ~/smart-room-logger.
  3. Create the environment if needed: python3 -m venv --system-site-packages venv.
  4. Activate it using source venv/bin/activate.
  5. Install Flask using python -m pip install Flask.
  6. Verify OpenCV using python -c "import cv2; print(cv2.__version__)". Resolve any import error before continuing.
  7. Check the webcam using ls -l /dev/video0.
  8. Save the complete program below as app.py in the experiment directory.
  9. Run python app.py. The CSV file is created automatically.
  10. Find the Pi address using hostname -I in another terminal.
  11. Open http://PI-IP:5000 in a browser, replacing PI-IP with the actual address.
  12. Move in front of the webcam and observe the activity start event.
  13. Stop movement and wait approximately 65–70 seconds for the activity end event.
  14. Press Ctrl+C in the application terminal to stop.

Result

The system demonstrates webcam motion detection, timestamped activity-session logging in CSV and a local Flask dashboard. It estimates session durations without continuously recording video.

What You Learn

  • Capturing and preprocessing camera frames with OpenCV.
  • Detecting movement through frame differences and pixel thresholds.
  • Using monotonic timing for inactivity detection.
  • Writing timestamped start and end events to CSV.
  • Running camera processing in a background thread.
  • Serving Flask routes and JSON APIs.
  • Updating a browser dashboard with JavaScript.
  • Distinguishing movement detection from confirmed room occupancy.
