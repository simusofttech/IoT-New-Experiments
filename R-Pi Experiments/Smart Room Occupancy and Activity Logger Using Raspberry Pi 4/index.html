Aim

To develop a Raspberry Pi room-activity logger that detects motion through a USB webcam, logs activity start and end times, estimates session duration, and presents recent results on a local Flask dashboard without saving continuous video.

About the Experiment

The Raspberry Pi 4 uses OpenCV to compare webcam frames. When movement passes the configured threshold, it starts a logged activity session. After 60 seconds without movement, the session ends and the duration is saved in a CSV file. A Flask web dashboard shows motion status, active sessions, recent events and the last motion time.

The camera processes frames locally in memory. It does not store photos or continuous video. This is movement/activity detection, not proof that a room is occupied by a person.

Components Required

Raspberry Pi 4 Model B (×1)

Runs motion detection, logging and the Flask dashboard.

USB Webcam (×1)

Captures room frames for local activity detection.

The SOP also requires a compatible Raspberry Pi power supply, microSD card containing Raspberry Pi OS, and a working Wi-Fi or Ethernet connection for dashboard access. These are setup requirements rather than component cards.

Working Principle

USB webcam captures frames
↓
Resize, grayscale and blur
↓
Compare consecutive frames
↓
Detect motion above 1500 changed pixels
↓
Log ACTIVITY_START
↓
Refresh timer while motion continues
↓
60 seconds without motion
↓
Log ACTIVITY_END and duration
↓
Dashboard reads status and CSV history

The dashboard refreshes every 3 seconds. Motion logs are recorded in activity_log.csv.

Procedure

  1. Connect the USB webcam to the Raspberry Pi 4 and start Raspberry Pi OS.
  2. Verify the camera is available at /dev/video0 or identify the correct video device.
  3. Install OpenCV if needed and create the project folder using mkdir -p ~/smart-room-logger.
  4. Run cd ~/smart-room-logger and python3 -m venv --system-site-packages venv.
  5. Activate it with source venv/bin/activate and install Flask using python -m pip install Flask.
  6. Verify OpenCV with python -c "import cv2; print(cv2.__version__)".
  7. Save the complete Explore the Code program as app.py in the project folder.
  8. Run python -m py_compile app.py, then python app.py.
  9. Find the Raspberry Pi IP using hostname -I; open http://<PI-IP>:5000 on the Pi or another device on the same network.
  10. Move your hand in view of the webcam and check for “Motion detected” and an ACTIVITY_START event.
  11. Stop moving and wait at least 65–70 seconds to observe ACTIVITY_END and the recorded duration.
  12. Press Ctrl+C to stop the application.

Expected Output

Starting the app displays “Camera started. Monitoring room activity.” and “Video recording is disabled.” The Flask dashboard is available locally on port 5000 and shows camera status, detected motion, active session, last motion time and recent recorded events.

After moving in front of the camera, ACTIVITY_START is saved; following 60 seconds of inactivity, ACTIVITY_END and duration are appended to the CSV.

Result

The activity logger detects changes in room imagery using a USB webcam, saves timestamped motion-activity events and estimated session durations to CSV, and displays live information through a local Flask dashboard without recording video.

What You Learn

  • Using a USB webcam with Raspberry Pi and OpenCV.
  • Converting frames to grayscale and comparing changes.
  • Threshold-based motion detection and debouncing of inactivity.
  • Logging start/end timestamps and durations in CSV.
  • Creating an interactive Flask dashboard and JSON API.
  • Running a camera worker thread alongside a web server.
  • Monitoring without saving continuous video footage.
