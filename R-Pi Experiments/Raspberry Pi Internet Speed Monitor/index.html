Raspberry Pi Internet Speed Monitor

← R-Pi ExperimentsAimAboutComponentsConnectionsCircuitWorkingProcedureCodeOutputResultLearn

Aim

Monitor internet download, upload, idle ping, loaded latency, jitter and packet loss on a Raspberry Pi 4, save timestamped test results to CSV every ten minutes and display historical charts in a Flask dashboard.

About the Experiment

An Ookla Speedtest CLI command performs network measurements. A Python monitoring script writes results to logs/speed_history.csv. A systemd oneshot service and timer schedule tests at ten-minute calendar boundaries. A separate Flask application reads the recorded history and serves a browser dashboard on port 5001 with latest values, averages, Chart.js plots, recent records and CSV download. Network measurements vary with congestion and server choice.

Procedure

  1. Connect Raspberry Pi to its appropriate power supply and configure internet access.
  2. Verify network using hostname -I and ping -c 3 1.1.1.1.
  3. Check /home/pi/speedtest-install/speedtest --version; accept CLI terms where required.
  4. Verify /usr/bin/python3 and Flask installation.
  5. Place the deployed speed_monitor.py, app.py and templates/dashboard.html at the SOP paths; the SOP does not provide their full source.
  6. Check CSV header and data in logs/speed_history.csv.
  7. Create and enable internet-speed-monitor.service and internet-speed-monitor.timer (OnCalendar=*:0/10).
  8. Enable internet-speed-dashboard.service, configured for /usr/bin/python3 app.py.
  9. Verify both services with systemctl is-active, and open http://PI-IP:5001.
  10. Review latest metrics, historical charts and CSV download.

Expected Output

Every 10 minutes, a status row is recorded in the CSV (success or error). On the Flask dashboard, the latest result, averages of successful measurements, historical charts and recent rows are shown. The CSV can be downloaded. Dashboard port: 5001. The original deployment also refreshes dashboard contents every 60 seconds.

Result

With a configured Ookla CLI, functioning monitoring service, scheduled timer and deployed Flask application, the Pi records internet speed tests and serves a historical browser dashboard. The page's illustrative monitor code is not verified as identical to the deployed project.
