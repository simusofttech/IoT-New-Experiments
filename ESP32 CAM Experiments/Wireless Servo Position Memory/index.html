Aim

To design a Wi-Fi controlled two-servo positioning system using ESP32 DevKitC.

The system allows users to move two servo motors to selected angles, save their positions in non-volatile memory, and recall those positions later.

About the Experiment

Servo motors are widely used in robotics and automation for angular position control.

This experiment uses an ESP32 DevKitC to control two servo motors independently.

Servo 1 is connected to GPIO18, and Servo 2 is connected to GPIO19.

The ESP32 hosts a Wi-Fi dashboard that allows users to select servo angles using sliders and quick-angle controls.

When MOVE SERVOS is selected, both motors rotate to their requested angles.

The ESP32 Preferences library stores the selected positions in non-volatile storage.

This means the saved angles remain available after an ESP32 restart.

The SAVE POSITION control stores both current angles.

The RECALL POSITION control reloads saved values and moves both motors back to their stored angles.

Two physical push buttons are also included.

The Save button connects to GPIO25 and the Recall button to GPIO26.

The SSD1306 OLED displays servo angle and memory status information.

Position Memory:

The experiment initializes saved servo positions to 90 degrees when no values are stored.

The Preferences library retains saved data across normal resets.

Servo Supply Note:

Two servo motors can draw substantial current, particularly during startup or under mechanical load.

Use a regulated 5V supply with sufficient current capacity for both servos.

Connect the servo supply ground and ESP32 ground together. Do not power both servos from an ESP32 GPIO pin.

The uploaded connection table specifies 5V servo power, but does not specify a separate supply component or its current rating.

Servo Position Control

Each servo is controlled using a PWM-style position-control signal generated by the ESP32Servo library.

Servo 1 uses GPIO18, while Servo 2 uses GPIO19.

The requested angles are limited to the range 0 to 180 degrees.

Wi-Fi Dashboard

ESP32 runs a local web server on port 80.

The browser provides two angle sliders, quick-angle buttons, and MOVE, SAVE and RECALL controls.

Moving the sliders changes the requested angles on the page.

Pressing MOVE sends the selected angles to the ESP32.

Non-Volatile Storage

Preferences provides access to the ESP32 non-volatile storage system.

Two integer values are stored using the keys servo1 and servo2.

The stored values remain available after a normal restart.

Save Operation

When SAVE is selected, the current servo angles are copied into the saved-angle variables.

Preferences then writes both values into non-volatile memory.

Recall Operation

When RECALL is selected, the saved values are read from Preferences.

The servo motors return to the saved positions.

Physical Buttons

The save and recall buttons use INPUT_PULLUP.

Pressing either button connects the input to ground, producing a LOW reading.

The reconstructed sketch includes simple button debouncing and detects a press once rather than repeatedly saving during a long hold.

OLED Status Display

The OLED shows the two current angles, saved positions and latest action.

Procedure

  1. Arrange the ESP32 DevKitC, two servo motors, two push buttons, SSD1306 OLED, breadboard and jumper wires.
  2. Connect Servo 1 signal to GPIO18.
  3. Connect Servo 2 signal to GPIO19.
  4. Connect both servo power terminals to a suitable 5V supply.
  5. Connect servo grounds and ESP32 ground together.
  6. Connect Save Button between GPIO25 and GND.
  7. Connect Recall Button between GPIO26 and GND.
  8. Connect OLED SDA to GPIO21 and SCL to GPIO22.
  9. Connect OLED VCC to 3.3V and GND to GND.
  10. Open Arduino IDE.
  11. Install the ESP32 board package and ESP32Servo library.
  12. Install the required Adafruit SSD1306 and Adafruit GFX libraries.
  13. Create a new sketch named Wireless_Servo_Position_Memory.ino.
  14. Copy the complete reconstructed sketch from Explore the Code.
  15. Replace the Wi-Fi SSID and password placeholders with the credentials of your local network.
  16. Select the appropriate ESP32 DevKit board and serial port.
  17. Verify and upload the sketch.
  18. Open Serial Monitor at 115200 baud.
  19. Note the ESP32 IP address after Wi-Fi connects.
  20. Open the displayed IP address in a browser connected to the same network.
  21. Select Servo 1 and Servo 2 angles using the sliders.
  22. Press MOVE SERVOS and observe the motors.
  23. Press SAVE POSITION to store both angles.
  24. Move the servos to different positions.
  25. Press RECALL POSITION to return to the saved positions.
  26. Test the physical Save and Recall buttons.
  27. Restart the ESP32 and verify the stored positions are restored.

Result

The Wireless Servo Position Memory experiment demonstrates independent control of two servo motors using an ESP32-based Wi-Fi dashboard.

Users can select angles, move both motors, store their positions in non-volatile memory, and recall the saved positions later.

The system provides both browser-based and physical save/recall controls.

The OLED displays the current angles and memory status.

This experiment demonstrates servo control, web-server communication, persistent storage and embedded input handling.
