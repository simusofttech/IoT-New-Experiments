Aim

To design a Wi-Fi-controlled two-servo positioning system using ESP32 DevKitC.

The system allows users to move two servo motors to selected angles, save their positions in non-volatile memory, and recall those positions later.

About the Experiment

Servo motors are used in robotics and automation for angular position control.

The ESP32 DevKitC controls two servo motors independently. Servo 1 is connected to GPIO18 and Servo 2 to GPIO19.

The ESP32 creates a Wi-Fi web dashboard with two servo angle sliders and quick-angle controls.

The MOVE SERVOS button changes the motor positions according to the selected angles.

The SAVE POSITION button saves both current angles using the Preferences library.

The RECALL POSITION button restores the saved angles from non-volatile memory.

Physical buttons connected to GPIO25 and GPIO26 provide the same save and recall operations.

The SSD1306 OLED displays servo positions and memory status.

Position Memory: When no saved values exist, both servo angles default to 90°. Saved angles persist across normal ESP32 restarts.

Servo Control

The ESP32Servo library generates the control signals needed to move both servo motors independently.

Wi-Fi Control

The ESP32 hosts a local web server that provides sliders and buttons for changing servo positions.

Position Memory

Preferences stores the two servo angles under the keys servo1 and servo2.

The values remain available across normal restarts.

Physical Controls

The Save and Recall buttons use INPUT_PULLUP and become LOW when pressed.

OLED Display

The OLED displays the current servo angles, stored angles and recent action.

Procedure

  1. Connect Servo 1 signal to GPIO18.
  2. Connect Servo 2 signal to GPIO19.
  3. Connect servo V+ terminals to a suitable 5V supply.
  4. Connect servo grounds and ESP32 GND together.
  5. Connect Save Button between GPIO25 and GND.
  6. Connect Recall Button between GPIO26 and GND.
  7. Connect OLED SDA to GPIO21 and SCL to GPIO22.
  8. Connect OLED VCC to 3.3V and GND to GND.
  9. Install the ESP32 board package in Arduino IDE.
  10. Install the ESP32Servo and Adafruit display libraries.
  11. Create Wireless_Servo_Position_Memory.ino.
  12. Enter your local Wi-Fi SSID and password in the sketch.
  13. Verify and upload the sketch.
  14. Open Serial Monitor at 115200 baud.
  15. Note the ESP32 IP address.
  16. Open the IP address in a browser on the same network.
  17. Select both servo angles using the sliders.
  18. Press MOVE SERVOS.
  19. Press SAVE POSITION.
  20. Move both servos to different angles.
  21. Press RECALL POSITION.
  22. Test the physical Save and Recall buttons.
  23. Restart ESP32 to verify stored-angle restoration.

Result

The Wireless Servo Position Memory experiment demonstrates control of two servo motors using an ESP32 Wi-Fi dashboard and physical buttons.

The current servo positions can be saved in non-volatile memory and recalled later.

The OLED displays angle and memory status information.
