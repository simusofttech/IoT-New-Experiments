Aim

To create a Wi-Fi controlled two-servo system that can move to selected angles, save the current positions in ESP32 non-volatile memory, and recall the saved positions later.

About the Experiment

Two servo motors are controlled from an ESP32 web dashboard and by physical controls. The current angles can be saved using the Preferences library, which stores the values in non-volatile memory. Saved positions can later be recalled from the browser or with the physical recall button. The dashboard provides sliders, quick-angle buttons, move, save and recall controls.

Procedure

  1. Connect Servo 1 signal to GPIO 18 and Servo 2 signal to GPIO 19.
  2. Power both servos from 5V and connect their grounds to ESP32 GND.
  3. Connect the save push button between GPIO 25 and GND.
  4. Connect the recall push button between GPIO 26 and GND.
  5. Connect the SSD1306 OLED as shown in the circuit: SDA to GPIO 21 and SCL to GPIO 22.
  6. Upload the sketch and open Serial Monitor at 115200 baud.
  7. Open the ESP32 IP address in a browser.
  8. Choose angles for both servos and press MOVE SERVOS.
  9. Press SAVE POSITION to store the current servo angles.
  10. Change the angles, then press RECALL POSITION to restore the saved values.
  11. Test the physical save and recall buttons.

Explore the Code

Key sketch sections used in this experiment:

Wireless_Servo_Position_Memory.ino
#include <WiFi.h>
#include <WebServer.h>
#include <ESP32Servo.h>
#include <Preferences.h>

#define SERVO1_PIN 18
#define SERVO2_PIN 19
#define SAVE_BUTTON 25
#define RECALL_BUTTON 26

WebServer server(80);
Servo servo1;
Servo servo2;
Preferences preferences;

int servo1Angle = 90;
int servo2Angle = 90;
int savedServo1 = 90;
int savedServo2 = 90;

void handleMove() {
  if (server.hasArg("s1")) servo1Angle = server.arg("s1").toInt();
  if (server.hasArg("s2")) servo2Angle = server.arg("s2").toInt();

  servo1Angle = constrain(servo1Angle, 0, 180);
  servo2Angle = constrain(servo2Angle, 0, 180);

  servo1.write(servo1Angle);
  servo2.write(servo2Angle);

  server.send(200, "text/plain", "OK");
}

void handleSave() {
  savedServo1 = servo1Angle;
  savedServo2 = servo2Angle;

  preferences.putInt("servo1", savedServo1);
  preferences.putInt("servo2", savedServo2);

  server.send(200, "text/plain", "SAVED");
}

void handleRecall() {
  savedServo1 = preferences.getInt("servo1", 90);
  savedServo2 = preferences.getInt("servo2", 90);

  servo1Angle = savedServo1;
  servo2Angle = savedServo2;

  servo1.write(servo1Angle);
  servo2.write(servo2Angle);
}

void loop() {
  server.handleClient();

  if (digitalRead(SAVE_BUTTON) == LOW) {
    savedServo1 = servo1Angle;
    savedServo2 = servo2Angle;
    preferences.putInt("servo1", savedServo1);
    preferences.putInt("servo2", savedServo2);
  }

  if (digitalRead(RECALL_BUTTON) == LOW) {
    servo1.write(savedServo1);
    servo2.write(savedServo2);
  }
}

Expected Output

The web dashboard starts with the saved servo positions, using 90° as the default when no saved data exists.

Moving the sliders and pressing MOVE SERVOS changes the two servo positions.

SAVE POSITION stores both current angles in ESP32 Preferences memory.

RECALL POSITION restores the saved angles and moves both servos to those positions.

The physical GPIO 25 and GPIO 26 buttons provide save and recall functionality without using the browser.

Result

The wireless servo position memory system successfully controls two servos, stores their positions in ESP32 non-volatile memory, and recalls them through both browser controls and physical buttons.
