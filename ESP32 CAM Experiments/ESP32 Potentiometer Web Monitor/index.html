Aim

To create an ESP32-based potentiometer monitoring system that reads the knob position through an analog input, displays the reading on an SSD1306 OLED, and sends live data to a Wi-Fi dashboard.

About the Experiment

The Potentiometer Web Monitor demonstrates analog input measurement using an ESP32 DevKitC microcontroller.

A potentiometer is a variable resistor. Turning its knob changes the voltage at its middle terminal.

The middle terminal is connected to GPIO34, which is used as an analog input.

The ESP32 reads this voltage using its Analog-to-Digital Converter (ADC).

With a configured 12-bit resolution, the ADC produces readings from 0 to 4095.

The program converts the raw reading into a percentage between 0% and 100%.

The SSD1306 OLED displays the percentage, ADC reading, and a graphical progress bar.

The ESP32 connects to Wi-Fi and hosts a web dashboard that displays the potentiometer position in a browser.

The dashboard also shows the raw ADC reading, percentage, and a continuously updating graph.

Measurement Note:

The percentage represents the relative potentiometer position derived from the ADC.

Actual ADC readings may show noise and may not reach exactly 0 or 4095.

The potentiometer must be supplied with 3.3V and GND so its signal remains within the ESP32 input range.

Connection Note:

GPIO34 is an input-only GPIO suitable for reading analog signals.

Connect the potentiometer's two outer terminals to 3.3V and GND. The middle terminal connects to GPIO34.

Swapping the two outer terminals reverses the direction in which the reading changes when the knob is rotated.

Analog Input

Turning the potentiometer changes the voltage on its middle terminal.

ADC Conversion

The ESP32 converts the analog input voltage into a digital reading using analogRead().

Percentage Calculation

The ADC reading is mapped from 0–4095 into a percentage from 0–100%. 

Percentage = map(ADC, 0, 4095, 0, 100)

OLED Monitoring

The OLED shows the percentage, raw ADC value, and corresponding progress bar.

Web Dashboard

The ESP32 hosts an HTTP web server. A browser displays the current potentiometer reading.

Live Graph

JavaScript requests updated sensor data from the /data endpoint every 500 milliseconds.

The dashboard updates the displayed percentage, progress bar, and graph without reloading the page.

Procedure

  1. Arrange the ESP32, potentiometer, OLED, breadboard and jumper wires.
  2. Place the ESP32 on the breadboard.
  3. Connect one outer potentiometer terminal to 3.3V.
  4. Connect the other outer terminal to GND.
  5. Connect the middle potentiometer terminal to GPIO34.
  6. Connect OLED VCC to 3.3V.
  7. Connect OLED GND to GND.
  8. Connect OLED SDA to GPIO21.
  9. Connect OLED SCL to GPIO22.
  10. Verify all connections.
  11. Open Arduino IDE.
  12. Install the ESP32 board package.
  13. Install the Adafruit GFX library.
  14. Install the Adafruit SSD1306 library.
  15. Create a sketch named ESP32_Potentiometer_Web_Monitor.ino.
  16. Copy the complete program from Explore the Code.
  17. Configure your Wi-Fi SSID and password.
  18. Select the correct ESP32 board and serial port.
  19. Verify and upload the sketch.
  20. Open Serial Monitor at 115200 baud.
  21. Wait for the ESP32 to connect to Wi-Fi.
  22. Note the IP address shown in Serial Monitor.
  23. Open that IP address in a browser connected to the same network.
  24. Rotate the potentiometer slowly.
  25. Observe changes on the OLED.
  26. Observe changes in the browser percentage and graph.
