Aim

To monitor machine condition using two vibration inputs and a DHT22 temperature sensor, and to automatically trigger a relay, buzzer and fault LED when excessive vibration or high temperature is detected.

About the Experiment

The ESP32 uses two pushbuttons as simulated vibration sensors in Wokwi and reads temperature from a DHT22. A machine fault occurs when either vibration input is active or the measured temperature reaches 50°C or higher. During a fault, the relay is turned off, the buzzer is activated and the red fault LED is switched on. The OLED displays temperature, vibration status and the overall machine condition.

Circuit Diagram

→
2 Vibration Inputs + DHT22 + OLED + Buzzer + Relay + Fault LED

The two pushbuttons simulate vibration sensors on GPIO 18 and GPIO 19. DHT22 data connects to GPIO 4. The OLED uses SDA 21 and SCL 22. The buzzer uses GPIO 25, relay input GPIO 26, and the red fault LED is driven from GPIO 27 through a 220 Ω resistor to GND.

Procedure

  1. Connect vibration input button 1 between GPIO 18 and GND.
  2. Connect vibration input button 2 between GPIO 19 and GND.
  3. Connect the DHT22 data pin to GPIO 4.
  4. Connect the SSD1306 OLED SDA to GPIO 21 and SCL to GPIO 22.
  5. Connect the buzzer signal to GPIO 25.
  6. Connect the relay module input to GPIO 26 and power the relay from 5V.
  7. Connect the red LED anode to GPIO 27 and its cathode through a 220 Ω resistor to GND.
  8. Upload the sketch and open Serial Monitor at 115200 baud.
  9. Observe NORMAL operation when no vibration is detected and temperature is below 50°C.
  10. Press either vibration button or raise the simulated temperature to 50°C or above.
  11. Verify that the relay turns off, buzzer sounds, fault LED turns on and the OLED shows FAULT.

Explore the Code

Key sketch sections used in this experiment:

ESP32_IoT_Machine_Condition_Monitor.ino
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#include <DHT.h>

#define VIBRATION1_PIN 18
#define VIBRATION2_PIN 19
#define DHT_PIN 4
#define DHT_TYPE DHT22
#define BUZZER_PIN 25
#define RELAY_PIN 26
#define LED_PIN 27

const float TEMPERATURE_LIMIT = 50.0;

DHT dht(DHT_PIN, DHT_TYPE);

void loop() {
  float temperature = dht.readTemperature();

  bool vibration1 = digitalRead(VIBRATION1_PIN) == LOW;
  bool vibration2 = digitalRead(VIBRATION2_PIN) == LOW;
  bool vibrationDetected = vibration1 || vibration2;

  bool temperatureHigh = false;

  if (!isnan(temperature)) {
    temperatureHigh = temperature >= TEMPERATURE_LIMIT;
  }

  bool machineFault = vibrationDetected || temperatureHigh;

  if (machineFault) {
    digitalWrite(RELAY_PIN, LOW);
    digitalWrite(BUZZER_PIN, HIGH);
    digitalWrite(LED_PIN, HIGH);
  } else {
    digitalWrite(RELAY_PIN, HIGH);
    digitalWrite(BUZZER_PIN, LOW);
    digitalWrite(LED_PIN, LOW);
  }

  updateOLED();
  delay(500);
}

Expected Output

During normal operation, the OLED shows the measured temperature, both vibration inputs as OK and the machine state as NORMAL.

If either vibration button is pressed, the machine state changes to FAULT.

If the DHT22 temperature reaches 50°C or higher, the machine state changes to FAULT.

During a fault, the relay output goes LOW, the buzzer turns on and the red fault LED lights.

When the fault condition clears, the relay returns HIGH, the buzzer turns off and the fault LED switches off.

Result

The ESP32 machine condition monitor successfully detects vibration or over-temperature conditions and automatically activates protective outputs while showing the machine status on the OLED and Serial Monitor.
