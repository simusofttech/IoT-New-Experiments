Aim

To create a Wi-Fi based relay control system using ESP32 that allows a relay to be switched ON and OFF through a web browser while an LED shows the relay status.

About the Experiment

In this Experiment, the ESP32 connects to Wi-Fi and creates a web-based relay control panel.

The user can press TURN RELAY ON or TURN RELAY OFF from a phone or computer.

The ESP32 controls the relay through GPIO 26. A green LED connected to GPIO 25 works as a visual status indicator.

Procedure

  1. Place the ESP32 on the breadboard.
  2. Connect relay IN to GPIO 26.
  3. Connect relay VCC to ESP32 5V.
  4. Connect relay GND to ESP32 GND.
  5. Connect the LED anode to GPIO 25.
  6. Connect the LED cathode through a 220 Ω resistor to GND.
  7. Check all connections carefully.
  8. Connect the ESP32 to the computer.
  9. Open Arduino IDE.
  10. Upload the ESP32 program.
  11. Open Serial Monitor at 115200 baud.
  12. Wait for ESP32 to connect to Wi-Fi.
  13. Note the IP address shown in Serial Monitor.
  14. Open the IP address in a web browser connected to the same Wi-Fi network.
  15. Press TURN RELAY ON.
  16. Observe the relay switch and LED turn ON.
  17. Press TURN RELAY OFF.
  18. Observe the relay and LED turn OFF.

Explore more: relay control

The relay is controlled using:

digitalWrite(RELAY_PIN, HIGH);

or

digitalWrite(RELAY_PIN, LOW);

The status LED follows the same ON/OFF state as the relay.

Expected Output

After connecting to Wi-Fi, the ESP32 prints its IP address in Serial Monitor.

Opening this IP address shows the Wi-Fi Relay Control Panel.

  • TURN RELAY ON switches the relay ON.
  • TURN RELAY OFF switches the relay OFF.
  • The green LED follows the relay state.
  • The dashboard displays the relay status.

Result

The Wi-Fi Relay Control Panel Experiment successfully controls a relay from a web browser using an ESP32.

The relay is controlled through GPIO 26 while the LED connected to GPIO 25 provides a visual indication of the relay state.
