Aim

To create a Wi-Fi-based relay control system using ESP32 DevKitC that allows a relay to be switched ON and OFF through a web browser while an LED indicates the relay control status.

About the Experiment

The Wi-Fi Relay Control Panel demonstrates wireless control of an electrical switching module using an ESP32 microcontroller.

The ESP32 connects to Wi-Fi and starts an HTTP web server on port 80.

A 1-channel relay module is connected to ESP32 GPIO26.

A green LED is connected to GPIO25 through a 220 Ω current-limiting resistor.

The ESP32 hosts a browser-based dashboard with TURN RELAY ON and TURN RELAY OFF buttons.

When the user presses TURN RELAY ON, the browser sends a request to the /on route.

The ESP32 sets GPIO26 and GPIO25 HIGH, enabling the relay control output and illuminating the green status LED.

Pressing TURN RELAY OFF sends a request to the /off route.

Both GPIO outputs are set LOW, switching the control output and status LED OFF.

The dashboard displays the current logical relay state and ESP32 network IP address.

Relay Compatibility Note:

The supplied sketch assumes a HIGH-level-triggered relay module.

Some relay modules are active-LOW. Their physical switching behavior will be reversed unless the control logic is adjusted.

Confirm that the 5V relay module accepts 3.3V GPIO logic signals.

For classroom testing, use a suitable low-voltage load. Do not connect mains voltage through a breadboard.

Relay Control

The ESP32 sends a digital control signal to the relay module through GPIO26.

LED Status Indication

GPIO25 controls the green LED. The program changes both outputs together.

Wi-Fi Connection

WiFi.begin() connects the ESP32 to the configured wireless network.

Web Server

WebServer server(80) creates a local web server accessible through the ESP32 IP address.

Relay ON Operation

The /on route calls setRelay(true), setting both outputs HIGH.

Relay OFF Operation

The /off route calls setRelay(false), setting both outputs LOW.

Dashboard Status

The web dashboard shows ON or OFF based on the relayState Boolean variable.

Procedure

  1. Arrange the ESP32 DevKitC, relay module, green LED, 220 Ω resistor, breadboard and jumper wires.
  2. Place the ESP32 on the breadboard.
  3. Connect relay IN to GPIO26.
  4. Connect relay VCC to the appropriate 5V supply.
  5. Connect relay GND to ESP32 GND.
  6. Connect the green LED anode to GPIO25.
  7. Connect the LED cathode through the 220 Ω resistor to GND.
  8. Verify all electrical connections.
  9. Confirm that the relay module is 3.3V logic compatible and active-HIGH.
  10. Open Arduino IDE.
  11. Install the ESP32 board package.
  12. Select the correct ESP32 board and port.
  13. Create a sketch named WiFi_Relay_Control_Panel.ino.
  14. Copy the complete sketch from Explore the Code.
  15. Configure the Wi-Fi SSID and password.
  16. Verify and upload the sketch.
  17. Open Serial Monitor at 115200 baud.
  18. Wait for the Wi-Fi connection.
  19. Note the IP address shown in Serial Monitor.
  20. Open that IP address in a browser on the same local network.
  21. Observe the initial relay status: OFF.
  22. Press TURN RELAY ON.
  23. Observe the relay switching and the green LED illuminating.
  24. Press TURN RELAY OFF.
  25. Observe the relay and LED switching OFF.
  26. Repeat the operation to test wireless control.
