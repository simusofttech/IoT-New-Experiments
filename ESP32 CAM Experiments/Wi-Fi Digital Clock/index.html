Aim

To create a Wi-Fi Digital Clock using ESP32 DevKitC that automatically obtains the current time from an internet NTP server.

The system displays the current time, date, weekday and Wi-Fi connection status on a 0.96-inch SSD1306 OLED display.

About the Experiment

The Wi-Fi Digital Clock demonstrates internet-based time synchronization using an ESP32.

The ESP32 connects to a Wi-Fi network and obtains accurate current time from an NTP server.

NTP stands for Network Time Protocol. It allows network-connected devices to synchronize their clocks.

The experiment uses pool.ntp.org as the time server.

The received time is adjusted to Indian Standard Time using the UTC +5:30 timezone offset.

The current time is displayed on the OLED in HH:MM:SS format.

The date is displayed in DD MMM YYYY format, and the current weekday is also shown.

A Wi-Fi connection indicator appears in the top-right area of the OLED.

The clock refreshes approximately every second.

Important:

An internet connection is required for initial NTP synchronization.

After synchronization, the ESP32 maintains its internal system time while powered.

This experiment does not include a separate RTC backup module.

OLED Initialization

The ESP32 initializes the SSD1306 OLED using I²C communication.

GPIO21 is connected to SDA and GPIO22 is connected to SCL.

Wi-Fi Connection

The ESP32 connects to the configured wireless network using WiFi.begin().

During connection, the OLED displays a Wi-Fi progress message.

NTP Synchronization

configTime() configures the clock using pool.ntp.org.

The ESP32 obtains network time and maintains its internal clock.

Indian Standard Time

Indian Standard Time is UTC +5:30. The sketch applies an offset of 19800 seconds.

Date and Time Formatting

getLocalTime() obtains the local time, while strftime() formats the time, date and weekday.

OLED Clock Display

The OLED displays the WIFI CLOCK heading, Wi-Fi indicator, time, date and weekday.

Automatic Refresh

The program updates the display approximately every second.

Procedure

  1. Arrange ESP32 DevKitC V4, SSD1306 OLED, breadboard and jumper wires.
  2. Place the ESP32 on the breadboard.
  3. Connect OLED VCC to ESP32 3.3V.
  4. Connect OLED GND to ESP32 GND.
  5. Connect OLED SDA to GPIO21.
  6. Connect OLED SCL to GPIO22.
  7. Verify the I²C and power connections.
  8. Open Arduino IDE.
  9. Install the ESP32 board package.
  10. Install Adafruit GFX and Adafruit SSD1306 libraries.
  11. Create a sketch named WiFi_Digital_Clock.ino.
  12. Copy the complete program from Explore the Code.
  13. Configure the Wi-Fi SSID and password.
  14. Select the ESP32 DevKitC board and correct serial port.
  15. Verify and upload the sketch.
  16. Open Serial Monitor at 115200 baud.
  17. Wait for the ESP32 to connect to Wi-Fi.
  18. Wait for NTP time synchronization.
  19. Observe the current time on the OLED.
  20. Check the displayed date and weekday.
  21. Observe the Wi-Fi status indicator.
  22. Confirm that the clock updates every second.
  23. Compare the OLED time with a phone configured for Indian Standard Time.

Explore More: NTP

NTP stands for Network Time Protocol. It allows the ESP32 to synchronize its clock with a network time server.

This experiment uses pool.ntp.org.

Explore More: Indian Standard Time

India uses UTC +5:30.

The offset is calculated as: 5 × 3600 + 30 × 60 = 19800 seconds.

Explore More: I²C

I²C is a serial communication protocol. GPIO21 carries data and GPIO22 carries the clock signal.

Explore More: strftime()

strftime() formats time data.

%H:%M:%S displays hours, minutes and seconds.

%d %b %Y displays the date. %A displays the weekday.

Explore More: OLED Graphics

Adafruit SSD1306 and Adafruit GFX provide text and drawing functions.

The sketch uses circles and lines for the Wi-Fi status indicator.
