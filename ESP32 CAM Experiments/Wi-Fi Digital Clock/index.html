Aim

To create a Wi-Fi Digital Clock using ESP32 that automatically gets the current time from an internet NTP server and displays the time, date and day on an OLED display.

About the Experiment

In this Experiment, the ESP32 connects to Wi-Fi and communicates with an NTP time server.

The ESP32 receives accurate internet time and applies the India timezone offset of UTC +5:30.

The current time, date and day are displayed on the SSD1306 OLED.

The OLED also shows a Wi-Fi status icon to indicate whether the ESP32 is connected.

Procedure

  1. Place the ESP32 on the breadboard.
  2. Connect OLED VCC to ESP32 3.3V.
  3. Connect OLED GND to ESP32 GND.
  4. Connect OLED SDA to GPIO 21.
  5. Connect OLED SCL to GPIO 22.
  6. Check all connections carefully.
  7. Connect the ESP32 to the computer.
  8. Open Arduino IDE.
  9. Install Adafruit GFX library.
  10. Install Adafruit SSD1306 library.
  11. Upload the program to ESP32.
  12. Open Serial Monitor at 115200 baud.
  13. Wait while the ESP32 connects to Wi-Fi.
  14. Wait for the ESP32 to synchronize with the NTP server.
  15. Observe the time on the OLED display.
  16. Check the current date.
  17. Check the current day.
  18. Observe the Wi-Fi icon on the OLED.
  19. Check that the clock updates every second.

Explore more: NTP

NTP means Network Time Protocol .

It allows the ESP32 to obtain accurate time from an internet time server.

This Experiment uses:

pool.ntp.org

Explore more: India time

The NTP server normally provides UTC time.

India is UTC +5 hours and 30 minutes.

The program therefore uses:

gmtOffset_sec = 19800

Expected Output

After Wi-Fi connection and NTP synchronization, the OLED displays:

  • WIFI CLOCK heading
  • Current time in HH:MM:SS
  • Current date
  • Current weekday
  • Wi-Fi connection icon

The Serial Monitor also prints the current time and date every second.

Result

The Wi-Fi Digital Clock Experiment successfully connects the ESP32 to Wi-Fi and obtains accurate time from an NTP server.

The ESP32 displays the current time, date and day on the SSD1306 OLED and updates the clock every second.
