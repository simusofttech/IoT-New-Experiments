Aim

To develop an ESP32-CAM security monitor that detects movement using a PIR sensor, activates a buzzer, displays alerts on a 1.3-inch SH1106 OLED, and provides a Wi-Fi dashboard with live camera view and event counter.

About the Experiment

The AI-Thinker ESP32-CAM monitors a restricted area using an HC-SR501 PIR sensor. On motion, it sounds an alarm for five seconds, updates the OLED and event counter, and reports status through a browser-based dashboard. The camera supplies periodically refreshed JPEG snapshots. No SD card or physical control button is required.

Working Principle

1. Initialize camera, OLED and Wi-Fi2. Monitor PIR motion3. Activate buzzer for 5 seconds4. Update OLED and event count5. Refresh camera and security dashboard6. Return to monitoring

Procedure

  1. Connect the ESP32-CAM, PIR sensor, OLED and active buzzer according to the circuit connections.
  2. In Arduino IDE, install the ESP32 board package and the U8g2 library.
  3. Select AI Thinker ESP32-CAM and the correct COM port.
  4. Replace the Wi-Fi SSID and password placeholders in the program with your own 2.4 GHz network details.
  5. For manual USB-to-TTL programming, connect GPIO0 to GND, upload the code, disconnect GPIO0 from GND, then reset.
  6. Open Serial Monitor at 115200 baud and read the ESP32-CAM IP address.
  7. Open the IP address in a browser connected to the same Wi-Fi network.
  8. Move in front of the PIR sensor and observe the buzzer, OLED, motion counter, camera and dashboard.

Expected Output

Serial Monitor prints the device IP address and motion events. The OLED normally shows AREA: MONITORING and BUZZER: OFF. On motion, it shows MOTION ALERT, the buzzer turns on for five seconds, and the event counter increases. The web dashboard shows the camera snapshot, motion status, buzzer state, event count and IP address.

Result

The ESP32-CAM Motion Security Monitor detects restricted-area motion, provides a local audible alert and OLED indication, and updates a Wi-Fi security dashboard with a live camera view and motion event counter.

What You Learn

ESP32-CAM camera initialization, PIR motion sensing, digital output control, I2C SH1106 display interfacing, Wi-Fi networking, web dashboard development, and event counting.
