Aim

To develop an ESP32-CAM security monitor that detects motion using an HC-SR501 PIR sensor, activates a buzzer, displays alerts on a 1.3-inch SH1106 OLED, and provides a Wi-Fi dashboard with a camera view and event counter.

About the Experiment

The ESP32-CAM Motion Security Monitor monitors an area using the HC-SR501 PIR sensor. When motion is detected, the ESP32-CAM activates a buzzer for five seconds.

It also updates the OLED with the motion alert and increases the event counter.

A Wi-Fi webpage displays the monitored area, alarm condition, event count and camera image.

The camera provides periodically refreshed JPEG snapshots rather than a continuous streaming video connection.

The OLED shows AREA: MONITORING during normal operation and MOTION ALERT when the alarm is active.

Important Hardware Notes:

GPIO12 is an ESP32 boot-strapping pin. A HIGH level on this pin during reset may prevent an ESP32-CAM from starting. Verify a boot-safe sensor interface.

GPIO4 may also operate the ESP32-CAM onboard flash LED.

Confirm OLED power and I²C logic-voltage compatibility. Use an appropriate transistor driver if the buzzer exceeds GPIO current capabilities.

A stable power source is important because camera operation and Wi-Fi can cause significant current peaks.

PIR Detection

The HC-SR501 produces a digital output when its sensing circuitry detects motion.

Alarm Control

The ESP32-CAM activates the buzzer when a new motion event is registered and turns it off after five seconds.

OLED Monitoring

The SH1106 OLED displays the current security state, buzzer status and cumulative motion event count.

Camera Snapshot

The browser requests a JPEG image from the /snapshot endpoint every second.

Web Dashboard

The /status endpoint provides motion, buzzer and event count values as JSON. The webpage uses these values to update its status indicators.

Procedure

  1. Arrange the ESP32-CAM, PIR sensor, SH1106 OLED, buzzer, breadboard and jumper wires.
  2. Connect OLED SDA to GPIO13.
  3. Connect OLED SCL to GPIO14.
  4. Connect OLED power according to its module rating and GND to common ground.
  5. Connect PIR VCC to its appropriate supply and GND to GND.
  6. Connect PIR OUT to GPIO12 using a boot-compatible interface.
  7. Connect the buzzer control circuit to GPIO4.
  8. Verify all wiring and voltage compatibility.
  9. Open Arduino IDE.
  10. Install the ESP32 board package and U8g2 library.
  11. Select the AI Thinker ESP32-CAM board.
  12. Create the sketch ESP32_CAM_Motion_Security_Monitor.ino.
  13. Copy the complete program from Explore the Code.
  14. Enter your 2.4 GHz Wi-Fi SSID and password.
  15. Connect the USB-to-TTL programmer for uploading.
  16. Connect GPIO0 to GND for flashing, upload the program, then remove the connection and reset.
  17. Open Serial Monitor at 115200 baud.
  18. Note the IP address displayed in Serial Monitor.
  19. Open the IP address on a device connected to the same Wi-Fi network.
  20. Observe the camera snapshot and security status.
  21. Move in front of the PIR sensor.
  22. Observe the buzzer, OLED alert and motion counter.
  23. Wait five seconds and observe the return to monitoring.
