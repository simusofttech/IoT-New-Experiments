Aim

Measure atmospheric pressure, temperature and calculated altitude using the BMP180. Show pressure status on an OLED and serve the latest measurements over Wi-Fi.

About the Experiment

Measure atmospheric pressure, temperature and calculated altitude using the BMP180. Show pressure status on an OLED and serve the latest measurements over Wi-Fi. The local OLED and Wi-Fi interface work with the same ESP32 controller.

Components Required

ESP32 DevKitC V4

Controller and Wi-Fi

BMP180 Barometric Pressure Sensor

Pressure and temperature sensor

SSD1306 OLED Display

Local pressure display

Breadboard

Physical prototyping

Jumper Wires

Connections

Breadboard and jumper wires are included for physical assembly. Wi-Fi and a USB data cable are required for programming and browser access.

Circuit Diagram

Working Principle

BMP180 → ESP32 I²C → Pressure and temperature → OLED + Wi-Fi web dashboard

Procedure

  1. Install WiFi, WebServer, Wire, Adafruit BMP085 and U8g2 libraries.
  2. Wire the BMP180 and OLED to shared I²C GPIO21/GPIO22.
  3. Replace the Wi-Fi credentials for your physical network.
  4. Open the ESP32 IP address in a browser to view live pressure.
  5. Upload the sketch and open Serial Monitor at 115200 baud. Replace Wokwi-GUEST credentials when using real Wi-Fi.
