Aim

To develop a Wi-Fi-enabled atmospheric pressure monitoring experiment using an ESP32 DevKitC V4, BMP180 barometric pressure sensor and SSD1306 OLED display.

The system measures atmospheric pressure and temperature, estimates altitude from pressure, classifies pressure as LOW, NORMAL or HIGH, and displays the information locally and through a Wi-Fi dashboard.

About the Experiment

The Wi-Fi Pressure Monitor demonstrates I²C sensor interfacing, barometric pressure measurement, temperature monitoring, estimated altitude calculation and wireless visualization.

The BMP180 is a digital barometric pressure and temperature sensor. It communicates with the ESP32 through the I²C interface on GPIO21 and GPIO22.

The sensor measures atmospheric pressure in pascals. The ESP32 converts the reading to hectopascals (hPa) for display.

The program calculates an estimated altitude using the standard atmosphere formula and a reference sea-level pressure of 1013.25 hPa.

A 128×64 SSD1306 OLED displays atmospheric pressure, temperature, estimated altitude and pressure classification.

The ESP32 connects to Wi-Fi and provides an HTTP dashboard that displays the latest measurement values.

Important:

The altitude displayed by this experiment is calculated from atmospheric pressure, assuming a reference sea-level pressure of 1013.25 hPa.

Weather changes and actual local sea-level pressure affect this estimate. It is not a GPS altitude measurement or a precisely calibrated elevation measurement.

LOW, NORMAL and HIGH are educational classifications based on the supplied thresholds, not weather warnings.

Hardware Precautions:

The BMP180 and OLED share the same I²C bus because they use different addresses. Check that both devices have compatible 3.3V logic levels.

Some BMP180 breakout boards expose separate 3V3 and VIN pins. Their internal power arrangements vary. Do not connect both supply pins merely because they appear in a generic connection table.

Connect the correct power input according to the actual module's specifications. Verify the module markings before applying power.

Pressure Measurement

The BMP180 measures ambient atmospheric pressure. The sensor library returns pressure in pascals. The program divides this reading by 100 to obtain hPa.

Temperature Measurement

The BMP180 also measures temperature and returns a value in degrees Celsius.

Estimated Altitude

The ESP32 calculates estimated altitude from measured pressure using a standard atmosphere approximation.

Pressure Status

Pressure below 1000 hPa is classified LOW. Pressure from 1000 to 1020 hPa is NORMAL. Above 1020 hPa is HIGH.

OLED Display

The OLED displays the latest pressure, temperature, estimated altitude and pressure classification.

Wi-Fi Dashboard

The ESP32 hosts a local browser dashboard. The web page requests updated measurement values from the controller through an HTTP JSON endpoint.

Procedure

  1. Arrange the ESP32 DevKitC V4, BMP180 pressure sensor, SSD1306 OLED, breadboard and jumper wires.
  2. Verify the BMP180 breakout board's voltage and pin markings.
  3. Connect BMP180 GND to ESP32 GND.
  4. Connect BMP180 SDA to GPIO21.
  5. Connect BMP180 SCL to GPIO22.
  6. Connect the BMP180 power input according to the module rating.
  7. Connect OLED VCC to 3V3 and GND to GND.
  8. Connect OLED SDA to GPIO21.
  9. Connect OLED SCL to GPIO22.
  10. Verify that both devices share the I²C bus correctly.
  11. Open Arduino IDE.
  12. Install the ESP32 board support package.
  13. Install the Adafruit BMP085/BMP180 library.
  14. Install the U8g2 library.
  15. Select ESP32 DevKitC V4 or the matching board configuration.
  16. Copy the complete program from Explore the Code.
  17. Replace the Wi-Fi SSID and password placeholders.
  18. Verify and upload the sketch.
  19. Open Serial Monitor at 115200 baud.
  20. Check whether the BMP180 initializes successfully.
  21. Observe pressure, temperature and estimated altitude on the OLED.
  22. Note the ESP32 IP address shown on Serial Monitor.
  23. Open that IP address using a browser on the same network.
  24. Observe the live pressure, temperature, altitude and status.
  25. Compare the OLED and dashboard readings.
