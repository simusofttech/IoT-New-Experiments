Aim

To control the position of a bipolar stepper motor wirelessly using an ESP32, A4988 stepper motor driver and a Wi-Fi web dashboard.

About the Experiment

The ESP32 sends STEP and DIR signals to an A4988 stepper motor driver. The driver controls the bipolar stepper motor position.

The web dashboard allows manual movement, fixed-step movement, target-position control, return-to-home operation and preset positions.

The SSD1306 OLED displays the current motor position, target position and movement status.

Procedure

  1. Connect A4988 STEP to ESP32 GPIO 18.
  2. Connect A4988 DIR to ESP32 GPIO 19.
  3. Connect A4988 VDD to ESP32 3.3V.
  4. Connect the A4988 logic grounds to ESP32 GND.
  5. Connect ENABLE, MS1, MS2 and MS3 to GND.
  6. Connect RESET and SLEEP to ESP32 3.3V.
  7. Connect the bipolar stepper motor coils to A4988 outputs 1A, 1B, 2A and 2B.
  8. Connect OLED SDA to GPIO 21.
  9. Connect OLED SCL to GPIO 22.
  10. Connect OLED VCC and GND to 3.3V and GND.
  11. Upload the program to the ESP32.
  12. Open Serial Monitor at 115200 baud.
  13. Note the displayed ESP32 IP address.
  14. Open the IP address in a web browser.
  15. Use manual direction, quick-step controls, target position or presets to move the motor.

Expected Output

The OLED displays the current position, target position and motor status.

The web dashboard displays the stepper position from 0 to 199 steps.

LEFT and RIGHT controls move the motor manually.

Quick-step controls move the motor by -100, -50, +50 or +100 steps.

The target control moves the motor to a selected position from 0 to 199.

Presets provide quick positions for 0°, 90°, 180° and 270°.

Result

The Wireless Stepper Position Controller experiment was successfully implemented using an ESP32, A4988 driver, bipolar stepper motor and OLED display.

The motor position can be controlled wirelessly from a web dashboard while the OLED displays live position information.
