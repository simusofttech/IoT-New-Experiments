Aim

To wirelessly control the position of a bipolar stepper motor using an ESP32 DevKitC V4, A4988 stepper motor driver and a browser-based Wi-Fi dashboard, while monitoring the current and target positions on an SSD1306 OLED.

About the Experiment

The Wireless Stepper Position Controller demonstrates precise rotational movement using an ESP32 and an A4988 motor driver.

The ESP32 sends STEP pulses through GPIO18 and controls the motor direction through GPIO19.

Each STEP pulse requests one motor step in the selected direction.

The program assumes a 200-step-per-revolution motor operating in full-step mode.

The ESP32 connects to a Wi-Fi network and hosts the Motion Hub dashboard.

The user can rotate the motor clockwise or counterclockwise, send fixed-step commands, select a target position, return to a software-defined zero position or choose preset angles.

The OLED displays the current motor position, target position and movement status.

Position Tracking:

The displayed position is calculated by counting commanded steps. It is not measured by an encoder.

A stepper motor can miss steps under excessive load, incorrect current settings or insufficient power.

The HOME function returns to software zero. An actual mechanical home reference requires an additional homing sensor or limit switch.

Additional Electrical Requirements:

An appropriate separate motor supply, a suitable electrolytic capacitor across VMOT and motor GND (typically at least 47 µF, rated above the supply voltage), and properly rated motor wiring are required for reliable physical operation.

The motor supply is not the ESP32 3.3V output. Select the motor supply according to the A4988 and motor specifications. Do not route motor current through ordinary breadboard power contacts.

Set the A4988 current limit to match the motor before running it.

Step Generation

A HIGH-to-LOW pulse on the A4988 STEP input advances the motor one configured step. The DIR signal determines the rotation direction.

Target Position

The program calculates the shortest path from the current position to the selected target on a 200-step circular position scale.

OLED Monitoring

The SSD1306 OLED shows the current position, target position and whether the motor is moving or ready.

Wi-Fi Control

The Motion Hub webpage sends HTTP requests to the ESP32 to perform movement commands. It also retrieves the latest position.

Procedure

  1. Arrange the ESP32, A4988 driver, bipolar stepper motor, OLED, breadboard and jumper wires.
  2. Identify the bipolar stepper motor coil pairs.
  3. With power disconnected, connect the two motor coils to the A4988 outputs.
  4. Connect A4988 STEP to GPIO18.
  5. Connect A4988 DIR to GPIO19.
  6. Connect A4988 VDD to ESP32 3.3V.
  7. Connect the A4988 logic ground and ESP32 ground.
  8. Configure ENABLE, MS1, MS2, MS3, RESET and SLEEP as shown in the connections table.
  9. Connect a suitable separate motor supply to VMOT and motor GND.
  10. Connect the required bulk capacitor across VMOT and motor GND.
  11. Set the A4988 motor current limit for the motor.
  12. Connect OLED SDA to GPIO21 and SCL to GPIO22.
  13. Connect OLED VCC to 3.3V and GND to GND.
  14. Verify wiring, polarity and common ground.
  15. Open Arduino IDE and install the ESP32 board package.
  16. Install Adafruit GFX and Adafruit SSD1306 libraries.
  17. Copy the program from Explore the Code.
  18. Configure the Wi-Fi SSID and password.
  19. Select the correct ESP32 board and port.
  20. Verify and upload the program.
  21. Open Serial Monitor at 115200 baud.
  22. Open the displayed IP address in a browser on the same Wi-Fi network.
  23. Observe the Motion Hub control panel.
  24. Test LEFT and RIGHT movement at low speed with no mechanical load.
  25. Test the ±50 and ±100 quick-step controls.
  26. Enter a target position between 0 and 199.
  27. Test the preset angles and software HOME function.
  28. Observe the OLED and web position updates.

Explore More: A4988 Driver

The A4988 interprets STEP and DIR signals to control the motor coils. The motor current is supplied through VMOT, not the ESP32 GPIO pins.

Explore More: Home Position

HOME moves to the software's position zero. It cannot establish a physical reference without a homing sensor.
