Wireless Stepper Position Controller

Control the position of a stepper motor wirelessly using ESP32.

← Back to ESP32 Experiments

About the Experiment

In this Experiment, an ESP32 controls a bipolar stepper motor through an A4988 motor driver. A web-based control interface allows the motor to move left or right and move to selected step positions. An OLED display shows the current position, target position and motor status.

Components Required

ESP32 DevKitC V4 ×1

Main controller that connects to Wi-Fi and controls the Experiment.

Bipolar Stepper Motor ×1

Rotates in precise steps according to commands from the ESP32.

A4988 Stepper Motor Driver ×1

Drives the stepper motor using STEP and DIR signals from the ESP32.

SSD1306 OLED 128×64 I²C ×1

Displays the motor position, target position and operating status.

Breadboard ×1

Helps organize temporary connections while building the circuit.

Jumper Wires

Used to make electrical connections between the ESP32 and other components.

How Does It Work?

1

ESP32 Connects to Wi-Fi

The ESP32 connects to the wireless network and starts its web server.

2

Open the Control Dashboard

Open the ESP32 IP address in a web browser to access the Motion Hub control interface.

3

Select a Position

Use LEFT, RIGHT, quick-step buttons or enter a target position from 0 to 199 steps.

4

ESP32 Sends Motor Signals

The ESP32 sends STEP and DIR signals to the A4988 motor driver.

5

Stepper Motor Moves

The A4988 drives the bipolar stepper motor until the requested position is reached.

6

Position Is Displayed

The OLED and web dashboard show the current position, target position and motor status.

Explore the Code

Click the button below to explore the important parts of the ESP32 program.

1. Include the required libraries
These libraries provide Wi-Fi, web server and OLED functionality.
#include <WiFi.h> #include <WebServer.h> #include <Wire.h> #include <Adafruit_GFX.h> #include <Adafruit_SSD1306.h>
2. Set the Wi-Fi details
The ESP32 uses these details to connect to the wireless network.
const char* ssid = "Wokwi-GUEST"; const char* password = ""; WebServer server(80);
3. Define the A4988 control pins
GPIO 18 sends STEP pulses and GPIO 19 controls motor direction.
#define STEP_PIN 18 #define DIR_PIN 19
4. Set up the OLED display
The OLED has a resolution of 128 × 64 pixels and uses I²C address 0x3C.
#define SCREEN_WIDTH 128 #define SCREEN_HEIGHT 64 #define OLED_ADDR 0x3C Adafruit_SSD1306 display( SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1 );
5. Store the motor position
One complete revolution is treated as 200 steps.
const int STEPS_PER_REV = 200; long currentPosition = 0; long targetPosition = 0; int stepDelay = 1200; bool motorMoving = false;
6. Move the motor by one step
The DIR pin selects the direction and the STEP pin produces the pulse that moves the motor.
void singleStep(bool clockwise) { digitalWrite( DIR_PIN, clockwise ? HIGH : LOW ); digitalWrite(STEP_PIN, HIGH); delayMicroseconds(stepDelay); digitalWrite(STEP_PIN, LOW); delayMicroseconds(stepDelay); if (clockwise) currentPosition++; else currentPosition--; if (currentPosition >= STEPS_PER_REV) currentPosition = 0; if (currentPosition < 0) currentPosition = STEPS_PER_REV - 1; }
7. Start the OLED
GPIO 21 is used for SDA and GPIO 22 is used for SCL.
Wire.begin(21, 22); display.begin( SSD1306_SWITCHCAPVCC, OLED_ADDR );
8. Connect the ESP32 to Wi-Fi
After connecting, the ESP32 prints its IP address in the Serial Monitor.
WiFi.begin(ssid, password); while (WiFi.status() != WL_CONNECTED) { delay(500); Serial.print("."); } Serial.println(WiFi.localIP());
9. Create the web controls
These routes allow the browser dashboard to move the motor, select a target and return it home.
server.on("/", handleRoot); server.on("/move", handleMove); server.on("/target", handleTarget); server.on("/home", handleHome); server.on("/position", handlePosition); server.begin();
10. Keep the web server running
The ESP32 continuously checks for commands from the browser.
void loop() { server.handleClient(); }

Result

The ESP32 successfully controls the bipolar stepper motor through the A4988 driver. The motor can be moved wirelessly to different step positions, while the OLED and web dashboard display its position and status.
