Aim

To create a Wi-Fi controlled digital dice using an ESP32 DevKitC, OLED display and push button, with both physical and web-based dice control.

About the Experiment

The ESP32 generates a random dice value from 1 to 6 and displays the dice pattern on a 0.96-inch OLED display.

The dice can be rolled using the physical push button or from a Wi-Fi web dashboard. The dashboard can also directly set the dice to a selected number from 1 to 6 and reset the dice to 1.

Procedure

  1. Connect OLED VCC to ESP32 3.3V.
  2. Connect OLED GND to ESP32 GND.
  3. Connect OLED SDA to GPIO 21.
  4. Connect OLED SCL to GPIO 22.
  5. Connect one push button terminal to GPIO 4.
  6. Connect the other button terminal to GND.
  7. Open Arduino IDE.
  8. Install Adafruit GFX and Adafruit SSD1306 libraries.
  9. Upload the program to ESP32.
  10. Open Serial Monitor at 115200 baud.
  11. Note the IP address displayed in Serial Monitor.
  12. Open that IP address in a web browser.
  13. Press ROLL DICE or use the physical push button.

Expected Output

The OLED displays a dice value from 1 to 6.

Pressing the physical button generates a new random dice value.

The Wi-Fi dashboard also allows the user to roll the dice, select a number from 1 to 6 and reset the dice.

Result

The Wi-Fi Digital Dice experiment was successfully implemented using ESP32, an SSD1306 OLED display and a push button.

The dice can be controlled physically and through a Wi-Fi web dashboard.
