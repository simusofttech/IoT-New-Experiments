Aim

To develop a Wi-Fi Digital Dice system using an ESP32 DevKitC, a 0.96-inch SSD1306 OLED display and a push button. The dice can be rolled using the physical button or a Wi-Fi web dashboard. The user can also select numbers from 1 to 6 and reset the dice through the dashboard.

About the Experiment

Wi-Fi Digital Dice is an interactive electronic dice system controlled locally or through a web browser. The ESP32 generates a dice value between 1 and 6 and displays the corresponding pip arrangement on the SSD1306 OLED screen.

The ESP32 hosts a web dashboard using the built-in WebServer library. The dashboard displays a digital dice face, the current result, a Roll Dice button, six direct-selection buttons and a Reset button.

Pressing the physical push button on GPIO4 starts a rolling animation and generates a new random result. Selecting a dashboard number updates the OLED directly. Reset sets the result to 1.

Circuit Diagram

The circuit uses an ESP32 DevKitC, one I²C OLED and one push button. The display connects to GPIO21 and GPIO22, while the button connects between GPIO4 and GND.

OLED Dice Drawing

The display draws a rounded dice outline and places dots in the appropriate positions. Values 1, 3 and 5 include a center dot; other dots are added based on the selected dice number.

Rolling Animation

The sketch displays twelve random dice faces with a 70-millisecond delay between frames, then generates and displays the final result.

Wi-Fi Dashboard

The browser loads the page served by the ESP32. The Roll Dice, Set and Reset controls send requests to the corresponding web-server routes.

Procedure

  1. Arrange the ESP32 DevKitC, SSD1306 OLED, push button, breadboard and jumper wires.
  2. Connect OLED VCC to 3.3V and GND to GND.
  3. Connect OLED SDA to GPIO21.
  4. Connect OLED SCL to GPIO22.
  5. Connect one push-button terminal to GPIO4 and the other to GND.
  6. Open Arduino IDE or the Wokwi ESP32 simulator.
  7. Install Adafruit GFX and Adafruit SSD1306 libraries.
  8. Select the compatible ESP32 board and port.
  9. Copy the complete sketch from Explore the Code.
  10. Save the sketch as Sketch.ino.
  11. For hardware, update the Wi-Fi credentials in the sketch.
  12. Upload the program and open Serial Monitor at 115200 baud.
  13. Confirm OLED initialization and Wi-Fi connection.
  14. Read the assigned IP address from Serial Monitor.
  15. Open http://ESP32_IP_ADDRESS/ in a browser on the same network.
  16. Press ROLL DICE and observe the displayed result.
  17. Select each number from 1 to 6 to verify direct control.
  18. Press RESET and verify the dice changes to 1.
  19. Press the physical button to roll the dice.
  20. Compare the OLED result and web dashboard result.

Result

The Wi-Fi Digital Dice system demonstrates electronic dice generation using an ESP32 DevKitC, an SSD1306 OLED and a push button. The dice can be rolled locally or through a web browser, and the result is displayed as a dice face.

The web dashboard also supports setting a specific value between 1 and 6 and resetting the dice to 1.
