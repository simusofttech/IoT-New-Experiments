Aim

An ESP32 countdown timer with OLED, buzzer, push-button control and a Wi-Fi web interface. The buzzer rings when the configured countdown ends.

About the Experiment

An ESP32 countdown timer with OLED, buzzer, push-button control and a Wi-Fi web interface. The buzzer rings when the configured countdown ends. The local OLED and Wi-Fi interface work with the same ESP32 controller.

Working Principle

Set timer → Start countdown → OLED updates → Timer reaches zero → Buzzer rings

Procedure

  1. Install U8g2 and ESP32 libraries.
  2. Connect the OLED via I²C and button to GPIO27 with internal pull-up.
  3. Use GPIO25 for a compatible buzzer or a suitable driver.
  4. Use the web page to set, start, stop or reset the countdown.
  5. Upload the sketch and open Serial Monitor at 115200 baud. Replace Wokwi-GUEST credentials when using real Wi-Fi.

 38  void loop(){
 39   server.handleClient();bool b=digitalRead(BUTTON_PIN);
 40   if(lastButton==HIGH&&b==LOW){if(timerRunning)stopTimer();else startTimer();delay(35);}lastButton=b;
 41   unsigned long now=millis();
 42   if(timerRunning&&now-lastTick>=1000){lastTick+=1000;if(remainingTime>0)--remainingTime;
 43   if(remainingTime==0){timerRunning=false;bellRinging=true;bellStart=now;digitalWrite(BUZZER_PIN,HIGH);}drawTimer();}
 44   if(bellRinging&&now-bellStart>=3000){bellRinging=false;digitalWrite(BUZZER_PIN,LOW);drawTimer();}
