Aim

To develop a Wi-Fi-controlled electronic countdown timer using an ESP32 DevKitC V4, SSD1306 OLED display, active buzzer and push button. The timer can be configured and controlled through a web dashboard or a physical button, with an audible bell when the countdown reaches zero.

About the Experiment

The Wi-Fi Electronic Timer Bell demonstrates embedded countdown timing, I²C display interfacing, digital input handling, buzzer control and web-based operation using the ESP32 DevKitC V4.

The SSD1306 OLED displays the remaining countdown time in minutes and seconds, along with the timer state: RUNNING, STOPPED or BELL.

The push button connected to GPIO27 toggles the timer between the running and stopped states. It uses the ESP32's internal pull-up resistor.

The active buzzer connected to GPIO25 produces a three-second alarm when the remaining time reaches zero.

The ESP32 connects to a Wi-Fi network and hosts a browser dashboard from which users can configure the timer duration and use Start, Stop and Reset controls.

Hardware Precautions:

Ensure the OLED module is compatible with 3.3V power and I²C signaling.

The supplied code assumes an active-high buzzer. Use a compatible low-current buzzer or an appropriate transistor driver if the buzzer requires more current than the GPIO can safely deliver.

Connect the buzzer, OLED and button grounds to the ESP32's common ground.

Countdown Timer

The countdown starts with a configured duration and decreases by one second for every elapsed 1000 milliseconds.

OLED Display

The SSD1306 OLED displays the remaining time and operating status using I²C communication over GPIO21 and GPIO22.

Push Button

The push button is configured using INPUT_PULLUP. A debounced press toggles between starting and stopping the countdown.

Buzzer Alert

When the remaining time reaches zero, the buzzer switches HIGH for approximately three seconds and then switches LOW.

Wi-Fi Dashboard

The ESP32 hosts an HTTP server on port 80. The browser provides timer configuration and controls, and displays the current countdown through the status endpoint.

Procedure

  1. Arrange the ESP32 DevKitC V4, SSD1306 OLED, buzzer, push button, breadboard and jumper wires.
  2. Connect OLED VCC to 3V3 and GND to GND.
  3. Connect OLED SDA to GPIO21.
  4. Connect OLED SCL to GPIO22.
  5. Connect the active buzzer to GPIO25 using a driver if required.
  6. Connect the buzzer ground to common GND.
  7. Connect one push-button terminal to GPIO27.
  8. Connect the opposite push-button terminal to GND.
  9. Verify all circuit connections.
  10. Open Arduino IDE.
  11. Install the ESP32 board package.
  12. Install the U8g2 library.
  13. Select the appropriate ESP32 Dev Module / ESP32 DevKitC board setting.
  14. Copy the complete program from Explore the Code.
  15. Replace the Wi-Fi SSID and password placeholders.
  16. Verify and upload the sketch.
  17. Open Serial Monitor at 115200 baud.
  18. Note the ESP32 IP address after Wi-Fi connection.
  19. Open the address in a browser on the same network.
  20. Observe the initial 05:00 countdown.
  21. Set a short duration such as 10 seconds.
  22. Click START or press the physical button.
  23. Observe the countdown on both OLED and dashboard.
  24. Test STOP and RESET.
  25. Restart the countdown and allow it to reach zero.
  26. Verify that the buzzer rings for approximately three seconds.

Explore More: millis()

millis() tracks elapsed time. It allows the countdown and web server to operate without a one-second blocking delay.

Explore More: I²C OLED

GPIO21 carries SDA and GPIO22 carries SCL for the SSD1306 display.

Explore More: INPUT_PULLUP

The internal pull-up keeps GPIO27 HIGH when released. Pressing the button connects the input to GND.

Explore More: Wi-Fi Server

The web server provides a dashboard, command endpoint and JSON status endpoint for the timer.

Result

The Wi-Fi Electronic Timer Bell experiment demonstrates an ESP32-based countdown timer with an SSD1306 OLED display, physical push-button control, Wi-Fi dashboard and audible buzzer.

The timer can be configured, started, stopped and reset through the browser. When the countdown reaches zero, the buzzer activates for approximately three seconds.
