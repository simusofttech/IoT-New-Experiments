Aim

To create an ESP32-based Wi-Fi IR remote decoder that receives infrared signals from a remote control, decodes the signal information and displays the results on an OLED and web dashboard.

About the Experiment

In this Experiment, the VS1838B IR receiver detects infrared signals sent by an IR remote control.

The ESP32 decodes the IR protocol, command, address and raw data.

The decoded information is displayed on the SSD1306 OLED, Serial Monitor and a Wi-Fi web dashboard.

Procedure

  1. Place the ESP32 on the breadboard.
  2. Connect VS1838B VCC to ESP32 3.3V.
  3. Connect VS1838B GND to ESP32 GND.
  4. Connect VS1838B OUT / DATA to GPIO 15.
  5. Connect OLED VCC to ESP32 3.3V.
  6. Connect OLED GND to ESP32 GND.
  7. Connect OLED SDA to GPIO 21.
  8. Connect OLED SCL to GPIO 22.
  9. Open Arduino IDE.
  10. Install the IRremote library.
  11. Install Adafruit GFX library.
  12. Install Adafruit SSD1306 library.
  13. Upload the program to the ESP32.
  14. Open Serial Monitor at 115200 baud.
  15. Wait for ESP32 to connect to Wi-Fi.
  16. Note the IP address shown in Serial Monitor.
  17. Open the IP address in a web browser.
  18. Point the IR remote toward the VS1838B receiver.
  19. Press any remote button.
  20. Observe the decoded command on the OLED.
  21. Observe protocol, address, raw data and signal count on the web dashboard.
  22. Try different buttons and compare the decoded values.

Expected Output

The OLED displays:

  • IR command
  • IR protocol
  • IR address
  • Number of received signals
  • Wi-Fi status

The web dashboard additionally shows the raw IR data, last received signal time and signal activity.

Result

The Wi-Fi IR Remote Decoder Experiment successfully receives and decodes infrared commands using the VS1838B IR receiver.

The ESP32 displays the decoded IR information on the OLED, Serial Monitor and Wi-Fi web dashboard.
