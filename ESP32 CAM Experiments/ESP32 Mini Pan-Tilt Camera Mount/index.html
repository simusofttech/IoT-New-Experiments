Aim

To build a Wi-Fi-controlled pan-tilt camera mount using an ESP32 DevKitC, two servo motors, and an SSD1306 OLED display.

The experiment demonstrates wireless control of horizontal and vertical servo angles through a web dashboard.

About the Experiment

A pan-tilt mechanism provides movement in two directions. Pan represents horizontal movement, while tilt represents vertical movement.

This experiment uses two servo motors controlled by ESP32 DevKitC.

The pan servo is connected to GPIO13 and the tilt servo is connected to GPIO14.

ESP32 hosts a local web server that accepts movement commands from a browser.

LEFT and RIGHT change the pan angle in steps of 10 degrees. UP and DOWN change the tilt angle in steps of 10 degrees.

The CENTER command returns both motors to 90 degrees.

Additional commands provide fixed angle selections and predefined pan-tilt positions.

The SSD1306 OLED uses I²C communication to show the current pan and tilt angles.

The experiment uses the ESP32Servo library to generate servo control pulses.

Important:

The supplied experiment is a servo-controlled pan-tilt mount demonstration.

No separate camera sensor or camera video-streaming code is specified in the supplied HTML.

The mechanism can position a compatible lightweight camera mount, but this experiment does not capture images or video.

Hardware Power Note:

The original uploaded HTML lists both servo V+ connections as ESP32 3.3V.

This should not be assumed suitable for physical servo motors. Most common hobby servos require a rated supply, typically around 5V, and may draw significant current.

For physical hardware, power the servos according to their specifications and connect their supply ground to ESP32 GND. Do not power servo motors from ESP32 GPIO pins.

The original GPIO13 and GPIO14 control-signal assignments are unchanged.

Pan Movement

The pan servo controls horizontal motion.

The LEFT command reduces panAngle by 10 degrees, while RIGHT increases panAngle by 10 degrees.

Tilt Movement

The tilt servo controls vertical motion.

UP increases tiltAngle by 10 degrees, while DOWN decreases it.

Angle Limits

Both servo angles are restricted to the range 0° to 180°.

Center Position

The CENTER command sets panAngle and tiltAngle to 90°.

Preset Positions

Browser Commands

The original program provides the HTTP endpoints /, /control, and /angles.

Movement requests use the command parameter on the /control route.

After a command, the ESP32 responds with the current angles in JSON format.

OLED Feedback

The OLED displays the current P and T values using the SSD1306 library.

Important Dashboard Detail:

The original embedded dashboard contains UP, LEFT, CENTER, RIGHT and DOWN buttons.

Its firmware also recognizes preset commands and fixed-angle commands, but the original dashboard does not provide visible buttons for all those additional commands.

Those commands remain available through their HTTP control URLs.

Procedure

  1. Arrange ESP32 DevKitC, two servo motors, SSD1306 OLED, breadboard and jumper wires.
  2. Connect the pan servo control signal to GPIO13.
  3. Connect the tilt servo control signal to GPIO14.
  4. Supply both servo motors using a suitable rated power source and connect common ground.
  5. Connect OLED VCC to ESP32 3.3V.
  6. Connect OLED GND to ESP32 GND.
  7. Connect OLED SDA to GPIO21.
  8. Connect OLED SCL to GPIO22.
  9. Verify all signal, power and ground connections.
  10. Open Arduino IDE.
  11. Install the ESP32 board package.
  12. Install ESP32Servo, Adafruit GFX and Adafruit SSD1306 libraries.
  13. Create a sketch named ESP32_Mini_Pan_Tilt_Camera_Mount.ino.
  14. Copy the complete program from Explore the Code.
  15. Configure the appropriate Wi-Fi connection.
  16. Select the ESP32 development board and serial port.
  17. Verify and upload the program.
  18. Open Serial Monitor at 115200 baud.
  19. Read the displayed ESP32 IP address.
  20. Open the address using a browser that can access the ESP32 network.
  21. Press LEFT and RIGHT to control the pan angle.
  22. Press UP and DOWN to control the tilt angle.
  23. Press CENTER to return both motors to 90°.
  24. Observe the updated angles on the OLED.
  25. Test the additional preset commands using their HTTP URLs.

Explore More: Pan and Tilt

panAngle controls horizontal movement and tiltAngle controls vertical movement.

Both start at 90° and remain within 0°–180°.

Explore More: ESP32Servo

The ESP32Servo library produces the servo control pulses.

The source sets a 50 Hz update period and attaches both servos.

Explore More: I²C OLED

The OLED uses GPIO21 as SDA and GPIO22 as SCL.

The configured I²C address is 0x3C.

Explore More: HTTP Commands

The browser sends commands to /control?cmd=...

The controller interprets the command and adjusts the motor angles.

Explore More: JSON

The angleJSON function returns the current pan and tilt values in JSON format.

Example: {"pan":90,"tilt":90}

Result

The ESP32 Mini Pan-Tilt Camera Mount experiment demonstrates the control of two servo motors through an ESP32-hosted Wi-Fi web dashboard.

Horizontal and vertical movement can be controlled using browser commands.

The program limits the angles to the supported 0°–180° range.

The SSD1306 OLED displays current pan and tilt angles.

This experiment demonstrates servo motor control, I²C communication, wireless command handling and embedded web-server programming.
