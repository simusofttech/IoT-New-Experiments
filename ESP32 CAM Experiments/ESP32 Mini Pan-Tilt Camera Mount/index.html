ESP32 Mini Pan-Tilt Camera Mount

Aim

To build a Wi-Fi controlled pan-tilt camera mount using two servo motors and an SSD1306 OLED, allowing the pan and tilt angles to be controlled from a browser.

About the Experiment

The ESP32 controls two servos: one for pan and one for tilt. The browser sends movement commands to the /control route, while the /angles route returns the current pan and tilt angles as JSON. The OLED continuously shows the current pan and tilt positions. The system starts centered at 90° for both axes and supports directional movement and preset positions.

The pan servo signal connects to GPIO 13 and the tilt servo signal connects to GPIO 14. Both servos are powered from 3.3V and GND in the supplied Wokwi circuit. The OLED uses I²C with SDA on GPIO 21 and SCL on GPIO 22.

Procedure

  1. Connect the pan servo signal wire to GPIO 13.
  2. Connect the tilt servo signal wire to GPIO 14.
  3. Connect both servos to 3.3V and GND as shown in the supplied circuit.
  4. Connect the SSD1306 OLED SDA to GPIO 21 and SCL to GPIO 22.
  5. Upload the ESP32 sketch.
  6. Open Serial Monitor at 115200 baud.
  7. Wait for the Wi-Fi connection and note the ESP32 IP address.
  8. Open the IP address in a browser.
  9. Use the directional buttons and presets to move the pan and tilt servos.
  10. Observe the current angles on both the OLED and web dashboard.

Explore the Code

Key sketch sections used in this experiment:

ESP32_Mini_Pan_Tilt_Camera_Mount.ino
#include <WiFi.h>
#include <WebServer.h>
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#include <ESP32Servo.h>

#define PAN_SERVO_PIN 13
#define TILT_SERVO_PIN 14
#define OLED_SDA 21
#define OLED_SCL 22
#define OLED_ADDRESS 0x3C

WebServer server(80);
Servo panServo;
Servo tiltServo;

int panAngle = 90;
int tiltAngle = 90;

String angleJSON() {
  return "{\"pan\":" + String(panAngle) +
         ",\"tilt\":" + String(tiltAngle) + "}";
}

void moveCamera() {
  panServo.write(panAngle);
  tiltServo.write(tiltAngle);
  updateOLED();
}

void handleControl() {
  if (!server.hasArg("cmd")) {
    server.send(400, "text/plain", "Missing command");
    return;
  }

  String cmd = server.arg("cmd");

  if (cmd == "L") panAngle = max(0, panAngle - 10);
  else if (cmd == "R") panAngle = min(180, panAngle + 10);
  else if (cmd == "U") tiltAngle = min(180, tiltAngle + 10);
  else if (cmd == "D") tiltAngle = max(0, tiltAngle - 10);
  else if (cmd == "C") { panAngle = 90; tiltAngle = 90; }

  moveCamera();
  server.send(200, "application/json", angleJSON());
}

void loop() {
  server.handleClient();
}

Expected Output

At startup, the pan and tilt angles are both 90° and the OLED shows P:90 and T:90.

Pressing LEFT or RIGHT changes the pan angle in 10° steps between 0° and 180°.

Pressing UP or DOWN changes the tilt angle in 10° steps between 0° and 180°.

The browser dashboard and OLED both update to show the new angles.

Preset buttons move the servos to predefined positions.

Result

The ESP32 successfully controls two servo motors over Wi-Fi, provides directional and preset movement, and displays the current pan and tilt angles on the OLED and browser dashboard.
