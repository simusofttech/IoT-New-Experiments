Aim

To build a Wi-Fi controlled pan-tilt camera mount using an ESP32, two servo motors and an SSD1306 OLED display.

About the Experiment

The ESP32 controls two servo motors: one servo controls horizontal pan movement and the second servo controls vertical tilt.

A Wi-Fi web dashboard sends movement commands to the ESP32, while the OLED displays the current pan and tilt angles.

The system starts with both servos at 90 degrees and supports directional movement, centre reset and preset positions.

Procedure

  1. Connect the pan servo signal to GPIO 13.
  2. Connect the tilt servo signal to GPIO 14.
  3. Connect both servo V+ pins to ESP32 3.3V.
  4. Connect both servo GND pins to ESP32 GND.
  5. Connect OLED SDA to GPIO 21.
  6. Connect OLED SCL to GPIO 22.
  7. Connect OLED VCC to ESP32 3.3V.
  8. Connect OLED GND to ESP32 GND.
  9. Open Arduino IDE and install the required OLED and ESP32Servo libraries.
  10. Upload the program to ESP32.
  11. Open Serial Monitor at 115200 baud.
  12. Note the ESP32 IP address.
  13. Open the IP address in a web browser.
  14. Use the directional buttons and preset controls to move the pan and tilt servos.

Expected Output

The OLED displays the current pan angle and tilt angle.

The browser dashboard displays navigation controls and current servo angle readouts.

LEFT and RIGHT commands change the pan angle in 10-degree steps.

UP and DOWN commands change the tilt angle in 10-degree steps.

The centre command returns both servo motors to 90 degrees.

Result

The ESP32 Mini Pan-Tilt Camera Mount experiment was successfully implemented using an ESP32, two servo motors and an SSD1306 OLED display.

The pan and tilt positions can be controlled wirelessly through a Wi-Fi web dashboard.
