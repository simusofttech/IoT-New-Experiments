Aim

To create a Wi-Fi-controlled LED message board using an ESP32 DevKitC and a MAX7219 4-in-1 LED dot matrix display, allowing text messages entered through a web browser to scroll across a 32×8 LED display.

About the Experiment

The Wi-Fi LED Matrix Message Board demonstrates wireless communication, text processing and LED display control using an ESP32.

The ESP32 connects to Wi-Fi and hosts a browser-based message control page.

A user can enter a message using a mobile phone or computer connected to the same Wi-Fi network.

The entered message is transmitted to the ESP32 through an HTTP request.

The ESP32 processes the message, removes extra spaces at its beginning and end, and converts it into uppercase.

The updated text is displayed on the MAX7219 4-in-1 LED matrix.

The MD_Parola library controls the scrolling animation.

The text scrolls continuously from right to left across the display.

MAX7219 LED Matrix

The 4-in-1 MAX7219 module contains four 8×8 LED matrix sections.

These sections are connected together to form a display measuring 32 LEDs wide and 8 LEDs high.

The MAX7219 communicates with the ESP32 using data, clock and chip-select signals.

Wi-Fi Message Dashboard

The dashboard provides a message input box and a SEND MESSAGE button.

It also provides quick message buttons such as HELLO, WELCOME, ESP32, GOOD DAY and SMART IOT.

A live text preview displays the selected or typed message before it is submitted.

Hardware Notes:

Connect the ESP32 data pins to the input side of the MAX7219 module, not the output connector.

Use a suitable 5V supply for the matrix and maintain a common ground with ESP32.

Some MAX7219 boards require proper 3.3V-to-5V logic-level compatibility for reliable operation.

GPIO5 is an ESP32 strapping pin. The connected module must not interfere with startup.

If the displayed text is reversed or incorrectly arranged, verify the MAX7219 hardware type and module orientation.

MAX7219 Initialization

The MD_Parola library initializes the four LED matrix sections as one 32×8 display.

Wi-Fi Connection

WiFi.begin() connects the ESP32 to the configured Wi-Fi network.

Web Dashboard

The ESP32 provides a local webpage containing a message field and quick message buttons.

Message Reception

After SEND MESSAGE is pressed, the browser sends the entered text to the /send endpoint.

Message Processing

The ESP32 reads the msg parameter, removes surrounding spaces, and converts the text to uppercase.

Scrolling Display

matrix.displayText() configures the selected text and scrolling effect.

matrix.displayAnimate() advances the text animation during each iteration of the main loop.

Procedure

  1. Arrange ESP32 DevKitC, MAX7219 4-in-1 LED Matrix, breadboard and jumper wires.
  2. Place the ESP32 on the breadboard.
  3. Connect MAX7219 DIN to GPIO23.
  4. Connect MAX7219 CLK to GPIO18.
  5. Connect MAX7219 CS / LOAD to GPIO5.
  6. Connect MAX7219 VCC to the appropriate 5V supply.
  7. Connect MAX7219 GND to ESP32 GND.
  8. Verify all connections and the display's input connector.
  9. Open Arduino IDE.
  10. Install the ESP32 board package.
  11. Install the MD_Parola library.
  12. Install the MD_MAX72xx library.
  13. Create a sketch named WiFi_LED_Matrix_Message_Board.ino.
  14. Copy the complete program from Explore the Code.
  15. Configure Wi-Fi SSID and password.
  16. Select the correct ESP32 board and port.
  17. Verify and upload the program.
  18. Open Serial Monitor at 115200 baud.
  19. Wait for the ESP32 to connect to Wi-Fi.
  20. Note the IP address in Serial Monitor.
  21. Open the IP address in a browser connected to the same network.
  22. Observe the message control dashboard.
  23. Type HELLO in the message box.
  24. Press SEND MESSAGE.
  25. Observe HELLO scrolling across the LED matrix.
  26. Enter another message such as WELCOME.
  27. Press SEND MESSAGE again.
  28. Observe the updated scrolling message.
  29. Test the quick message buttons.
