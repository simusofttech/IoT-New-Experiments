Aim

To create a Wi-Fi controlled LED message board using ESP32 and a MAX7219 4-in-1 LED matrix that displays text entered through a web browser.

About the Experiment

In this Experiment, an ESP32 creates a web-based message control page.

The user enters a message from a phone or computer. The message is sent to the ESP32 through Wi-Fi.

The ESP32 then displays and scrolls the message across the MAX7219 32 × 8 LED matrix.

Components Required

ESP32 DevKitC (×1)

Main controller with built-in Wi-Fi.

MAX7219 4-in-1 8×8 LED Dot Matrix (×1)

Displays scrolling text using 32 × 8 LEDs.

Breadboard (×1)

Provides a convenient base for circuit connections.

Jumper Wires

Used to connect the ESP32 to the MAX7219 display.

Procedure

  1. Place the ESP32 on the breadboard.
  2. Connect MAX7219 DIN to GPIO 23.
  3. Connect MAX7219 CLK to GPIO 18.
  4. Connect MAX7219 CS / LOAD to GPIO 5.
  5. Connect MAX7219 VCC to ESP32 5V / VIN.
  6. Connect MAX7219 GND to ESP32 GND.
  7. Open Arduino IDE.
  8. Install the MD_Parola library.
  9. Install the MD_MAX72xx library.
  10. Upload the program to ESP32.
  11. Open Serial Monitor at 115200 baud.
  12. Wait for ESP32 to connect to Wi-Fi.
  13. Note the IP address displayed in Serial Monitor.
  14. Open the IP address in a web browser.
  15. Enter a message in the message box.
  16. Press the SEND MESSAGE button.
  17. Observe the message scrolling on the LED matrix.
  18. Try quick messages such as HELLO, WELCOME, ESP32, GOOD DAY and SMART IOT.
