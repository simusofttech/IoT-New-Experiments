Aim

To monitor plant-growing environmental conditions, including temperature, humidity and light, using a DHT22 sensor and a digital LDR module with an ESP32, display the readings and alerts on an SSD1306 OLED, and upload monitoring data to ThingSpeak using Wi-Fi.

About the Experiment

The Plant-Growing Environment Supervisor is an IoT experiment that monitors environmental conditions relevant to plant growth.

The DHT22 sensor measures temperature and relative humidity. A digital LDR sensor module detects whether the surroundings are classified as light or dark.

The ESP32 compares sensor readings with predefined thresholds and generates an alert code when a monitored condition is outside the configured range.

Under normal conditions, the green LED is ON and the red LED and buzzer are OFF. During an alert, the green LED turns OFF while the red LED and buzzer turn ON.

An SSD1306 OLED displays temperature, humidity, light status and the alert code. Every 20 seconds, the ESP32 attempts to upload valid readings to ThingSpeak.

ThingSpeak provides online graphs for monitoring the uploaded sensor values. The ESP32 does not host its own local HTML dashboard in this program.

Hardware Precautions:

GPIO34 is input-only and does not provide an internal pull-up. Use a digital LDR module with a defined 3.3V-compatible output.

A bare four-pin DHT22 may require an external pull-up resistor on DATA. Some DHT22 modules already include one.

Verify buzzer current consumption. Use a transistor driver if it exceeds the ESP32 GPIO's safe drive capability.

Sensor Monitoring

DHT22 readings and LDR digital status are sampled approximately every 2.5 seconds.

Alert Decision

Temperature, humidity and light conditions are compared against the selected limits. An alert code is generated for the current condition.

Local Indication

The OLED displays environmental readings. LEDs and the buzzer indicate normal or alert conditions.

Cloud Monitoring

The ESP32 uploads four fields to ThingSpeak. ThingSpeak charts display the data when the channel has been configured correctly.

Procedure

  1. Arrange all required components.
  2. Connect DHT22 DATA to GPIO16.
  3. Connect LDR digital output to GPIO34.
  4. Connect OLED SDA to GPIO21 and SCL to GPIO22.
  5. Connect the green LED to GPIO25 through 220 Ω.
  6. Connect the red LED to GPIO26 through 220 Ω.
  7. Connect a suitable buzzer control circuit to GPIO27.
  8. Connect all required supply and ground connections.
  9. Verify the circuit before powering it.
  10. Open Arduino IDE and install the ESP32 board package.
  11. Install DHT, U8g2 and ThingSpeak libraries.
  12. Create a ThingSpeak channel with four fields.
  13. Copy the complete sketch from Explore the Code.
  14. Enter Wi-Fi credentials, channel ID and Write API key.
  15. Select the appropriate ESP32 board and port.
  16. Verify and upload the sketch.
  17. Open Serial Monitor at 115200 baud.
  18. Observe OLED readings and LED status.
  19. Change environmental conditions near the sensors.
  20. Observe alert codes and buzzer response.
  21. Open ThingSpeak and verify incoming field values.

Result

The Plant-Growing Environment Supervisor demonstrates temperature, humidity and light-state monitoring using ESP32. The system displays readings on an OLED, indicates environmental alerts through LEDs and a buzzer, and uploads valid data to ThingSpeak for cloud monitoring.
