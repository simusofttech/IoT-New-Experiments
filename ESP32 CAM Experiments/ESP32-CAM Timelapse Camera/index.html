Aim

To develop a Wi-Fi-based timelapse camera using an ESP32-CAM and an SH1106 OLED that captures JPEG images at regular 10-second intervals and provides a browser dashboard for starting, stopping and monitoring the timelapse operation.

About the Experiment

The ESP32-CAM Timelapse Camera demonstrates automatic image capture using the AI-Thinker ESP32-CAM board.

The ESP32-CAM connects to Wi-Fi and hosts a web dashboard that displays periodically refreshed camera snapshots.

The dashboard contains START TIMELAPSE and STOP controls.

When the user starts the timelapse, the ESP32-CAM schedules its first automatic photo after 10 seconds.

Further images are captured every 10 seconds while the timelapse is running.

The SH1106 OLED displays the photo counter, Wi-Fi status and timelapse operating condition.

The web dashboard shows the photo count, current operating status, capture interval and countdown to the next scheduled image.

Image Storage

The current program maintains the latest captured JPEG in memory.

Each new automatic capture replaces the previous saved JPEG.

The photo counter continues increasing, but earlier captured images are not retained in a permanent gallery.

Important:

The firmware does not save a complete sequence of images to a microSD card or external storage.

The latest captured image is retained only while the ESP32-CAM remains powered and the memory allocation succeeds.

Hardware Notes:

Check that the SH1106 OLED module supports the intended supply voltage. Its I²C signals must be compatible with ESP32-CAM 3.3V logic.

The ESP32-CAM requires a stable power source capable of supporting Wi-Fi and camera operation.

GPIO13 and GPIO14 are shared with the ESP32-CAM SD-card interface. This experiment does not use that interface.

Camera Initialization

The ESP32-CAM initializes its onboard camera using the appropriate AI-Thinker pin mapping.

Timelapse Timing

millis() is used to schedule a photo every 10 seconds without continuously blocking the main program.

JPEG Capture

The camera captures a JPEG image, which is copied into a memory buffer.

Memory Management

A new successful image replaces the previous saved image. The camera frame buffer is returned after the image has been copied.

OLED Display

The OLED shows the photo counter, Wi-Fi condition and whether timelapse recording is running.

Wi-Fi Dashboard

The webpage provides camera snapshots, operating controls, the total capture count and a next-capture countdown.

Procedure

  1. Arrange the AI-Thinker ESP32-CAM, SH1106 OLED, breadboard and jumper wires.
  2. Connect OLED SDA to GPIO13.
  3. Connect OLED SCL to GPIO14.
  4. Connect OLED GND to ESP32-CAM GND.
  5. Connect OLED VCC to a compatible regulated supply.
  6. Verify all circuit connections.
  7. Open Arduino IDE.
  8. Install the ESP32 board package.
  9. Install the U8g2 library.
  10. Select the AI-Thinker ESP32-CAM board.
  11. Create a sketch named ESP32_CAM_Timelapse_Camera.ino.
  12. Copy the complete program from Explore the Code.
  13. Enter the correct Wi-Fi SSID and password.
  14. Upload the sketch using a compatible programming interface and the board's required flashing procedure.
  15. Restart the ESP32-CAM in normal running mode.
  16. Open Serial Monitor at 115200 baud.
  17. Wait for Wi-Fi connection.
  18. Note the IP address printed in Serial Monitor.
  19. Open the IP address in a browser on the same Wi-Fi network.
  20. Observe the Timelapse Camera dashboard.
  21. Check the periodically refreshed live camera image.
  22. Click START TIMELAPSE.
  23. Observe the countdown to the first image capture.
  24. Wait for a successful capture.
  25. Observe the photo counter, OLED and latest image.
  26. Allow additional automatic captures at 10-second intervals.
  27. Click STOP to stop automatic image capture.
