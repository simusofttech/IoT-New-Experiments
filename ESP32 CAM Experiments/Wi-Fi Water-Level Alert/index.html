Aim

To develop a Wi-Fi-enabled sound-level indication experiment using an ESP32 development board, analog sound sensor, SSD1306 OLED display and red LED. The system monitors a relative analog sensor reading, classifies the reading as QUIET, MODERATE or LOUD, and displays the information on an OLED and local Wi-Fi dashboard.

About the Experiment

The Wi-Fi Sound Level Indicator demonstrates analog sensor interfacing, ADC sampling, threshold classification, LED control, OLED display programming and wireless monitoring.

An analog sound sensor is connected to GPIO34 of the ESP32. The ESP32 reads its analog output using the built-in ADC.

The provided program calculates the average of ten successive ADC measurements and maps the value to a relative percentage between 0 and 100%.

The percentage is classified into three categories: QUIET, MODERATE and LOUD.

The SSD1306 OLED shows the percentage and classification. A red LED connected to GPIO2 through a 220Ω resistor turns on for MODERATE and LOUD classifications.

The ESP32 hosts a local Wi-Fi dashboard that displays the relative reading, classification, ADC value and device IP address.

Important:

The original experiment maps average ADC voltage to a percentage. This is not a calibrated decibel measurement or a reliable physical loudness measurement.

Microphone modules with a biased analog waveform may produce similar average ADC readings at different sound intensities. Measuring waveform amplitude and calibrating thresholds would be necessary for a more meaningful loudness indicator.

Hardware Precautions:

GPIO34 is an input-only ADC1 pin. It is suitable for analog input while Wi-Fi is active.

Confirm that the sound sensor supports 3.3V operation and does not output a voltage above 3.3V to GPIO34.

The 220Ω resistor must be connected in series with the LED. GPIO2 is also a boot-strapping pin, so check that the LED circuit does not interfere with startup.

Analog Sensor Input

The microphone module generates an analog voltage. The ESP32 reads this voltage on GPIO34.

ADC Sampling

Ten successive ADC samples are averaged to produce one reading. The average is mapped to a relative 0–100% scale.

Threshold Classification

The software divides the mapped reading into QUIET, MODERATE and LOUD categories.

LED Output

GPIO2 remains LOW for QUIET. When the calculated value reaches 31% or higher, GPIO2 becomes HIGH.

OLED Display

The OLED displays the sensor percentage and classification through I²C communication.

Wi-Fi Dashboard

The ESP32 sends the current ADC reading and classification to a browser through the /data endpoint.

Procedure

  1. Arrange the ESP32 development board, sound sensor, OLED, red LED, 220Ω resistor, breadboard and jumper wires.
  2. Connect the analog sound sensor VCC to 3V3.
  3. Connect the sound sensor GND to GND.
  4. Connect the analog sensor output to GPIO34.
  5. Connect OLED VCC to 3V3.
  6. Connect OLED GND to GND.
  7. Connect OLED SDA to GPIO21.
  8. Connect OLED SCL to GPIO22.
  9. Connect GPIO2 to the red LED anode through a 220Ω resistor.
  10. Connect the LED cathode to GND.
  11. Verify all connections.
  12. Open Arduino IDE.
  13. Install the ESP32 board support package.
  14. Install the U8g2 library.
  15. Select the appropriate ESP32 board configuration.
  16. Create a new sketch named WiFi_Sound_Level_Indicator.ino.
  17. Copy the entire program from Explore the Code.
  18. Replace the Wi-Fi SSID and password placeholders.
  19. Verify and upload the sketch.
  20. Open Serial Monitor at 115200 baud.
  21. Note the IP address displayed after network connection.
  22. Open that IP address in a browser on the same network.
  23. Observe the OLED and Wi-Fi dashboard values.
  24. Change the sound conditions around the microphone sensor.
  25. Observe the sensor readings and classification.
  26. Verify whether the LED responds at the configured threshold.
  27. Adjust or recalibrate the sensing method if the ADC average does not respond meaningfully to changes in sound intensity.

Explore More: Analog Microphone

The microphone module converts sound vibrations into an electrical signal. Different modules may have different output circuits.

Explore More: ADC

The ESP32 ADC converts analog voltage into a digital reading. GPIO34 belongs to ADC1.

Explore More: Thresholds

The original demonstration uses 31% and 66% as classification boundaries. The LED is ON from 31%.

Explore More: Sound Measurement

Averaging raw microphone samples does not necessarily measure loudness. More useful methods may calculate signal amplitude, peak-to-peak variation or RMS, with appropriate calibration.

Explore More: Web Dashboard

The ESP32 hosts a web page and a JSON data endpoint. The browser updates the displayed measurements approximately once per second.

Result

The Wi-Fi Sound Level Indicator demonstrates analog microphone interfacing, relative ADC reading, threshold classification, OLED display output, LED control and wireless dashboard monitoring.

The program classifies the mapped sensor voltage as QUIET, MODERATE or LOUD, and activates the LED when the configured percentage reaches 31% or more.

The displayed measurement represents an ADC-based demonstration value rather than calibrated sound intensity.
