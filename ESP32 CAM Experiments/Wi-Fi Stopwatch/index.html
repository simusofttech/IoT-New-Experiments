Aim

To design and implement a Wi-Fi-enabled digital stopwatch using an ESP32 DevKitC V4, an SSD1306 OLED display and two push buttons. The system measures elapsed time in minutes, seconds and hundredths of a second and supports Start, Stop and Reset operations through physical buttons and a web dashboard.

About the Experiment

The Wi-Fi Stopwatch experiment demonstrates precise elapsed-time measurement using an ESP32 microcontroller.

The stopwatch uses the ESP32's internal millis() timer to calculate elapsed time without relying on continuous blocking delays.

A 128×64 SSD1306 OLED shows the elapsed time in MM:SS.hh format, along with the current RUNNING or STOPPED status.

Two physical buttons are provided. The first button connected to GPIO18 starts or stops the stopwatch. The second button connected to GPIO19 resets the stopwatch.

The ESP32 also operates as a Wi-Fi web server. Users can view the stopwatch and control it from a web browser connected to the same network.

Hardware Precautions:

Use the correct terminals of each four-pin tactile switch. When pressed, the selected GPIO must connect to GND.

The software uses INPUT_PULLUP, so no external pull-up resistors are required for the buttons.

Check the OLED module's supply and I²C logic-level requirements before connecting it to 3.3V.

Elapsed-Time Measurement

The stopwatch records the value returned by millis() when timing begins.

The difference between the current millisecond value and the start value determines the elapsed duration.

Start and Stop

When the stopwatch is stopped, the elapsed time is stored. Starting again continues from the stored duration rather than zero.

Reset

Reset stops the stopwatch and clears the elapsed time to 00:00.00.

OLED Output

The SSD1306 OLED refreshes approximately every 50 milliseconds, showing the current formatted time and operating status.

Wi-Fi Dashboard

The ESP32 web dashboard provides START, STOP and RESET commands. The dashboard periodically retrieves the elapsed time through a JSON status endpoint.

Procedure

  1. Arrange the ESP32 DevKitC V4, SSD1306 OLED, two push buttons, breadboard and jumper wires.
  2. Connect OLED VCC to 3V3 and GND to GND.
  3. Connect OLED SDA to GPIO21.
  4. Connect OLED SCL to GPIO22.
  5. Connect the Start/Stop button between GPIO18 and GND.
  6. Connect the Reset button between GPIO19 and GND.
  7. Verify the wiring and common ground.
  8. Open Arduino IDE.
  9. Install the ESP32 board package.
  10. Install Adafruit GFX and Adafruit SSD1306 libraries.
  11. Select the appropriate ESP32 board configuration.
  12. Create a new sketch named WiFi_Stopwatch.ino.
  13. Copy the complete sketch from Explore the Code.
  14. Replace the Wi-Fi placeholders with your network credentials.
  15. Verify and upload the program.
  16. Open Serial Monitor at 115200 baud.
  17. Observe the initial OLED reading of 00:00.00.
  18. Press the physical Start/Stop button to start timing.
  19. Observe the elapsed time on the OLED.
  20. Press the button again to stop the stopwatch.
  21. Press it once more to resume timing.
  22. Press the Reset button and verify the display returns to zero.
  23. Note the ESP32 IP address in Serial Monitor.
  24. Open the IP address in a browser on the same Wi-Fi network.
  25. Test START, STOP and RESET using the dashboard.
  26. Compare the OLED and dashboard time readings.

Explore More: millis()

millis() returns the number of milliseconds since the microcontroller started. It is used to measure elapsed stopwatch time.

Explore More: Hundredths

One hundredth of a second equals 10 milliseconds. Dividing the elapsed milliseconds by 10 converts them into hundredths.

Explore More: INPUT_PULLUP

The buttons are normally HIGH. Pressing either button pulls its GPIO input LOW.

Explore More: Wi-Fi Dashboard

The ESP32 hosts a local web page. Browser controls send HTTP requests, and the status endpoint supplies the elapsed stopwatch time.
