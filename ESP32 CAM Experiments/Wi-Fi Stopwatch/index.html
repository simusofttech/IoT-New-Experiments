Aim

A Wi-Fi-enabled stopwatch with a 128×64 OLED, physical start/stop and reset buttons, and a browser dashboard showing minutes, seconds and hundredths.

About the Experiment

A Wi-Fi-enabled stopwatch with a 128×64 OLED, physical start/stop and reset buttons, and a browser dashboard showing minutes, seconds and hundredths. The local OLED and Wi-Fi interface work with the same ESP32 controller.

Components Required

ESP32 DevKitC V4

Controller and Wi-Fi

SSD1306 OLED Display

Elapsed-time display

Push Button (×2)

Start/stop and reset controls

Breadboard

Physical prototyping

Jumper Wires

Connections

Breadboard and jumper wires are included for physical assembly. Wi-Fi and a USB data cable are required for programming and browser access.

Circuit Diagram

Working Principle

Press START → ESP32 measures elapsed milliseconds → OLED + web dashboard → STOP / RESET

Procedure

  1. Install Adafruit GFX and Adafruit SSD1306 libraries.
  2. Connect start/stop and reset buttons to GPIO18 and GPIO19, respectively.
  3. Use the ESP32 web dashboard or the physical buttons.
  4. Read elapsed time in minutes, seconds and hundredths.
  5. Upload the sketch and open Serial Monitor at 115200 baud. Replace Wokwi-GUEST credentials when using real Wi-Fi.
