Aim

To develop a remote camera-monitoring system using an AI-Thinker ESP32-CAM with an SH1106 OLED display, enabling live MJPEG streaming, still-image capture, downloading, fullscreen viewing and system-status monitoring through a Wi-Fi web dashboard.

About the Experiment

The ESP32-CAM Remote Image Viewer allows users to view camera images wirelessly from a browser connected to the same network.

The AI-Thinker ESP32-CAM captures JPEG frames using its onboard camera. The frames are used for continuous MJPEG streaming and individual still-image capture.

The web server on port 80 serves the dashboard, JPEG capture and status endpoints. A separate TCP server on port 81 supplies the MJPEG image stream.

The SH1106 OLED displays initialization, Wi-Fi connection and IP-address information.

Important: This experiment is designed for a trusted local Wi-Fi network. It does not include authenticated camera access or encrypted streaming. Do not expose the camera or its control ports to the public internet.

Power and Programming:

Provide a stable supply suitable for the ESP32-CAM camera and Wi-Fi load. A USB-to-TTL programmer used for flashing must have 3.3V UART logic levels.

GPIO0 is connected to GND only for programming. Disconnect it and reset the board for normal camera operation.

Verify the OLED module's voltage rating and use compatible 3.3V I²C levels.

Camera Initialization

The ESP32-CAM configures its onboard camera for JPEG image capture.

MJPEG Streaming

The stream server sends successive JPEG images as an MJPEG multipart HTTP response on port 81.

Still Image Capture

When Capture Image is selected, the browser requests the /capture endpoint on port 80.

System Monitoring

The /status endpoint returns the camera's IP address, uptime and current stream state.

OLED Information

The OLED displays startup messages and the network IP address when Wi-Fi connects successfully.

Procedure

  1. Arrange the ESP32-CAM, SH1106 OLED, programmer, breadboard and jumper wires.
  2. Connect OLED SDA to GPIO13.
  3. Connect OLED SCL to GPIO14.
  4. Connect the OLED power and ground according to its specification.
  5. Connect programmer TX to ESP32-CAM RX.
  6. Connect programmer RX to ESP32-CAM TX.
  7. Connect the grounds together.
  8. Connect GPIO0 to GND during flashing.
  9. Open Arduino IDE.
  10. Install the ESP32 board package and U8g2 library.
  11. Select AI Thinker ESP32-CAM as the board.
  12. Copy the complete sketch from Explore the Code.
  13. Enter your Wi-Fi credentials.
  14. Verify and upload the sketch.
  15. Disconnect GPIO0 from GND.
  16. Restart the ESP32-CAM.
  17. Open Serial Monitor at 115200 baud.
  18. Observe the OLED status and IP address.
  19. Open the IP address from a browser on the same network.
  20. Verify the live MJPEG camera feed.
  21. Click Capture Image and check the JPEG preview.
  22. Click Download Image to save the captured photograph.
  23. Test Refresh Stream and Fullscreen.
  24. Observe the changing uptime value.

Result

The ESP32-CAM Remote Image Viewer demonstrates wireless camera monitoring using separate dashboard and MJPEG streaming services, with still-image capture, browser downloads, fullscreen preview and network status monitoring.

The SH1106 OLED displays connection information, enabling users to access the remote camera from another device on the same network.
