ESP32-CAM Experiment

ESP32-CAM Remote Image Viewer

← ESP32 Experiments Aim Components Connections Circuit Working Procedure Code Result

Aim

To view the ESP32-CAM remotely through Wi-Fi, display a live camera stream in a browser, capture still images and show system status on an OLED.

About the Experiment

The ESP32-CAM runs a web dashboard on port 80 and a live MJPEG stream server on port 81.

The OV2640 camera supplies live video and still JPEG captures, while a 1.3-inch SH1106 OLED displays device status.

The dashboard provides live viewing, capture, refresh and fullscreen controls.

Components Required

AI-Thinker ESP32-CAM (×1)

Main Wi-Fi camera controller.

1.3" I²C SH1106 OLED 128×64 (×1)

Displays system information.

USB-to-TTL / FTDI Adapter (×1)

Used to program the ESP32-CAM.

Jumper Wires (6–8)

Used for electrical connections.

Procedure

  1. Connect the USB-TTL adapter to 5V, GND, U0R and U0T.
  2. Connect GPIO 0 to GND during upload.
  3. Connect OLED SDA to GPIO 13 and SCL to GPIO 14.
  4. Upload the program to the AI-Thinker ESP32-CAM.
  5. Remove GPIO 0 from GND and press RESET.
  6. Open Serial Monitor and note the IP address.
  7. Open the IP address in a browser.
  8. Confirm the live camera feed appears.
  9. Use Capture Image, Refresh Stream and Fullscreen controls.

    U8G2_R0,
    U8X8_PIN_NONE,
    14,
    13

WebServer server(80);
WiFiServer streamServer(81);

void loop()
{
    server.handleClient();

    WiFiClient client =
    streamServer.available();

    if(client)
    {
        handleStreamClient(client);
    }
}

Expected Output

The web dashboard shows a live camera feed from the ESP32-CAM.

Port 81 supplies the MJPEG stream while port 80 serves the dashboard and capture/status routes.

A captured JPEG can be previewed in the dashboard.

The dashboard reports Wi-Fi connection, IP address, camera module, resolution and uptime.

Result

The ESP32-CAM Remote Image Viewer successfully provides wireless live video, still-image capture and system monitoring from a web browser.
