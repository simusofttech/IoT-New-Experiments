Aim

To view the ESP32-CAM remotely through Wi-Fi, display a live camera stream in a browser, capture still images and show system status on an OLED.

About the Experiment

The ESP32-CAM creates a Wi-Fi camera monitoring system that can be opened from a web browser on the same network.

Port 80 serves the dashboard, capture and status routes, while port 81 provides the live MJPEG camera stream.

The 1.3-inch SH1106 OLED displays startup, Wi-Fi and IP-address information so the system can be monitored locally as well as remotely.

Components Required

AI-Thinker ESP32-CAM with OV2640 (×1)

Main Wi-Fi camera controller used for live streaming and image capture.

Displays startup, Wi-Fi and IP-address information.

Procedure

  1. Connect the USB-to-TTL programmer: 5V to 5V, GND to GND, TX to U0R / GPIO 3 and RX to U0T / GPIO 1.
  2. Connect GPIO 0 to GND only while uploading the program.
  3. Connect the SH1106 OLED VCC to 3.3V, GND to GND, SDA to GPIO 13 and SCL to GPIO 14.
  4. Enter the Wi-Fi details in the program.
  5. Upload the program to the AI-Thinker ESP32-CAM.
  6. Remove GPIO 0 from GND and press RESET.
  7. Open Serial Monitor at 115200 baud and note the ESP32-CAM IP address.
  8. Open the IP address in a web browser on the same Wi-Fi network.
  9. Confirm that the live camera feed appears and test Capture Image, Refresh Stream and Fullscreen.

Expected Output

The browser dashboard displays the ESP32-CAM live camera feed.

Port 81 supplies the MJPEG stream while port 80 serves the dashboard, capture and status routes.

The Capture Image control returns a still JPEG that can be previewed in the dashboard.

The OLED shows startup, Wi-Fi connection and the ESP32-CAM IP address.

Result

The ESP32-CAM Remote Image Viewer successfully provides wireless live video, remote still-image capture and system-status monitoring from a web browser.

  • Displaying Wi-Fi and IP-address information on an OLED.
  • Building a browser-based remote camera monitoring interface.
