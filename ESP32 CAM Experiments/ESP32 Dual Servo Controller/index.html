Aim

To control two SG90 servo motors independently using an ESP32 DevKit V1 and a Wi-Fi web dashboard with angle sliders, preset positions, Center Both and Refresh controls.

About the Experiment

The ESP32 Dual Servo Controller demonstrates wireless control of two SG90 servo motors using a browser-based dashboard hosted directly by the ESP32.

The ESP32 generates servo control signals on GPIO13 and GPIO14. Each servo motor can be moved independently between 0° and 180°.

The dashboard provides separate sliders for the left and right motors. Each motor also has preset buttons for 0°, 90° and 180°.

The Center Both button commands both servo motors to their 90° center positions.

The Refresh button retrieves the currently commanded angles from the ESP32.

The browser displays a connection status based on whether its requests to the ESP32 succeed.

Important: The webpage displays the angles commanded to the servos. The experiment does not include a feedback sensor that measures their actual physical positions.

Additional Power Requirement:

Use a separate regulated 5V supply rated for the combined current required by both servo motors.

The servos must share a common ground with the ESP32.

Important Safety Instructions:

Power both SG90 servo motors using an external regulated 5V supply with adequate current capacity.

Do not power the two servos from the ESP32 3.3V pin.

Connect ESP32 GND and external supply GND together.

Servo motors can draw high startup and stall currents. Avoid forcing the servo arms against mechanical stops.

The 500–2400 µs pulse range used in the sketch should be checked against the actual servo specification. Not every SG90 unit supports the entire range without mechanical strain.

Procedure

  1. Arrange the ESP32 DevKit V1, two SG90 servo motors, breadboard and jumper wires.
  2. Connect the left servo signal wire to GPIO13.
  3. Connect the right servo signal wire to GPIO14.
  4. Connect both servo red wires to an external regulated +5V supply.
  5. Connect both servo ground wires to the external supply ground.
  6. Connect ESP32 GND to the external supply ground.
  7. Check all wiring before applying power.
  8. Open Arduino IDE and install the ESP32 board package.
  9. Install the ESP32Servo library.
  10. Create a sketch named ESP32_Dual_Servo_Controller.ino.
  11. Copy the complete program from Explore the Code.
  12. Enter your Wi-Fi SSID and password.
  13. Select the correct ESP32 board and serial port.
  14. Verify and upload the program.
  15. Open Serial Monitor at 115200 baud.
  16. Note the IP address printed by the ESP32.
  17. Connect your browser device to the same reachable network.
  18. Open the ESP32 IP address.
  19. Observe the Dual Servo Control dashboard.
  20. Move the left servo slider.
  21. Move the right servo slider.
  22. Test 0°, 90° and 180° presets as supported by the servos.
  23. Select Center Both and observe both motors moving to 90°.
  24. Select Refresh and verify both angle values.

Result

The ESP32 Dual Servo Controller demonstrates independent wireless control of two SG90 servo motors using an ESP32-hosted web dashboard.

Users can command individual servo angles using sliders or preset buttons, center both servos at 90°, and retrieve the current software angle values.
