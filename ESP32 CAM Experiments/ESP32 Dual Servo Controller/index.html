ESP32 Dual Servo Controller

Two servo motors controlled over a local Wi-Fi dashboard

← Back to Experiments Home

Aim

Control two SG90 servo motors independently using a Wi-Fi web dashboard hosted by ESP32.

About the Experiment

ESP32 serves a local webpage with two angle sliders, 0°, 90°, 180° presets, Center Both, Refresh and browser connection status.

Servo positions shown are commanded angles, not physical feedback.

Circuit Connections

Component Connection
Left SG90 signal (orange/yellow) ESP32 GPIO 13
Right SG90 signal (orange/yellow) ESP32 GPIO 14
Both servo red wires External regulated +5 V
Both servo brown/black wires External supply GND
ESP32 GND External supply GND (common ground)
Safety: Both servos need a regulated external 5V supply with adequate current. Never connect them to ESP32 3.3V. Disconnect power before changing wiring.

Circuit Diagram

Working Principle

Browser sliders / preset buttons → Wi-Fi → ESP32 HTTP server → GPIO 13 and GPIO 14 PWM → Two SG90 servos

The dashboard reads software angle values through /angles and sends new positions through /set.

Procedure

  1. Connect left servo signal to GPIO13 and right servo signal to GPIO14.
  2. Connect both servos to an external regulated 5V supply, and connect its ground to ESP32 GND.
  3. Install the ESP32 board support and ESP32Servo library in Arduino IDE.
  4. Replace the Wi-Fi placeholders in the sketch with your own 2.4 GHz network credentials.
  5. Select your ESP32 DevKit board and upload the code.
  6. Open Serial Monitor at 115200 baud and note the displayed IP address.
  7. Open that address in a browser on the same reachable network.
  8. Move sliders, test presets, Center Both and Refresh.

Check Your Understanding

Q: Why do both servos and ESP32 need a common ground?

A: The PWM control signals require a shared voltage reference.

Q: What does Refresh show?

A: The most recently commanded software angles, not actual shaft feedback.

Expected Output

The webpage shows separate left and right servo sliders and preset controls.

At startup both servos move to 90°. Changing either slider commands its servo to the selected angle between 0° and 180°.

Result

Two SG90 servos can be independently commanded through the ESP32 local Wi-Fi dashboard.

What You Learn

ESP32 web server programming, Wi-Fi communication, servo PWM signals, GPIO interfacing, common-ground wiring, browser controls and JSON API responses.
