Aim

To measure gas and smoke levels using an MQ-2 sensor and ESP32, display the live reading on an OLED display and monitor the sensor remotely through a Wi-Fi web dashboard.

About the Experiment

The MQ-2 gas sensor provides an analog reading to the ESP32. The ESP32 converts this reading into a percentage from 0% to 100%.

The system classifies the gas level as SAFE, WARNING or HIGH GAS.

The gas percentage, raw ADC reading and status are displayed on the OLED and on a Wi-Fi web dashboard.

Procedure

  1. Place the ESP32 on the breadboard.
  2. Connect MQ-2 VCC to ESP32 5V / VIN.
  3. Connect MQ-2 GND to ESP32 GND.
  4. Connect MQ-2 AO to GPIO 34.
  5. Leave the MQ-2 DO pin unconnected.
  6. Connect OLED VCC to ESP32 3.3V.
  7. Connect OLED GND to ESP32 GND.
  8. Connect OLED SDA to GPIO 21.
  9. Connect OLED SCL to GPIO 22.
  10. Open Arduino IDE.
  11. Install Adafruit GFX and Adafruit SSD1306 libraries.
  12. Upload the program to the ESP32.
  13. Open Serial Monitor at 115200 baud.
  14. Note the ESP32 IP address displayed in Serial Monitor.
  15. Open the IP address in a web browser.
  16. Observe the live MQ-2 gas level on the OLED and web dashboard.

Expected Output

The OLED displays the gas percentage, raw ADC value, gas status and Wi-Fi connection status.

The web dashboard displays the current gas level, sensor ADC value and MQ-2 sensor status.

The gas status changes between SAFE, WARNING and HIGH GAS depending on the measured value.

Result

The Wi-Fi Gas Sensor Data Logger Experiment was successfully implemented using an ESP32, MQ-2 gas sensor and SSD1306 OLED display.

The ESP32 continuously reads the gas sensor and displays the gas level locally on the OLED and remotely through a Wi-Fi web dashboard.
