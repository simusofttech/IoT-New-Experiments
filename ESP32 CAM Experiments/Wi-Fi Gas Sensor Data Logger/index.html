Aim

To measure changes in gas and smoke sensor readings using an MQ-2 sensor and ESP32, display the reading on an SSD1306 OLED, and monitor the sensor through a Wi-Fi web dashboard.

About the Experiment

The Wi-Fi Gas Sensor Data Logger demonstrates analog sensor measurement, ADC conversion, OLED interfacing and wireless monitoring using ESP32.

The MQ-2 gas sensor responds to changes in the concentration of certain combustible gases and smoke.

Its analog output is read by ESP32 GPIO34.

The ESP32 uses its 12-bit ADC to convert the analog signal into a numerical reading between 0 and 4095.

The program maps the ADC reading into a relative percentage between 0% and 100%.

Based on the percentage, the program displays one of three demonstration statuses: SAFE, WARNING or HIGH GAS.

The SSD1306 OLED shows the percentage, raw ADC value, gas status and Wi-Fi connection state.

The ESP32 also hosts a web dashboard that displays the sensor reading, status and current ADC value.

The browser dashboard refreshes automatically every two seconds, while the ESP32 samples the sensor approximately once every second.

Important Measurement Note:

The displayed percentage is calculated from the ADC value. It does not represent calibrated gas concentration or ppm.

The SAFE, WARNING and HIGH GAS labels are example classifications based on the relative ADC percentage. They must not be used as verified fire, smoke or gas-leak safety alarms.

MQ-2 readings require suitable sensor warm-up and calibration for meaningful concentration measurements.

MQ-2 Voltage Compatibility:

The uploaded circuit lists MQ-2 VCC at 5V and AO at GPIO34.

Many 5V MQ-2 modules can produce an AO voltage above the ESP32's maximum permissible GPIO input.

Before physically connecting AO, verify its output range and use appropriate voltage conditioning if required.

Never apply 5V directly to ESP32 GPIO34.

Analog Measurement

The MQ-2 provides an analog voltage that varies with the sensor response.

ADC Conversion

analogRead(GPIO34) produces a digital measurement in the configured 12-bit range.

Gas Percentage

map() scales the ADC value into a percentage between 0% and 100%.

Status Classification

The program assigns SAFE, WARNING or HIGH GAS according to the percentage thresholds.

OLED Monitoring

The OLED displays the percentage, ADC reading, gas status and Wi-Fi connection state.

Wireless Dashboard

The ESP32 web server provides a browser dashboard displaying the current reading.

Procedure

  1. Arrange the ESP32 DevKitC, MQ-2 sensor, SSD1306 OLED, breadboard and jumper wires.
  2. Place the ESP32 on the breadboard.
  3. Identify the MQ-2 VCC, GND, AO and DO pins.
  4. Verify the MQ-2 module's required power voltage.
  5. Connect MQ-2 VCC to the appropriate 5V / VIN supply specified for the module.
  6. Connect MQ-2 GND to ESP32 GND.
  7. Check the MQ-2 AO voltage range before connecting it to GPIO34.
  8. Provide a suitable 3.3V-safe signal to GPIO34.
  9. Leave MQ-2 DO unconnected.
  10. Connect OLED VCC to 3.3V.
  11. Connect OLED GND to GND.
  12. Connect OLED SDA to GPIO21.
  13. Connect OLED SCL to GPIO22.
  14. Verify all electrical connections.
  15. Open Arduino IDE.
  16. Install the ESP32 board package.
  17. Install Adafruit GFX and Adafruit SSD1306 libraries.
  18. Create the sketch WiFi_Gas_Sensor_Data_Logger.ino.
  19. Copy the complete program from Explore the Code.
  20. Configure Wi-Fi SSID and password.
  21. Select the correct ESP32 board and serial port.
  22. Verify and upload the program.
  23. Open Serial Monitor at 115200 baud.
  24. Wait for Wi-Fi connection.
  25. Note the ESP32 IP address.
  26. Open that IP address in a browser connected to the same network.
  27. Observe gas sensor values on OLED and web dashboard.
  28. Observe the readings after an appropriate MQ-2 warm-up period.

Explore More: ADC

The ESP32's 12-bit ADC produces values from 0 to 4095.

The program converts the reading to a percentage using map().

Explore More: MQ-2 Sensor

The MQ-2 sensor contains a heated sensing element. Its analog output varies with environmental exposure.

It must be warmed up and calibrated for any meaningful concentration estimate.

Explore More: Status Thresholds

Values below 30% display SAFE. Values from 30% to 69% display WARNING.

Values of 70% and above display HIGH GAS.

These are example ADC thresholds, not validated gas safety limits.

Explore More: Web Dashboard

The ESP32 hosts an HTTP webpage that presents the sensor reading and current status.

The webpage refreshes every two seconds.

Result

The Wi-Fi Gas Sensor Data Logger demonstrates analog sensor monitoring using an ESP32, MQ-2 sensor and SSD1306 OLED.

The ESP32 converts the MQ-2 ADC reading into a relative percentage and assigns a demonstration status.

The reading is displayed on the OLED and Serial Monitor and is available through the Wi-Fi web dashboard.
