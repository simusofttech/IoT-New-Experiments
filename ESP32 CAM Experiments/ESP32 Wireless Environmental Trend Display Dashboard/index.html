ESP32 Wireless Environmental Trend Display Dashboard

Sensor readings, OLED monitoring and a wireless web dashboard

Arduino ESP32 R-Pi

Aim

To build a wireless environmental monitoring dashboard using an ESP32, DHT22, BMP180, LDR module and I2C OLED, with readings available on a local web page.

About the Experiment

The ESP32 gathers temperature and humidity from a DHT22, barometric pressure from a BMP180 and ambient light level from an LDR module. It shows key values on an OLED and hosts a web dashboard with an additional JSON data endpoint.

SOP clarification: The LM35 is included and connected to GPIO34 in the provided circuit, but the supplied sketch does not read GPIO34. The displayed temperature comes from the DHT22. The sketch uses the Wokwi-GUEST Wi-Fi network; for a physical setup, replace the credentials with your own Wi-Fi network.

Circuit Connections

Component pinsESP32 connections
DHT22 VCC / GND / DATA3V3 / GND / GPIO4
BMP180 VCC / GND / SDA / SCL3V3 / GND / GPIO21 / GPIO22
OLED VCC / GND / SDA / SCL3V3 / GND / GPIO21 / GPIO22
LDR VCC / GND / AO3V3 / GND / GPIO35
LM35 VCC / GND / OUT3V3 / GND / GPIO34 (wired but not read by supplied sketch)

All sensor grounds must share the ESP32 ground. The BMP180 and OLED share the I2C bus (SDA GPIO21, SCL GPIO22).

Working Principle

Sensor measurements → ESP32 processing → OLED display → Wi-Fi web server → Browser dashboard / JSON data

Every two seconds, the ESP32 refreshes sensor readings and updates the OLED. The web server responds to requests at / and /data.

Procedure

  1. Place the ESP32 and sensors on the breadboard and connect each pin according to the table.
  2. Connect the OLED and BMP180 to the shared I2C bus.
  3. Install the ESP32 board package and the U8g2, DHT and Adafruit BMP085 libraries in Arduino IDE.
  4. Replace the sample Wi-Fi credentials when using real hardware.
  5. Upload the supplied sketch to the ESP32 and open Serial Monitor at 115200 baud.
  6. Note the IP address shown after Wi-Fi connection.
  7. Open that IP address in a browser on the same network to view the dashboard; append /data to view JSON readings.
  8. Change temperature, humidity and light conditions to observe the responses.

Check Your Understanding

Q1. Which GPIO receives DHT22 data? GPIO4

Q2. Which two devices share the I2C bus? BMP180 and OLED

Q3. Does the current code read the LM35? No; it reads temperature from DHT22.

Expected Output

The OLED shows temperature, humidity and light percentage. The browser displays temperature, humidity, pressure and light readings; the /data endpoint provides the same values as JSON. The Serial Monitor reports the device's IP address after connecting to Wi-Fi.

Result

The ESP32 environmental dashboard demonstrates sensor interfacing, local display output and wireless monitoring through a web server.

What You Learn

  • Understanding the difference between connected hardware and code-enabled readings.
