Aim

To develop a Smart Decision Maker using an ESP32 development board, SSD1306 OLED display, three push buttons and two indicator LEDs. The system allows users to browse a predefined list of activities, shortlist preferred activities and randomly choose one from the shortlisted options.

About the Experiment

The Smart Decision Maker is an interactive ESP32-based experiment demonstrating digital input handling, OLED interfacing, selection logic, random number generation and visual output indications.

Six activities are stored in the program: Study, Exercise, Read a book, Take a break, Learn coding, and Go for a walk.

Three push buttons control the experiment. NEXT browses the activity list, SELECT adds an activity to the shortlist, and DECIDE randomly chooses one of the shortlisted activities.

The red LED provides feedback when an activity is added to the shortlist. The green LED activates when a decision is successfully generated.

Activity Browsing

The program stores six predefined activities in an array. Every NEXT button press advances the current activity index. After the last activity, browsing returns to the first.

Activity Shortlisting

Pressing SELECT marks the displayed activity as selected. A boolean array prevents duplicate selections.

Random Decision

When DECIDE is pressed, the ESP32 generates a random index within the number of shortlisted activities and locates the matching choice.

LED Feedback

The red LED indicates successful shortlisting. The green LED turns on when the ESP32 successfully makes a decision.

OLED Feedback

The OLED displays the current activity, the selection status, feedback messages and the final randomly chosen activity.

Procedure

  1. Arrange the ESP32 development board, OLED, three push buttons, two LEDs, two 220Ω resistors, breadboard and jumper wires.
  2. Connect OLED VCC to 3V3 and GND to GND.
  3. Connect OLED SDA to GPIO21.
  4. Connect OLED SCL to GPIO22.
  5. Connect NEXT button between GPIO18 and GND.
  6. Connect SELECT button between GPIO19 and GND.
  7. Connect DECIDE button between GPIO23 and GND.
  8. Connect GPIO25 to the green LED through a 220Ω resistor.
  9. Connect GPIO26 to the red LED through a 220Ω resistor.
  10. Connect both LED cathodes to GND.
  11. Verify wiring and common ground.
  12. Open Arduino IDE.
  13. Install ESP32 board support and the U8g2 library.
  14. Select the appropriate ESP32 development board.
  15. Create a new sketch named Smart_Decision_Maker.ino.
  16. Copy the complete program from Explore the Code.
  17. Verify and upload the sketch.
  18. Open Serial Monitor at 115200 baud.
  19. Observe the first activity on the OLED.
  20. Press NEXT to cycle through the six activities.
  21. Press SELECT to shortlist an activity.
  22. Observe the red LED and selection message.
  23. Shortlist two or more different activities.
  24. Press DECIDE to select one randomly.
  25. Observe the final decision and green LED.
  26. Repeat the experiment with different shortlisted activities.

Explore More: INPUT_PULLUP

Each push button uses the ESP32 internal pull-up. The input reads HIGH normally and LOW when pressed.

Explore More: Arrays

The options array stores six activities. The picked array records which activities have been shortlisted.

Explore More: Random Selection

The random() function generates an index into the shortlisted activities. The sketch then finds and displays that choice.

Explore More: Button Debouncing

The code uses a 60-millisecond interval to reduce repeated actions caused by mechanical button contact bounce.

Result

The Smart Decision Maker experiment demonstrates button-controlled activity browsing, shortlisting and pseudorandom decision making using an ESP32 development board.

The SSD1306 OLED displays activity choices and final decisions, while red and green LEDs indicate shortlist and decision operations.
