Aim

To create a Wi-Fi based light intensity monitoring system using an ESP32 and LDR sensor that measures ambient light, displays the reading on an OLED and shows the live data on a web dashboard.

About the Experiment

In this Experiment, the LDR sensor module measures the surrounding light intensity.

The ESP32 reads the analog output of the sensor through GPIO 34.

The raw ADC value is converted into a percentage from 0% to 100%.

The light level is then classified as DARK, DIM, BRIGHT or VERY BRIGHT.

Procedure

  1. Place the ESP32 on the breadboard.
  2. Connect LDR module VCC to ESP32 3.3V.
  3. Connect LDR module GND to ESP32 GND.
  4. Connect LDR module AO to GPIO 34.
  5. Connect OLED VCC to ESP32 3.3V.
  6. Connect OLED GND to ESP32 GND.
  7. Connect OLED SDA to GPIO 21.
  8. Connect OLED SCL to GPIO 22.
  9. Open Arduino IDE.
  10. Install Adafruit GFX library.
  11. Install Adafruit SSD1306 library.
  12. Upload the program to the ESP32.
  13. Open Serial Monitor at 115200 baud.
  14. Wait for the ESP32 to connect to Wi-Fi.
  15. Note the ESP32 IP address.
  16. Open the IP address in a web browser.
  17. Cover the LDR sensor with your hand.
  18. Observe the light percentage decrease.
  19. Expose the sensor to more light.
  20. Observe the light percentage increase.
  21. Compare DARK, DIM, BRIGHT and VERY BRIGHT conditions.

Expected Output

The OLED displays:

  • Light intensity percentage
  • Graphical progress bar
  • DARK, DIM, BRIGHT or VERY BRIGHT status

The web dashboard displays:

  • Raw LDR ADC value
  • Light level percentage
  • Light condition
  • Description of the detected light
  • Wi-Fi connection status

Result

The Wi-Fi Light Intensity Monitor Experiment successfully measures ambient light using an LDR sensor module connected to ESP32.

The light intensity is displayed as a percentage on the OLED and can also be monitored through the Wi-Fi dashboard.
