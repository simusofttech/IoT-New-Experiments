Aim

To develop a Wi-Fi-based light intensity monitoring system using ESP32 DevKitC and an LDR Light Sensor Module.

The system measures changes in ambient light, displays the relative light percentage and status on an SSD1306 OLED, and publishes live readings through a Wi-Fi dashboard.

About the Experiment

The Wi-Fi Light Intensity Monitor demonstrates analog sensor interfacing and wireless monitoring using an ESP32.

An LDR, or Light Dependent Resistor, changes its resistance according to the light falling on it.

The LDR Sensor Module converts this change into an analog voltage.

The module's AO pin connects to ESP32 GPIO34. The ESP32 reads the signal using its Analog-to-Digital Converter (ADC).

A 12-bit ADC reading is represented by values from 0 to 4095.

The program maps the raw reading into a percentage between 0% and 100%.

The percentage is classified into DARK, DIM, BRIGHT and VERY BRIGHT.

The SSD1306 OLED displays the percentage, a graphical progress bar and the current condition.

The ESP32 also hosts a wireless dashboard showing the raw ADC value, percentage, light status and description.

Measurement Note:

The percentage is derived from the LDR module's analog output.

It is a relative measurement, not a calibrated illuminance reading in lux.

The direction of the reading depends on the module's voltage-divider circuit.

The original program assumes mapped ADC values increase as the light level increases.

Important:

GPIO34 is an input-only GPIO suitable for analog measurements.

Power the LDR module from 3.3V so that its output remains within the ESP32's acceptable input voltage range.

GPIO21 and GPIO22 are used for OLED I²C communication.

LDR Sensor Operation

The LDR module produces an analog voltage that changes according to ambient light.

ADC Measurement

The ESP32 reads the analog value on GPIO34 using analogRead().

With 12-bit ADC resolution, the raw reading range is 0 to 4095.

Percentage Calculation

The map() function converts the raw ADC reading into a percentage. 

Light Percentage =
map(ADC Value, 0, 4095, 0, 100)

Light Classification

The program compares the percentage against predefined thresholds to classify DARK, DIM, BRIGHT and VERY BRIGHT conditions.

OLED Display

The OLED displays the current percentage, progress bar and light condition.

Wi-Fi Web Dashboard

ESP32 runs a web server on port 80.

The browser opens the dashboard using the ESP32 IP address.

JavaScript retrieves readings from the /data endpoint.

Update Intervals

The OLED refreshes approximately every 500 milliseconds.

The dashboard requests updated data every 1000 milliseconds.

Procedure

  1. Arrange ESP32 DevKitC V4, LDR Light Sensor Module, SSD1306 OLED, breadboard and jumper wires.
  2. Place the ESP32 on the breadboard.
  3. Connect LDR VCC to ESP32 3.3V.
  4. Connect LDR GND to ESP32 GND.
  5. Connect LDR AO to GPIO34.
  6. Connect OLED VCC to 3.3V.
  7. Connect OLED GND to GND.
  8. Connect OLED SDA to GPIO21.
  9. Connect OLED SCL to GPIO22.
  10. Verify all circuit connections.
  11. Open Arduino IDE.
  12. Install the ESP32 board package.
  13. Install Adafruit GFX and Adafruit SSD1306 libraries.
  14. Create a sketch named WiFi_Light_Intensity_Monitor.ino.
  15. Copy the full program from Explore the Code.
  16. Configure Wi-Fi SSID and password.
  17. Select the correct ESP32 board and port.
  18. Verify and upload the sketch.
  19. Open Serial Monitor at 115200 baud.
  20. Wait for Wi-Fi connection.
  21. Note the ESP32 IP address.
  22. Open the IP address in a web browser on the same network.
  23. Observe the light percentage on OLED.
  24. Cover the LDR with your hand.
  25. Observe ADC, percentage and status changes.
  26. Expose the sensor to more light.
  27. Observe changes on OLED and web dashboard.
  28. Test DARK, DIM, BRIGHT and VERY BRIGHT conditions.
