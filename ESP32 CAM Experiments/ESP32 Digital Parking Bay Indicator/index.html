Aim

To create a two-bay parking indicator using an ESP32 DevKitC and two ultrasonic sensors to determine whether parking spaces are available or occupied.

Green and red LEDs indicate each bay's condition, while an SSD1306 OLED displays parking status, measured distance and the total number of free spaces.

About the Experiment

The Digital Parking Bay Indicator demonstrates distance-based vehicle detection using two HC-SR04 ultrasonic sensors connected to ESP32.

Each ultrasonic sensor transmits a short ultrasonic pulse and measures the time taken for its echo to return.

The ESP32 converts this time into distance and compares it with an 8 cm threshold.

When an object is detected closer than 8 cm, the corresponding parking bay is marked OCCUPIED and its red LED turns ON.

Otherwise, the bay is marked AVAILABLE and its green LED turns ON.

The ESP32 also counts the number of occupied bays and calculates the remaining free parking spaces.

The SSD1306 OLED displays the bay status, Bay 1 distance and free-space count. The Serial Monitor provides distance readings for both bays.

Detection Rule:

Distance below 8 cm: OCCUPIED.

Distance of 8 cm or more: AVAILABLE.

A missing ultrasonic echo is represented as 999 cm in the supplied program and treated as AVAILABLE.

Parking Bay Conditions

AVAILABLE

Object distance is 8 cm or greater.

Green LED ON

Red LED OFF

OCCUPIED

Object distance is less than 8 cm.

Important Hardware Notes:

Standard HC-SR04 sensors powered from 5V can output approximately 5V on their ECHO pins.

Use suitable level shifting or voltage dividers to keep GPIO18 and GPIO21 signals within the ESP32's 3.3V limit.

The original source's pin table listed GPIO14 for Bay 2's red LED, while the actual sketch uses GPIO17. This version follows GPIO17.

GPIO5 is an ESP32 boot strapping pin. The connected circuit must not force an incompatible boot level.

Distance Measurement

The ESP32 sends a 10-microsecond trigger pulse to each ultrasonic sensor. The sensor returns an ECHO pulse representing the measured distance. 

Distance (cm) =
Echo duration (microseconds) × 0.0343 / 2

Parking Decision

The ESP32 compares the measured distance with the programmed 8 cm threshold. A value below 8 cm means OCCUPIED.

LED Indication

Each bay has one green and one red LED. Only the LED representing the selected parking state is turned ON.

Free Space Calculation

The number of occupied bays is subtracted from the total of two bays. 

Free Spaces = 2 - Occupied Bays

OLED Monitoring

The OLED displays the condition of both parking bays, the Bay 1 distance and the total number of free spaces.

Serial Monitoring

The Serial Monitor prints the distances and statuses of both bays and the available-space count.

Procedure

  1. Arrange the ESP32, two HC-SR04 sensors, four LEDs, four 220 Ω resistors, OLED, breadboard and jumper wires.
  2. Place the ESP32 on the breadboard.
  3. Connect Sensor 1 TRIG to GPIO5.
  4. Connect Sensor 1 ECHO to GPIO18 through suitable level shifting.
  5. Connect Sensor 2 TRIG to GPIO19.
  6. Connect Sensor 2 ECHO to GPIO21 through suitable level shifting.
  7. Connect the ultrasonic sensors to their appropriate 5V supply and common GND.
  8. Connect Bay 1 green LED to GPIO25 using a 220 Ω resistor.
  9. Connect Bay 1 red LED to GPIO26 using a 220 Ω resistor.
  10. Connect Bay 2 green LED to GPIO27 using a 220 Ω resistor.
  11. Connect Bay 2 red LED to GPIO17 using a 220 Ω resistor.
  12. Connect all LED cathodes to GND.
  13. Connect OLED VCC to 3.3V and OLED GND to GND.
  14. Connect OLED SDA to GPIO23.
  15. Connect OLED SCL to GPIO22.
  16. Verify the complete circuit and voltage compatibility.
  17. Open Arduino IDE and install the ESP32 board package.
  18. Install the U8g2 library.
  19. Create the sketch named ESP32_Digital_Parking_Bay_Indicator.ino.
  20. Copy the program from Explore the Code.
  21. Select the correct ESP32 board and port.
  22. Verify and upload the sketch.
  23. Open Serial Monitor at 115200 baud.
  24. Observe the OLED startup message.
  25. Place an object within 8 cm of Sensor 1.
  26. Observe Bay 1 become OCCUPIED and its red LED turn ON.
  27. Remove the object and observe the green LED turn ON.
  28. Repeat the test for Sensor 2.
  29. Place objects in front of both sensors.
  30. Observe the total free-space count change from 2 to 0.
  31. Remove both objects and verify that both bays return to AVAILABLE.

Result

The Digital Parking Bay Indicator demonstrates two-bay parking detection using an ESP32 and two HC-SR04 ultrasonic sensors.

Each bay is classified as AVAILABLE or OCCUPIED using an 8 cm distance threshold.

Green and red LEDs represent the parking status, while the OLED and Serial Monitor display the available parking information.
