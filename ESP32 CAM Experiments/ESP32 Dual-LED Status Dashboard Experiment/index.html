Aim

To create a Wi-Fi-based ESP32 control system that independently switches two LEDs ON and OFF from a web dashboard while displaying their current status on an OLED display.

About the Experiment

This experiment uses an ESP32 to control two LEDs through a wireless web dashboard.

The red LED is connected to GPIO18 and the green LED is connected to GPIO19.

Both LEDs use individual 220 Ω resistors to limit current.

The SSD1306 OLED displays the ON/OFF condition of both LEDs and the Wi-Fi connection status.

The ESP32 hosts an HTTP web server on port 80.

When the user opens the ESP32 IP address, a Dual-LED Control Dashboard appears.

The dashboard provides independent TURN ON and TURN OFF buttons for both LEDs.

Commands are sent through HTTP requests. The ESP32 changes the corresponding GPIO and updates the OLED display.

The dashboard also requests LED status every second to keep the displayed information synchronized.

Important:

Each LED uses its own 220 Ω resistor. Do not connect the LEDs directly to the ESP32 GPIO pins without current-limiting resistors.

The OLED is powered from 3.3V and communicates using I²C.

Digital Output

GPIO18 and GPIO19 operate as digital outputs. HIGH turns the corresponding LED ON, while LOW turns it OFF.

Wi-Fi Connection

The ESP32 joins the configured wireless network using WiFi.begin().

Web Server

The ESP32 creates an HTTP web server on port 80.

Independent LED Control

The web dashboard provides individual ON and OFF buttons for both LEDs.

OLED Display

Whenever a command changes an LED state, the OLED is refreshed with the current status of LED 1, LED 2 and Wi-Fi.

Live Dashboard

JavaScript requests the /status endpoint every second to synchronize the displayed ON/OFF indicators.

Procedure

  1. Arrange the ESP32 DevKitC V4, red LED, green LED, two 220 Ω resistors, SSD1306 OLED, breadboard and jumper wires.
  2. Place the ESP32 on the breadboard.
  3. Connect the red LED anode to GPIO18 through one 220 Ω resistor.
  4. Connect the red LED cathode to GND.
  5. Connect the green LED anode to GPIO19 through the second 220 Ω resistor.
  6. Connect the green LED cathode to GND.
  7. Connect OLED VCC to 3.3V.
  8. Connect OLED GND to GND.
  9. Connect OLED SDA to GPIO21.
  10. Connect OLED SCL to GPIO22.
  11. Verify all connections.
  12. Open Arduino IDE.
  13. Install the ESP32 board package.
  14. Install the Adafruit GFX and Adafruit SSD1306 libraries.
  15. Create the sketch ESP32_Dual_LED_Status_Dashboard.ino.
  16. Copy the complete program from Explore the Code.
  17. Configure the Wi-Fi SSID and password.
  18. Select the correct ESP32 board and port.
  19. Verify and upload the program.
  20. Open Serial Monitor at 115200 baud.
  21. Wait for ESP32 to connect to Wi-Fi.
  22. Note the IP address displayed in Serial Monitor.
  23. Open the IP address in a browser connected to the same network.
  24. Observe the Dual-LED Dashboard.
  25. Press TURN ON for LED 1.
  26. Observe the red LED illuminate.
  27. Press TURN OFF for LED 1.
  28. Observe the red LED switch OFF.
  29. Repeat the test for LED 2.
  30. Turn both LEDs ON together.
  31. Observe the OLED and dashboard status.
  32. Turn both LEDs OFF.

Dashboard

Result

The ESP32 Dual-LED Status Dashboard allows two LEDs to be controlled independently through a Wi-Fi web interface.

The red LED on GPIO18 and green LED on GPIO19 respond to separate ON/OFF commands.

The SSD1306 OLED displays the status of both LEDs and the Wi-Fi connection.

The web dashboard continuously retrieves the latest LED states from the ESP32.
