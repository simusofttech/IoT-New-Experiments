Aim

To create a Wi-Fi based ESP32 control system that independently switches two LEDs ON and OFF from a web dashboard while displaying their current status on an OLED display.

About the Experiment

This Experiment uses an ESP32 to control two LEDs through a wireless web dashboard.

The first LED is connected to GPIO 18 and the second LED is connected to GPIO 19.

The SSD1306 OLED displays the ON/OFF condition of both LEDs and the Wi-Fi connection status.

Procedure

  1. Place the ESP32 on the breadboard.
  2. Connect the Red LED anode to GPIO 18 through a 220 Ω resistor.
  3. Connect the Red LED cathode to GND.
  4. Connect the Green LED anode to GPIO 19 through a 220 Ω resistor.
  5. Connect the Green LED cathode to GND.
  6. Connect OLED VCC to ESP32 3.3V.
  7. Connect OLED GND to ESP32 GND.
  8. Connect OLED SDA to GPIO 21.
  9. Connect OLED SCL to GPIO 22.
  10. Open Arduino IDE.
  11. Install Adafruit GFX and Adafruit SSD1306 libraries.
  12. Upload the program to ESP32.
  13. Open Serial Monitor at 115200 baud.
  14. Wait for the ESP32 to connect to Wi-Fi.
  15. Note the IP address shown in Serial Monitor.
  16. Open that IP address in a browser connected to the same Wi-Fi network.
  17. Press TURN ON or TURN OFF for LED 1.
  18. Repeat the test for LED 2.
  19. Observe the physical LEDs, OLED display and dashboard status.

Explore more: web control

The ESP32 runs a web server on port 80.

When a button on the dashboard is pressed, the browser sends a request such as:

/led1/on or /led2/off

The ESP32 receives the request and changes the corresponding GPIO output.

Result

The ESP32 Dual-LED Status Dashboard Experiment successfully controls two LEDs independently through a Wi-Fi web interface.

The OLED continuously displays the state of LED 1, LED 2 and the ESP32 Wi-Fi connection.
