Aim

To create a touch-sensitive interface using an ESP32 and TTP223 capacitive touch sensor that detects each new touch and displays the touch status and total number of touches on an OLED display.

About the Experiment

The Touch Button Interface demonstrates capacitive touch sensing and digital input detection using an ESP32 microcontroller.

The TTP223 capacitive touch sensor operates like an electronic push button.

When the touch pad is touched, its digital output becomes HIGH.

The ESP32 detects this signal through GPIO4.

The OLED displays READY when the touch sensor is inactive.

When a touch is detected, the display shows ACTIVE and a simple touch animation.

The program also counts how many new touch events have occurred.

It increases the counter only when the input changes from LOW to HIGH.

This prevents a continuously held touch from being counted repeatedly.

Touch Detection:

Sensor output LOW: no touch detected.

Sensor output HIGH: touch detected.

Every LOW-to-HIGH transition increases the touch counter by one.

Touch Status

○

READY

The sensor is waiting for the user to touch the pad.

GPIO4: LOW

●

ACTIVE

A finger is touching the capacitive sensor.

GPIO4 is an ESP32 strapping pin. Ensure the external circuit does not interfere with boot operation.

Verify the OLED controller before uploading the program. The supplied sketch uses an SSD1306 U8g2 constructor, whereas the component description identifies SH1106.

Capacitive Touch Detection

The TTP223 sensor detects changes in capacitance when a finger approaches or touches its pad.

Digital Input

The ESP32 reads GPIO4 using digitalRead().

Touch Event Detection

The program compares the current touch state with the previous touch state.

A LOW-to-HIGH transition is interpreted as a new touch event.

Touch Counting

Each new touch increases the touchCount variable by one.

OLED Status

READY appears when the sensor is not being touched.

ACTIVE appears when the sensor detects a touch.

Touch Animation

The animation changes every 500 milliseconds using millis().

ON / OFF Indicator

The OLED displays ON during a touch and OFF when the sensor is inactive.

Procedure

  1. Arrange the ESP32 DevKitC, TTP223 touch sensor, OLED, breadboard and jumper wires.
  2. Place the ESP32 on the breadboard.
  3. Connect TTP223 VCC to ESP32 3.3V.
  4. Connect TTP223 GND to ESP32 GND.
  5. Connect TTP223 OUT to GPIO4.
  6. Connect OLED VCC to ESP32 3.3V.
  7. Connect OLED GND to ESP32 GND.
  8. Connect OLED SDA to GPIO21.
  9. Connect OLED SCL to GPIO22.
  10. Check all connections.
  11. Open Arduino IDE.
  12. Install the ESP32 board package.
  13. Install the U8g2 library.
  14. Verify that the selected OLED driver matches the actual display.
  15. Create the sketch ESP32_Touch_Button_Interface.ino.
  16. Copy the complete program from Explore the Code.
  17. Select the correct ESP32 board and port.
  18. Verify and upload the program.
  19. Open Serial Monitor at 115200 baud.
  20. Observe the initial OLED startup screen.
  21. Touch the TTP223 sensor.
  22. Observe READY change to ACTIVE.
  23. Observe the touch counter increase.
  24. Hold your finger on the sensor and confirm the counter does not continuously increase.
  25. Release the touch sensor.
  26. Observe the display return to READY.
  27. Repeat the touch several times and observe the updated count.

Result

The Touch Button Interface demonstrates digital touch detection using an ESP32 and TTP223 capacitive touch sensor.

The sensor output is monitored through GPIO4.

The OLED displays READY or ACTIVE, an animated touch indicator, the ON/OFF state and the total number of touch events.

A new touch is counted when the input changes from LOW to HIGH.
