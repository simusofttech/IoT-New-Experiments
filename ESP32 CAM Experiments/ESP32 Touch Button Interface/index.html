Aim

To create a touch-sensitive interface using an ESP32 and TTP223 touch sensor that detects each touch and displays the touch status and total number of touches on an OLED display.

About the Experiment

In this Experiment, the TTP223 capacitive touch sensor acts like a digital button.

When the sensor is touched, its output becomes HIGH and the ESP32 detects the touch through GPIO 4.

The OLED displays whether the touch sensor is READY or ACTIVE and also shows the total number of touches.

Procedure

  1. Place the ESP32 on the breadboard.
  2. Connect TTP223 VCC to ESP32 3.3V.
  3. Connect TTP223 GND to ESP32 GND.
  4. Connect TTP223 OUT to GPIO 4.
  5. Connect OLED VCC to ESP32 3.3V.
  6. Connect OLED GND to ESP32 GND.
  7. Connect OLED SDA to GPIO 21.
  8. Connect OLED SCL to GPIO 22.
  9. Open Arduino IDE.
  10. Install the U8g2 library.
  11. Upload the program to ESP32.
  12. Open Serial Monitor at 115200 baud.
  13. Touch the TTP223 sensor.
  14. Observe the OLED change from READY to ACTIVE.
  15. Observe the touch count increase after every new touch.
  16. Release the sensor and observe the status return to READY.

The program increases the touch counter only when the sensor changes from LOW to HIGH.

This prevents one long touch from being counted many times.

Result

The ESP32 Touch Button Interface Experiment successfully detects touch input from the TTP223 sensor.

The OLED displays the current touch condition, an animated touch indicator and the total number of touches detected.
