Aim

To develop a motion-activated snapshot system using an AI-Thinker ESP32-CAM, HC-SR501 PIR motion sensor, active buzzer and SSD1306 OLED display. The system automatically captures a JPEG image when motion is detected and provides manual capture and image viewing through a Wi-Fi dashboard.

About the Experiment

The Motion Snapshot System is a camera-based monitoring experiment that automatically records a snapshot whenever a new motion event is detected by an HC-SR501 PIR sensor.

The PIR sensor is connected to GPIO13. When its output becomes HIGH, the ESP32-CAM detects the event, activates a buzzer connected to GPIO12 and captures a JPEG photograph using its onboard camera.

A 1.3-inch SSD1306 OLED displays startup, Wi-Fi, motion detection and snapshot status. The OLED uses GPIO14 for SDA and GPIO15 for SCL.

The latest successfully captured photograph is stored temporarily in the ESP32-CAM's memory. A web dashboard makes the latest image available to devices connected to the same Wi-Fi network.

Users can also capture an image manually using the Capture Now button. The dashboard displays device status, motion state and the total number of successful captures.

Important:

Only the latest successful JPEG image is retained in memory. Each new image replaces the previous one. This sketch does not archive photographs permanently on a memory card.

A five-second cooldown is applied between automatic motion-triggered captures. Continuous motion that keeps the PIR output HIGH is treated as one motion event.

Hardware Precautions:

GPIO12 and GPIO15 are boot-strapping pins on the ESP32. External components must not force inappropriate logic levels during startup or uploading.

The PIR output connected to GPIO13 must remain within the ESP32's 3.3V GPIO input limits. Check the actual HC-SR501 module.

Ensure the buzzer is suitable for 3.3V GPIO control. If it requires higher current, use an appropriate transistor driver.

Use a stable supply for the ESP32-CAM and camera. USB-to-TTL serial signals must use 3.3V logic levels.

PIR Motion Detection

The HC-SR501 PIR sensor detects changes in infrared radiation caused by movement.

When the PIR output changes from LOW to HIGH, the controller identifies a new motion event.

Buzzer Alert

After detecting a valid motion event, the active buzzer produces two short alert beeps.

JPEG Snapshot

The onboard camera captures a JPEG frame. The ESP32-CAM copies the image into memory and updates the capture counter.

OLED Status

The SSD1306 OLED displays system startup, Wi-Fi status, motion detection and capture confirmation.

Web Dashboard

The web dashboard retrieves the most recent image using the /image endpoint. The /capture endpoint allows manual photographs.

Procedure

  1. Arrange the ESP32-CAM, HC-SR501 PIR sensor, buzzer, OLED, programmer, breadboard and jumper wires.
  2. Connect the PIR sensor output to GPIO13.
  3. Connect PIR VCC to its supported supply and GND to common ground.
  4. Connect the buzzer control to GPIO12 using a suitable driver if required.
  5. Connect OLED SDA to GPIO14.
  6. Connect OLED SCL to GPIO15.
  7. Connect the OLED power and ground pins.
  8. Connect the USB-to-TTL programmer to the ESP32-CAM.
  9. Connect GPIO0 to GND during uploading.
  10. Open Arduino IDE.
  11. Install the ESP32 board package.
  12. Install Adafruit GFX and Adafruit SSD1306 libraries.
  13. Select AI Thinker ESP32-CAM.
  14. Create a sketch named ESP32_CAM_Motion_Snapshot_System.ino.
  15. Copy the complete program from Explore the Code.
  16. Enter the correct Wi-Fi SSID and password.
  17. Verify and upload the program.
  18. Disconnect GPIO0 from GND and restart the ESP32-CAM.
  19. Open Serial Monitor at 115200 baud.
  20. Allow the PIR sensor time to stabilize after power-up.
  21. Note the ESP32-CAM IP address.
  22. Open the IP address in a browser on the same Wi-Fi network.
  23. Move in front of the PIR sensor.
  24. Observe the buzzer alert and OLED status.
  25. Verify the latest captured image on the dashboard.
  26. Press Capture Now to take a manual photograph.
  27. Press Refresh to update the displayed information.
  28. Repeat the motion test and observe the capture counter.

Explore More: Capture Cooldown

A five-second cooldown limits repeated automatic captures. The PIR signal must return LOW before a new rising-edge event can trigger another capture.

Result

The Motion Snapshot System demonstrates automatic motion-triggered JPEG capture using an HC-SR501 PIR motion sensor and AI-Thinker ESP32-CAM.

The buzzer provides an audible alert, the SSD1306 OLED displays operating information, and the Wi-Fi dashboard provides access to the latest captured photograph and manual capture controls.
