ESP32-CAM Motion Snapshot System

Aim

To detect motion using an HC-SR501 PIR sensor and automatically capture a snapshot using the ESP32-CAM, while providing buzzer, OLED and Wi-Fi web-dashboard feedback.

About the Experiment

The HC-SR501 PIR sensor detects movement and sends its output to GPIO 13 of the ESP32-CAM.

When motion is detected, the buzzer connected to GPIO 12 gives an alert and the OV2640 camera captures a JPEG snapshot.

The latest image is stored in memory and can be viewed from a Wi-Fi web dashboard. The OLED displays Wi-Fi, motion and capture status.

Procedure

  1. Connect OLED VCC to 3.3V, GND to GND, SDA to GPIO 14 and SCL to GPIO 15.
  2. Connect the HC-SR501 PIR sensor VCC to 5V, GND to GND and OUT to GPIO 13.
  3. Connect the buzzer positive pin to GPIO 12 and negative pin to GND.
  4. Connect the USB-to-TTL programmer: 5V to 5V, GND to GND, TX to U0R / GPIO 3 and RX to U0T / GPIO 1.
  5. Connect GPIO 0 to GND only while uploading the program.
  6. Upload the program, remove GPIO 0 from GND and press RST.
  7. Open Serial Monitor at 115200 baud and note the IP address.
  8. Open the IP address in a browser to access the snapshot dashboard.
  9. Move in front of the PIR sensor and observe the buzzer, OLED and automatic image capture.
  10. Use the Capture Now button to test a manual snapshot.

Expected Output

The OLED shows startup, Wi-Fi and motion/capture messages.

When the PIR sensor detects motion, the buzzer sounds and the camera captures a snapshot.

The web dashboard displays the latest stored snapshot and provides a manual Capture Now control.

Result

The ESP32-CAM Motion Snapshot System successfully detects motion, gives a buzzer alert, captures a JPEG snapshot and makes the latest image available through a Wi-Fi web dashboard.
