Aim

To control an LED connected to an ESP32 DevKitC wirelessly through a Wi-Fi web dashboard.

The experiment demonstrates digital output control using HTTP requests and an ESP32 web server.

About the Experiment

The Wi-Fi LED Web Controller demonstrates basic wireless control of an electronic component.

The ESP32 DevKitC connects to a Wi-Fi network and starts an HTTP web server on port 80.

An external red LED connects to GPIO2 through a 220 Ω current-limiting resistor.

The ESP32 hosts a browser-based control dashboard containing POWER ON and POWER OFF buttons.

Pressing POWER ON sends an HTTP request to the /on route. The controller sets GPIO2 to HIGH and switches the LED ON.

Pressing POWER OFF sends a request to the /off route. GPIO2 is set to LOW, turning the LED OFF.

The dashboard also displays the current LED state using the /state endpoint.

This experiment introduces Wi-Fi connectivity, web servers, GPIO control and IoT communication.

Wi-Fi Note:

The example sketch uses the Wokwi-GUEST network. Replace it with your local Wi-Fi credentials for physical hardware.

Wi-Fi Communication

The ESP32 connects to the configured Wi-Fi network using WiFi.begin(). Its IP address appears in Serial Monitor.

Web Server

The WebServer library creates an HTTP server on port 80. The root route serves the dashboard.

LED ON Operation

When the /on endpoint receives a request, digitalWrite() sets GPIO2 HIGH and switches the external LED ON.

LED OFF Operation

When the /off endpoint receives a request, digitalWrite() sets GPIO2 LOW and switches the LED OFF.

Dashboard Status

The dashboard requests the /state endpoint to display the LED's current ON or OFF state.

Procedure

  1. Arrange ESP32 DevKitC, red LED, 220 Ω resistor, breadboard and jumper wires.
  2. Place the red LED on the breadboard.
  3. Connect the LED anode to one end of the 220 Ω resistor.
  4. Connect the other end of the resistor to ESP32 GPIO2.
  5. Connect the LED cathode to ESP32 GND.
  6. Verify LED polarity and wiring.
  7. Open Arduino IDE.
  8. Install the ESP32 board package.
  9. Select the ESP32 development board.
  10. Create a sketch named WiFi_LED_Web_Controller.ino.
  11. Copy the complete program from Explore the Code.
  12. Configure the correct Wi-Fi SSID and password.
  13. Select the appropriate serial port.
  14. Verify and upload the program.
  15. Open Serial Monitor at 115200 baud.
  16. Wait for the Wi-Fi connection.
  17. Note the ESP32 IP address.
  18. Open that IP address in a browser on the same local network.
  19. Observe the LED control dashboard.
  20. Press POWER ON and confirm that the red LED glows.
  21. Press POWER OFF and confirm that the LED switches off.
  22. Repeat the operation to check reliable wireless control.
