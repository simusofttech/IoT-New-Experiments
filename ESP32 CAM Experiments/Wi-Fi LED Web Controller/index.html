Aim

To create a Wi-Fi based LED control system using an ESP32, allowing an LED connected to GPIO 2 to be switched ON and OFF from a web browser.

About the Experiment

The ESP32 connects to Wi-Fi and starts a web server on port 80. When the user opens the ESP32 IP address in a browser, a control dashboard is displayed with POWER ON and POWER OFF buttons.

The browser sends requests to the ESP32 using the /on and /off routes. The ESP32 then changes GPIO 2 to control the LED and updates the dashboard state.

Procedure

  1. Connect the LED cathode to ESP32 GND.
  2. Connect the LED anode through a 220 Ω resistor to GPIO 2.
  3. Connect the ESP32 to the computer and open Arduino IDE or the Wokwi simulator.
  4. Upload the supplied ESP32 program.
  5. Open Serial Monitor at 115200 baud.
  6. Wait until the ESP32 reports that Wi-Fi is connected.
  7. Note the IP address shown in Serial Monitor.
  8. Open that IP address in a web browser connected to the same Wi-Fi network.
  9. Press POWER ON and observe the LED turn on.
  10. Press POWER OFF and observe the LED turn off.

Expected Output

When the ESP32 connects successfully to Wi-Fi, the Serial Monitor shows the assigned IP address and confirms that the web server has started.

Opening the ESP32 IP address in a web browser displays the Wi-Fi LED Web Controller dashboard.

When the user presses POWER ON, the LED connected to GPIO 2 turns ON and the dashboard status changes to LED IS ON.

When the user presses POWER OFF, the LED turns OFF and the dashboard status changes to LED IS OFF.

Result

The Wi-Fi LED Web Controller experiment was successfully implemented using an ESP32 development board, one LED and a 220 Ω resistor.

The ESP32 hosts a web-based control dashboard that allows the user to switch the LED ON and OFF remotely through a browser.

The experiment demonstrates Wi-Fi connectivity, browser-based device control and ESP32 GPIO output control through a simple web server.

What You Learn

  • Connecting an LED to ESP32 safely using a 220 Ω resistor.
  • Using GPIO 2 as a digital output pin.
  • Connecting ESP32 to Wi-Fi.
  • Creating an ESP32 web server using WebServer.h.
  • Serving an HTML dashboard directly from ESP32 memory.
  • Creating browser buttons that send requests to ESP32.
  • Using the /on and /off routes to control hardware.
  • Building a simple IoT-based remote control system.
  • Combining Arduino programming, HTML, CSS and JavaScript in a single ESP32 project.
