Aim

To control an LED connected to an ESP32 DevKitC wirelessly through a Wi-Fi web dashboard.

The experiment demonstrates digital output control using HTTP requests and an ESP32 web server.

About the Experiment

The Wi-Fi LED Web Controller demonstrates basic wireless control of an electronic component.

The ESP32 DevKitC connects to a Wi-Fi network and starts an HTTP web server on port 80.

An external red LED is connected to GPIO2 through a 220 Ω current-limiting resistor.

The ESP32 hosts a browser-based control dashboard containing POWER ON and POWER OFF buttons.

When POWER ON is pressed, the browser sends a request to the /on route.

The controller sets GPIO2 to HIGH, allowing current to flow through the LED.

When POWER OFF is pressed, the /off route sets GPIO2 to LOW.

The updated dashboard displays the LED's current ON or OFF state.

This experiment introduces the concepts of Wi-Fi connectivity, web servers, GPIO control and basic Internet of Things communication.

Important:

The supplied sketch uses Wokwi-GUEST as its Wi-Fi network.

For a physical ESP32, change the credentials to a suitable local 2.4 GHz Wi-Fi network.

Hardware Note:

The LED must be connected in series with the 220 Ω resistor.

Do not connect an external LED directly between GPIO2 and GND without a suitable resistor.

GPIO2 is also a boot-related pin on common ESP32 boards. Ensure the external circuit does not interfere with normal startup.

Wi-Fi Communication

The ESP32 connects to the configured Wi-Fi network using WiFi.begin().

After connection, the ESP32 receives an IP address. This address is displayed on Serial Monitor.

Web Server

The WebServer library runs an HTTP server on port 80.

The root route serves the LED control dashboard.

LED ON Operation

When the browser sends an /on request, the ESP32 executes digitalWrite() with the HIGH value.

This turns the external LED ON.

LED OFF Operation

When the browser sends an /off request, the ESP32 sets GPIO2 to LOW.

The LED turns OFF.

Dashboard Status

The dashboard updates its status after each command and can retrieve the current LED state from the /state endpoint.

Procedure

  1. Arrange ESP32 DevKitC, red LED, 220 Ω resistor, breadboard and jumper wires.
  2. Place the red LED on the breadboard.
  3. Connect the LED anode to one end of the 220 Ω resistor.
  4. Connect the other end of the resistor to GPIO2.
  5. Connect the LED cathode to ESP32 GND.
  6. Verify the LED polarity and resistor connection.
  7. Open Arduino IDE.
  8. Install the ESP32 board package.
  9. Select the ESP32 DevKitC development board.
  10. Create a sketch named WiFi_LED_Web_Controller.ino.
  11. Copy the program from Explore the Code.
  12. Configure the Wi-Fi SSID and password for your environment.
  13. Select the correct serial port.
  14. Verify and upload the program.
  15. Open Serial Monitor at 115200 baud.
  16. Wait for the ESP32 to connect to Wi-Fi.
  17. Note the IP address displayed in Serial Monitor.
  18. Open the IP address in a web browser on the same network.
  19. Observe the LED control dashboard.
  20. Press POWER ON and verify that the red LED glows.
  21. Press POWER OFF and verify that the red LED turns OFF.
  22. Repeat the operation to verify reliable wireless control.
