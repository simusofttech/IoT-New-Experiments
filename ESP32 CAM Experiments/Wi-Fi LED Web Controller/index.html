Aim

To control an LED connected to the ESP32 wirelessly through a Wi-Fi web dashboard.

About the Experiment

The ESP32 connects to Wi-Fi and starts a web server on port 80.

An LED connected to GPIO 2 can be switched ON or OFF using buttons provided on the browser dashboard.

The dashboard sends requests to the /on and /off routes, and the ESP32 changes the LED output state accordingly.

Procedure

  1. Connect the LED anode to a 220 Ω resistor.
  2. Connect the other end of the resistor to GPIO 2.
  3. Connect the LED cathode to ESP32 GND.
  4. Open Arduino IDE.
  5. Select the ESP32 board.
  6. Upload the program to the ESP32.
  7. Open Serial Monitor at 115200 baud.
  8. Wait for the ESP32 to connect to Wi-Fi.
  9. Note the IP address shown in Serial Monitor.
  10. Open that IP address in a web browser.
  11. Press POWER ON to turn the LED ON.
  12. Press POWER OFF to turn the LED OFF.

Expected Output

The Serial Monitor displays a successful Wi-Fi connection and the ESP32 IP address.

Opening the IP address displays the ESP32 LED web control dashboard.

Pressing POWER ON turns the LED ON and updates the dashboard status.

Pressing POWER OFF turns the LED OFF and updates the dashboard status.
