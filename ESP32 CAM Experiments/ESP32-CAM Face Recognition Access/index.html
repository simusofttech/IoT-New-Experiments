ESP32-CAM Face Recognition Access

Aim

To build a face-recognition access-control prototype using an ESP32-CAM, OLED, servo motor and buzzer with a browser-based recognition interface.

About the Experiment

The ESP32-CAM supplies camera images to a browser dashboard where face-api.js is used for face registration and recognition.

An authorized face can unlock a servo-controlled door for approximately 5 seconds, while an unknown face produces a denied indication and buzzer alert.

The OLED shows GRANTED, DENIED and LOCKED states, and the dashboard also provides manual lock and unlock controls.

Procedure

  1. Connect OLED SDA to GPIO 13 and SCL to GPIO 14.
  2. Connect the servo signal to GPIO 2 and power the servo from an external 5V supply with common ground.
  3. Connect the buzzer signal to GPIO 15.
  4. Connect the OV2640 camera to the ESP32-CAM camera socket.
  5. Program the ESP32-CAM using a USB-TTL adapter.
  6. Open the dashboard in a browser.
  7. Capture and register an authorized face.
  8. Start recognition.
  9. Verify that a matching face unlocks the servo and an unknown face is denied.
  10. Confirm automatic locking after approximately 5 seconds.

Explore the Code

ESP32-CAM_Face_Recognition_Access.ino 
#include "esp_camera.h"
#include <WiFi.h>
#include <WebServer.h>
#include <Wire.h>
#include <U8g2lib.h>
#include <ESP32Servo.h>

#define OLED_SDA 13
#define OLED_SCL 14
#define SERVO_PIN 2
#define BUZZER_PIN 15
#define LOCK_POSITION 0
#define UNLOCK_POSITION 90

Servo doorServo;
WebServer server(80);

void unlockDoor()
{
    doorServo.write(
        UNLOCK_POSITION
    );

    beepOnce();
}

void lockDoor()
{
    doorServo.write(
        LOCK_POSITION
    );
}

void loop()
{
    server.handleClient();
}

Expected Output

The dashboard shows live camera, face registration, recognition status and door controls.

An authorized face produces ACCESS GRANTED and moves the servo from 0° to 90°.

After about 5 seconds the servo returns to 0° and locks the door.

An unknown face keeps the servo locked and triggers three short buzzer beeps.

The OLED displays GRANTED, DENIED or LOCKED messages.

Result

The ESP32-CAM Face Recognition Access experiment successfully combines browser-based face recognition with servo door control, OLED status and buzzer feedback.
