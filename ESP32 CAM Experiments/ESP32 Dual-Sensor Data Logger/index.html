Aim

To create an ESP32-based environmental data logger that measures temperature, humidity and atmospheric pressure using DHT22 and BMP180 sensors and displays the readings on an SSD1306 OLED and Serial Monitor.

About the Experiment

The Dual-Sensor Data Logger uses two environmental sensors connected to an ESP32 DevKitC microcontroller.

The DHT22 measures air temperature and relative humidity.

The BMP180 measures atmospheric pressure and its own temperature.

The DHT22 communicates through GPIO4. The BMP180 uses I²C communication through GPIO21 and GPIO22.

The SSD1306 OLED is connected to the same I²C data and clock lines.

The ESP32 collects environmental data every two seconds.

The program prints DHT22 temperature, humidity, BMP180 temperature and atmospheric pressure to Serial Monitor.

The OLED displays the DHT22 temperature, relative humidity and BMP180 pressure.

Important Connection Notes:

The BMP180 and SSD1306 OLED share the same SDA and SCL lines using the I²C communication protocol.

Ensure that both devices have compatible and distinct I²C addresses.

A bare four-pin DHT22 generally requires a DATA pull-up resistor. Some DHT22 modules already include one. Verify the actual sensor board before assembling the circuit.

GPIO4 is an ESP32 strapping pin, so external circuitry must not interfere with startup.

DHT22 Sensor

The DHT22 measures air temperature and relative humidity. Its DATA pin connects to GPIO4.

BMP180 Sensor

The BMP180 measures atmospheric pressure and temperature. It communicates over I²C.

I²C Communication

GPIO21 and GPIO22 provide SDA and SCL signals for the BMP180 and OLED.

Serial Monitoring

The ESP32 prints all four sensor readings to Serial Monitor at 115200 baud.

OLED Monitoring

The OLED displays DHT22 temperature, relative humidity and BMP180 pressure.

Timing

The millis() function controls the measurement interval without requiring a continuous delay in loop().

Procedure

  1. Arrange the ESP32 DevKitC, DHT22, BMP180, SSD1306 OLED, breadboard and jumper wires.
  2. Place the ESP32 on the breadboard.
  3. Connect DHT22 VCC to 3.3V.
  4. Connect DHT22 DATA to GPIO4.
  5. Connect DHT22 GND to GND.
  6. Leave the DHT22 NC pin unconnected.
  7. Check whether the DHT22 DATA line requires an external pull-up resistor.
  8. Connect BMP180 VCC / VIN to 3.3V.
  9. Connect BMP180 GND to GND.
  10. Connect BMP180 SDA to GPIO21.
  11. Connect BMP180 SCL to GPIO22.
  12. Connect OLED VCC to 3.3V.
  13. Connect OLED GND to GND.
  14. Connect OLED SDA to GPIO21.
  15. Connect OLED SCL to GPIO22.
  16. Verify all connections.
  17. Open Arduino IDE.
  18. Install the ESP32 board package.
  19. Install the DHT sensor library.
  20. Install the Adafruit BMP085 library.
  21. Install the Adafruit GFX library.
  22. Install the Adafruit SSD1306 library.
  23. Create the sketch ESP32_Dual_Sensor_Data_Logger.ino.
  24. Copy the complete program from Explore the Code.
  25. Select the correct ESP32 board and port.
  26. Verify and upload the program.
  27. Open Serial Monitor at 115200 baud.
  28. Observe the startup message on OLED.
  29. Observe the DHT22 temperature and humidity readings.
  30. Observe the BMP180 temperature and pressure readings.
  31. Observe the environmental readings on the OLED display.
  32. Confirm that readings update approximately every two seconds.

Explore More: Shared I²C Pins

The BMP180 and OLED share GPIO21 for SDA and GPIO22 for SCL.

I²C allows multiple compatible devices with different addresses to communicate over the same bus.

Explore More: Sensor Readings

The DHT22 provides humidity and temperature. The BMP180 provides atmospheric pressure and temperature.

Explore More: millis()

The program uses millis() to take readings every 2000 milliseconds.

Result

The Dual-Sensor Data Logger demonstrates environmental monitoring using an ESP32, DHT22 sensor, BMP180 sensor and SSD1306 OLED display.

The ESP32 reads air temperature, relative humidity and atmospheric pressure at two-second intervals.

The measurements are displayed on the OLED and Serial Monitor.
