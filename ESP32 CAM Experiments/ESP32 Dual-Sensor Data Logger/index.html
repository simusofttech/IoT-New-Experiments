Aim

To create an ESP32-based environmental data logger that measures temperature, humidity and atmospheric pressure using two different sensors and displays the readings on an OLED display.

About the Experiment

This Experiment uses two environmental sensors with the ESP32.

The DHT22 measures temperature and humidity, while the BMP180 measures barometric pressure and temperature.

The ESP32 collects data from both sensors every two seconds and displays important environmental readings on the SSD1306 OLED.

Procedure

  1. Place the ESP32 on the breadboard.
  2. Connect DHT22 VCC to ESP32 3.3V.
  3. Connect DHT22 DATA to GPIO 4.
  4. Connect DHT22 GND to ESP32 GND.
  5. Leave the DHT22 NC pin unconnected.
  6. Connect BMP180 VCC / VIN to 3.3V.
  7. Connect BMP180 GND to GND.
  8. Connect BMP180 SDA to GPIO 21.
  9. Connect BMP180 SCL to GPIO 22.
  10. Connect OLED VCC to 3.3V.
  11. Connect OLED GND to GND.
  12. Connect OLED SDA to GPIO 21.
  13. Connect OLED SCL to GPIO 22.
  14. Open Arduino IDE.
  15. Install the DHT sensor library.
  16. Install Adafruit BMP085 library.
  17. Install Adafruit GFX library.
  18. Install Adafruit SSD1306 library.
  19. Upload the program to ESP32.
  20. Open Serial Monitor at 115200 baud.
  21. Observe temperature, humidity and pressure readings.
  22. Observe the same environmental information on the OLED display.

1. Load libraries

The program loads libraries for I²C communication, DHT22, BMP180 and SSD1306 OLED control.

Explore more: shared I²C pins

The BMP180 and OLED both use GPIO 21 for SDA and GPIO 22 for SCL.

I²C allows multiple compatible devices to share the same SDA and SCL wires.
