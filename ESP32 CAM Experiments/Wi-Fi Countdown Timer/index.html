Aim

To create a Wi-Fi controlled countdown timer using ESP32 that can be operated using physical push buttons or a web dashboard and gives an alarm using a buzzer when the timer reaches zero.

About the Experiment

This Experiment uses an ESP32 as a digital countdown timer.

The user can add time, start or pause the timer, reset it and control the timer through Wi-Fi.

The remaining time and timer status are shown on the SSD1306 OLED display.

When the countdown reaches 00:00, the buzzer produces an alarm.

Procedure

  1. Place the ESP32 on the breadboard.
  2. Connect OLED VCC to ESP32 3.3V.
  3. Connect OLED GND to ESP32 GND.
  4. Connect OLED SDA to GPIO 21.
  5. Connect OLED SCL to GPIO 22.
  6. Connect the Green Push Button to GPIO 18 and GND.
  7. Connect the Yellow Push Button to GPIO 19 and GND.
  8. Connect buzzer signal to GPIO 25.
  9. Connect buzzer ground to ESP32 GND.
  10. Open Arduino IDE.
  11. Install Adafruit GFX library.
  12. Install Adafruit SSD1306 library.
  13. Upload the program to ESP32.
  14. Open Serial Monitor at 115200 baud.
  15. Wait for the ESP32 to connect to Wi-Fi.
  16. Note the ESP32 IP address.
  17. Open the IP address in a web browser.
  18. Press the Add button to add 10 seconds.
  19. Press the Start button once to start the countdown.
  20. Press the Start button again to pause the timer.
  21. Long-press the Start button to reset the timer.
  22. Allow the timer to reach 00:00.
  23. Observe the buzzer alarm.
