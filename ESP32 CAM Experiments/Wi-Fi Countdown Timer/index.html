Aim

To develop a Wi-Fi-controlled countdown timer using ESP32 DevKitC V4, an SSD1306 OLED, two push buttons and a buzzer.

The timer can be operated through physical buttons or a wireless web dashboard. When the countdown reaches zero, the buzzer produces an audible alarm.

About the Experiment

The Wi-Fi Countdown Timer demonstrates time-based automation using an ESP32.

The initial countdown duration is 60 seconds.

The green push button adds 10 seconds to the remaining time.

The yellow push button starts or pauses the countdown.

A long press of approximately one second on the yellow button resets the timer to 60 seconds.

The SSD1306 OLED continuously displays the remaining countdown time and current status.

The displayed status can be RUNNING, PAUSED or TIME UP.

The ESP32 connects to Wi-Fi and hosts a web dashboard.

The dashboard provides +10 SEC, -10 SEC, START / PAUSE and RESET controls.

When the countdown reaches 00:00, the buzzer produces an alarm.

The timer uses millis() for countdown and alarm scheduling.

Timer Configuration:

Default duration: 60 seconds

Add time: 10 seconds

Remove time: 10 seconds through the web dashboard

Maximum configured time: 5999 seconds

Button long-press duration: approximately one second

Alarm tone: 2000 Hz

Timer Control Functions

+10 Seconds Adds 10 seconds to the remaining time.
-10 Seconds Removes 10 seconds using the web dashboard.
Start / Pause Starts or pauses the countdown.
Reset Restores the timer to 60 seconds.

Connection Notes:

The push buttons use INPUT_PULLUP mode. Pressing a button connects its GPIO input to GND.

OLED I²C address: 0x3C

The buzzer connection assumes a compatible low-current passive buzzer or piezo element. A higher-current buzzer requires a suitable driver.

Timer Initialization

The ESP32 initializes the countdown to 60 seconds.

The timer initially remains paused.

Green Button

Pressing the green button increases the remaining countdown by 10 seconds.

Yellow Button

A short press starts or pauses the timer.

A long press of at least one second resets the timer to 60 seconds.

Countdown Calculation

millis() measures elapsed time.

While the timer is running, the remaining time decreases every 1000 milliseconds.

Buzzer Alarm

When the timer reaches zero, the buzzer emits a repeated 2000 Hz tone.

The alarm uses non-blocking timing so web requests can continue to be handled.

OLED Display

The OLED displays the remaining time in MM:SS format.

It also shows Wi-Fi status and whether the timer is RUNNING, PAUSED or TIME UP.

Wireless Control

The ESP32 runs a web server on port 80.

The web dashboard provides buttons for adding time, removing time, starting, pausing and resetting.

Procedure

  1. Arrange the ESP32, OLED, two push buttons, buzzer, breadboard and jumper wires.
  2. Place the ESP32 on the breadboard.
  3. Connect OLED VCC to 3.3V.
  4. Connect OLED GND to GND.
  5. Connect OLED SDA to GPIO21.
  6. Connect OLED SCL to GPIO22.
  7. Connect the green push button between GPIO18 and GND.
  8. Connect the yellow push button between GPIO19 and GND.
  9. Connect the buzzer signal to GPIO25.
  10. Connect buzzer GND to ESP32 GND.
  11. Verify the connections.
  12. Open Arduino IDE.
  13. Install the ESP32 board package.
  14. Install Adafruit GFX and Adafruit SSD1306.
  15. Create a sketch named WiFi_Countdown_Timer.ino.
  16. Copy the complete program from Explore the Code.
  17. Configure the Wi-Fi credentials.
  18. Select the ESP32 board and serial port.
  19. Verify and upload the program.
  20. Open Serial Monitor at 115200 baud.
  21. Note the ESP32 IP address.
  22. Open the IP address in a browser.
  23. Observe the initial countdown of 01:00.
  24. Press the green button to add 10 seconds.
  25. Press the yellow button to start.
  26. Press again to pause.
  27. Long-press to reset.
  28. Test the web dashboard controls.
  29. Allow the timer to reach 00:00.
  30. Observe the buzzer alarm.

Explore More: Push Buttons

INPUT_PULLUP keeps a button input HIGH until the button connects it to GND.

A short press starts or pauses the countdown. A long press resets it.

Explore More: millis()

millis() returns the milliseconds elapsed since the ESP32 started.

It supports timing without using a one-second blocking delay.

Explore More: Alarm

The buzzer emits a 2000 Hz tone when time reaches zero.

Alternating tone() and noTone() produces an intermittent alarm.

Explore More: Web Server

The dashboard sends HTTP requests to control the timer.

The /status endpoint returns the countdown information as JSON.
