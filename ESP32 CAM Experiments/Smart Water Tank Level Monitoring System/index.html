Aim

To monitor a water tank's level using an HC-SR04 ultrasonic sensor and ESP32, display the percentage on a local Wi-Fi dashboard, and send Telegram and buzzer alerts when the tank becomes nearly empty or full.

About the Experiment

The ultrasonic sensor measures the distance to the water surface. The ESP32 estimates the water percentage from a configured tank height and provides EMPTY, NORMAL and FULL status. The system provides notifications only; it does not operate a pump.

Working Principle

HC-SR04 Distance Measurement → ESP32 Water-Level Calculation → Web Dashboard → EMPTY / NORMAL / FULL → Buzzer and Telegram Alerts

EMPTY: 10% or less; NORMAL: above 10% and below 90%; FULL: 90% or more. EMPTY and FULL send an alert on state entry.

Procedure

  1. Place the HC-SR04 above the water surface, protected from splashes.
  2. Wire the sensor and buzzer as specified, using safe ECHO voltage-level conversion.
  3. Install the ESP32 board package in Arduino IDE.
  4. Configure the actual Wi-Fi SSID and password and your private Telegram bot token and recipient Chat ID.
  5. Set the measured tank height (100 cm is only the SOP's example configuration).
  6. Compile and upload the verified sketch from the SOP.
  7. Open Serial Monitor at 115200 baud and find the dashboard IP address.
  8. Open that IP in a browser on the same Wi-Fi network and test EMPTY, NORMAL and FULL states safely.

Expected Output

The web dashboard displays live water level percentage, measured distance, tank visualization and status. Telegram sends an EMPTY alert at 10% or below and a FULL alert at 90% or above, with a brief buzzer signal.

Result

The system demonstrates remote monitoring and alerting for water level without automatic pump control.

What You Learn

Ultrasonic distance sensing, ESP32 GPIO and voltage-level safety, percentage calculations, local web dashboards, Wi-Fi networking, Telegram notifications and state-change alerts.
