Aim

To create an RFID-based identification system using ESP32, RC522 RFID reader, OLED display and buzzer, with live identification details shown on a Wi-Fi web dashboard.

About the Experiment

This experiment reads RFID cards using the RC522 reader and checks whether the scanned card is stored as an authorized card.

The ESP32 displays the result on the OLED, gives a buzzer indication and updates a web dashboard with the card UID, user name, scan time and access status.

Components Required

ESP32 DevKitC (×1)

Main controller with built-in Wi-Fi.

RC522 RFID Reader (×1)

Reads the UID of RFID cards and key fobs.

RFID Card / Key Fob (×2–4)

Used as identification cards for users.

0.96" OLED SSD1306 I²C (×1)

Displays system status, user and RFID UID.

Buzzer (×1)

Gives different sounds for granted and denied access.

Breadboard (×1)

Provides an easy base for making temporary circuit connections.

Jumper Wires

Used to connect the ESP32, RFID reader, OLED display and buzzer.

Procedure

  1. Connect RC522 3.3V to ESP32 3V3.
  2. Connect RC522 GND to ESP32 GND.
  3. Connect RC522 SDA / SS to GPIO 5.
  4. Connect RC522 SCK to GPIO 18.
  5. Connect RC522 MOSI to GPIO 23.
  6. Connect RC522 MISO to GPIO 19.
  7. Connect RC522 RST to GPIO 27.
  8. Connect OLED VCC to ESP32 3V3.
  9. Connect OLED GND to ESP32 GND.
  10. Connect OLED SDA to GPIO 21.
  11. Connect OLED SCL to GPIO 22.
  12. Connect buzzer positive terminal to GPIO 25.
  13. Connect buzzer negative terminal to GND.
  14. Open Arduino IDE.
  15. Install the MFRC522, Adafruit GFX and Adafruit SSD1306 libraries.
  16. Upload the program to ESP32.
  17. Open Serial Monitor at 115200 baud.
  18. Note the IP address shown in Serial Monitor.
  19. Open that IP address in a browser connected to the same Wi-Fi network.
  20. Scan an RFID card and observe the result on the OLED, buzzer and web dashboard.

Expected Output

When the ESP32 starts, the OLED shows that the RFID system is ready.

When an authorized RFID card is scanned, the user name and UID appear and the system shows ACCESS GRANTED.

When an unknown RFID card is scanned, the system shows UNKNOWN CARD and ACCESS DENIED.

The latest card details are also shown on the ESP32 web dashboard.

Result

The RFID Web Identification System experiment was successfully implemented using ESP32, RC522 RFID reader, SSD1306 OLED display and buzzer.

The system identifies authorized RFID cards, rejects unknown cards and displays the latest identification information on a Wi-Fi web dashboard.
