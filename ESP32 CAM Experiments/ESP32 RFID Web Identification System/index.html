Aim

To develop an RFID-based identification system using an ESP32, RC522 RFID reader, SSD1306 OLED and buzzer, with the latest identification details displayed through a Wi-Fi web dashboard.

About the Experiment

The RFID Web Identification System demonstrates contactless card identification using an RC522 RFID reader and ESP32.

Each RFID card or key fob contains a unique identifier, commonly called a UID.

When a card is brought close to the RC522 reader, the ESP32 reads its UID through SPI communication.

The scanned UID is compared with four authorized UID values stored in the program.

If the UID matches a stored card, the system displays ACCESS GRANTED and the corresponding user name.

If the UID does not match, the system displays UNKNOWN CARD and ACCESS DENIED.

The SSD1306 OLED shows the identification result, while the buzzer provides a different sound for approved and unknown cards.

The ESP32 also hosts a local web dashboard that displays the last scanned UID, user name, access result, elapsed scan time and number of scans.

JavaScript retrieves the latest scan information automatically every second.

Important:

UID matching is used here for identification demonstrations. RFID card UIDs can be copied or spoofed, so this experiment is not a secure physical access-control system.

Replace the example authorized UID values with the UIDs of your own cards.

The scan time is calculated using millis() and represents device uptime, not real-world clock time.

Identification States

✓

ACCESS GRANTED

The UID matches one of the authorized cards.

The associated user name appears on the display.

✕

ACCESS DENIED

The UID does not match any stored authorized card.

The system identifies the card as UNKNOWN.

The buzzer should be a suitable 3.3V-compatible passive buzzer for the tone-based output. Use a transistor driver if its current exceeds GPIO capability.

Important Hardware Notes:

Power the RC522 reader from 3.3V, not 5V. Its signal lines are designed for 3.3V logic.

GPIO5 is a boot strapping pin. Ensure the connected RC522 circuit does not interfere with ESP32 startup.

The reader supports compatible 13.56 MHz RFID cards such as common MIFARE-type cards. Not all RFID technologies are supported.

RFID Card Detection

The RC522 detects a compatible RFID card near its antenna.

SPI Communication

The reader communicates with the ESP32 through the SPI interface.

UID Processing

The UID bytes are converted into uppercase hexadecimal text separated by spaces.

Authorized Card Matching

The program compares the scanned UID with four stored sample UIDs.

OLED Indication

The display shows the scanned card's status, associated user name or an access-denied message.

Buzzer Indication

A recognized card produces three short ascending tones. An unknown card produces one lower tone.

Web Monitoring

The dashboard requests the latest scan details through the /data endpoint every second.

Procedure

  1. Arrange the ESP32, RC522 reader, RFID cards, OLED, buzzer, breadboard and jumper wires.
  2. Place the ESP32 on the breadboard.
  3. Connect RC522 3.3V to ESP32 3V3.
  4. Connect RC522 GND to ESP32 GND.
  5. Connect RC522 SDA / SS to GPIO5.
  6. Connect RC522 SCK to GPIO18.
  7. Connect RC522 MOSI to GPIO23.
  8. Connect RC522 MISO to GPIO19.
  9. Connect RC522 RST to GPIO27.
  10. Connect OLED VCC to ESP32 3.3V.
  11. Connect OLED GND to GND.
  12. Connect OLED SDA to GPIO21.
  13. Connect OLED SCL to GPIO22.
  14. Connect a suitable low-current passive buzzer to GPIO25 and GND.
  15. Verify the circuit connections carefully.
  16. Open Arduino IDE.
  17. Install the ESP32 board package.
  18. Install the MFRC522, Adafruit GFX and Adafruit SSD1306 libraries.
  19. Create the sketch ESP32_RFID_Web_Identification.ino.
  20. Copy the complete program from Explore the Code.
  21. Configure the actual Wi-Fi SSID and password.
  22. Replace example authorized UIDs with the UIDs of your RFID cards.
  23. Select the correct ESP32 board and serial port.
  24. Verify and upload the sketch.
  25. Open Serial Monitor at 115200 baud.
  26. Wait for the Wi-Fi connection and note the ESP32 IP address.
  27. Open the IP address in a browser connected to the same Wi-Fi network.
  28. Observe the RFID identification dashboard.
  29. Scan an authorized RFID card.
  30. Observe the OLED result, buzzer indication and updated dashboard.
  31. Scan an unknown RFID card.
  32. Observe ACCESS DENIED and the updated scan information.
  33. Repeat with different cards to test the system.

Result

The RFID Web Identification System demonstrates contactless card identification using an ESP32, RC522 RFID reader, SSD1306 OLED and buzzer.

The system compares the scanned card UID with stored sample UIDs and indicates whether the card is recognized or unknown.

The latest scan details are displayed on the OLED and web dashboard, while the buzzer provides an audible identification response.
