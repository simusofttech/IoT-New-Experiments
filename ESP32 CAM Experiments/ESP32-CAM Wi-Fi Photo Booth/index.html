Aim

To build a Wi-Fi Photo Booth and time-lapse image-capture system using an AI-Thinker ESP32-CAM, a 1.3-inch SH1106 I²C OLED and a push button.

The system captures JPEG images every ten seconds during a time-lapse session and displays operating information through an OLED and browser dashboard.

About the Experiment

The ESP32-CAM uses an OV2640 camera to capture digital images. Its built-in Wi-Fi interface allows users on the local network to access a browser-based photo booth dashboard.

The dashboard displays camera snapshots, photo count, capture status and Start/Stop controls. The OLED shows connection status, photograph count and time-lapse status.

A push button connected to GPIO2 can be used to start or stop time-lapse capture. The first image is scheduled ten seconds after starting.

Storage behavior: Only the latest captured JPEG is retained in RAM. The system does not maintain a permanent historical photo gallery.

Camera Capture

The esp_camera library initializes the OV2640 image sensor and captures JPEG frames. The sketch uses VGA frame resolution.

Timed Capture

The program uses millis() to schedule image capture at ten-second intervals without a continuous ten-second delay.

OLED Status

The SH1106 display is updated after changes to time-lapse state or successful image captures.

Web Dashboard

The browser communicates with the ESP32-CAM using local HTTP routes for Start, Stop, Status, Snapshot and Latest Photo.

RAM Storage

Each new JPEG replaces the previously stored latest image. It is not saved to a microSD card or persistent storage.

Procedure

  1. Arrange the ESP32-CAM, SH1106 OLED, push button, breadboard, programmer and jumper wires.
  2. Connect OLED SDA to GPIO13 and SCL to GPIO14.
  3. Connect OLED GND to GND and VCC to its supported supply voltage.
  4. Connect the push button between GPIO2 and GND.
  5. Connect the USB-to-TTL programmer to the ESP32-CAM UART pins with correct voltage levels.
  6. For flashing, connect GPIO0 to GND and reset the board.
  7. Open Arduino IDE and install the ESP32 board package and U8g2 library.
  8. Create a sketch named ESP32_CAM_WiFi_Photo_Booth.ino.
  9. Copy the code from the Explore the Code section.
  10. Replace YOUR_WIFI_NAME and YOUR_WIFI_PASSWORD with local Wi-Fi details.
  11. Select the AI Thinker ESP32-CAM board configuration and correct port.
  12. Compile and upload the firmware.
  13. Disconnect GPIO0 from GND and restart the board.
  14. Open Serial Monitor at 115200 baud.
  15. Note the IP address displayed after Wi-Fi connects.
  16. Open that IP address in a browser on the same network.
  17. Press Start Timelapse.
  18. Confirm that the first scheduled photo is captured after ten seconds.
  19. Observe the OLED count and browser status.
  20. Press Stop and confirm capture stops.
  21. Test the physical push button after normal boot.

Web Dashboard

The browser displays a camera image, Start and Stop controls, photo count, time-lapse status, IP address and the latest captured JPEG.

The exact IP address varies with the local Wi-Fi network. Gallery history is not persistent.

Result

The ESP32-CAM Wi-Fi Photo Booth experiment demonstrates wireless image capture, time-lapse scheduling, push-button control, OLED status display and a browser-based camera dashboard.
