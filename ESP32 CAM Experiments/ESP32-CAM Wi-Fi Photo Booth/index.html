ESP32-CAM Wi-Fi Photo Booth

Aim

To create a Wi-Fi photo booth and timelapse camera using an ESP32-CAM, OLED and push button with browser-based monitoring and image capture.

About the Experiment

The ESP32-CAM captures JPEG images using the OV2640 camera and serves a browser dashboard over Wi-Fi.

A push button on GPIO 2 can start or stop the timelapse sequence, and the software uses a 10-second capture interval.

The OLED displays Wi-Fi state, photo count and timelapse status. The latest captured photo is stored in RAM and displayed in the dashboard gallery.

Procedure

  1. Connect OLED SCL to GPIO 14 and SDA to GPIO 13.
  2. Connect the OLED VCC to 5V and GND to GND as shown in the source document.
  3. Connect one push-button leg to GPIO 2 and the opposite leg to GND.
  4. Program the ESP32-CAM and restart it in normal mode.
  5. Open Serial Monitor at 115200 baud and note the IP address.
  6. Open the ESP32-CAM dashboard in a browser.
  7. Press Start Timelapse or use the physical push button.
  8. Wait for the first photo after 10 seconds.
  9. Observe new images and photo count in the gallery.
  10. Press Stop or use the physical button again to stop the timelapse.

Expected Output

The first timelapse photo is captured 10 seconds after Start.

Additional captures occur every 10 seconds while the timelapse is running.

The web dashboard shows the live camera, photo count, status and captured-image gallery.

Result

The ESP32-CAM Wi-Fi Photo Booth successfully captures timed JPEG images, updates the OLED and presents the latest photos through a Wi-Fi dashboard.
