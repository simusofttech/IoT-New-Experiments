Aim

To develop a Wi-Fi-based photo booth using an AI-Thinker ESP32-CAM, 1.3-inch SH1106 OLED and push button that captures JPEG images automatically at 10-second intervals and provides browser-based Start and Stop controls.

About the Experiment

The ESP32-CAM Wi-Fi Photo Booth demonstrates wireless photography, timed image capture, OLED status monitoring and web-based control.

The ESP32-CAM captures digital photographs using its onboard camera and provides a webpage accessible over a local Wi-Fi network.

The browser dashboard displays periodically refreshed camera snapshots, timelapse status, total photographs captured and Start/Stop controls.

A physical push button connected to GPIO2 can also start and stop automatic image capture.

The first photograph is captured approximately 10 seconds after starting the timelapse. Additional photos are captured at 10-second intervals while active.

The SH1106 OLED provides operating status and photo-count information.

Image Storage

Only the latest successfully captured JPEG is retained in RAM. New photographs replace the previously stored image.

Important: This program does not permanently save every photo to a microSD card. Captured image history is not preserved after restarting the device.

Hardware Precautions:

GPIO2 is an ESP32 boot-strapping pin. Do not hold the button pressed during startup, reset or firmware uploading.

Verify the OLED supply rating and ensure I²C signal levels are compatible with ESP32 3.3V GPIO.

Use a stable supply suitable for the ESP32-CAM's camera and Wi-Fi current requirements. The USB-to-TTL programmer must use 3.3V UART logic levels.

Camera Initialization

The esp_camera library initializes the onboard camera and configures JPEG image capture.

Image Capture

The ESP32-CAM captures a JPEG frame using esp_camera_fb_get().

Timelapse Scheduling

The millis() function schedules image capture every 10 seconds while timelapse mode is active.

Push Button

GPIO2 is configured using INPUT_PULLUP. A valid press toggles the timelapse operating state.

OLED Status

The SH1106 OLED displays the current running or stopped condition and total successful photograph count.

Web Dashboard

The dashboard provides Start and Stop controls, periodic camera snapshots, photo count and a link to the latest successfully captured image.

Procedure

  1. Arrange the ESP32-CAM, SH1106 OLED, push button, USB-to-TTL programmer, breadboard and jumper wires.
  2. Connect OLED SDA to GPIO13.
  3. Connect OLED SCL to GPIO14.
  4. Connect OLED GND to common ground.
  5. Connect OLED VCC to its supported supply voltage.
  6. Connect the push button between GPIO2 and GND.
  7. Connect the USB-to-TTL programmer to the ESP32-CAM UART pins.
  8. Use the appropriate ESP32-CAM programming setup and supply.
  9. Connect GPIO0 to GND for flashing and reset the board.
  10. Open Arduino IDE.
  11. Install the ESP32 board package.
  12. Install the U8g2 library.
  13. Select AI Thinker ESP32-CAM as the board.
  14. Create a sketch named ESP32_CAM_WiFi_Photo_Booth.ino.
  15. Copy the complete sketch from Explore the Code.
  16. Enter the Wi-Fi SSID and password.
  17. Verify and upload the sketch.
  18. Disconnect GPIO0 from GND after uploading.
  19. Restart the board in normal operating mode.
  20. Open Serial Monitor at 115200 baud.
  21. Wait for the Wi-Fi connection.
  22. Note the IP address shown in Serial Monitor.
  23. Open the IP address in a browser on the same network.
  24. Observe the Photo Booth dashboard.
  25. Press Start Timelapse.
  26. Wait for the first scheduled photograph.
  27. Observe the image counter and OLED.
  28. Open the latest captured photograph.
  29. Press Stop Timelapse.
  30. Test the physical push button after normal boot.
