Aim

To design a wireless RFID-based queue token generator using ESP32 DevKitC and RC522 RFID reader.

The system checks registered RFID card UIDs, generates sequential three-digit tokens, displays status on an OLED, provides buzzer feedback and exposes information through a Wi-Fi dashboard.

About the Experiment

Radio Frequency Identification uses radio communication to recognize compatible RFID cards and key fobs.

The RC522 RFID reader is connected to ESP32 DevKitC through the SPI interface.

When a card is presented, the reader obtains its UID.

ESP32 compares that UID with two predefined authorized UID values.

If the UID matches, the system generates the next queue token.

Each token is formatted using three digits, such as 001, 002 and 003.

The token counter wraps from 999 back to 001.

An authorized scan produces a short success beep, while an unauthorized scan produces an error indication without generating a token.

The SSD1306 OLED shows reader readiness, access granted, access denied and token reset information.

The ESP32 web dashboard displays the current token, total generated tokens, latest scanned UID, scan status, latest event, IP address and uptime.

The token counter can be reset using a physical button or the dashboard control.

Important RFID Note:

The authorized UIDs in the supplied experiment are example values: 01 02 03 04 and 55 66 77 88.

These values must match your actual test cards for an authorized scan to succeed.

UID matching is appropriate for this educational demonstration, but card UIDs alone are not a secure authentication method for real access control or payments.

RFID Reading

The RC522 scans a compatible RFID card and obtains its UID.

The MFRC522 library transfers UID data through the ESP32 SPI interface.

UID Verification

ESP32 compares the scanned UID against the two stored authorized UID arrays.

A matching UID is treated as authorized for this experiment.

Queue Token Generation

An authorized scan increases currentToken.

The number is formatted with leading zeros so that it always contains three digits. 

001
002
003
004

Unauthorized Card

An unauthorized UID generates a denial message without increasing the token counter.

Duplicate Scan Protection

The experiment uses a 3000 ms interval between accepted scan events.

This helps prevent rapid repeated scans.

Buzzer Feedback

The buzzer provides a short signal for authorized cards and a different pattern for unauthorized cards.

OLED Feedback

The OLED reports reader readiness, authorized access, unauthorized access and token reset events.

Web Dashboard

The ESP32 web server displays the latest system information.

The browser refreshes dashboard data every one second using the /api endpoint.

Reset Operation

GPIO26 is configured using INPUT_PULLUP.

The physical button resets the current and total token counters.

The web reset control provides the same operation through the /reset route.

Important:

This version uses a global 3-second interval between processed RFID scans.

It is a token-generation demonstration, not a secure access-control or production queue system.

Procedure

  1. Arrange ESP32 DevKitC, RC522 RFID reader, RFID cards or key fobs, SSD1306 OLED, buzzer, reset button, breadboard and jumper wires.
  2. Connect RC522 SDA/SS to GPIO5.
  3. Connect RC522 RST to GPIO27.
  4. Connect SCK to GPIO18, MISO to GPIO19 and MOSI to GPIO23.
  5. Connect RC522 VCC to 3.3V and GND to ESP32 GND.
  6. Connect OLED SDA to GPIO21 and SCL to GPIO22.
  7. Connect OLED VCC to 3.3V and GND to GND.
  8. Connect the suitable buzzer signal to GPIO25.
  9. Connect the reset button between GPIO26 and GND.
  10. Check all wiring connections carefully.
  11. Open Arduino IDE.
  12. Install the ESP32 board package.
  13. Install MFRC522, Adafruit GFX and Adafruit SSD1306 libraries.
  14. Create a sketch named Wireless_RFID_Token_Generator.ino.
  15. Copy the complete reconstructed program from Explore the Code.
  16. Configure the Wi-Fi SSID and password.
  17. Check the UID values used in the program.
  18. Select ESP32 DevKitC and the correct port.
  19. Verify and upload the sketch.
  20. Open Serial Monitor at 115200 baud.
  21. Note the ESP32 IP address after Wi-Fi connects.
  22. Open the IP address in a browser on the same local network.
  23. Scan an authorized RFID card.
  24. Observe the generated three-digit token, OLED message and buzzer response.
  25. Scan an unauthorized RFID card.
  26. Verify that the token counter does not increase for an unauthorized UID.
  27. Test the reset push button.
  28. Test the web dashboard reset control.

Result

The Wireless RFID Token Generator demonstrates queue token generation using ESP32 and RC522 RFID reader.

Authorized RFID UIDs generate sequential three-digit tokens.

Unauthorized UIDs are rejected without changing the token counter.

The SSD1306 OLED provides status feedback, while the buzzer indicates successful or denied scans.

A local Wi-Fi dashboard displays system information, and both physical and browser controls can reset the counters.
