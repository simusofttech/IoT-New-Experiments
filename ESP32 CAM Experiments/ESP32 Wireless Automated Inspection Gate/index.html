Aim

To design a wireless automated inspection gate using an ESP32 DevKitC, two ultrasonic sensors, a servo motor, an SSD1306 OLED and a buzzer.

The system detects an approaching object, evaluates a second inspection zone, opens or closes the gate according to the inspection result, and publishes status information through a Wi-Fi web dashboard.

About the Experiment

Automated inspection gates use sensors and actuators to control the movement of objects through an inspection area.

This experiment uses two HC-SR04 ultrasonic sensors to measure object distances.

The first sensor detects an approaching object. If the object is within 50 cm, the system proceeds to the inspection stage.

The second ultrasonic sensor measures the distance in the inspection zone.

A distance of 30 cm or less at Sensor 2 is interpreted as a PASSED result.

After a successful inspection, the servo gate moves from its closed position at 0° to the open position at 90°.

The gate remains open for approximately four seconds before returning to 0°.

If Sensor 2 does not satisfy the inspection condition, the result is FAILED, and the gate remains closed.

The buzzer indicates inspection events. The OLED shows live distance measurements, gate status and inspection status.

A wireless dashboard allows users to monitor the inspection process using a web browser.

Inspection Logic:

Detection threshold: 50 cm

Pass threshold: 30 cm

Gate closed angle: 0°

Gate open angle: 90°

Gate opening duration: 4000 milliseconds

This is a distance-based demonstration, not an actual measurement of material quality or defects.

Important Hardware Notes:

A conventional 5V HC-SR04 can output approximately 5V on its ECHO pin. ESP32 GPIO pins are not 5V tolerant.

Use an appropriate voltage divider or logic-level shifter on each ECHO signal before connecting it to GPIO18 and GPIO21.

The servo requires a suitable 5V supply and a common ground with the ESP32.

GPIO12 is an ESP32 strapping pin. The connected buzzer circuit must not force an unsuitable logic level during startup.

The buzzer connection assumes a compatible low-current active buzzer. A higher-current buzzer requires a suitable driver.

The existing circuit image reference is preserved. Verify its voltage connections before assembling hardware.

Object Detection

Ultrasonic Sensor 1 sends sound pulses and measures the reflected echo.

If a valid object distance is 50 cm or less, the inspection process begins.

Inspection Decision

Ultrasonic Sensor 2 measures the object distance in the inspection area.

A valid measurement at or below 30 cm produces the PASSED result.

A larger distance or unavailable inspection reading produces FAILED.

Gate Operation

A passed inspection rotates the servo to 90 degrees.

A timer starts when the gate opens.

After 4000 milliseconds, the gate returns to its closed position at 0°.

The reconstructed program prevents an ongoing inspection from repeatedly restarting the four-second timer.

Buzzer Feedback

The buzzer operates for a short period to indicate a completed inspection.

OLED Display

The OLED presents both ultrasonic distances, inspection result and gate status.

Wireless Monitoring

ESP32 hosts a web dashboard. The dashboard requests data from the /api endpoint and updates its displayed values automatically.

Timing Details:

Sensor reading interval: approximately 300 ms.

Gate open duration: 4000 ms.

Dashboard refresh interval: 1000 ms in the reconstructed implementation.

Procedure

  1. Arrange ESP32 DevKitC, two ultrasonic sensors, a servo motor, SSD1306 OLED, buzzer, breadboard and jumper wires.
  2. Connect Ultrasonic Sensor 1 TRIG to GPIO5.
  3. Connect its ECHO signal to GPIO18 through suitable voltage-level protection.
  4. Connect Ultrasonic Sensor 2 TRIG to GPIO19.
  5. Connect its ECHO signal to GPIO21 through suitable voltage-level protection.
  6. Supply the HC-SR04 sensors according to their voltage requirements and connect common ground.
  7. Connect the servo signal wire to GPIO14.
  8. Connect the servo to a suitable 5V supply with common ground.
  9. Connect the buzzer signal to GPIO12 using a compatible buzzer circuit.
  10. Connect OLED SDA to GPIO25.
  11. Connect OLED SCL to GPIO26.
  12. Connect OLED VCC to 3.3V and GND to GND.
  13. Verify all circuit connections and safe voltage levels.
  14. Open Arduino IDE.
  15. Install the ESP32 board package.
  16. Install ESP32Servo, Adafruit GFX and Adafruit SSD1306 libraries.
  17. Create the sketch Wireless_Automated_Inspection_Gate.ino.
  18. Copy the complete program from Explore the Code.
  19. Enter your local Wi-Fi SSID and password.
  20. Select the appropriate ESP32 board and serial port.
  21. Verify and upload the sketch.
  22. Open Serial Monitor at 115200 baud.
  23. Note the ESP32 IP address after Wi-Fi connects.
  24. Open the IP address in a browser on the same network.
  25. Move an object into the detection area of Sensor 1.
  26. Place the object within 30 cm of Sensor 2.
  27. Observe PASSED status and gate opening to 90°.
  28. Observe the gate closing after approximately four seconds.
  29. Repeat the experiment with a failed inspection condition.
  30. Observe the updated OLED and web dashboard information.

Explore More: Ultrasonic Sensors

Each HC-SR04 sends an ultrasonic pulse and measures the time required for its echo to return.

The time measurement is converted to distance in centimeters.

Explore More: Servo Gate

The servo rotates between 0° and 90° to represent closed and open gate states.

ESP32Servo generates the control pulses required by the motor.

Explore More: millis()

millis() provides elapsed time since the ESP32 started.

It allows gate timing and buzzer timing without a blocking four-second delay.

Explore More: I²C OLED

The OLED uses the I²C protocol.

GPIO25 is configured as SDA and GPIO26 as SCL.

Explore More: Wi-Fi Dashboard

The web server provides a homepage and JSON API.

The dashboard periodically requests measurements and updates the displayed inspection status.

Result

The ESP32 Wireless Automated Inspection Gate experiment demonstrates staged object detection using two ultrasonic sensors.

The first sensor identifies an approaching object, while the second performs the distance-based inspection check.

A passing condition opens the servo gate to 90° for approximately four seconds.

A failed inspection keeps the gate closed and produces buzzer feedback.

The OLED and Wi-Fi dashboard provide live monitoring of sensor distances and gate status.
