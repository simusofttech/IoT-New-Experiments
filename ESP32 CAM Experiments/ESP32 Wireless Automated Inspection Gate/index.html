ESP32 Wireless Automated Inspection Gate

Aim

To build a wireless automated inspection gate using two ultrasonic sensors, a servo motor, an OLED display and a buzzer, with live status available through an ESP32 web dashboard.

About the Experiment

Ultrasonic Sensor 1 detects an approaching object. Ultrasonic Sensor 2 performs the inspection check. Objects detected within 50 cm enter the inspection process; a reading of 30 cm or less at the inspection sensor is treated as a pass. A passed object opens the servo gate to 90 degrees for 4 seconds, while failed inspections keep the gate closed. The OLED and web dashboard show live distances, inspection status and gate status.

Procedure

  1. Connect both ultrasonic sensors to their TRIG and ECHO GPIO pins.
  2. Connect the servo signal to GPIO 14 and power it from 5V.
  3. Connect the buzzer to GPIO 12 and GND.
  4. Connect the SSD1306 OLED to GPIO 25 (SDA) and GPIO 26 (SCL).
  5. Upload the ESP32 sketch and open Serial Monitor at 115200 baud.
  6. Wait for Wi-Fi to connect and note the ESP32 IP address.
  7. Open the IP address in a browser to view the wireless inspection dashboard.
  8. Move an object into Sensor 1's detection zone.
  9. Move it into the second sensor's inspection zone and observe PASSED or FAILED status.
  10. Verify that a passed inspection opens the gate for about 4 seconds.

Explore the Code

Key sketch sections used in this experiment:

Wireless_Automated_Inspection_Gate.ino
#include <WiFi.h>
#include <WebServer.h>
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#include <ESP32Servo.h>

#define TRIG1 5
#define ECHO1 18
#define TRIG2 19
#define ECHO2 21
#define SERVO_PIN 14
#define BUZZER_PIN 12
#define OLED_SDA 25
#define OLED_SCL 26

#define DETECTION_DISTANCE 50
#define INSPECTION_DISTANCE 30
#define GATE_CLOSED 0
#define GATE_OPEN 90

WebServer server(80);
Servo gateServo;

void processInspection() {
  if (distance1 > DETECTION_DISTANCE) {
    gateServo.write(GATE_CLOSED);
    inspectionStatus = "WAITING";
    gateStatus = "CLOSED";
    return;
  }

  if (distance2 <= INSPECTION_DISTANCE) {
    inspectionStatus = "PASSED";
    gateServo.write(GATE_OPEN);
    gateIsOpen = true;
    gateOpenTime = millis();
    gateStatus = "OPEN";
    startBuzzer();
  } else {
    inspectionStatus = "FAILED";
    gateServo.write(GATE_CLOSED);
    gateStatus = "CLOSED";
    startBuzzer();
  }
}

void loop() {
  server.handleClient();
  updateBuzzer();

  if (millis() - lastSensorRead >= 300) {
    lastSensorRead = millis();
    distance1 = readDistance(TRIG1, ECHO1);
    delay(20);
    distance2 = readDistance(TRIG2, ECHO2);
    processInspection();
    updateOLED();
  }
}

Expected Output

The OLED shows both ultrasonic distances, gate status, inspection status and Wi-Fi status.

The web dashboard updates the two distance readings, system state, inspection result and gate state.

Objects passing the inspection cause the servo gate to open to 90 degrees for about four seconds before closing.

Failed inspections keep the gate closed and trigger buzzer feedback.

Result

The automated inspection gate detects an object, evaluates the second inspection zone, controls the servo gate automatically and publishes live system information over Wi-Fi.
