Aim

To develop a Wi-Fi-based environmental monitoring system using ESP32 DevKitC, DHT22, BMP180, an LDR module and an SSD1306 OLED display.

The system measures temperature, relative humidity, atmospheric pressure and relative light level, then displays the readings locally and on a web dashboard.

About the Experiment

The Wireless Environmental Dashboard combines multiple environmental sensors with ESP32 wireless communication.

DHT22 measures temperature and humidity. BMP180 measures atmospheric pressure. An LDR sensor module provides an analog voltage that changes with ambient light.

The ESP32 processes these readings and displays them on an SSD1306 OLED.

The BMP180 and OLED use the same I²C bus on GPIO21 and GPIO22. The LDR connects to GPIO35, while DHT22 DATA connects to GPIO4.

The ESP32 runs a local web server that provides sensor measurements through the /data JSON endpoint.

The browser dashboard retrieves updated sensor values every two seconds and displays them in measurement cards with progress bars and status messages.

Light Measurement: The LDR percentage is a relative measurement derived from the analog input, not a calibrated illuminance reading in lux.

Temperature and Humidity

DHT22 provides temperature in °C and humidity as relative percentage.

Atmospheric Pressure

BMP180 provides atmospheric pressure in pascals. The value is divided by 100 to obtain hPa.

Light-Level Measurement

ESP32 analogRead() reads the LDR analog output and maps the value between 0 and 100.

OLED and Web Dashboard

The current measurements are displayed on the OLED and returned as JSON. The browser refreshes every two seconds.

Procedure

  1. Connect DHT22 DATA to GPIO4.
  2. Connect DHT22 VCC to 3.3V and GND to GND.
  3. Connect the LDR analog output to GPIO35.
  4. Power the LDR module using 3.3V and GND.
  5. Connect BMP180 SDA to GPIO21 and SCL to GPIO22.
  6. Connect the SSD1306 OLED to the same I²C pins.
  7. Connect BMP180 and OLED power and ground.
  8. Verify all connections before powering the circuit.
  9. Open Arduino IDE and install the ESP32 board package.
  10. Install DHT, Adafruit BMP085, Adafruit GFX and SSD1306 libraries.
  11. Copy the sketch from Explore the Code.
  12. Update the Wi-Fi SSID and password.
  13. Select the ESP32 DevKitC board and correct port.
  14. Verify and upload the sketch.
  15. Open Serial Monitor at 115200 baud.
  16. Note the IP address displayed by ESP32.
  17. Open the IP address in your browser.
  18. Observe the four environmental readings.
  19. Compare dashboard values with the OLED.
  20. Change sensor conditions and observe updated readings.
