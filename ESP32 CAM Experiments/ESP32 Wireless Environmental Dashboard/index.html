Aim

To create a Wi-Fi environmental monitoring system that measures temperature, humidity, atmospheric pressure and light level, displays the readings on an OLED, and publishes them to a live ESP32 web dashboard.

About the Experiment

The ESP32 reads temperature and humidity from a DHT22, pressure from a BMP180 and light intensity from an analog LDR module. The readings are shown locally on an SSD1306 OLED and are also returned by a /data JSON endpoint for a browser dashboard that refreshes every two seconds.

Procedure

  1. Connect the DHT22 data pin to GPIO 4 and power it from 3.3V.
  2. Connect the LDR module analog output to GPIO 35.
  3. Connect BMP180 SDA/SCL to GPIO 21/22.
  4. Connect the SSD1306 OLED to the same I²C GPIO 21/22 bus.
  5. Upload the sketch and open Serial Monitor at 115200 baud.
  6. Wait for Wi-Fi connection and note the ESP32 IP address.
  7. Open the IP address in a browser.
  8. Observe temperature, humidity, pressure and light readings on the dashboard.
  9. Compare the web readings with the OLED readings.
  10. Change environmental conditions and observe the dashboard status messages and progress bars.

Explore the Code

Key sketch sections used in this experiment:

Wireless_Environmental_Dashboard.ino
#include <WiFi.h>
#include <WebServer.h>
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#include <DHT.h>
#include <Adafruit_BMP085.h>

#define DHT_PIN 4
#define DHT_TYPE DHT22
#define LDR_PIN 35
#define I2C_SDA 21
#define I2C_SCL 22

DHT dht(DHT_PIN, DHT_TYPE);
Adafruit_BMP085 bmp;
WebServer server(80);

float temperature = 0.0;
float humidity = 0.0;
float pressure = 0.0;
int lightPercent = 0;

void readSensors() {
  float t = dht.readTemperature();
  float h = dht.readHumidity();

  if (!isnan(t)) temperature = t;
  if (!isnan(h)) humidity = h;

  pressure = bmp.readPressure() / 100.0;

  int ldrRaw = analogRead(LDR_PIN);
  lightPercent = map(ldrRaw, 0, 4095, 0, 100);
  lightPercent = constrain(lightPercent, 0, 100);
}

void handleData() {
  String json = "{";
  json += "\"temperature\":" + String(temperature, 2) + ",";
  json += "\"humidity\":" + String(humidity, 2) + ",";
  json += "\"pressure\":" + String(pressure, 2) + ",";
  json += "\"light\":" + String(lightPercent);
  json += "}";
  server.send(200, "application/json", json);
}

void loop() {
  readSensors();
  updateOLED();
  server.handleClient();
  delay(2000);
}

Expected Output

The OLED displays temperature, humidity, pressure and light percentage.

The web dashboard presents the same four measurements in live sensor cards.

Temperature status changes between cool, warm and high-temperature messages based on the measured value.

Humidity, pressure and light cards update their progress bars and status messages every two seconds.

Result

The ESP32 successfully monitors four environmental parameters, displays them locally on the OLED and publishes the readings through a Wi-Fi web dashboard.
