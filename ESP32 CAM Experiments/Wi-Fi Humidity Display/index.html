Aim

To create a Wi-Fi based temperature and humidity monitoring system using ESP32 and DHT22 that displays live sensor values on an OLED and a web dashboard.

About the Experiment

In this Experiment, the DHT22 sensor measures temperature and relative humidity.

The ESP32 reads the sensor through GPIO 4 and displays the values on a 1.3-inch SH1106 OLED display.

The ESP32 also connects to Wi-Fi and creates a web dashboard for live monitoring of temperature and humidity.

Procedure

  1. Place the ESP32 on the breadboard.
  2. Connect DHT22 VCC to ESP32 3.3V.
  3. Connect DHT22 DATA to GPIO 4.
  4. Leave the DHT22 NC pin unconnected.
  5. Connect DHT22 GND to ESP32 GND.
  6. Connect OLED VCC to ESP32 3.3V.
  7. Connect OLED GND to ESP32 GND.
  8. Connect OLED SDA to GPIO 21.
  9. Connect OLED SCL to GPIO 22.
  10. Open Arduino IDE.
  11. Install the DHT sensor library.
  12. Install the U8g2 library.
  13. Upload the program to ESP32.
  14. Open Serial Monitor at 115200 baud.
  15. Wait for ESP32 to connect to Wi-Fi.
  16. Note the IP address shown in Serial Monitor.
  17. Open the IP address in a web browser.
  18. Observe temperature and humidity on the OLED.
  19. Observe the same readings on the web dashboard.
  20. Notice that the readings update every 3 seconds.

1. Load libraries

The program loads libraries for Wi-Fi, web server, I²C communication, SH1106 OLED and the DHT22 sensor.

Explore more: DHT22

The DHT22 provides two environmental measurements:

  • Temperature in °C
  • Relative humidity in %

The ESP32 reads both values from the DATA pin connected to GPIO 4.

Check your understanding
  • Which GPIO reads the DHT22? GPIO 4
  • Which GPIO is OLED SDA? GPIO 21
  • Which GPIO is OLED SCL? GPIO 22
  • Which sensor measures humidity? DHT22
  • How often are new readings taken? Every 3 seconds

Try it: Breathe gently near the DHT22 sensor and observe whether the humidity value changes on the OLED and web dashboard.

Expected Output

The OLED displays:

  • Current temperature
  • Current humidity
  • Humidity level bar
  • Wi-Fi status indicator

The web dashboard displays live temperature, humidity, sensor status and history.

Result

The Wi-Fi Humidity Display Experiment successfully measures temperature and relative humidity using the DHT22 sensor.

The ESP32 displays the readings on the SH1106 OLED and also provides live monitoring through a Wi-Fi web dashboard.
