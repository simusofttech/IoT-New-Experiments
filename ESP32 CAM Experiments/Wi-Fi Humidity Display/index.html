Aim

To create an ESP32-based Wi-Fi IR Remote Decoder that receives infrared signals from a remote control, decodes the signal information and displays the results on an OLED and wireless web dashboard.

About the Experiment

The Wi-Fi IR Remote Decoder demonstrates infrared communication, signal decoding and wireless monitoring using an ESP32 DevKitC.

A VS1838B IR Receiver detects infrared signals transmitted by an IR Remote Control.

The receiver converts incoming infrared pulses into digital signals that are processed by the ESP32.

The IRremote library decodes the received signal and identifies the IR protocol, command, address and raw data.

The decoded information is displayed on a 0.96-inch SSD1306 OLED.

The Serial Monitor also displays the complete decoded values.

The ESP32 connects to Wi-Fi and hosts a web dashboard that displays the latest received IR command.

The dashboard also shows the protocol, address, raw data, number of received signals and time since the last signal.

The experiment demonstrates how infrared signals can be monitored and analyzed through an IoT-based interface.

IR Data Information:

Protocol: The communication format used by the remote.

Command: The value associated with a remote button.

Address: The address field decoded from the signal.

Raw Data: The received encoded infrared data value.

Signal Count: The number of decoded signal events.

Important Hardware Notes:

Verify the physical pinout of your VS1838B receiver. Different modules may use different pin arrangements.

GPIO15 is an ESP32 strapping pin. Ensure the receiver circuit does not interfere with startup.

The IR remote control does not require a wired connection to the ESP32.

IR Signal Transmission

The remote control transmits infrared pulses whenever a button is pressed.

IR Signal Reception

The VS1838B receiver detects infrared pulses and sends a digital signal to GPIO15.

Signal Decoding

IRremote processes the signal and identifies the protocol, command and address.

Signal Counter

The counter increases whenever a complete IR signal event is decoded.

OLED Display

The OLED displays the latest command, protocol, address and signal count.

Web Dashboard

The ESP32 sends stored IR information to a browser through the /data endpoint.

The dashboard refreshes every 500 milliseconds.

Procedure

  1. Arrange the ESP32 DevKitC V4, VS1838B receiver, IR remote, OLED, breadboard and jumper wires.
  2. Place the ESP32 on the breadboard.
  3. Verify the VS1838B receiver pinout.
  4. Connect receiver VCC to 3.3V.
  5. Connect receiver GND to ESP32 GND.
  6. Connect receiver OUT to GPIO15.
  7. Connect OLED VCC to 3.3V.
  8. Connect OLED GND to GND.
  9. Connect OLED SDA to GPIO21.
  10. Connect OLED SCL to GPIO22.
  11. Verify all connections.
  12. Open Arduino IDE.
  13. Install the ESP32 board package.
  14. Install IRremote, Adafruit GFX and Adafruit SSD1306 libraries.
  15. Create a sketch named WiFi_IR_Remote_Decoder.ino.
  16. Copy the complete program from Explore the Code.
  17. Configure your Wi-Fi credentials.
  18. Select the ESP32 board and port.
  19. Verify and upload the sketch.
  20. Open Serial Monitor at 115200 baud.
  21. Wait for Wi-Fi connection.
  22. Note the ESP32 IP address.
  23. Open the IP address in a browser.
  24. Point the IR remote toward the VS1838B receiver.
  25. Press a button on the remote.
  26. Observe the decoded information on the OLED.
  27. Check the same information in Serial Monitor.
  28. Observe the web dashboard.
  29. Press different remote buttons and compare their decoded values.
