Aim

To develop a gesture-controlled servo interface using an AI-Thinker ESP32-CAM, SH1106 OLED and SG90 servo motor, supporting automatic hand-gesture recognition through a PC-side MediaPipe program and manual control through a Wi-Fi web dashboard.

About the Experiment

The ESP32-CAM AI Gesture Interface demonstrates communication between camera-based gesture recognition, servo motor control and a browser dashboard.

In AUTO mode, a Python program running on a computer retrieves camera images from the ESP32-CAM and uses OpenCV and MediaPipe Gesture Recognizer to classify supported hand gestures.

The recognized gesture is sent to the ESP32-CAM through an HTTP request. The controller then commands the corresponding servo angle.

In MANUAL mode, users can directly select OPEN PALM, CLOSED FIST or THUMB UP from the browser dashboard.

The SH1106 OLED displays the current operating mode, latest gesture and commanded servo angle.

Operating Modes

Mode Operation
AUTO Receives gesture commands from the external Python MediaPipe program.
MANUAL Receives commands from browser dashboard buttons.
Important: The ESP32-CAM firmware does not perform MediaPipe inference by itself. Automatic gesture recognition requires the separate Python application running on a computer. The displayed servo angle is a commanded position, not a measured physical angle.

Hardware Precautions:

Power the SG90 servo from an appropriate external regulated 5V supply. Connect the servo supply ground to the ESP32-CAM ground.

GPIO15 is a boot-strapping pin. Verify that the connected OLED does not interfere with startup.

The 0° and 180° commands should only be used if the servo's mechanical travel supports those endpoints.

For local educational use, connect the PC and ESP32-CAM to a trusted network. This example does not implement authentication for its control routes.

Camera Capture

The camera captures JPEG images that are available through the /capture endpoint.

Automatic Gesture Recognition

A PC-side program processes camera images using OpenCV and MediaPipe. Recognized gestures are converted to PALM, FIST or THUMB commands.

Manual Control

In MANUAL mode, dashboard buttons send the corresponding command directly to the ESP32-CAM.

Servo Positioning

The ESP32-CAM uses the ESP32Servo library to command the SG90 servo to 0°, 90° or 180°.

OLED and Dashboard Status

The SH1106 OLED displays the gesture and commanded position, while the dashboard requests updated mode, gesture and servo information.

Procedure

  1. Arrange all required hardware components.
  2. Connect OLED SDA to GPIO14.
  3. Connect OLED SCL to GPIO15.
  4. Connect OLED VCC to the compatible supply and GND to common ground.
  5. Connect SG90 signal to GPIO13.
  6. Connect SG90 power to an external regulated 5V supply.
  7. Connect the external supply ground to ESP32-CAM GND.
  8. Connect the USB-to-TTL programmer to the ESP32-CAM UART pins.
  9. For programming, connect GPIO0 to GND and restart the board.
  10. Open Arduino IDE.
  11. Install the ESP32 board package.
  12. Install U8g2 and ESP32Servo libraries.
  13. Select AI Thinker ESP32-CAM board.
  14. Copy the complete sketch from Explore the Code.
  15. Replace Wi-Fi credentials with your network details.
  16. Verify and upload the firmware.
  17. Disconnect GPIO0 from GND and reset the board.
  18. Open Serial Monitor at 115200 baud.
  19. Note the IP address of the ESP32-CAM.
  20. Open the IP address in a browser on the same network.
  21. Select MANUAL mode.
  22. Test OPEN PALM, CLOSED FIST and THUMB UP buttons.
  23. Observe servo movement and OLED readings.
  24. Install Python, OpenCV, MediaPipe and HTTP requests on the PC.
  25. Configure the separate Python recognizer to read `/capture` and send commands to `/ai?g=COMMAND`.
  26. Select AUTO mode in the dashboard.
  27. Run the Python gesture-recognition application.
  28. Present supported gestures and observe the servo response.
The ESP32 sketch below is complete. The PC-side Python gesture-recognition program is a separate application and is not contained in this HTML.

Result

The ESP32-CAM AI Gesture Interface demonstrates servo positioning through browser commands in MANUAL mode and through external Python gesture-recognition commands in AUTO mode.

The SH1106 OLED displays the mode, recognized command and servo angle, while the web dashboard provides camera preview and control functions.
