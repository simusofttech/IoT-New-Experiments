Aim

To control a servo from hand gestures using an ESP32-CAM with both automatic AI mode and manual web-dashboard mode.

About the Experiment

The ESP32-CAM captures images while a PC-side AI program uses MediaPipe to recognize gestures such as Open Palm, Closed Fist and Thumb Up.

In AUTO mode, recognized gestures are sent to the ESP32-CAM as commands. In MANUAL mode, the same servo positions can be selected directly from the browser dashboard.

The OLED shows operating mode, gesture and servo status.

Procedure

  1. Connect OLED SDA to GPIO 14 and SCL to GPIO 15.
  2. Connect the servo signal to GPIO 13.
  3. Power the servo from an external 5V supply and connect grounds together.
  4. Connect and program the ESP32-CAM using a USB-TTL programmer.
  5. Open the dashboard in a browser.
  6. In MANUAL mode, test PALM, FIST and THUMB buttons.
  7. Confirm PALM moves the servo to 0°, FIST to 90° and THUMB to 180°.
  8. For AUTO mode, run the PC-side gesture AI program and ensure the PC and ESP32-CAM are on the same Wi-Fi network.
  9. Show the supported gestures and verify automatic servo movement.

Explore the Code

ESP32-CAM_AI_GESTURE_INTERFACE.ino 
#include "esp_camera.h"
#include <WiFi.h>
#include <WebServer.h>
#include <Wire.h>
#include <U8g2lib.h>
#include <ESP32Servo.h>

#define OLED_SDA 14
#define OLED_SCL 15
#define SERVO_PIN 13

Servo gestureServo;
WebServer server(80);

String currentMode = "MANUAL";

void setGesture(String gesture)
{
    gesture.toUpperCase();

    if(gesture == "PALM")
    {
        gestureServo.write(0);
    }
    else if(gesture == "FIST")
    {
        gestureServo.write(90);
    }
    else if(
        gesture == "THUMB" ||
        gesture == "THUMBS" ||
        gesture == "THUMB_UP"
    )
    {
        gestureServo.write(180);
    }
}

void loop()
{
    server.handleClient();
    delay(5);
}

Expected Output

The dashboard shows operating mode, detected gesture, servo position and live camera status.

PALM moves the servo to 0°.

FIST moves the servo to 90°.

THUMB or THUMB UP moves the servo to 180°.

AUTO mode accepts AI gesture commands, while MANUAL mode accepts dashboard commands.

Result

The ESP32-CAM AI Gesture Interface successfully controls a servo using either AI-recognized hand gestures or manual browser controls.

What You Learn

  • Integrating ESP32-CAM with a PC-side MediaPipe workflow.
  • Using AUTO and MANUAL operating modes.
  • Sending gesture commands over HTTP.
  • Controlling a servo on GPIO 13.
  • Using a SH1106 OLED on GPIO 14 and GPIO 15.
  • Mapping gestures to servo angles.
