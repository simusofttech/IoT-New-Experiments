Aim

To build an ESP32-CAM gesture interface that controls a servo using AI-recognized hand gestures in AUTO mode and browser controls in MANUAL mode.

About the Experiment

The ESP32-CAM provides camera images over Wi-Fi while a PC-side Python program uses OpenCV and MediaPipe Gesture Recognizer to identify supported hand gestures.

Open Palm, Closed Fist and Thumb Up are mapped to servo positions of 0°, 90° and 180°. The browser dashboard also allows direct manual control of the same positions.

The SH1106 OLED displays the operating mode, detected gesture and servo position.

Procedure

  1. Connect OLED SDA to GPIO 14 and SCL to GPIO 15.
  2. Connect the servo signal wire to GPIO 13.
  3. Connect the servo power and ESP32-CAM ground so they share a common ground.
  4. Connect the USB-to-TTL programmer to the ESP32-CAM.
  5. Connect GPIO 0 to GND only while uploading, then remove the connection and reset the board.
  6. Enter the Wi-Fi credentials and upload the program.
  7. Open Serial Monitor at 115200 baud and note the ESP32-CAM IP address.
  8. Open the dashboard and test PALM, FIST and THUMB in MANUAL mode.
  9. For AUTO mode, run the Python MediaPipe gesture program on a PC connected to the same Wi-Fi network.
  10. Show Open Palm, Closed Fist and Thumb Up gestures and verify 0°, 90° and 180° servo movement.

Expected Output

The dashboard displays the current operating mode, gesture and servo position.

Open Palm maps to PALM and moves the servo to 0°.

Closed Fist maps to FIST and moves the servo to 90°.

Thumb Up maps to THUMBS and moves the servo to 180°.

In AUTO mode the commands come from the PC-side MediaPipe program, while MANUAL mode uses dashboard buttons.

Result

The ESP32-CAM AI GESTURE INTERFACE successfully provides both automatic AI gesture control and manual browser control of the servo while displaying system status on the OLED.

  • Using AUTO and MANUAL operating modes.
  • Mapping MediaPipe gestures to servo positions.
